图中的“商品区”只是抽象区域，不代表具体SKU、实物比例、材质、结构或参数。图外说明、编号、虚线、区域名称和比例是教学标记，不应复制进成图。阅读完整正文并用自己的真实商品图、批准文字和人工尺寸。

当前24张原创示意，分别采用表中对应卡的默认画布，标题和脚注在画布外。它们解释默认模板，不是所有变体的通用构图；抽象区域不必等于商品外接框，只有明确写出的比例才是该卡要求。26张常用精选入口均有示意或既有预览，其中G22为来源参考、G23为历史用户结果，不把26张都称为原创示意或已验证2.5成图。参考图、示意与本库结果分别标注，不能互相替代。
