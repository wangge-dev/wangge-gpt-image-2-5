图中的“商品区”只是抽象区域，不代表具体SKU、实物比例、材质、结构或参数。图外说明、编号、虚线、区域名称和比例是教学标记，不应复制进成图。阅读完整正文并用自己的真实商品图、批准文字和人工尺寸。

画布外的标题和页脚仅用于说明；EC49内部为1:1，EC05、EC50与EC52内部为4:5，EC14内部为3:2。五张示意解释各卡默认模板，不是所有变体的通用构图。参考图、示意与本库实测结果分别标注，不能互相替代。
