# E009 · 同一主题的横竖封面

- 类型：通用 / wangge-dev 原创提示词
- 编写日期：2026-09-09
- 目标模型：OpenAI GPT Image 2.5；具体型号与设置按 [模型说明](../guides/models.md) 选择

## 要解决的问题

在不同版式里保持主题识别，避免简单裁切损失主体。

## 准备素材

确定主题、标题和自有参考视觉；两种目标比例。

先替换所有双花括号变量，再发送。比例/尺寸还需在可配置的平台上实际设置，不能只写在提示词里。

## 首轮提示词

```text
为“{{主题}}”设计一张{{本轮比例}}的封面。标题逐字为“{{标题}}”，只出现一次。核心视觉采用{{主体描述}}，配色保持{{配色}}。根据当前比例重新安排标题与主体，保留完整主体与足够边缘留白。若提供图 A，它仅规定{{参考图作用}}。不要添加第二标题、作者名、平台水印或额外解释。
```

## 后续修改指令

```text
只调整标题位置，避开{{被遮挡主体}}；保持标题文字、配色和主体形象不变。
```

## 看什么才算完成

检查横竖版是否属于同一主题，标题是否正确，主要对象是否完整；不假设某平台固定裁切规则。

## 怎样继续挖掘

分别运行两种比例，用各自原始输出检查；不是把一张图裁成两份后宣称模型生成了一套。
