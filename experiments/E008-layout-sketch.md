# E008 · 草图控制标题与主体位置

- 类型：通用 / wangge-dev 原创提示词
- 编写日期：2026-09-09
- 目标模型：OpenAI GPT Image 2.5；具体型号与设置按 [模型说明](../guides/models.md) 选择

## 要解决的问题

检验粗略位置图能否减少构图沟通中的歧义。

## 准备素材

一张自绘草图，明确标出标题区、主体区、留白；可选主体参考图。

先替换所有双花括号变量，再发送。比例/尺寸还需在可配置的平台上实际设置，不能只写在提示词里。

## 首轮提示词

```text
图 A 是构图草图，只提供位置和大小关系，不把草图里的框线与标注文字画进成品。主体参考图 B，画面主题为{{主题}}，风格为{{风格}}。标题区写“{{标题}}”，主体放在草图指定区域，其余区域保留适当空白。不要添加草图未安排的角标、贴纸或边框。
```

## 后续修改指令

```text
仅把{{元素}}移回草图指定区域，保留其他元素内容与当前风格，不把草图标注当作成品文字。
```

## 看什么才算完成

检查标题、主体、留白是否位于指定区域；区分位置遵循与艺术风格是否满意。

## 怎样继续挖掘

同一需求分别使用文字描述和草图输入。草图路径只是参考图实验，不冒充 ChatGPT Sketch 按钮的界面验证。
