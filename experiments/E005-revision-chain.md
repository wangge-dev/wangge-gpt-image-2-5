# E005 · 三轮返工保留已完成修改

- 类型：电商 / wangge-dev 原创提示词
- 编写日期：2026-09-09
- 目标模型：OpenAI GPT Image 2.5；具体型号与设置按 [模型说明](../guides/models.md) 选择

## 要解决的问题

检查后续修改是否破坏前面已完成的工作。

## 准备素材

一张商品宣传图，商品与标题清晰；约定三个互不相同的编辑目标。

先替换所有双花括号变量，再发送。比例/尺寸还需在可配置的平台上实际设置，不能只写在提示词里。

## 首轮提示词

```text
第一轮：把画面的环境背景调整为{{背景}}。商品、标题内容和相对位置保持不变。不要增加新的文案、物品或商品附件。
```

## 后续修改指令

```text
第二轮：以上一轮结果为输入，仅把画面外加主标题换成“{{新标题}}”，商品包装文字不改。
第三轮：以上一轮结果为输入，仅让环境光更柔和，保留新标题、背景和商品可见细节。
```

## 看什么才算完成

每轮记两列：本轮要求是否完成、额外变化有哪些。最后还要回看第一轮背景、第二轮标题是否保留。

## 怎样继续挖掘

连续路径与重新从原图执行全部目标的路径分别记录；没有两种实际输出，不比较哪种更好。
