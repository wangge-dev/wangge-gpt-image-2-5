# E002 · 中文商品主图构图

- 类型：电商 / wangge-dev 原创提示词
- 编写日期：2026-09-09
- 目标模型：OpenAI GPT Image 2.5；具体型号与设置按 [模型说明](../guides/models.md) 选择

## 要解决的问题

让产品和一条真实卖点有清晰主次，观察文字与商品的相互影响。

## 准备素材

清晰商品图；一条已确认卖点；明确的主标题。不要输入未经证实的销量或功效。

先替换所有双花括号变量，再发送。比例/尺寸还需在可配置的平台上实际设置，不能只写在提示词里。

## 首轮提示词

```text
制作一张方形商品宣传图。图 A 的商品完整置于右侧约六成区域，左侧安排标题与一条说明。主标题逐字为“{{标题}}”，说明逐字为“{{真实卖点}}”。背景使用{{背景}}，文字颜色与背景清楚区分。画面只出现这两处外加文字；保留商品包装原有文字和标识。商品外观严格依据图 A，不添加装饰性奖章、销量数字、证书或功能示意。输出一张图。
```

## 后续修改指令

```text
只调整左侧文案的行距和字号，让主标题明显大于说明；文案内容、商品与背景保持当前状态。
```

## 看什么才算完成

先看商品是否变样，再逐字校对两处文字，缩小查看信息层级；平台审核要求另行核实。

## 怎样继续挖掘

保持商品与文案相同，仅对比两种布局。不要同时改卖点和背景，否则难判断差异。
