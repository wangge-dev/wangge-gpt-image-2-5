# E004 · 一品三图各有用途

- 类型：电商 / wangge-dev 原创提示词
- 编写日期：2026-09-09
- 目标模型：OpenAI GPT Image 2.5；具体型号与设置按 [模型说明](../guides/models.md) 选择

## 要解决的问题

做用途不同的三张商品图，观察跨图的商品一致性。

## 准备素材

同一商品的清晰正面和已确认细节照片；不得靠模型虚构背面或内部结构。

先替换所有双花括号变量，再发送。比例/尺寸还需在可配置的平台上实际设置，不能只写在提示词里。

## 首轮提示词

```text
本轮仅生成{{本轮图型}}这一张图片。商品主体依据图 A；图 B 仅在它确实展示对应细节时作为细节证据。商品的{{身份特征}}须保持一致。三种图型的要求分别是：清晰展示图采用简洁背景并完整呈现商品；使用环境图将商品放入{{真实使用场景}}；细节图只展示图 B 中已有的{{局部}}。现在只执行本轮图型，不拼接、不制作三宫格、不生成未经参考图确认的部位。
```

## 后续修改指令

```text
这张{{图型}}中的{{特征}}与图 A 不一致，请恢复其原始形态，保留这张图的用途和场景。
```

## 看什么才算完成

分别核对三张图的商品配色、结构、标识。细节图要能回到参考照片找到证据。

## 怎样继续挖掘

分三次运行，每次明确图型；记录使用哪些参考图。不要把同一张图仅改背景色算作完成三种用途。
