# T123 · 补充袋角嘴焊接区与盖环组件归属

## 拿来就用的具体示例

正背面、透光焊接区、盖环分离与闭合状态需来自同一补充袋；组件归属由人工确认。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。



## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”组件核对板。固定同一{{包装}}的外形、印刷、液面与{{柔性层}}；依据外观及透光实拍展示{{角嘴}}，W1必须夹在F/B之间并与S1边界相接，不让角嘴漂浮、穿出袋膜或补造内部流道。分离与闭合栏只保留一套{{盖环}}，C1沿真实T1就位，R1/J1按实拍状态归属，不复制防拆环或把它并入袋膜。底部逐字写“{{记录}}”，D57只框R1/J1。不要倒出内容物或生成剖面，不推断焊接强度、密封、防拆有效性、材料相容、容量、卫生或运输安全。只输出一张静态核对板。
```
