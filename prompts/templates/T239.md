# T239 · 透明铰接放大窗与底层中文视读边界继承

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

展示透明放大窗绕固定铰轴覆盖底层中文时，只在镜片边界内产生实拍放大与折射，文字本体始终留在底板。

## 准备材料与变量

图1：放大窗抬起态L0；图2：半落下态L1；图3：覆盖态L2；图4：透明镜片G1边界、铰轴H1与焦点位置；图5：底板B1审定中文T1；图6：覆盖态正斜视实拍；图7：人工视读表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{对象}}` | 阅读辅助透明放大窗ML18 |
| `{{状态}}` | L0抬起、L1绕H1半落、L2覆盖T1 |
| `{{结构锚点}}` | T1只属于固定底板B1；G1只绕H1转动；L2的放大、边缘畸变和高光只限G1内部且取实拍 |
| `{{保护}}` | 底板、中文、镜片轮廓、铰轴、边框、表面尘点、光源和背景 |
| `{{记录}}` | T1底层身份与H1已核对；L2右边缘折射待复核D167 |
| `{{标题}}` | 镜片覆盖后只改变视读，底层文字本体不移动不复制 |

## 拿来就用的具体示例

提供同一装置抬起、半落、覆盖及正斜视实拍、底板审定中文和镜片边界；不得凭通用放大镜效果推断倍率。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成ML18的L0抬起、L1半落、L2覆盖三栏图。中文“使用说明”只印在固定B1，G1绕H1覆盖后仅在镜片内按实拍产生放大和边缘折射，镜片外不变。底部写“T1底层身份与H1已核对；L2右边缘折射待复核D167”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7生成同一{{对象}}的L0-L2状态核对图，只执行“{{状态}}”。B1/T1固定，G1/H1保持身份并继承{{结构锚点}}；L1/L2保留真实透明度、反射、遮挡和镜片边界，G1外的T1保持原尺寸。严格保护{{保护}}。不可把放大后的文字印到镜片表面、复制第二层清晰字、让整张底板放大、把镜片画成屏幕特效、断开H1、抹掉高光或凭空改变焦点。底部逐字写“{{记录}}”，D167只框L2右边缘。只输出一张三状态核对图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

状态图不替代光学倍率、焦距、清晰度、材料、耐久、阅读效果、无障碍、安全或实物测试。
