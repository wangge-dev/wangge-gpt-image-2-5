# T101 · 三联单据书写区与压痕跨联归属核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Documents & Publishing · 本库原创设计**

核对同一本三联单的第一联书写区、第二三联对应压痕和联次颜色归属，不补造模糊文字或推断票据效力。

## 准备材料与变量

图1：空白三联单整体；图2：第一联人工填写后的正面；图3：三联分离同框；图4至图6：同一字段在三联上的微距；图7：人工联次、字段与状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{单据}}` | 三联手写出库单RC15 |
| `{{联次}}` | 第一联L1白、第二联L2粉、第三联L3黄 |
| `{{字段}}` | 编号F1、日期F2、品名F3、数量F4、签字F5 |
| `{{人工状态}}` | F1–F4跨联归属已核对；L3的F5压痕待复核D35 |
| `{{隐私}}` | 姓名与签字统一遮挡，编号仅保留末四位7314 |
| `{{标题}}` | 同一字段跨三联，压痕不补字 |

## 拿来就用的具体示例

空白、填写和分离状态必须来自同一本同一组联单；字符与联次由人工核对并先做隐私处理。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“同一字段跨三联，压痕不补字”。RC15的L1白、L2粉、L3黄按实物排列，F1–F5垂直对应；模糊压痕写“不可辨认”，不按L1补字。姓名与签字统一遮挡，编号只留末四位7314。写“F1–F4跨联归属已核对；L3的F5压痕待复核D35”。不判断票据效力。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”核对板。左栏放{{单据}}空白叠联与图2填写后第一联；右侧按“{{联次}}”上下排列图3分离实物，逐栏只框“{{字段}}”在相同印刷区域的真实墨迹或压痕。用垂直细线连接同一字段位置，保持纸色、联次文字、撕边、孔位、压痕深浅和缺笔；第二三联没有清楚字符时只写“不可辨认”，禁止按第一联补齐。所有栏执行“{{隐私}}”。底部逐字写“{{人工状态}}”，D35只框L3的F5。不要增加印章、金额、审批或系统状态，不推断真实性、法律效力、财务有效、签收、库存变更或已归档。只输出一张静态核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

核对板不替代原始单据、逐字符人工核验、法律财务审核、库存系统或正式归档记录。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
