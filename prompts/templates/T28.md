# T28 · 短中文规格对比表

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Charts & Infographics · 本库原创设计**

把已核对的少量规格做成可读对比表，逐格绑定数据，不让模型计算或补齐空项。

## 准备材料与变量

图1至图3：三个对象参考；提供不超过5行的审定表格，含列名、行名、单元格原值和空值标记。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{标题}}` | 三款规格对比 |
| `{{列名}}` | 轻巧款；标准款；大容量款 |
| `{{表格数据}}` | 容量：350 mL／500 mL／750 mL；净重：210 g／260 g／—；颜色：白／蓝／黑 |
| `{{空值规则}}` | —保持为—，不推算 |

## 拿来就用的具体示例

准备三个对象参考和人工核对后的三列表；控制在3列、5行以内，缺失值明确写—。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
依据图1至图3制作4:5“三款规格对比”图。三列依次为“轻巧款”“标准款”“大容量款”，顶部商品图分别绑定图1、图2、图3。三行数据逐格为：容量350 mL、500 mL、750 mL；净重210 g、260 g、—；颜色白、蓝、黑。“—”保持不变。白底、浅蓝表头、细分隔线。不要计算、排名、推荐或补值。只输出一张图。
```


## 完整提示词

```text
依据图1至图3制作4:5中文规格对比表。标题只写“{{标题}}”；三列依次为{{列名}}，各列顶部使用对应参考图，不交换对象。表格逐字逐格排入{{表格数据}}，行列对齐，单位与大小写原样保留；遵守{{空值规则}}。采用白底、深灰字、浅蓝表头和细分隔线，每格只放一个值，不使用长句。不要计算差值、排序优劣、补齐缺失值、添加推荐、冠军、性价比、价格、星级或未提供规格。只输出一张表格图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

生成图不替代原始规格表；数值、单位和空值必须回到数据源逐格复核。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 两列差异表

```text
制作{{标题}}两列差异表。左右分别绑定图1、图2，逐格排入{{表格数据}}，空值按{{空值规则}}。只做事实对照，不添加优劣、推荐或计算结果。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图。本轮只修正{{列名}}列、{{行名}}行的值为“{{正确值}}”；其他单元格、商品图和版式不变。
```
