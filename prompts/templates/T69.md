# T69 · 实体折页面板与阅读方向映射

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把批准展开稿的面板编号映射到真实折页的正反面与展开顺序，核对阅读方向、折线和遮挡，不把视觉板当成印刷或折页工艺文件。

## 准备材料与变量

图1：已批准展开稿正面；图2：已批准展开稿背面；图3至图6：同一实体折页闭合、第一次展开、完全展开正面与背面；图7：面板编号、折线和人工阅读顺序表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{物料}}` | 三折产品说明页 |
| `{{面板}}` | 正面F1/F2/F3，背面B1/B2/B3 |
| `{{顺序}}` | 闭合C0→先展开F3得C1→再展开F1得C2 |
| `{{阅读方向}}` | C0封面F2朝外；C2从F1向F3阅读 |
| `{{声明}}` | 本图仅核对面板与方向，生产以批准源文件和打样为准 |
| `{{标题}}` | 展开顺序决定读到哪一面 |

## 拿来就用的具体示例

展开稿必须是当前批准版本，所有状态照片来自同一折页，折序与阅读方向由人工提供；视觉映射不能证明印刷、裁切或折页工艺合格。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“展开顺序决定读到哪一面”。左栏放三折产品说明页批准正背展开稿并标F1/F2/F3、B1/B2/B3；中栏展示同一实物C0闭合、先展开F3得到C1、再展开F1得到C2；右栏放完全展开正反面并逐面连接。C0封面F2朝外，C2从F1向F3阅读。保持折痕与遮挡，不镜像或透出背面。底部写“本图仅核对面板与方向，生产以批准源文件和打样为准”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”映射板。左栏上下原样放{{物料}}批准正面稿与背面稿，按{{面板}}编号，折线位置不移动；中栏依次放同一实体的{{顺序}}三状态，保持纸张尺寸观感、图文、折痕、页边与手风琴式遮挡关系；右栏放完全展开正反面实拍并连接到对应F1–F3、B1–B3。用三支短箭头表示人工给定的{{阅读方向}}，箭头不得跨面或替换折线。文字与图案跟随实体面板旋转，不镜像、不把背面内容透到正面、不补缺失页。若稿件与实物不一致，只标人工问题号，不自动修稿。底部写“{{声明}}”。不要输出裁切尺寸、出血、色值、纸张克重、折序合格、印刷合格或可生产结论。只输出一张静态映射板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

映射板不替代矢量源文件、印前检查、折页打样、尺寸测量或生产验收。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
