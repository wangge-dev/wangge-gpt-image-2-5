# T341 · 详情页批准模块顺序与接缝装配预览板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把已经批准的独立详情模块按人工清单缩略装配，核对顺序、版本、上下接缝和缺页，不让生成模型重绘模块或擅自补齐页面。

## 准备材料与变量

图1至图6：批准模块原图P1-P6；图7：人工顺序与版本表；图8：接缝状态表；图9：缺页和禁用版本表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{项目}}` | 折叠水杯详情页DP79 |
| `{{顺序}}` | P1v4首屏→P2v3卖点→P3v5材质→B1v2桥页→P4v4结构→P5v2包装 |
| `{{接缝状态}}` | S12通过；S23待复核D265；S3B通过；SB4通过；S45待复核D266 |
| `{{禁用版本}}` | P2v1、P3v4、P4v2不得出现 |
| `{{缺页}}` | 收尾P6未提供，保留灰色空位并写未提供 |
| `{{显示规则}}` | 所有模块只等比缩略，不裁切、不重绘、不改字、不自动融合接缝 |

## 拿来就用的具体示例

只接收人工批准版本及明确顺序表；若模块或版本缺失，必须显式留空，不能让模型根据上下文生成替代内容。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作DP79批准模块装配预览，顺序P1v4、P2v3、P3v5、B1v2、P4v4、P5v2；全部只等比缩略且不改字。S12、S3B、SB4标通过，S23待复核D265，S45待复核D266。P6未提供保留灰位，不得补页；禁用P2v1、P3v4、P4v2。底部写“装配预览，不是发布文件”。只输出一张图。
```


## 完整提示词

```text
依据图1至图9制作16:9“{{项目}}批准模块装配预览”。严格按“{{顺序}}”从左到右、再向下排列等宽缩略图，并执行“{{显示规则}}”。每张下方写准确版本号；接缝之间只标“{{接缝状态}}”，D265和D266用橙框，不自动修复。{{缺页}}；不要生成替代页。完整排除“{{禁用版本}}”，不得把多个版本混合、交换顺序、裁掉模块上下边界或把缩略图拼成一张新详情长图。底部只写“装配预览，不是发布文件”。只输出一张核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

装配预览不等于真实拼接文件、发布批准或平台上传结果；原尺寸拼接、像素接缝与导出规格仍在设计软件中完成。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
