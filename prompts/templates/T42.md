# T42 · 商品素材版本状态交接板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

按人工版本清单展示当前可用、已替换和禁止使用的商品素材，防止后续生成混入旧包装或未审定图。

## 准备材料与变量

图1起：需要交接的素材版本；提供资产编号、版本号、状态、生效日期、替代关系、允许用途和禁止用途六列表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品身份}}` | 燕麦坚果棒210克 |
| `{{版本表}}` | A01 v3 当前可用 2026-09-13 正面包装；A02 v2 已替换→A01 禁止使用；B01 v1 当前可用 2026-09-12 背面文字核对；C01 v4 待审 不得生成 |
| `{{当前组合}}` | 正面用A01 v3；背面文字用B01 v1 |
| `{{标题}}` | 商品素材版本交接 |
| `{{责任说明}}` | 状态仅来自本次人工版本表 |

## 拿来就用的具体示例

版本号、状态、生效日期和替代关系必须来自项目清单；文件修改时间、分辨率和画面观感都不能代替审批状态。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“商品素材版本交接”板，商品为“燕麦坚果棒210克”。A01 v3标绿“当前可用｜2026-09-13｜正面包装”；A02 v2标灰并斜线“已替换→A01｜禁止使用”；B01 v1标绿“当前可用｜2026-09-12｜背面文字核对”；C01 v4标橙“待审｜不得生成”。中央只写“当前组合：正面用A01 v3；背面文字用B01 v1”，底部写“状态仅来自本次人工版本表”。不按清晰度自动选图、不融合版本。只输出一张图。
```


## 完整提示词

```text
依据所附素材与{{版本表}}制作16:9“{{标题}}”板，顶部只写“{{商品身份}}”。每项素材按资产编号排列原图缩略图，不重绘、不合成、不校色；缩略图旁逐字写“资产编号｜版本号｜状态｜生效日期｜替代关系｜允许用途”。“当前可用”用绿色边框，“已替换”用灰色并画一条斜线，“待审”用橙色，“禁止使用”用红色边框；状态颜色只服从版本表，不由画面质量决定。中央单独写“当前组合：{{当前组合}}”，底部写“{{责任说明}}”。已替换素材必须显示其指向的新资产编号，但不得把两个版本融合成新图。不要自动选择更清晰或日期更新的素材，不判断包装合规、真伪和内容正确性，不生成新版本、补缺图或修改状态。只输出一张版本交接板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

交接板只可视化人工版本清单；它不读取文件系统状态，也不能证明素材已获法律、合规或品牌批准。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
