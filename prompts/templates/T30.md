# T30 · 系列页面跨页视觉一致性

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Documents & Publishing · 本库原创设计**

以已验收母版和视觉规则逐页生成系列页面，锁定网格、色彩、标题层级与固定元素。

## 准备材料与变量

图1：已验收4:5母版页，负责网格、标志、字体层级、边距和品牌色，不提供本页旧内容；图2：本页专用主图，只替换指定主图区。视觉规则可用文字提供，无需另做规则图；明确本页标题、正文、页码及可变区，每次只做一页。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{页码页名}}` | 第3页｜核心能力 |
| `{{本页页码}}` | 03 |
| `{{本页标题}}` | 从数据到行动 |
| `{{本页正文}}` | 统一口径｜定位问题｜形成方案 |
| `{{正文排法}}` | 三条各占一行，保留原顺序，不显示分隔符｜ |
| `{{固定区}}` | 左上标志、顶部页眉线、右下页码的承载位置和字形、12栏网格、蓝白配色 |
| `{{可变区}}` | 中央主图、标题、正文与右下页码文字 |
| `{{序号}}` | 3 |

## 拿来就用的具体示例

上传已验收第1页母版和本页批准主图，提供本页定稿文字与页码03；规则为12栏、蓝白配色、原标志位置及字体层级。无需另生成视觉规则卡，每页继续引用同一母版，不把上一轮结果自动当权威母版。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1为已验收系列第1页母版，只取12栏网格、蓝白配色、左上标志、顶部页眉线、标题层级与右下页码承载位置，不取旧主图或文字。图2为本页已批准的数据看板示意，只放中央主图区，不把示意数据写成实际经营结果。本次只生成第3页“核心能力”的4:5平面成品；页名用于任务定位，不另外上屏。标题只写“从数据到行动”。正文只写“统一口径”“定位问题”“形成方案”，依次三行，不显示分隔符、不续写。右下页码只写“03”，不能沿用母版的“01”。标志、边距、页眉线和字体层级不变；不加新数据、其他页、封面、样机或拼贴。只输出一张图。
```


## 完整提示词

```text
图1只作为已验收系列母版，图2只提供本页主图，本次只输出{{页码页名}}的一张平面成品。先锁{{固定区}}的相对位置、比例、边距、字体层级、品牌色和留白；固定页码承载位置与字形，不继承图1的旧页码内容。只在{{可变区}}替换本页内容，图2只用在主图区，不改变母版网格或压住文字。标题逐字为“{{本页标题}}”；正文逐字为“{{本页正文}}”，仅按{{正文排法}}排版，不强行凑三项、不续写；右下页码只写“{{本页页码}}”。页码页名是任务标识，不另作横幅上屏。不要复制母版旧主图、标题、正文或旧页码，不新增其他数字、章节、标志或数据。保留与母版相同的视觉密度，内容放不下时不要缩成不可读小字，正式文字可在排版工具补齐。不生成封面、其他页、书本样机或全册拼贴。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

固定的是版式承载，不是上一页内容。正文数量及序号来自批准文本，系列任务一次一页；生成结果不是可编辑排版文件，正式出版仍需统一排版校对。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 社媒系列卡

```text
图1为已验收系列母版，图2只提供本张主图。本次只生成系列第{{序号}}张的一张平面成品，保持母版画布比例。锁定{{固定区}}的承载位置、比例、边距、字体层级、品牌色和留白；在{{可变区}}替换图2、标题“{{本页标题}}”、正文“{{本页正文}}”和序号。正文只按{{正文排法}}排版，不续写、不凑项目。右下承载位置只写本张序号“{{序号}}”，不要再写出版页码，不继承母版的旧序号、旧标题或旧正文。图2不得改变网格、遮住文字或带入新标志；没有批准信息不补数据、价格或章节。序号只出现一次，不把任务名另作横幅。不输出其他序号、整组拼贴或样机；文字放不下时保留可读层级并在排版工具处理。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮本页为底图，重新附原母版图1。本轮只修正{{不一致区域}}的{{位置、字形、间距或颜色}}；若修页码，只替换为本页批准编号，不恢复母版旧编号。本页主图、其余定稿文字和网格不变。
```
