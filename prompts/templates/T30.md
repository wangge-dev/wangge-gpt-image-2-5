# T30 · 系列页面跨页视觉一致性

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Documents & Publishing · 本库原创设计**

以已验收母版和视觉规则逐页生成系列页面，锁定网格、色彩、标题层级与固定元素。

## 准备材料与变量

图1：已验收母版页；图2：视觉规则卡；图3起：本页专用素材。提供页码、页名、准确标题正文、可变区和固定区。每次只做一页。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{页码页名}}` | 第3页｜核心能力 |
| `{{本页标题}}` | 从数据到行动 |
| `{{本页正文}}` | 统一口径｜定位问题｜形成方案 |
| `{{固定区}}` | 左上标志、顶部页眉线、右下页码、12栏网格 |
| `{{可变区}}` | 中央主图和三项正文 |

## 拿来就用的具体示例

准备母版平面图、视觉规则卡、本页素材和审定文字；每页单独生成，上一页不自动替代母版。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1为已验收母版，图2为规则卡。本次只生成“第3页｜核心能力”。锁定左上标志、顶部页眉线、右下页码、12栏网格、品牌蓝和标题层级；中央主图只用图3。标题只写“从数据到行动”，正文只写“统一口径｜定位问题｜形成方案”，不续写。不要复制母版主图，不生成其他页、样机或全册拼贴。只输出一张本页平面图。
```


## 完整提示词

```text
图1是已验收母版，图2是视觉规则卡。本次只生成{{页码页名}}。严格锁定{{固定区}}的相对位置、比例、字体气质、品牌色、边距和装饰；只在{{可变区}}使用图3起本页素材。标题逐字为“{{本页标题}}”，正文逐字为“{{本页正文}}”，按三项短句排版，不续写。保持与母版相同的视觉密度和层级，但不要复制母版主图或旧页正文。不得同时生成封面、其他页、书本样机或全册拼贴，不新增页码、标志、数据和章节。只输出一张本页平面成品。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

跨页一致性依赖母版与规则卡的持续复用；生成图不是可编辑排版文件，正式出版仍应在版式工具中统一。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 社媒系列卡

```text
以图1母版和图2规则卡生成系列第{{序号}}张。固定{{固定区}}，只在{{可变区}}替换为图3素材与“{{本页标题}}”“{{本页正文}}”。不同时输出其他序号。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，并重新附图1、图2。本轮只修正{{不一致区域}}，恢复母版中的{{规则}}；本页主图和已校对文字不变。
```
