# T03 · 科学尺度缩放图

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Charts & Infographics · 通用来源改写**

生成多尺度科学信息图，强调层级、标签和可读性。

## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{主题}}` | 一片叶子 |
| `{{尺度表}}` | 填写六层对象、尺寸或倍率、短说明；无可靠数值写“示意” |
| `{{标题}}` | 一片叶子的尺度之旅 |

## 完整提示词

```text
制作主题“{{主题}}”的尺度缩放科普图。按{{尺度表}}由微观到宏观排列六个圆形窗口，每窗放该尺度的对象示意、准确名称和给定尺寸或单位。窗口以细线相连，图示不意味着窗口之间按同一比例绘制。顶部标题“{{标题}}”，底部小字“各窗口为独立尺度示意”。白底、深灰文字、少量青色，不自行推算或补造测量值。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。
