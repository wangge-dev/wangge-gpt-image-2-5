# T347 · 多SKU前后遮挡可见锚点与数量守恒

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在紧凑套装构图中为每个被遮挡SKU指定必须露出的身份锚点和最大遮挡边界，防止模型把后排商品吞掉、融合或复制到前排。

## 准备材料与变量

图1至图4：SKU A-D独立原图；图5：目标构图草图；图6：人工遮挡关系表；图7：每件必露锚点；图8：数量表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品组}}` | 咖啡冲泡四件组 |
| `{{数量}}` | A手冲壶×1、B滤杯×1、C分享壶×1、D豆罐×1 |
| `{{前后关系}}` | A在左后，被C遮挡下部；B在中央前，不遮壶嘴；C在右前；D在右后，被C遮挡左下角 |
| `{{必露锚点}}` | A壶嘴、把手与盖钮；B锥形杯口与底座；C玻璃把手与刻度区；D黑盖与正面标签 |
| `{{禁止融合}}` | A壶嘴不能接到C，B底座不能变成C杯口，D标签不能贴到A |
| `{{标题}}` | 四件，各有位置 |

## 拿来就用的具体示例

遮挡关系和必露锚点需人工指定；若目标构图无法同时满足，应先调整草图，不让模型靠透明化或复制解决。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作咖啡冲泡四件组16:9紧凑图，A-D各一件。A左后被C遮下部但露壶嘴、把手、盖钮；B中央前露杯口与底座；C右前露玻璃把手与刻度；D右后仅左下角被挡并露黑盖与标签。不同SKU部件不得融合或复制。不加咖啡豆、液体、滤纸和参数。只输出一张图。
```


## 完整提示词

```text
依据图1至图8制作16:9{{商品组}}紧凑陈列。总数严格为“{{数量}}”，按“{{前后关系}}”形成真实遮挡；即使被遮挡，每件仍必须露出“{{必露锚点}}”。保持各SKU材质、轮廓和标签来源独立，执行“{{禁止融合}}”。遮挡边缘要有可信景深、接触阴影和空间前后关系，不能通过半透明、剖视、缩小到不合比例或复制局部来补可见性。标题只写“{{标题}}”。不要增加咖啡豆、液体、滤纸、杯子、赠品、容量、材质结论或冲泡性能。只输出一张成品图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

可见锚点只保证画面身份辨认，不证明套装实物完整、组件兼容、容量或功能。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
