# T22 · 概念产品研发拆解

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Other Use Cases · 通用来源改写**

生成研发板、拆解图、混合任务和特殊输出。

## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{概念产品}}` | 桌面收纳灯 |
| `{{结构设想}}` | 填写设计者提出的部件和装配关系，不让模型代替工程计算 |

## 完整提示词

```text
制作{{概念产品}}的研发概念板。顶部一张外观渲染，中部依据{{结构设想}}安排分解示意，底部三张细节小图展示材料、接口与使用姿态。各部件名称按所给清单标注，不添加工程参数。图1若提供是外观草图，保持其轮廓与比例。底部准确写“概念设计，非工程图”。白底、细引线、灰蓝配色，图文对应清晰。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 布局或风格变体

```text
制作{{概念产品}}的研发概念板。横向三栏依次展示外观渲染、依据{{结构设想}}的分解示意、使用姿态。各部件名称按所给清单标注，不添加工程参数。图1若提供是外观草图，保持其轮廓与比例。底部准确写“概念设计，非工程图”。白底、细引线、灰蓝配色，图文对应清晰。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，重新附所需原始参考。本轮只修改概念板{{结构区域}}：按{{结构设想}}调整部件关系，保留外观草图轮廓与概念标注，不加工程数值。只输出这一张修改后的图。
```
