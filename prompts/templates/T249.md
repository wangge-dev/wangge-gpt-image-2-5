# T249 · 折扇多扇骨共轴展开与扇面分片图文归属

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

核对折扇从收拢到展开时，多根扇骨围绕同一扇钉改变夹角，扇面图文分片始终附着在对应相邻骨区，完整画面只在展开状态形成。

## 准备材料与变量

图1：完全收拢态F0；图2：半展开态F1；图3：完全展开态F2；图4：扇钉P1、边骨R0/R8与中间骨R1-R7；图5：扇面分片M1-M8及审定完整中文；图6：正反面同状态实拍；图7：人工骨序和分片表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{对象}}` | 八分片纸面折扇FF26 |
| `{{状态}}` | F0九骨收拢、F1按实拍半展开、F2围绕P1完全展开 |
| `{{结构锚点}}` | R0-R8次序固定并共用P1；M1-M8各跨相邻两骨且不换片；中文笔画随所在分片折叠遮挡，只有F2按实拍组成完整题字 |
| `{{保护}}` | 单个扇钉、九根扇骨、八个扇面分片、折痕、中文、纸纹、边骨厚度、光源和背景 |
| `{{记录}}` | R0-R8与M1-M8归属已核对；F1 M5折痕文字待复核D177 |
| `{{标题}}` | 扇骨共轴改变夹角，图文分片不能脱离原来的两根骨 |

## 拿来就用的具体示例

提供同一折扇收拢、半展、全展及正反面实拍、扇骨编号和扇面分片表；不得用全展图臆造收拢时隐藏笔画。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成FF26的F0九骨收拢、F1半展开、F2完全展开三栏图。R0-R8共用P1且次序固定，M1-M8各守相邻骨区；题字“清风入怀”在收拢/半展时按折痕遮挡，只在F2按实拍完整。底部写“R0-R8与M1-M8归属已核对；F1 M5折痕文字待复核D177”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7生成同一{{对象}}的F0-F2状态核对图，只执行“{{状态}}”。P1、R0-R8、M1-M8及分片中文保持身份并继承{{结构锚点}}；每栏只改变各骨绕P1的实拍夹角，保留纸面折痕、层叠遮挡和正反面关系。严格保护{{保护}}。不可复制扇钉或扇骨、交换骨序/分片、让完整题字悬浮在收拢扇外、把折痕抹平、镜像背面、让扇面脱骨、自动补全被遮文字或把折扇画成单片圆盘。底部逐字写“{{记录}}”，D177只框F1的M5折痕。只输出一张三状态核对图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

状态图不替代扇骨强度、扇钉松紧、纸面耐折、印刷套准、文物鉴定、耐久、安全或实物验收。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
