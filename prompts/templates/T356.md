# T356 · 中文步骤图双层短文与溢出停止规则

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Charts & Infographics · 本库原创设计**

把每步文字限定为编号标题和一行说明两层，并为每格设置人工字数与字号边界；遇到长文不压缩、不跨格，明确停止并返回文案缩短。

## 准备材料与变量

图1至图4：真实步骤S1-S4；图5：审定双层文案；图6：每格文字区；图7：最小字号和最大行数表；图8：最终状态。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{任务}}` | 滤网拆洗四步 |
| `{{步骤}}` | S1‘断电并取下水箱’/‘确认设备静止’；S2‘旋出滤网盖’/‘按实拍方向转动’；S3‘取出滤网’/‘保持原观察侧’；S4‘按原位装回’/‘以实拍完成状态为准’ |
| `{{文字边界}}` | 每格标题1行、说明1行；标题不低于38 px，说明不低于28 px；不允许第三行 |
| `{{溢出规则}}` | 任何文案超出文字区时不缩字、不截断、不跨格，保留空位并写‘文案待缩短’ |
| `{{标题}}` | 四步看清拆装顺序 |

## 拿来就用的具体示例

每步需有对应实拍、审定的两层短文、明确文字区和字号行数规则；长说明应在生成前由人工改短。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作“滤网拆洗四步”3:4图，S1至S4各用对应实拍；每格标题1行不低于38 px、说明1行不低于28 px，不允许第三行。任何文字放不下则该格写“文案待缩短”，不能缩字、截断或跨格。箭头只连格间，S4按实拍完成状态。不补工具或安全结论。只输出一张图。
```


## 完整提示词

```text
依据图1至图8制作3:4“{{标题}}”步骤图。四格按S1→S2→S3→S4排列，每格只使用对应实拍，并逐字放入“{{步骤}}”。严格执行“{{文字边界}}”和“{{溢出规则}}”；字号数值不显示。箭头只在格间连接，不覆盖手、部件和文字。S4必须对应图8真实完成状态。不可压缩字宽、使用第三行、把说明移到别格、合并或交换步骤，也不补工具、动作、警告、时间、清洁剂、通电状态或安全结论。只输出一张步骤图。
```

## 参数设置

建议画布：`1536x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

图片步骤图不替代完整说明书、无障碍文本、风险警示和实际操作培训；精确字号需在成片中测量。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
