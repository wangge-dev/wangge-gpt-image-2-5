# T38 · 商品参考素材职责清点板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在正式生成系列素材前，把每张商品参考图、可见范围和唯一职责整理成带编号的清点板，减少后续串图与补造。

## 准备材料与变量

图1起：本次商品的全部原始照片与资料截图；提供图片编号、来源、拍摄面、唯一职责、可见限制和缺失项清单。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品身份}}` | 墨绿色不锈钢保温杯，样品编号CUP-07 |
| `{{素材职责表}}` | 图1→正面轮廓与杯盖；图2→背面标签；图3→杯口与螺纹；图4→包装准确文字；图5→人工实测尺寸 |
| `{{缺失项}}` | 杯底、内胆底部、装箱配件 |

## 拿来就用的具体示例

先由人给每张素材指定唯一职责与缺失项；清点板用于沟通和索引，后续生成仍应重新附原始图片，不能用缩略图板替代原图。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“商品参考素材职责清点”板，顶部写“墨绿色不锈钢保温杯，样品编号CUP-07”。按图号排列原图缩略图，不重绘或补视角。图1“正面轮廓与杯盖”；图2“背面标签”；图3“杯口与螺纹”；图4“包装准确文字”；图5“人工实测尺寸”。右侧“缺失项”只写“杯底、内胆底部、装箱配件”；底部“禁止推断”只写“容量、保温时长、材质等级、未拍摄结构”。不评价真假或质量，不生成缺失内容。只输出一张图。
```


## 完整提示词

```text
依据所附原始素材制作16:9“{{标题}}”板。顶部只写商品身份“{{商品身份}}”。中部按图号从左到右、从上到下排列每张原图的等比例缩略图，不重绘、不换背景、不修商品、不合成新视角；每张只出现一次，完整保留其原始裁切。缩略图下方严格按{{素材职责表}}写“图号｜唯一职责｜可见限制”，不从照片新增职责。右侧单独设置“缺失项”栏，只写“{{缺失项}}”；底部设置“禁止推断”栏，只写“{{禁止推断}}”。使用白底、深灰文字、蓝色图号标签与清晰表格线。不要评价图片质量、真假、合规、性能和是否足够，不生成缺失视角、参数、配件、结论或推荐。只输出一张职责清点板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

职责由人确认，不由模型看图推断；清点板不是新的商品事实源，也不能替代后续任务中的原始高清图。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
