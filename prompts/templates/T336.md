# T336 · 电商交付文件预览与外部元数据规格逐项核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把成片预览与外部工具读取的文件名、像素、格式、色彩模式和透明状态逐项对应，不从视觉预览猜分辨率或文件属性。

## 准备材料与变量

图1至图4：交付文件P1-P4预览；图5：外部元数据导出表；图6：人工渠道要求；图7：批准状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{项目}}` | 秋季商品图交付DV77 |
| `{{文件记录}}` | P1 main-v08.png｜2000×2000｜PNG｜RGB｜无透明；P2 detail-v06.jpg｜1500×2000｜JPEG｜RGB｜不适用；P3 xhs-v04.png｜1080×1440｜PNG｜RGB｜无透明；P4 cutout-v03.png｜2000×2000｜PNG｜RGB｜有透明 |
| `{{渠道状态}}` | P1淘宝主图已批准；P2详情模块已批准；P3小红书封面待批准D263；P4透明素材仅内部交付 |
| `{{显示规则}}` | 规格只抄外部元数据表；预览不缩放改图、不据外观猜格式或透明 |
| `{{标题}}` | 预览负责看内容，文件规格必须来自外部元数据 |

## 拿来就用的具体示例

提供交付文件预览、由文件工具导出的元数据、渠道要求和人工批准表；图片模型不能读取真实文件属性。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作DV77交付板，P1-P4预览不改，下方抄外部元数据：main-v08.png 2000×2000等四条；状态按人工表，P3待批准D263，P4仅内部交付。不得根据预览猜文件属性。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”交付核对板。按P1-P4原样放预览，下方逐字写“{{文件记录}}”和“{{渠道状态}}”；严格执行“{{显示规则}}”。批准、待批准和内部交付分别用绿/橙/灰边框，仅表示人工表状态。不可从预览计算像素、猜扩展名/色彩模式/透明、改尺寸格式、把待批准写成已发布、为P4添加渠道或生成下载链接。D263只框P3状态。只输出一张交付核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

核对板不替代文件系统元数据、图像解析器、色彩配置检查、透明通道检测、平台上传验证、审批或实际交付。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
