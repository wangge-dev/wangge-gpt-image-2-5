# T47 · 透明容器四层参考合成

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把透明容器的外轮廓、真实内容物、印刷标签和环境透视分别绑定权威参考，避免重影、穿透、假液位和标签漂浮。

## 准备材料与变量

图1：空容器正面与轮廓；图2：同容器装入真实内容物后的液位或填充状态；图3：标签正稿或清晰实拍；图4：目标环境与台面。提供容器材质、允许透视区域、必须遮挡区域和准确文字。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 透明玻璃蜂蜜罐 |
| `{{内容物}}` | 琥珀色蜂蜜，液位到瓶肩下方约一指 |
| `{{标签文字}}` | 山野蜂蜜｜净含量500克 |
| `{{允许透视}}` | 瓶口上方空隙与瓶身左右边缘 |
| `{{必须遮挡}}` | 蜂蜜覆盖区域后的背景细节 |
| `{{标题}}` | 一罐看得见的自然 |

## 拿来就用的具体示例

空瓶与装液图必须是同一容器或有人工确认的同款结构；内容物颜色和液位以真实装填照为准，不能用文字风格词替代产品证据。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
依据四张参考制作4:5透明玻璃蜂蜜罐主视觉。图1锁定瓶身、厚底、瓶口和瓶盖；图2锁定琥珀色蜂蜜，液位到瓶肩下方约一指；图3标签只写“山野蜂蜜｜净含量500克”；图4只提供浅米色石台、暖灰背景和左后侧光。前表面高光、标签、蜂蜜和后表面折射层次清楚；瓶口上方空隙及瓶身左右边缘可透视，蜂蜜覆盖区域后方背景不能清晰穿透。不生成第二标签、假液位、果肉或气泡。顶部只写“一罐看得见的自然”。不写功效、产地或认证。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作4:5{{商品}}商品主视觉。以图1锁定瓶身外轮廓、厚底、瓶口和瓶盖；以图2锁定{{内容物}}的真实颜色、液位、黏稠外观与瓶内边界；以图3锁定正面标签形状及准确文字“{{标签文字}}”；图4只提供台面、背景色与光向。透明关系分四层处理：前表面高光、标签印刷层、瓶内内容物、后表面折射。{{允许透视}}可看到经过玻璃折射的环境，{{必须遮挡}}不得让背景清晰穿透；不要把前后高光复制成第二个瓶口、第二张标签或额外液位。商品居中占画面高度约70%，柔和侧后轮廓光勾勒玻璃边缘，正面补光保证标签可读，接触阴影自然。顶部只写“{{标题}}”。不要新增气泡、果肉、配料、容量刻度、功效、产地、认证或包装背面信息。只输出一张完整图片。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡控制透明物体的可见层级，不证明玻璃成分、容量、密封、食品品质或液体真实性；仍需人工核对重影、边缘和文字。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
