# T233 · 球头关节球体座圈与方向标记状态继承

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

核对同一球头进入座圈后的包覆边界与多方向实拍姿态，球杆和中文方向标记始终随球体运动，禁止把球体复制或从座圈侧壁穿入。

## 准备材料与变量

图1：球头与座圈分离态B0；图2：入口对准态B1；图3：装入中立态B2；图4至图6：左倾、右倾、前倾实拍；图7：球体S1、座圈C1、开口E1、球杆R1与中文标记W1编号；图8：人工状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{对象}}` | 可调展示夹球头BJ16 |
| `{{状态}}` | B0分离、B1从E1对准、B2中立、B3左倾、B4右倾、B5前倾 |
| `{{结构锚点}}` | S1、R1和W1绑定；C1/E1固定；装入后S1始终由C1按实拍边界部分包覆 |
| `{{保护}}` | 同一球头、座圈、开口、球杆、中文、表面磨痕、光源和背景 |
| `{{记录}}` | B2/B3/B4包覆边界已核对；B5球杆遮挡待复核D161 |
| `{{标题}}` | 球体只从真实入口进入，转向时始终留在同一座圈 |

## 拿来就用的具体示例

提供同一球头分离、入口、装入及各方向实拍和人工状态表；不得由单一角度推断其他姿态。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成BJ16的B0分离、B1入口对准、B2中立、B3左倾、B4右倾、B5前倾六栏图。S1始终带R1和中文W1，装入后由固定C1部分包覆。底部写“B2/B3/B4包覆边界已核对；B5球杆遮挡待复核D161”。只输出一张图。
```


## 完整提示词

```text
依据图1至图8生成同一{{对象}}的B0-B5状态核对图，只执行“{{状态}}”。S1/R1/W1保持身份并继承{{结构锚点}}；B1只从E1对准，B2-B5只采用对应实拍姿态，座圈前后遮挡随角度变化但包覆关系不中断。严格保护{{保护}}。不可让球体从侧壁穿入、脱离后悬浮、复制第二个球头、改变球径、把W1留在座圈或补造内部弹簧。底部逐字写“{{记录}}”，D161只框B5。只输出一张状态核对图。
```
