# T25 · 线框草图驱动的图文版式

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Posters & Typography · 本库原创设计**

用编号线框草图控制图片、标题和信息块位置，再分别绑定真实素材与准确文字。

## 准备材料与变量

图1：带A、B、C区编号的线框草图；图2：主体素材；图3：辅助素材；另提供每区准确文字、背景与品牌色。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{A区文字}}` | 年度设计展 |
| `{{B区文字}}` | 9月20日 14:00 |
| `{{C区文字}}` | 城市美术馆一层 |
| `{{背景与品牌色}}` | 暖白背景、钴蓝强调色 |

## 拿来就用的具体示例

准备编号线框、主体图、辅助图和逐区审定短文字；草图中需明确边距、框位和主次。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1只控制版式，保留A标题区、B日期区、C地点区、中央主体框和右下辅助图框的位置与占比。图2放中央，图3放右下，不能互换或融合。A区只写“年度设计展”，B区只写“9月20日 14:00”，C区只写“城市美术馆一层”。暖白背景、钴蓝强调色。移除线框、编号和占位叉，不加正文、二维码、标志、票价或赞助信息。只输出一张图。
```


## 完整提示词

```text
图1只控制版式：A区标题、B区日期、C区地点、中央主体框和右下辅助图框的位置、占比与对齐关系必须保留。图2只负责中央主体，图3只负责右下辅助图，不交换、不融合、不补造素材。文字逐字排入A区“{{A区文字}}”、B区“{{B区文字}}”、C区“{{C区文字}}”，各出现一次；采用{{背景与品牌色}}，建立清楚的标题、信息和图像层级。线框、编号与占位叉在成品中全部移除。不要擅自移动版块、添加正文、二维码、标志、票价或赞助信息。只输出一张完成图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

草图用于约束相对布局，不证明像素级坐标；精确印刷网格仍应在专业排版工具中完成。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 信息图线框

```text
图1只控制四个编号模块和箭头顺序，图2至图5分别绑定模块1至4。逐区排入{{模块短文}}，每区标题与一句说明，不交换素材、不新增结论。移除草图线框和编号，只输出一张信息图。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
