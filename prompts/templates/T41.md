# T41 · 审定文案与上屏区域对应表

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Posters & Typography · 本库原创设计**

在正式上屏前，把每段审定文案、唯一目标区域和允许换行逐项对应，避免错放、漏字和模型续写。

## 准备材料与变量

图1：带区域编号的版式草图；图2：当前已验收主视觉，可选；提供文案编号、准确全文、目标区域、允许换行、字号层级和禁止拆分词表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{项目}}` | 秋季保温杯主视觉 |
| `{{文案表}}` | C1→区域A→秋日轻启→单行→主标题；C2→区域B→新品上架→单行→副标题；C3→区域C→容量：500毫升→单行→规格 |
| `{{禁止拆分词}}` | 秋日轻启、500毫升 |
| `{{空白区域}}` | 区域D保持空白 |
| `{{标题}}` | 审定文案上屏表 |

## 拿来就用的具体示例

文案须先由业务或编辑逐字审定，并由设计人员给出区域与换行；对应表是上屏任务输入，不替代最终成品逐字校对。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“审定文案上屏表”，项目名“秋季保温杯主视觉”。左侧放区域A至D版式草图；右侧表格逐行写：C1｜秋日轻启｜区域A｜单行｜主标题；C2｜新品上架｜区域B｜单行｜副标题；C3｜容量：500毫升｜区域C｜单行｜规格。连线分别到A、B、C，不交叉。另写“禁止拆分词：秋日轻启、500毫升”“区域D保持空白”。不把文案贴进正式主视觉，不翻译、续写或猜字号。只输出一张图。
```


## 完整提示词

```text
依据图1制作16:9“{{标题}}”，项目名只写“{{项目}}”。左侧完整放置图1版式草图，保留区域A至D的位置与比例，不生成正式商品图；若提供图2，只在角落以小缩略图显示并标“已验收主视觉”，不改图。右侧按{{文案表}}逐行排成五列表格：“编号｜准确全文｜目标区域｜允许换行｜层级”，每段文字逐字复制，不翻译、不润色、不补标点。用同色细线把C1、C2、C3连接到图1对应区域，连线不交叉、不串位。单独写“禁止拆分词：{{禁止拆分词}}”和“{{空白区域}}”。不要把文案真正贴入主视觉，不推测字体、字号数值、平台规范、字数上限或溢出是否可接受，不新增广告语、价格和按钮。只输出一张对应表。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

模型只排版人已审定的映射，不负责写文案、翻译或判断能否容纳；正式上屏后仍需人工逐字核对。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
