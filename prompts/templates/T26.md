# T26 · 同一主视觉跨比例重排

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Posters & Typography · 本库原创设计**

将已验收主视觉适配到单一目标比例，通过重排而非拉伸裁坏主体。

## 准备材料与变量

图1：已验收主视觉，负责主体身份、视角、配色、文字与背景质感；图2：同一视角的无字主体图（可选），只核对轮廓，不替换姿态。提供单个目标比例、内缩安全区、审定文字及允许断行方式；每轮只做一个比例。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{目标比例}}` | 9:16 |
| `{{安全区}}` | 从成品四边向内留空：上下各8%、左右各6% |
| `{{必须保留文字}}` | 主标题“向新而行”；日期“09.20” |
| `{{断行方案}}` | 主标题只允许在“向新”后断行；日期保持单行 |
| `{{允许删除}}` | 边缘两枚小星点装饰 |
| `{{横版比例}}` | 16:9 |
| `{{横版安全区}}` | 从成品四边向内留空：上下各6%、左右各8% |

## 拿来就用的具体示例

上传一张已验收主视觉即可；示例为蓝紫人物海报，批准主标题“向新而行”、日期“09.20”和上述断行。若附无字主体图，须与底图同视角。竖版建议1152×2048；横版变体建议2048×1152。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以图1已验收蓝紫色人物海报为底图，重排为9:16竖版，只输出一张平面成品。人物及手中商品完整可见，身份、姿态、视角和二者相对比例不变，只可整体等比例缩小或移动；不拉伸，不补画背面。没有图2，不虚构额外参考。向上下延展蓝紫背景，保持侧上方光线和原背景纹理。成品上下各8%、左右各6%留空，关键主体、标题和日期放在内侧；先读标题，再看人物和商品，最后读日期。主标题逐字写“向新而行”，只允许在“向新”后断行；日期“09.20”单行。只可删除边缘两枚小星点；不新增人物、标志、文案或装饰，不裁断商品。
```


## 完整提示词

```text
以图1为编辑底图，重排为{{目标比例}}，只输出一张该比例的平面成品。先锁主体层级：主体和手中物件均完整可见，身份、姿态、视角、形状和原相对比例不变；可整体等比例缩放和移动，不拉伸、不补画未知侧背面。图2若提供，只辅助核对同视角轮廓。优先延展原背景、重分配留白，再移动文字；保持原配色、光向、背景质感与文字到主体的阅读顺序。安全区为{{安全区}}，所有标题、日期和关键物件均在内。逐字保留{{必须保留文字}}，只按{{断行方案}}断行，不换词、不遮住主体。只可删除{{允许删除}}；不新增人物、商品、标志、文案或装饰。延展区不复制主体、不出现接缝。空间不足时先缩小整组主体和增加留白，不裁断商品。
```

## 参数设置

建议画布：`1152x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

默认1152×2048对应9:16，横版16:9须另设2048×1152，不沿用竖版尺寸。安全区来自当前渠道要求，示例比例不是平台通用规范。生成重排不保证原主体像素不变，要求原像素时用原素材合成。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 横版重排

```text
以图1已验收主视觉为编辑底图，重排为{{横版比例}}，只输出一张横版平面成品。主体及核心物件完整可见，身份、姿态、视角、形状与相对比例不变；只可等比例缩放和移动，不拉伸、不补画未知结构。图2若提供，只核对同视角主体轮廓。通过左右延展原背景、调整留白与文字位置适配，原配色、光向与背景纹理不变，阅读顺序仍为标题、主体、日期。安全区为{{横版安全区}}，所有关键内容位于内侧。逐字保留{{必须保留文字}}，只按{{断行方案}}断行，不改字、不压住主体。只可删除{{允许删除}}，不新增人物、商品、标志、文字或装饰；延展区不复制主体、不出现接缝。空间不足先缩小整组主体，不裁断商品。输出尺寸须匹配横版比例，16:9可用2048×1152。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
