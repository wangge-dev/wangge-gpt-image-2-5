# T26 · 同一主视觉跨比例重排

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Posters & Typography · 本库原创设计**

将已验收主视觉适配到单一目标比例，通过重排而非拉伸裁坏主体。

## 准备材料与变量

图1：已验收主视觉；图2：主体无字原图（如有）；提供目标比例、安全区、必须保留文字和允许删除的装饰。每次只指定一个目标比例。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{目标比例}}` | 9:16 |
| `{{安全区}}` | 上下各8%、左右各6% |
| `{{必须保留文字}}` | 主标题“向新而行”；日期“09.20” |
| `{{允许删除}}` | 边缘两枚小星点装饰 |

## 拿来就用的具体示例

准备已验收成品和可选无字主体图；明确单个目标比例、安全区、必须保留项和可删除项。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
把图1主视觉重排为9:16，只输出竖版。人物身份、姿态、手中商品、蓝紫配色和侧上方光线不变；通过向上下扩展背景和重新分配留白完成适配，不拉伸或裁断人物与商品。主标题“向新而行”和日期“09.20”逐字保留，放在上下各8%、左右各6%安全区内；标题可改为两行。只可删除边缘两枚小星点，不加其他文案、人物或标志。只输出一张图。
```


## 完整提示词

```text
把图1主视觉重排为{{目标比例}}，本次只输出该比例。保持图1的主体身份、姿态、商品或核心物件、色彩、光向和视觉主题；优先扩展背景与重新分配留白，不横向或纵向拉伸主体。所有关键内容位于{{安全区}}内，完整保留{{必须保留文字}}的逐字内容和层级；为适应比例可调整标题换行与相对位置，但不得压住主体。只可删除{{允许删除}}，不得增加新人物、商品、标志、文案或装饰。边缘扩展应延续原背景纹理和光线，不出现重复物体与接缝。只输出一张成品图。
```

## 参数设置

建议画布：`1024x1536`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

一次只做一个比例便于验收；不同渠道的安全区应来自实际平台规范，不由模型自行猜测。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 横版重排

```text
把图1主视觉重排为{{横版比例}}，只输出横版。主体、核心物件、色彩与光向不变，通过左右扩展背景和横向重组文字完成，不拉伸主体。关键内容位于{{横版安全区}}，逐字保留{{必须保留文字}}，只可删除{{允许删除}}。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，并重新附图1。本轮只修正{{被裁切或越界对象}}，使其完整进入{{安全区}}；其他构图、文字和扩展背景不变。
```
