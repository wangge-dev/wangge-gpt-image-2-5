# T337 · 候选成片淘汰原因码与禁止继承项记录板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

原样归档候选成片、人工淘汰原因和禁止继承属性，明确下一版只能从指定合格父版继续，避免把失败稿元素混回新版本。

## 准备材料与变量

图1至图5：候选成片V1-V5；图6：人工状态和原因码；图7：父版与禁止继承表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{任务}}` | 商品主视觉候选筛选RV78 |
| `{{候选状态}}` | V1淘汰R01商品变形；V2淘汰R02标签错字；V3合格基准；V4淘汰R03阴影悬浮；V5待复核R04道具越界 |
| `{{继承规则}}` | 下一版父版只用V3；禁止继承V1轮廓、V2标签、V4阴影、V5道具；不合并淘汰稿优点 |
| `{{原因码}}` | R01身份结构；R02文字；R03接触关系；R04布景边界 |
| `{{记录}}` | V3为当前人工合格父版；V5待复核D264；未标已发布 |
| `{{标题}}` | 淘汰稿保留原因证据，但下一版不能从失败元素拼装 |

## 拿来就用的具体示例

提供原始候选图、人工状态原因码、指定父版和禁止继承表；缺人工结论时不得由模型选择最佳稿。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作RV78候选记录板：V1 R01淘汰、V2 R02淘汰、V3合格基准、V4 R03淘汰、V5 R04待复核D264。下一版只从V3连线，其他稿停止，不合并所谓优点。写“V3为当前人工合格父版；未标已发布”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”记录板。V1-V5原样排列，不修图；逐张写“{{候选状态}}”，下方显示“{{原因码}}”和“{{继承规则}}”。只画V3到“下一版”的蓝线，淘汰稿用红色停止符，V5用橙色待复核；不可画V1/V2/V4/V5到下一版的继承线。不可自动评价画面、改原因码、把V3标为已发布、合并候选稿、重绘商品或生成下一版。底部逐字写“{{记录}}”，D264只框V5。只输出一张记录板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

记录板不替代创意评审、品牌审批、像素检查、法务、平台审核、版本控制或最终发布决定。
