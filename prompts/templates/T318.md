# T318 · 商品转台四方位外观连续与非镜像核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在固定机位、转台中心和光源下展示同一商品0/90/180/270度实拍方位，追踪非对称细节跨栏移动，禁止用水平镜像伪造背侧。

## 准备材料与变量

图1至图4：同一商品转台0°/90°/180°/270°实拍；图5：顶部方向标与转轴中心O1；图6：非对称锚点清单；图7：人工方位表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 便携音箱SP60 |
| `{{方位}}` | V0正面0°、V1右侧90°、V2背面180°、V3左侧270° |
| `{{身份锚点}}` | 按钮B1在顶部偏右、接口盖P1在背面偏左、挂绳孔H1在左侧、标志W1只在正面 |
| `{{固定条件}}` | 相机、焦距观感、转台中心O1、商品高度、背景与左上主光固定；商品仅绕竖直轴按实拍转动 |
| `{{记录}}` | V0-V3方位与B1/P1/H1/W1已核对；V2接口盖边缘待复核D246 |
| `{{标题}}` | 同一商品绕同一竖轴转四面，非对称细节不能靠镜像生成 |

## 拿来就用的具体示例

必须提供同一实物的四方位照片、顶部方向标和非对称锚点表；缺任一方位时该栏写未提供，不用镜像补齐。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成便携音箱SP60的V0正面、V1右侧、V2背面、V3左侧四栏转台图。相机、转台中心、尺寸、背景和左上主光固定；B1、P1、H1、W1按真实方位移动，不镜像或透视补面。底部写“V0-V3方位与B1/P1/H1/W1已核对；V2接口盖边缘待复核D246”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7生成同一{{商品}}的四栏方位核对图，严格按{{方位}}排列并执行“{{固定条件}}”。四栏保持同一商品身份、尺寸观感和转轴中心，{{身份锚点}}只按真实三维方位改变可见位置、透视与遮挡。不可水平镜像任一栏、把V0标志复制到背面、交换左右侧、补造被遮挡接口、改变按钮数量、用不同SKU凑四面或统一重绘文字。每栏角落只写V0/V1/V2/V3，底部逐字写“{{记录}}”，D246只框V2接口盖边缘。不要添加旋转箭头之外的卖点、规格、性能或认证。只输出一张四方位核对图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

方位图不替代尺寸测量、内部结构、接口规格、功能、声学、耐久、法规或实物审核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
