# T20 · 历史与古风题材

[全部提示词](../README.md) · [首页](../../README.md)

**分类：History & Classical Themes · 通用来源改写**

生成朝代服饰、长卷叙事、诗词和传统题材。

## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{时代}}` | 填写具体朝代或年份 |
| `{{场景}}` | 江畔送别 |
| `{{史料}}` | 填写服饰、船只、建筑的参考要点或上传对应图片 |
| `{{画风}}` | 绢本设色审美 |
| `{{标题}}` | 江上送别 |

## 完整提示词

```text
绘制{{时代}}背景下的{{场景}}，依据{{史料}}中的服饰、器物和建筑要点。采用{{画风}}，主体与环境层次清楚，不混入现代物件。若资料缺少细节，以克制的概念表现处理，不把推断写成事实。只排标题“{{标题}}”，不自动拼接古诗或落款。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 布局或风格变体

```text
绘制{{时代}}背景下的{{场景}}，依据{{史料}}中的服饰、器物和建筑要点。采用水墨淡彩，主体与环境层次清楚，不混入现代物件。若资料缺少细节，以克制的概念表现处理，不把推断写成事实。只排标题“{{标题}}”，不自动拼接古诗或落款。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，重新附所需原始参考。本轮只修改历史场景中的{{器物或服装}}：按{{史料依据}}改为{{正确形态}}，保留其他历史要点与标题。只输出这一张修改后的图。
```
