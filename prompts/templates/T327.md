# T327 · 包装批次喷码多光向原图与人工转写可读状态核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

并列同一喷码在正光、左掠射和右掠射下的原图，只显示人工转写与逐字符状态，不让模型OCR补齐反光遮挡字符。

## 准备材料与变量

图1至图3：同一批次码区域正光L0/左掠射L1/右掠射L2原图；图4：人工转写字符串；图5：字符位C01-C14状态表；图6：喷码边界M1；图7：人工问题位。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{包装}}` | 金属罐底批次喷码BC68 |
| `{{人工字符串}}` | BN240913-A0176 |
| `{{光向}}` | L0正光、L1左掠射、L2右掠射 |

## 拿来就用的具体示例

必须提供同一实物同一区域多光向原图、人工转写和逐字符状态表；只有一张照片或没有人工转写时不得补字。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作BC68喷码多光向核对板，原样放L0/L1/L2，不修图；下方逐格写人工字符串BN240913-A0176。C11标“L0遮挡，L1/L2人工核对为0”。底部写“字符串来自人工转写；C11跨光向核对为0；不代表批次真实性D256”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”核对板。上排原样放置{{光向}}三张喷码图，不修复、锐化、拼字或统一反光；下排按C01-C14逐格写入“{{人工字符串}}”及“{{字符状态}}”，连线只连接同一字符真实位置。严格保护{{保护}}。不可运行OCR补全、从相邻字符猜C11、合成一张无反光喷码、重绘点阵、改变划痕或把人工转写贴回包装。底部逐字写“{{记录}}”，D256只标声明。不要判断生产日期、有效期、批次真实性、追溯、合规或质量。只输出一张核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

核对板不替代批次真实性、生产日期、有效期、追溯系统、喷码质量、法规、法务或实物审核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
