# T200 · 温变油墨中文局部改字与冷热双状态显隐继承

## 拿来就用的具体示例

提供同一包装冷态与暖态实拍、两栏同位遮罩、人工审定新文、保留温变区和非温变底层参考；必须记录实拍状态，不让模型猜测临界温度。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
编辑TC24的C0/C1同机位双状态底图，只在两栏M-T1把“清凉时刻”改为“冰爽时刻”。两栏字形和印刷边界一致，严格继承P1实拍R1显隐关系、B1底层、F1纸纹与E1套准；其他图文和背景不变。底部写“新文逐字已审定；C1‘爽’字残影待复核D128”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7编辑同一{{对象}}的C0/C1双状态底图，只执行“{{改字}}”。两栏必须保持相同包装身份、构图、M-T1边界和新文字字形；按{{状态锚点}}继承实拍显色或消色关系，B1只在参考图允许处显露，状态差异不得扩散到非温变区域。严格保护{{保护}}。不可画成自发光、LED、热浪、结冰特效、烧焦、褪色故障或整盒色相变化，不可让两栏字形不同、自动发明临界温度、扩大M-T1、复制P1或改动其他文案。底部逐字写“{{记录}}”，D128只框C1“爽”字残影。只输出一张冷热双状态核对图。
```
