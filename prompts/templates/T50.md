# T50 · 车载用品驾驶视野遮挡预演

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在真实样车驾驶眼点照片上叠加人工提供的视野保护区与已装用品轮廓，预演可见遮挡而不宣称道路安全。

## 准备材料与变量

图1：驾驶员座椅固定位置拍摄的前向空景；图2：同机位真实装车照；图3：人工标定的保护区遮罩；图4：用品完整外观。提供样车、机位记录、遮挡结论和免责声明。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{用品}}` | 出风口手机支架与竖放手机 |
| `{{样车}}` | 样车A |
| `{{机位}}` | 座椅导轨刻度6、靠背角度按记录、镜头位于人工眼点E1 |
| `{{保护区}}` | 前风挡主要道路视野、左右后视镜可见区、仪表信息区 |
| `{{人工结论}}` | 用品轮廓未进入左右后视镜区；进入仪表信息区右下角，标为待调整 |
| `{{标题}}` | 样车A静态视野遮挡预演 |
| `{{声明}}` | 仅按固定机位照片展示可见重叠，不代表道路安全评估 |

## 拿来就用的具体示例

空景与装车照必须来自固定座椅和固定相机机位，保护区由人工或适用规范提供；机位不一致时不可做前后重叠判断。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“样车A静态视野遮挡预演”。左右栏分别放同一机位的空景和出风口手机支架加竖放手机的真实装车照，机位写“座椅导轨刻度6、靠背角度按记录、人工眼点E1”。按图3在两栏叠加前风挡主要道路视野、左右后视镜可见区和仪表信息区轮廓，不重算区域。下方逐字写“用品轮廓未进入左右后视镜区；进入仪表信息区右下角，标为待调整”。未给判断就写“未核对”。底部写“仅按固定机位照片展示可见重叠，不代表道路安全评估”。不写安全、合规或适合上路。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作16:9“{{标题}}”。左右两栏必须使用同一{{样车}}、同一画幅和{{机位}}：左栏为图1空景，右栏为图2安装{{用品}}后的真实照片，不重绘车辆、道路、风挡边界、后视镜、仪表、方向盘或用品。把图3人工遮罩以半透明轮廓叠加到两栏，保护区仅包括{{保护区}}，轮廓位置和大小不得由模型重算。右栏用品只保留图2实际可见轮廓，不根据图4扩大、缩小或移动。下方矩阵逐字写“{{人工结论}}”，进入保护区的项目用橙色标“待调整”，未提供判断的项目写“未核对”，不得看图自动判定通过。顶部另写机位记录，底部完整写“{{声明}}”。不要生成动态道路场景、驾驶员、碰撞线、法规图标、百分比、视角角度，也不要写不挡视线、安全、合规或适合上路。只输出一张静态预演板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

静态照片重叠只用于发现明显遮挡候选，不替代驾驶视野测量、法规判断、道路测试或专业安全评估。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
