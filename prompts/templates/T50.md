# T50 · 车载用品安装位置证据图

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把具体车辆的安装区域、用品结构和真实装车结果分别绑定参考，展示当前样车位置而不虚构车型兼容性。

## 准备材料与变量

图1：用品完整结构；图2：具体样车安装区域原照；图3：连接件与接触面微距；图4：同一用品在同一样车上的真实装车照；提供样车身份、安装步骤短句、保护区域和边界声明。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{用品}}` | 出风口手机支架 |
| `{{样车}}` | 样车A，中控横向格栅出风口 |
| `{{连接关系}}` | 夹臂夹住第二条横向叶片，支架背板位于叶片前方，手机竖向放置 |
| `{{保护区域}}` | 出风口拨片、应急灯按键、中控屏边缘与空调文字 |
| `{{标题}}` | 样车A安装位置示意 |
| `{{声明}}` | 仅展示所附样车与当前样品，不代表其他车型兼容 |

## 拿来就用的具体示例

必须提供同一样车的安装区和真实装车照；若只有用品白底图，只能展示结构，不能生成装车结果或兼容性结论。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9出风口手机支架安装位置证据图。左栏保留样车A中控横向格栅出风口，只框出第二条横向叶片；中栏展示支架正面、背面夹臂和接触面，组件各一次；右栏按真实装车照呈现夹臂夹住第二条叶片、背板在叶片前方、手机竖放。出风口拨片、应急灯按键、中控屏边缘和空调文字不被遮挡。顶部写“样车A安装位置示意”，底部写“仅展示所附样车与当前样品，不代表其他车型兼容”。不写全车型、稳固、安全或不挡视线。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作16:9{{用品}}安装位置证据图。左栏保留图2样车安装区域的真实布局、叶片方向、拨片、相邻按键、中控屏边缘和可见文字，用蓝色轮廓框标出唯一安装区，不改内饰；中栏以图1和图3展示用品正面、背面夹臂与接触面，组件各出现一次；右栏严格依据图4呈现{{连接关系}}，用品、车辆和手机的遮挡、方向与接触关系真实。{{保护区域}}必须完整可辨，不被支架、手机、引线或文字覆盖。下方只用三条短句写人工提供的安装顺序，不补拆装动作。顶部只写“{{标题}}”，底部完整写“{{声明}}”。不要新增转接件、改变出风口结构、推断磁吸或夹持强度，也不要写通用、全车型、稳固、安全、不挡视线或通过道路测试。只输出一张三栏证据图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡只记录一个样车与一个样品的可见安装关系，不证明兼容范围、固定强度、驾驶安全、法规符合或长期使用结果。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
