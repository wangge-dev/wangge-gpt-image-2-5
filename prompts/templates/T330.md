# T330 · 同一商品多角度瑕疵坐标与重复可见身份核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

原样并列同一实物多角度照片，把同一划痕或凹点用人工坐标跨视角对应，区分同一瑕疵、遮挡和未提供，不自动判质量等级。

## 准备材料与变量

图1至图4：同一实物V0-V3多角度原图；图5：表面区域坐标网格；图6：瑕疵D1-D4人工身份表；图7：人工状态与问题位。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 金属保温杯DF71 |
| `{{视角}}` | V0正面、V1右转、V2背面、V3左转 |
| `{{瑕疵映射}}` | D1杯肩细划痕在V0/V1可见；D2底缘凹点在V2/V3可见；D3标签墨点仅V0可见；D4杯盖反光疑点待复核 |
| `{{状态规则}}` | 原图不修复；同一D编号只指同一实体位置；不可见写遮挡；缺角度写未提供 |
| `{{记录}}` | D1-D3身份已人工核对；D4需补同角度漫射光照片D257 |
| `{{标题}}` | 同一个瑕疵跨角度仍是同一个坐标，不可见不等于消失 |

## 拿来就用的具体示例

提供同一实物多角度原图、区域网格、人工瑕疵身份和状态表；不同样品照片不得合并为同一瑕疵轨迹。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作DF71的V0-V3原图瑕疵核对板。D1在V0/V1同一杯肩坐标，D2在V2/V3同一底缘坐标，D3仅V0可见，D4反光疑点不判定。写“D1-D3身份已人工核对；D4需补同角度漫射光照片D257”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”四视角核对板。按{{视角}}原样放置同一{{商品}}照片，不磨皮、去尘、修划痕或统一反射；依据“{{瑕疵映射}}”用细框和短线标D1-D4，并严格执行“{{状态规则}}”。不可把不同位置的相似划痕合并、让同一编号漂移、镜像补角度、透视标出被遮挡瑕疵、把反光自动判成凹痕或给严重度评分。底部逐字写“{{记录}}”，D257只标补拍需求。不要判断合格/不合格、成因、耐久、材质或责任。只输出一张核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

核对板不替代质量标准、缺陷等级、尺寸测量、成因分析、责任判定、材质、耐久或实物检验。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

