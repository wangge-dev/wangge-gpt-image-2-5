# T349 · 套装中单一SKU定点替换与其余成员冻结

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

商品套装更新一款成员时，只在批准席位替换指定SKU，并冻结其余成员、数量、遮挡和文案，防止整套被重新设计。

## 准备材料与变量

图1：已验收套装V1；图2：旧SKU B身份照；图3至图4：新SKU B2正侧面；图5：唯一替换遮罩M-B；图6：人工新旧对应表；图7：其余成员保护遮罩；图8：审定新文案。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{套装}}` | 早餐杯碗三件套 |
| `{{替换}}` | B蓝色直筒杯→B2米白带把杯，位置仍为中央，数量1 |
| `{{冻结成员}}` | A左侧浅灰碗、C右侧木纹托盘 |
| `{{冻结关系}}` | A/C的尺寸、位置、透视、遮挡、标签、阴影和背景像素不变 |
| `{{新SKU保护}}` | B2杯型、单个把手、米白釉色、杯口厚度和底部标记按图3/4 |
| `{{文字}}` | 标题‘晨间三件套’不变；颜色行改为‘浅灰｜米白｜木色’ |

## 拿来就用的具体示例

必须提供旧套装合格图、唯一替换遮罩、新SKU多角度和其余成员保护区；新SKU缺侧面时不得猜把手背侧。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
编辑早餐杯碗三件套V1，只在中央M-B把蓝色直筒杯换成一只米白带把杯B2；杯型、单把、釉色、杯口与底标按新参考。左侧浅灰碗A和右侧木纹托盘C的位置、尺度、遮挡、阴影与背景不变。标题仍为“晨间三件套”，颜色行只改成“浅灰｜米白｜木色”。不加第四件或食物。只输出一张图。
```


## 完整提示词

```text
以图1为底图编辑{{套装}}，唯一修改区为M-B，只执行“{{替换}}”。B2严格保持“{{新SKU保护}}”，相机角度、尺度和接触位置匹配原席位，但不得沿用旧B的无把结构或蓝色。完整保护{{冻结成员}}及“{{冻结关系}}”，不得移动A/C、重算间距、改变遮挡或复制B2。文字只按“{{文字}}”修改，其他文字不动。不要重做整套光影、增加第四件、赠品、食物、容量、材质、适用场景、价格或兼容结论。只输出更新后的V2一张4:5成品图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

局部替换不证明新组合已正式上架、库存可用、尺寸适配或包装兼容；发布前仍需人工审核整套事实。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
只修正{{M-B、B2、A/C保护区、数量、位置、遮挡、颜色行或残留旧B}}，按图{{参考图号}}恢复；冻结区不变。
```
