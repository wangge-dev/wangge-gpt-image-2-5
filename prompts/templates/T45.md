# T45 · 失败轮次回退证据板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Other Use Cases · 本库原创设计**

把连续编辑中的合格底图、失败轮次和回退目标按人工日志排成证据链，防止误在失败图上继续叠改。

## 准备材料与变量

图1起：各轮保存图；提供版本号、父版本、人工状态、唯一改动、失败点和下一步六列表。状态只允许合格、失败、待验收。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{任务}}` | 保温杯海报标签返工 |
| `{{版本日志}}` | V03父V02合格；V04父V03失败：标签修复但杯盖漂移；V05父V03待验收：只重做标签D2 |
| `{{回退目标}}` | V03 |
| `{{禁止沿用}}` | V04 |
| `{{标题}}` | 编辑轮次与回退证据 |

## 拿来就用的具体示例

每轮必须保存独立文件并由人记录父版本与状态；若原图缺失，只保留文字节点并标“文件缺失”，不能补画版本。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“编辑轮次与回退证据”板，任务“保温杯海报标签返工”。从左到右放V03、V04、V05原图缩略图。V03父V02，绿框“合格”；V04父V03，红框叉号“失败：标签修复但杯盖漂移”；V05父V03，橙框“待验收：只重做标签D2”。只画V03→V04灰线和V03→V05蓝线，不画V04→V05。写“回退目标：V03”“禁止沿用：V04”。不比较优劣、不合并或修图。只输出一张图。
```


## 完整提示词

```text
依据版本图片与{{版本日志}}制作16:9“{{标题}}”板，任务名只写“{{任务}}”。按时间从左到右排列V03、V04、V05原图缩略图，不重绘、不修图；每张下方逐字写“版本｜父版本｜人工状态｜唯一改动｜失败点｜下一步”。连接线只按父版本关系绘制：V03到V04用灰线，V03到V05用蓝线，不画V04到V05。人工标“合格”的版本加绿色边框，“失败”加红色边框与叉号，“待验收”加橙色边框；状态不由画面推断。中央明确写“回退目标：{{回退目标}}”“禁止沿用：{{禁止沿用}}”。不要自动比较版本、判断哪张更好、合并V04与V05、修复失败图、删除失败记录或把待验收标成合格。只输出一张回退证据板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

回退关系来自人工版本日志；本板不执行文件恢复，也不能证明对应原始文件仍存在或可用。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
只修正版本{{版本号}}的{{父版本、状态、失败点或下一步}}为“{{正确内容}}”，并相应调整该节点连线；其他版本图片与日志不变。
```
