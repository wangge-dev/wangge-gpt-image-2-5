# T43 · 单差异遮罩返工执行

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Other Use Cases · 本库原创设计**

从人工差异板中一次选一个编号，以当前合格底图、精确遮罩和唯一权威参考执行最小范围返工。

## 准备材料与变量

图1：当前唯一合格底图；图2：仅覆盖本轮问题的黑白遮罩；图3：该属性唯一权威原图；图4：人工差异标注板。提供差异编号、准确修改、验收点、保护项和失败回退版本。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{差异编号}}` | D2 |
| `{{本轮修改}}` | 将正面标签第二行恢复为“轻盈随行” |
| `{{验收点}}` | 四字顺序准确，沿用原字号、颜色、基线与瓶身透视，无旧字重影 |
| `{{保护项}}` | 杯盖、杯身轮廓、墨绿色、金属边、商品位置、背景、阴影、标题与D1/D3区域 |
| `{{失败回退}}` | 仍以V03原图为底图，不使用本轮失败结果 |

## 拿来就用的具体示例

遮罩应只覆盖一个人工确认的问题；每轮保存合格底图，失败时回到该底图，不能在失败结果上连续叠改。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1是V03唯一合格底图，图4只确认差异D2，图2只定义正面标签第二行遮罩，图3是准确标签参考。本轮只把第二行恢复为“轻盈随行”。重绘不得超出白色遮罩；四字顺序准确，沿用原字号、颜色、基线和瓶身透视，不留旧字重影。锁定杯盖、杯身轮廓、墨绿色、金属边、商品位置、背景、阴影、标题与D1/D3区域。不处理其他差异。若失败，仍回到V03，不沿用失败图。移除遮罩与编号，只输出一张图。
```


## 完整提示词

```text
图1是当前唯一合格底图，图4只用于确认本轮差异编号{{差异编号}}，图2只定义允许重绘的遮罩，图3是本问题属性的唯一权威参考。本轮只执行：{{本轮修改}}。重绘范围不得超出图2白色区域；遮罩边缘要与图1的纹理、光向、透视和噪点自然衔接。验收点：{{验收点}}。完整锁定{{保护项}}，不处理图4中的其他差异，不顺手改字、校色、移动商品、优化背景或改变版式。若图2未覆盖完成修改所需区域，或图3证据不足，则保持图1并停止补造。{{失败回退}}。移除遮罩与编号，只输出一张本轮返工结果图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡执行T39之后的单问题返工；生成式编辑不能保证遮罩外逐像素不变，仍须与底图人工比对。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
仍以图1合格底图重做{{差异编号}}，本次只修正{{失败点}}；图2遮罩、图3权威参考、保护项和其他差异保持不变。
```
