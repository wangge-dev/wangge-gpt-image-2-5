# T02 · 信息图引擎

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Charts & Infographics · 通用来源改写 · 按 2.5 文档适配，未生图实测**

生成结构化图解、时间线、知识图谱和技术解释图。

## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{主题}}` | 咖啡手冲流程 |
| `{{标题}}` | 一杯咖啡的四步 |
| `{{模块内容}}` | 1.备水：准备热水；2.研磨：称取咖啡豆研磨；3.注水：分段注水；4.分享：倒入杯中；请按实际流程填写 |

## 完整提示词

```text
为{{主题}}绘制中文信息图。标题只写“{{标题}}”。内容按{{模块内容}}分成四个模块，每块有编号、短标题和说明；按给定顺序连接，不新增结论或数字。上方标题、中间主要图解、下方简短说明，浅底配深蓝和橙色，图标含义与内容一致。图1若提供是版式草图，保留模块相对位置。只输出一张信息图，不输出报告正文。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。这是本库的起步建议，不是效果保证。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 布局或风格变体

```text
为{{主题}}绘制中文信息图。标题只写“{{标题}}”。内容按{{模块内容}}分成四个模块，每块有编号、短标题和说明；按给定顺序连接，不新增结论或数字。上方标题、中间主要图解、下方简短说明，浅底配深蓝和橙色，图标含义与内容一致。图1若提供是版式草图，保留模块相对位置。只输出一张信息图，不输出报告正文。

本次版本调整（以此段替换基础正文中的对应布景、布局或风格，未提及要求继续保留）：
改为横向四步流程，箭头从左到右，内容和编号不变。
```

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
编辑上一张结果，只修正与本次输入原文或参考图不一致的文字、形态与对应关系。准确内容、主体身份、已确认的配色和构图保持不变。不要添加新的设计元素。
```

## 对照改写说明

- 保留模块化结构，要求事实和流程由输入决定。

适配依据：[2.5 适配规则](../../guides/adaptation.md)。这些方法可能同样适用于其他模型，不宣称 2.5 独占。
