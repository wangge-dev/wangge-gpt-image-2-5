# T21 · 文档与出版物

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Documents & Publishing · 通用来源改写**

生成白皮书、手册、百科图鉴和页面系统。

## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{出版物}}` | 企业画册 |
| `{{页名}}` | 公司介绍页 |
| `{{标题}}` | 关于我们 |
| `{{正文}}` | 填写已经审定的本页正文；建议按版面长度提供 |

## 完整提示词

```text
设计{{出版物}}的单页版式，本次只做{{页名}}。图1是统一版式参考，图2是本页主图。标题准确为“{{标题}}”，正文准确为“{{正文}}”。采用两栏网格、清楚的标题层级与舒适边距，文字不能溢出页面。保持参考图的配色和字体气质，不把文档变成书本透视样机，不生成额外页码、作者或数据。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 布局或风格变体

```text
设计{{出版物}}的单页版式，本次只做{{页名}}。图1是统一版式参考，图2是本页主图。标题准确为“{{标题}}”，正文准确为“{{正文}}”。采用单栏布局，上方大图、下方正文、清楚的标题层级与舒适边距，文字不能溢出页面。保持参考图的配色和字体气质，不把文档变成书本透视样机，不生成额外页码、作者或数据。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，重新附所需原始参考。本轮只修改出版单页{{文字区域}}：原样排入“{{准确正文}}”，调整该区换行，保持主图和其他栏内容。只输出这一张修改后的图。
```
