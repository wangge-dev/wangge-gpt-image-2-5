# T62 · 精密防呆接口方向与到位标记对照

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

用同一组真实防呆插头与插座展示方向标记、对齐和人工确认的到位状态，避免把相似外观误画成可互换接口。

## 准备材料与变量

图1：断电拆分状态正反面；图2：防呆缺口与对齐标记微距；图3：人工确认的完全到位实拍；图4：未到位示例；图5：接口编号与人工状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{部件}}` | 可拆电池的防呆插头与插座 |
| `{{方向标记}}` | 三角标记A对三角标记B，缺口朝上 |
| `{{到位状态}}` | 图3为人工确认已到位；图4为未到位示例D10 |
| `{{标题}}` | 方向正确，不等于已经到位 |

## 拿来就用的具体示例

必须是同一组已编号实物，方向与到位结论由人工在断电条件下提供；外观相似、方向对齐或看似插到底都不能证明电气兼容。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“方向正确，不等于已经到位”核对板。对象是同一组可拆电池防呆插头与插座，全部断电。左栏标P1、S1；中栏放大三角标记A对三角标记B、缺口朝上的真实方向；右栏按实拍展示人工确认已到位与未到位示例D10。保持触点数、缺口、接缝和观察方向，不旋转或补结构。不推断兼容、极性、插拔力、防水或安全性。只输出一张图。
```


## 完整提示词

```text
依据图1至图5制作16:9“{{标题}}”核对板。所有部件均处于断电、拆分或静止展示状态。左栏原样展示{{部件}}两端并分别标P1、S1；中栏只放大图2的防呆结构与{{方向标记}}，用两条短引线指向真实标记，不旋转、镜像、补触点或改变针脚数量；右栏上下排列图3与图4，逐字标注“{{到位状态}}”。图3只按实拍保留接缝、限位边和可见间隙，图4以红框标D10，不把未到位状态自动推成损坏。三栏使用同一实物编号和一致观察方向。不要表现通电、火花、带电操作，不推断电气兼容、极性、插拔力、防水、连接可靠性或可安全使用。只输出一张静态对照图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

视觉对照不替代规格书、电气测试、极性确认、断电操作规范或安全验收。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
