# T171 · 透明反印标签正反层局部中文改字锁定

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

区分透明标签前表面、背面反印文字和下方商品基材，只在反印层改指定中文，避免镜像方向、白墨层和背景串层。

## 准备材料与变量

图1：当前合格透明标签成品正视；图2：标签背面反印正稿；图3：目标字区遮罩M-B1；图4：旧文与审定新文；图5：白墨衬层和透明边微距；图6：人工层级表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{对象}}` | 透明瓶贴CL26 |
| `{{改字}}` | 背面反印层M-B1：‘清润配方’→‘清润系列’ |
| `{{层级}}` | 前表面F1、反印文字层P1、白墨衬层W1、透明无墨边E1、瓶身基材B1 |
| `{{保护}}` | 标签轮廓、透明边、白墨范围、标志、其他文字、瓶身颜色、高光、阴影和背景 |
| `{{记录}}` | M-B1新文与正面阅读方向已核对；白墨边界待复核D99 |
| `{{标题}}` | 只改透明标签背面的反印字，正面阅读方向与透明层级不变 |

## 拿来就用的具体示例

提供当前合格成品、背面正稿、唯一遮罩、审定新文和真实白墨层参考；文字不得由模型自行翻译。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
编辑CL26当前合格底图，只在背面反印层M-B1把“清润配方”改为“清润系列”。成品正面必须正常阅读，不镜像；F1、W1、E1、B1及其他文字、标志、高光和背景不变。底部写“M-B1新文与正面阅读方向已核对；白墨边界待复核D99”。只输出一张修改后的成品图。
```


## 完整提示词

```text
依据图1至图6编辑同一张{{对象}}底图，只执行“{{改字}}”。按{{层级}}处理：F1保持透明反光，P1的新文字印在背面但从正面正常阅读，W1只沿原有衬白边界承托文字，E1继续透明并透出B1。严格保护{{保护}}。不可把新字画成正面浮字、输出镜像中文、扩大白墨、把瓶身颜色填进标签、擦除透明边、自动修改其他文案、重绘瓶型或输出前后拼图。画面底部小字逐字写“{{记录}}”，D99只框W1边界。只输出一张修改后的成品图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

局部改字图不替代反印制版、白墨套印、色彩、材料、附着、法务或实物打样审核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
