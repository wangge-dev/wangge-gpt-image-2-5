# T46 · 发布资产清单拼版

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Documents & Publishing · 本库原创设计**

在发布或交付前，把已批准文件的预览、文件名、渠道、规格和人工状态整理成一张清单，不从图片伪造技术属性。

## 准备材料与变量

图1起：待发布资产预览；提供资产编号、文件名、渠道、像素规格、格式、人工状态、文案版本和用途八列表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{项目}}` | 保温杯秋季上新 |
| `{{发布清单}}` | R01 cup-autumn-tb-1x1-v05.png 淘宝 2000×2000 PNG 已批准 Copy-v3 主图；R02 cup-autumn-xhs-3x4-v04.png 小红书 1080×1440 PNG 已批准 Copy-v3 封面；R03 cup-autumn-banner-16x9-v02.png 横版广告 1920×1080 PNG 待批准 Copy-v3 横幅 |
| `{{标题}}` | 发布资产清单 |
| `{{阻塞项}}` | R03待批准，不进入发布包 |
| `{{说明}}` | 规格与状态来自人工交付清单，未读取文件元数据 |

## 拿来就用的具体示例

先用文件工具核对真实文件名、尺寸和格式，再由负责人填写批准状态；此视觉拼版只用于交接，不能替代目录、元数据或发布平台记录。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“发布资产清单”，项目“保温杯秋季上新”。R01预览下写“cup-autumn-tb-1x1-v05.png｜淘宝｜2000×2000｜PNG｜已批准｜Copy-v3｜主图”；R02写“cup-autumn-xhs-3x4-v04.png｜小红书｜1080×1440｜PNG｜已批准｜Copy-v3｜封面”；R03写“cup-autumn-banner-16x9-v02.png｜横版广告｜1920×1080｜PNG｜待批准｜Copy-v3｜横幅”。已批准绿框，待批准橙框。右侧只写“R03待批准，不进入发布包”，底部写“规格与状态来自人工交付清单，未读取文件元数据”。不声称已上传。只输出一张图。
```


## 完整提示词

```text
依据所附预览与{{发布清单}}制作16:9“{{标题}}”拼版，项目名只写“{{项目}}”。每项资产按R01、R02、R03顺序展示原始预览缩略图，不重绘、不裁切、不校色；缩略图下方逐字写“资产编号｜文件名｜渠道｜像素规格｜格式｜人工状态｜文案版本｜用途”。“已批准”用绿色边框，“待批准”用橙色边框，其他状态按清单原文显示，不根据画面判断。右侧单列“阻塞项”，只写“{{阻塞项}}”；底部写“{{说明}}”。不要从缩略图测量像素、读取真实文件格式、猜渠道规则、改文件名、自动批准、生成校验码或声称文件已上传。只输出一张发布清单拼版。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

清单字段全部来自外部人工记录；生成图不能读取文件元数据、验证像素或证明上传和发布成功。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
