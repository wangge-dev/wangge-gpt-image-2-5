# T329 · 电商卖点文案与批准证据逐条来源映射板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把拟上屏卖点逐条连接到批准文件中的明确证据或未提供状态，不从图片、品类常识或相邻文案推导新卖点。

## 准备材料与变量

图1：商品主图仅作身份参考；图2：批准规格表；图3：批准检测或说明文件摘页；图4：法务审定文案表；图5：候选卖点C1-C6；图6：来源映射表；图7：禁止推导项。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 保温杯TM70 |
| `{{候选卖点}}` | C1 500毫升；C2 双饮口；C3 杯盖可拆洗；C4 保温12小时；C5 食品级；C6 防漏 |
| `{{来源映射}}` | C1→规格表S-02已批准；C2→说明书M-03已批准；C3→说明书M-07已批准；C4未提供；C5未提供；C6未提供 |
| `{{输出状态}}` | C1-C3可进入文案候选；C4-C6停止补造，等待证据；不代表最终发布批准 |
| `{{禁止推导}}` | 不由商品照片、同类商品、材质外观、评价或常识推断容量、时长、等级、防漏 |
| `{{标题}}` | 每条卖点都要有自己的批准来源，没有证据就停在未提供 |

## 拿来就用的具体示例

提供商品身份图、批准规格/说明/检测文件、法务文案表和人工来源映射；未明确批准的材料不得被模型升级为证据。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作TM70卖点来源映射板：C1 500毫升连S-02，C2双饮口连M-03，C3杯盖可拆洗连M-07；C4保温12小时、C5食品级、C6防漏均灰色标未提供。底部写“C1-C3可进入文案候选；C4-C6停止补造，等待证据；不代表最终发布批准”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”来源映射板。左栏列“{{候选卖点}}”，中栏放批准资料原页缩略图且不改文，右栏严格按“{{来源映射}}”连接；已批准用蓝线，未提供用灰色停止符。底部逐字写“{{输出状态}}”与“{{禁止推导}}”。不可从图1识别外观后补卖点、把一个来源连给不支持的多条结论、改写证据原文、把候选状态写成已发布、生成认证徽章或替法务审批。只输出一张来源映射板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

映射板不替代事实核查、检测报告验证、认证查询、法务审查、平台规则、广告合规或最终发布批准。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
