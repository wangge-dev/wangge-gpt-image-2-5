# T401 · 揭页式包装标签外页内页与底层文字载体连续

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

核对揭页式标签从闭合、掀起到完全展开时，批准文字始终归属外页正面、外页背面或固定底层标签，不因遮挡变化被复制、删除或跨层重排。

## 准备材料与变量

图1：包装与闭合标签；图2：外页正面F1及批准文字表A；图3：外页背面F2及批准文字表B；图4：固定底层L1及批准文字表C；图5：半揭和全揭实拍；图6：铰接边H1与揭开方向；图7：逐字批准稿。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{产品}}` | 揭页式包装标签PK101 |
| `{{载体}}` | F1与F2是同一可揭外页的两面并沿H1翻转；L1固定在包装表面不移动 |
| `{{文字}}` | 表A只属于F1，表B只属于F2，表C只属于L1；逐字照录批准稿并保持原段序 |
| `{{状态}}` | P0闭合只见F1；P1外页掀起约45度，F1与L1局部可见；P2掀起约120度，F2与L1可见；P3外页完全展开，F2和完整L1分别可读 |
| `{{保护}}` | 包装身份、H1位置、外页轮廓与缺口、F1/F2正反关系、L1固定边界、真实遮挡和批准文字 |
| `{{记录}}` | 三层文字载体与翻转显隐已核对；法规完整性未验证D341 |
| `{{标题}}` | 标签揭开只改变可见面，三组批准文字不跨载体迁移 |

## 拿来就用的具体示例

闭合、半揭、全揭以及三面批准文字必须来自同一包装版本；未提供文字保持空缺并标未提供。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作PK101 P0-P3四栏。F1/F2为同一外页两面，沿H1从闭合翻到完全展开，L1始终固定；表A只在F1、表B只在F2、表C只在L1，逐字照录不跨层。写“三层文字载体与翻转显隐已核对；法规完整性未验证D341”。
```


## 完整提示词

```text
依据图1至图7制作16:9{{产品}}“{{标题}}”四状态核对板。严格保持{{载体}}，按{{状态}}执行翻转，并逐字执行{{文字}}和{{保护}}。不得把F1/F2当成两张独立标签、复制外页、让L1随外页移动、把表A/B/C互换、在P0透视显示底层、把被遮挡文字删除、为了排版重写批准文字、镜像背面、补造未提供的法规段落或二维码。每栏标明当前可见载体和被遮挡载体，不用画面坐标代替文字归属。底部逐字写“{{记录}}”，D341框H1、F1、F2、L1和三组文字。不要宣称法规、成分、剂量、功效、认证、印刷质量、粘贴牢度或合规性。只输出一张核对板。
```
