# T169 · 包装密集表格单元格局部改字与网格保护

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把密集包装表格中的行列坐标、目标单元格、审定新文和保护网格绑定，只修改指定格而不重排整表。

## 准备材料与变量

图1：当前合格包装表格正视底图；图2：带行列坐标的人工标注；图3：目标格遮罩M-R3C2；图4：旧文与审定新文；图5：原字体和线距微距；图6：人工保护项表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{对象}}` | 冲调粉包装信息表TB18 |
| `{{改单元格}}` | R3C2遮罩M-R3C2：‘每份 25克’→‘每份 30克’ |
| `{{保护}}` | 表头、R1至R6其他单元格、C1至C4列宽、全部横竖线、单位、脚注、外框和包装底色 |
| `{{记录}}` | R3C2新文已审定；数字与‘克’间距待复核D97 |
| `{{标题}}` | 只改一个有坐标的单元格，整张表的网格与其他文字不动 |

## 拿来就用的具体示例

提供正视合格底图、唯一单格遮罩、人工行列坐标和审定旧新文字；不得让模型自行重算或补写表格数据。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
编辑TB18当前合格底图，只在M-R3C2把“每份 25克”改成“每份 30克”。保持表头、其他单元格、C1至C4列宽、全部横竖线、单位、脚注、外框和底色不变；不得重算任何数字。底部写“R3C2新文已审定；数字与‘克’间距待复核D97”。只输出一张修改后的成品图。
```


## 完整提示词

```text
依据图1至图6编辑同一张{{对象}}底图，只执行“{{改单元格}}”。M-R3C2是唯一允许修改的像素区，新文字必须逐字准确并匹配原格内的字体、字号、字重、基线、行距、颜色和印刷质感；严格保护{{保护}}。修改后文字只能留在R3C2内，不得跨线、挤压相邻格或改变网格。不可重算数值、自动补单位、联动修改同列或同名字段、擦断边框、重新排整张表、增加宣传语或输出前后拼图。画面底部小字逐字写“{{记录}}”，D97只框R3C2字距。只输出一张修改后的成品图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

局部改字图不替代数据计算、配方核对、净含量、营养标签、法务、印前文件或实物打样审核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
