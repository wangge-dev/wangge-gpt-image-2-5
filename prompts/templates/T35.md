# T35 · 指定元素清除与底纹修复

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Other Use Cases · 本库原创设计**

按遮罩或编号删除指定文字、贴纸或小物件，并延续其背后的真实纹理、光影和透视。

## 准备材料与变量

图1：原图；图2：用纯色遮罩标明删除区域；图3：同一背景无遮挡参考（如有）。列出必须删除与必须保留项。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{删除项}}` | 右上角红色促销贴纸及其白色文字 |
| `{{必须保留}}` | 商品、品牌标志、左侧标题、桌面划痕、墙面光斑 |
| `{{背景依据}}` | 优先图3墙面纹理；缺失处延续图1邻近区域 |

## 拿来就用的具体示例

准备原图、紧贴目标边缘的遮罩和可选无遮挡背景；遮罩不要覆盖需要保留的商品边缘。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以图1为底图，图2只标右上角区域。只删除右上角红色促销贴纸及其白色文字，优先按图3恢复墙面纹理和光斑，缺失处延续图1邻近颗粒；不得留下模糊补丁或重复纹理。商品、品牌标志、左侧标题、桌面划痕和墙面其他光斑不变。不加替代文字或装饰。只输出一张图。
```


## 完整提示词

```text
以图1为底图，图2只定义最小删除区域。本轮只删除{{删除项}}，并按{{背景依据}}恢复被遮挡背景的纹理、颗粒、接缝、光斑、透视与噪点；修复边缘不得出现模糊补丁、重复纹理或色块。完整保护{{必须保留}}，不移动主体、不改字、不重绘商品、不调整整图色彩和构图。图3如提供只负责背景依据，不把其中其他物体带入。完成后移除遮罩，不增加替代文字、装饰、水印或空白标签。只输出一张修改图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

若被遮挡区域没有任何背景依据，只能做视觉补全，不能声称恢复了真实原始内容。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 仅清除文字

```text
以图1为底图，图2定义文字区域。只删除“{{待删文字}}”及其投影，按{{背景依据}}恢复底纹；保留所有图形、标志和未指定文字，不添加新字。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
仍以原图1为底图重做，只修正{{残影、重复纹理或误删边缘}}；缩小遮罩到{{准确范围}}，其他区域不动。
```
