# T35 · 指定元素清除与底纹修复

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Other Use Cases · 本库原创设计**

按遮罩或编号删除指定文字、贴纸或小物件，并延续其背后的真实纹理、光影和透视。

## 准备材料与变量

基础版图1为有权编辑的批准成片，图2为与图1画幅及坐标一致的删除区域标记，只定位不作纹理源；人工提供删除项、区域与保留清单。图3仅在明确提供同版本无遮挡背景时使用，只补目标局部，没有就不引用。仅简单连续底纹且无图2时用单图分支；复杂被遮挡商品、文字、图案或结构需补真实依据，不能恢复未知事实。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{删除项}}` | 右上角独立红色促销贴纸及其白色文字 |
| `{{删除区域}}` | 以图1左上角为原点，画面宽度78%–94%、高度6%–18%的矩形内；人工确认只圈贴纸、不碰商品和标题 |
| `{{必须保留}}` | 完整商品及包装原字、品牌标志、左侧标题、桌面划痕、墙面其他光斑 |
| `{{背景依据}}` | 只延续图1目标区紧邻、人工确认的均匀暖灰墙面，无额外背景参考；不补未知纹理或原字 |
| `{{待删文字}}` | 夏日限时 |
| `{{文字底纹依据}}` | 只延续文字四周人工确认的红色贴纸底色与已有细颗粒，保留贴纸边界，不借用墙面灰色覆盖贴纸 |

## 拿来就用的具体示例

自备一张4:5商品海报，右上独立贴纸位于宽78%–94%、高6%–18%，周边为人工确认的均匀暖灰墙面，贴纸不接触商品；图2只对齐标目标。此为素材条件示例，未提供图3；背景不是已恢复的原始证据。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以图1批准成片为底图，仅清除“右上角独立红色促销贴纸及其白色文字”。图2只定位以图1左上角为原点，画面宽度78%–94%、高度6%–18%的矩形内；人工确认只圈贴纸、不碰商品和标题，必须与图1画幅、坐标一致；它不是背景、商品或配色参考。画幅、商品占比、主体位置、原视角、阅读顺序和原有留白不变，不把本次清除变成整图重新设计。

修复依据：只延续图1目标区紧邻、人工确认的均匀暖灰墙面，无额外背景参考；不补未知纹理或原字。图3仅在确已提供、人工确认同版本且对齐时负责被删除元素背后的局部；没有图3不引用，不能从其他相似背景借入商品或改变光影。只沿图1邻近可确认区域延续平坦底色、已证实边界与噪点；跨到未知商品轮廓、包装原字、复杂图案、接缝或遮挡结构时暂停该区、补真实背景或转外部图层，不生成所谓原始细节。

保护清单：完整商品及包装原字、品牌标志、左侧标题、桌面划痕、墙面其他光斑。不移动、放大、镜像或重画商品，不更改未指定文字、原曝光、照片颜色、包装、纹理和图标。清除只限用户有权编辑的营销元素，不删除来源署名、许可信息或他人水印；只在目标区内消除指定元素及其专属投影，其他阴影与光斑不动。不以模糊块、重复贴图、色带、空白标签、新文字或装饰掩盖修补。完成后不保留区域标记。

只输出一张修改成片，尺寸和比例沿用图1；无依据的视觉填补不能证明恢复真实原貌。未编辑区须逐像素不变时，用外部遮罩合成批准局部，不依赖提示词保证。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

营销元素清除不等于重建被遮挡商品或恢复原始证据；没有素材能证明的复杂细节不补。单图分支只适用于可确认简单底纹，尺寸按实际原成片而非固定示例裁切。

1536x1920只对应4:5示例。其他原成片保留原比例与全部可见信息，按合法画布等比适配，不为默认尺寸裁图。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 仅清除文字

```text
以图1批准成片为底图，图2只定位{{删除区域}}；只清除该范围内的营销文字“{{待删文字}}”及其专属投影，保留贴纸底形、商品、品牌标志和所有未指定文字。若目标与包装原字、署名、许可或他人水印重合则暂停，不扩大为删标或整区清空。

背景依据：{{文字底纹依据}}。区域标记不提供纹理；图3仅在真实提供且确认同版本对齐时补目标文字下方局部，没有就不引用。只延续已确认的紧邻简单底纹，复杂图案、原字、商品轮廓或遮挡信息无法可靠复原时转外部图层，不编造原始细节。

保护{{必须保留}}，保持原画幅、构图、商品占比、视角、色彩、曝光、其他投影与留白。文字移除后不补新字、图标、空白标签或装饰，不移动剩余文字填空，不用模糊补丁掩盖残影。完成后移除标记，只输出一张修改图；精确像素保护需外部遮罩合成。
```

### 仅图1简单底纹清除 · single-image-removal

```text
只编辑图1批准成片，不需要额外图片或区域标记图。人工目标：{{删除项}}；准确区域：{{删除区域}}；保留{{必须保留}}。只清除指定营销元素及其专属投影，不能把大矩形内其他内容一并抹掉。

修复只用{{背景依据}}。本分支仅用于目标周边能人工确认连续简单底纹的情形；涉及商品轮廓、包装字、复杂花纹、接缝或遮挡后的未知结构时暂停、补真实背景或外部排版，不生成被遮挡事实。没有额外背景照就不引用；图1之外不引入任何商品、纹理或光源。

保留原画幅、主体比例、位置、视角、全部非目标文字、颜色、曝光、其他阴影与光斑；不把空位填成新标题、贴纸、装饰或水印，不移动其余元素填空。只处理用户有权编辑的营销元素，不移除来源署名、许可或他人水印。边缘不留残影、模糊块或重复纹理。只输出一张修改图；视觉补底不等于恢复原始证据，未编辑区要逐像素一致时外部合成。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
