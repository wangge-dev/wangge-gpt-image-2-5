# T09 · 商品商业视觉

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 通用来源改写**

生成商品图、包装、详情页和卖点排版。

## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 实际商品名称和规格 |
| `{{标题}}` | 日常随行 |
| `{{卖点一}}` | 填写真实卖点 |
| `{{卖点二}}` | 填写另一条真实卖点 |

## 完整提示词

```text
图1是实际商品。为{{商品}}制作商业展示图，保留外形、配色、结构、材质与包装文字。商品位于右侧，左侧只排标题“{{标题}}”和两条卖点“{{卖点一}}”“{{卖点二}}”。背景为柔和灰白摄影棚，用侧光体现真实材质，不增添未提供的价格与认证。三分之四视角仅在已有参考支持时使用，否则保留原视角。
```

## 参数设置

建议画布：`1024x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 布局或风格变体

```text
图1是实际商品。为{{商品}}制作商业展示图，保留外形、配色、结构、材质与包装文字。商品位于右侧，左侧只排标题“{{标题}}”和两条卖点“{{卖点一}}”“{{卖点二}}”。背景为柔和灰白摄影棚，用侧光体现真实材质，不增添未提供的价格与认证。三分之四视角仅在已有参考支持时使用，否则保留原视角。

本次版本调整（以此段替换基础正文中的对应布景、布局或风格，未提及要求继续保留）：
删除标题和卖点，主体移到中央，制作无字商品图。
```

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
编辑上一张结果，只修正与本次输入原文或参考图不一致的文字、形态与对应关系。准确内容、主体身份、已确认的配色和构图保持不变。不要添加新的设计元素。
```
