# T12 · 品牌触点视觉板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Brand & Logos · 通用来源改写**

生成包装、社媒、网页和展示场景里的品牌触点板。

## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{品牌名}}` | 自有品牌 |
| `{{主色}}` | 墨绿和米白 |
| `{{短句}}` | 本周精选 |

## 完整提示词

```text
图1为品牌标识，图2为主产品参考。为“{{品牌名}}”制作一张触点视觉板。中部主产品最大，左右分布包装、手提袋、菜单卡和生活场景四个小区。标识形状、主色{{主色}}与文字“{{短句}}”跨触点统一，文字只在菜单卡出现一次。材质细腻、阴影柔和、物料清楚分开；包装若无实物资料则作为概念设计，不添加赠品或认证。
```

## 参数设置

建议画布：`1536x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 布局或风格变体

```text
图1为品牌标识，图2为主产品参考。为“{{品牌名}}”制作一张触点视觉板。中部主产品最大，左右分布包装、手提袋、菜单卡和生活场景四个小区。标识形状、主色{{主色}}与文字“{{短句}}”跨触点统一，文字只在菜单卡出现一次。材质细腻、阴影柔和、物料清楚分开；包装若无实物资料则作为概念设计，不添加赠品或认证。

本次版本调整（以此段替换基础正文中的对应布景、布局或风格，未提及要求继续保留）：
改为四格整齐展示：主产品、包装、手提袋、菜单卡；每格使用同一标识。
```

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
编辑上一张结果，只修正与本次输入原文或参考图不一致的文字、形态与对应关系。准确内容、主体身份、已确认的配色和构图保持不变。不要添加新的设计元素。
```
