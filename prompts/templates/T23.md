# T23 · 成品图多处中文局部改字

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Posters & Typography · 本库原创设计**

在已确认成品图上按编号逐处替换短中文，限制改动区域并保留原版式。

## 准备材料与变量

图1：待修改成品图；图2：带编号框的修改位置图；提供编号、原文、正确文字三列表。文字较长时同时提供允许换行方式。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{修改清单}}` | ①春日上新→春日焕新；②限时好价→会员专享；③立即购买→查看详情 |
| `{{允许换行}}` | ①单行；②单行；③单行 |
| `{{保护区域}}` | 人物、商品、标志、价格、背景和全部未编号文字 |

## 拿来就用的具体示例

准备原成品图、编号位置图和人工校对后的三列表；超过四处时分轮修改并逐轮复核。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以图1海报为底图，图2只定义三个编号位置。依次把①“春日上新”改为“春日焕新”，②“限时好价”改为“会员专享”，③“立即购买”改为“查看详情”，三处均保持单行。沿用各自原字号、字重、颜色、对齐和透视，清除旧字重影。人物、商品、标志、价格、背景及所有未编号文字完全不动。完成后移除编号，只输出一张图。
```


## 完整提示词

```text
以图1为底图，图2只定义编号位置。严格按{{修改清单}}逐处替换中文，并遵守{{允许换行}}。每个编号只改对应文字框，沿用原字重、字号、字距、行距、颜色、对齐、透视和印刷质感；删除原文字后不得留下重影。完整保护{{保护区域}}，不移动版块、不重绘人物与商品、不顺手纠正未列出的文字、不新增标点、英文、数字或装饰。修改完成后移除编号框，只输出一张改好的成品图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

多处改字适合短文案视觉返工；合同、价格表或印刷终稿仍需人工逐字校对，不能把生成图当可编辑源文件。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 单处高精度返工

```text
以图1为底图，本轮只修改编号{{编号}}：把“{{原文}}”逐字替换为“{{正确文字}}”，按{{换行方式}}排版。保持该字框的字体气质、字号、颜色、对齐和透视；图中其他像素区域、文字和编号位置均不改。只输出一张修改图。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，并重新附图1、图2。本轮只返工编号{{编号}}，使其逐字为“{{正确文字}}”；其他已改文字与全部保护区域保持不变。
```
