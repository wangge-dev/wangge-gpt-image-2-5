# T136 · 旅行分装瓶盖色标签与托槽一一映射

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把多只分装瓶的瓶体、盖色、人工标签和收纳托槽逐只绑定，避免串盖、串字或移出后托槽仍被占用。

图1：完整套装；图2：各瓶独立正面；图3：空托盘；图4：装入完成；图5：人工对应表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 四瓶旅行分装套装TS40 |
| `{{瓶组}}` | B1至B4 |
| `{{盖色}}` | K1白、K2蓝、K3绿、K4灰 |
| `{{标签}}` | L1至L4审定短标签 |
| `{{托槽}}` | P1至P4 |

| `{{标题}}` | 每只瓶、盖、标签和托槽保持同一组编号 |

## 拿来就用的具体示例

完整套装、独立瓶、空托盘和装入完成照需来自同一套商品；标签由人工审定。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“每只瓶、盖、标签和托槽保持同一组编号”。TS40中B1/K1/L1只进P1，依次到B4/K4/L4只进P4；独立展示时对应托槽留空，装回后不留复制瓶。写“B1/K1/L1/P1至B4/K4/L4/P4已核对”。不推断容量、内容物或适航性。只输出一张图。
```


## 完整提示词

```text
依据图1至图5制作16:9“{{标题}}”套装映射板。固定同一{{商品}}的{{瓶组}}、{{盖色}}、{{标签}}和{{托槽}}，按人工表逐组一一对应；瓶移出时原托槽必须留空，装回后瓶数与槽数守恒。标签只写已审定短文，不按颜色猜内容物，不交换瓶盖，不复制瓶体，不让一瓶占两个槽。底部逐字写“{{记录}}”。不要生成人物或旅行场景，不推断容量、内容物、密封、防漏、适航、功效、卫生或安全。只输出一张静态映射板。
```
