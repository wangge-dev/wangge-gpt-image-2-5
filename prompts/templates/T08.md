# T08 · 自然科普海报

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Posters & Typography · 通用来源改写**

生成极简产品感自然科普海报。

## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{物种名}}` | 填写核实的中文物种名 |
| `{{英文名}}` | 填写核实的英文名 |
| `{{特征}}` | 填写四条短标题与说明，来自可靠物种资料 |

## 完整提示词

```text
制作物种“{{物种名}}”的自然科普海报。图1为形态参考，主体占中部约60%，纯白背景和少量必要承托物，真实质感与柔和阴影。顶部准确写中文名“{{物种名}}”及英文名“{{英文名}}”。底部四列分别排{{特征}}，细竖线分隔，小图标与内容对应，不加卡片框。物种事实只按给定资料，不猜分布、毒性或保护级别。
```

## 参数设置

建议画布：`1024x1536`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 布局或风格变体

```text
制作物种“{{物种名}}”的自然科普海报。图1为形态参考，主体占中部约60%，极浅灰背景和少量必要承托物，真实质感与柔和阴影。顶部准确写中文名“{{物种名}}”及英文名“{{英文名}}”。特征标题使用低饱和青色，底部四列分别排{{特征}}，细竖线分隔，小图标与内容对应，不加卡片框。物种事实只按给定资料，不猜分布、毒性或保护级别。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，重新附所需原始参考。本轮只修改科普图第{{列号}}列：改为“{{准确特征}}”，保持物种外观与其他三列，不添加新事实。只输出这一张修改后的图。
```
