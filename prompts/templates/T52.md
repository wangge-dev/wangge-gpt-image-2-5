# T52 · 拼装玩具分袋与检查点追踪

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把真实零件分袋、步骤检查点和阶段性半成品一一对应，避免跨袋取件、漏件和提前出现后续结构。

## 拿来就用的具体示例

每个检查点需有真实阶段照或说明书明确插图；如果只有最终成品，不能反推中间结构与分袋归属。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作4:5木质小火车分袋检查图。A段左侧各一次展示车底板1、轮轴2、车轮4，右侧按真实C1照显示底板、2根轮轴和4个车轮完成连接；B段左侧展示车厢侧板2、端板2、顶板1，右侧C2保留C1并只增加完整车厢。蓝线只连接本袋零件到本段新增位置，不跨段。烟囱、挂钩、贴纸和展示底座不能提前出现。不补榫卯、胶水、工具、年龄、安全或时长。顶部只写“按分袋完成两个检查点”。只输出一张图。
```


## 完整提示词

```text
依据图1至图6制作4:5{{玩具}}分袋检查图。画面自上而下两段：A段左侧按图2逐件展示“袋A：{{袋A}}”，右侧严格按图3展示“{{检查点一}}”；B段左侧按图4逐件展示“袋B：{{袋B}}”，右侧严格按图5展示“{{检查点二}}”。C2必须保留C1已完成结构，只新增袋B零件；每个零件在清点区各出现一次，半成品中数量与说明书图6一致，不复制轮子、侧板或连接点。{{禁止提前}}在两段都不得出现。用蓝色细线从每袋零件指向本段新增位置，不能跨段连线。顶部只写“{{标题}}”。不补隐藏榫卯、胶水、工具、年龄建议、完成时长、承重、安全认证或玩法功能。只输出一张完整图片。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡用于视觉清点与检查点沟通，不替代正式说明书、年龄分级、缺件判定或玩具安全检查。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
