# T63 · 冷冻食品三时点表面状态记录

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把同一样品在冷冻、指定解冻时点和人工指定终点的真实表面状态按时序并列，约束霜层、水珠和轮廓，不让画面替代食品安全判断。

## 准备材料与变量

图1至图3：同一样品三个真实时点照片；图4：样品编号、拍摄时点、环境条件和人工状态表；图5：包装或标签准确文字。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{食品}}` | 冷冻蓝莓 |
| `{{样品}}` | 样品B07 |
| `{{时点}}` | T0冷冻取出、T15取出后15分钟、T40取出后40分钟 |
| `{{人工状态}}` | T0已记录；T15已记录；T40仅作外观终点 |
| `{{标题}}` | 同一样品的三个真实时点 |

## 拿来就用的具体示例

照片需来自同一样品并有外部计时记录；视觉变化不能证明内部温度、微生物状态、食用品质或食品安全。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“同一样品的三个真实时点”。按T0冷冻取出、T15取出后15分钟、T40取出后40分钟并列样品B07冷冻蓝莓实拍。数量、容器、角度和光线一致；霜层、水珠、粘连与光泽只按各时点照片，不跨栏复制。栏底写“T0已记录；T15已记录；T40仅作外观终点”。缺图写未提供。不判断已解冻、可食用、中心温度、新鲜或安全。只输出一张图。
```


## 完整提示词

```text
依据图1至图5制作16:9“{{标题}}”。三栏从左到右严格为{{时点}}，每栏只使用{{样品}}对应时点的真实照片，保持{{食品}}数量、容器、观察角度、裁切和照明尽量一致。霜层、结露、水珠、表面光泽、颗粒粘连和接触阴影只按各时点实拍保留，不把后一个时点的状态回填前一栏，也不美化成广告级新鲜外观。栏底逐字写“{{人工状态}}”，时间来自图4，不从图片估算。若某时点缺图，保留空框并写“未提供”，不要插值生成。包装文字只按图5。不要写已解冻、可食用、中心温度、新鲜、营养、卫生、保质或安全结论。只输出一张时点记录板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本图只记录外观时点，不替代温度测量、解冻规范、保质判断或食品安全检测。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
