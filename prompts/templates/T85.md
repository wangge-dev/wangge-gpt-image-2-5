# T85 · 骑马钉册页页码与实体跨页顺序核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Documents & Publishing · 本库原创设计**

把批准单页文件的页码与真实骑马钉册封面、中心跨页和翻页顺序逐页对应，核对缺页、倒页与跨页方向，不让视觉板冒充拼版或印刷验收。

## 准备材料与变量

图1起：批准的封面及内页单页预览；实体册闭合、第一页、中心跨页、末页和封底照片；提供页码总数、中心页、阅读方向与人工状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{册页}}` | 12页产品手册 |
| `{{页序}}` | 封面P1，内页P2–P11，封底P12 |
| `{{中心跨页}}` | P6在左、P7在右 |
| `{{阅读方向}}` | 从左向右翻阅 |
| `{{人工状态}}` | P1–P5已核对；中心P6/P7已核对；P10/P11跨页待复核D21；P12已核对 |
| `{{声明}}` | 本图核对阅读页序，不是印刷拼版文件 |
| `{{标题}}` | 文件页码和手中翻到的页面一一对应 |

## 拿来就用的具体示例

批准单页应覆盖全部页码，实体照片来自同一本样册，阅读方向和状态由人工提供；阅读页序不能替代印刷拼版、装订或成品质检。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“文件页码和手中翻到的页面一一对应”。左栏按P1封面、P2–P11内页、P12封底放批准单页；中栏按从左向右翻阅展示真实跨页，中心严格为P6左/P7右；右栏列对应表。保持页码、标题、图像、中缝和骑马钉，不镜像或补被遮挡内容。状态写“P1–P5已核对；中心P6/P7已核对；P10/P11跨页待复核D21；P12已核对”。底部写“本图核对阅读页序，不是印刷拼版文件”。只输出一张图。
```


## 完整提示词

```text
依据全部资料制作16:9“{{标题}}”页序核对板。左栏按{{页序}}以小缩略图展示批准单页，页码清楚但正文不重排；中栏按“{{阅读方向}}”依次展示实体册闭合、P2/P3、P4/P5、{{中心跨页}}、P8/P9、P10/P11、封底P12的真实照片；右栏列页码—实拍编号对应表。每组跨页用两条短线从批准单页连到实体左页和右页，保持页码、标题、图片、骑马钉位置和中缝遮挡，不镜像、不交换左右、不把被中缝遮挡内容补全。缺少实拍的页写“未提供”，不复制相邻页。状态逐字写“{{人工状态}}”，D21只标P10/P11。底部写“{{声明}}”。不要生成印刷对开拼版、裁切线、出血、装订页序算法或缺失正文，不判断套印、裁切、装订牢度、色彩或可交付。只输出一张静态核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

核对板不替代印前拼版、PDF预检、打样、装订强度、裁切和色彩验收。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
