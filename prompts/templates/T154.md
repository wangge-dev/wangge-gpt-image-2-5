# T154 · 圆柱环绕标签首尾接缝与图文连续核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把批准平面正稿的起始边、结束边、定位基准和环绕后接缝映射到同一圆柱包装，避免图文断裂、重叠或水平镜像。

## 准备材料与变量

图1：批准标签平面正稿；图2：空白圆柱包装与定位线；图3：贴合起始边；图4：半环绕；图5：接缝正视微距；图6：成品四方位；图7：人工图文与接缝表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 圆筒茶罐CT72 |
| `{{标签}}` | 起始边E-S、结束边E-E、接缝J1、罐体定位线L1 |
| `{{图文}}` | 批准连续图案G1、正面短文“春山茶集”、批次留白区Z1 |

## 拿来就用的具体示例

批准平面正稿、空白罐定位、贴合过程、接缝微距和四方位成品需对应同一规格；文字与接缝由人工确认。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“平面正稿绕罐一周，首尾只在真实接缝相遇”。CT72中E-S从L1开始，E-E只在J1相遇；G1连续，0°正面逐字写“春山茶集”，Z1留白，四方位按实物旋转不镜像。写“E-S/E-E与G1连续已核对；J1重叠宽度待复核D82”。不判断套准或附着。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”映射板。左栏完整展示批准正稿并标{{标签}}；中栏依次展示起始贴合和半环绕；右栏按{{方位}}展示同一{{商品}}。E-S从L1开始，E-E只在J1与E-S按实拍相遇，{{图文}}沿圆柱曲率连续，遮挡和透视自然；正面短文逐字准确，Z1保持留白。不可镜像正稿、交换首尾、复制标签、让图案跨接缝跳变、把重叠区画成缺口或凭画面推算毫米值。底部逐字写“{{记录}}”，D82只框J1。不要生成多罐陈列或人物，不推断附着力、套准精度、色差、耐磨、耐水、生产公差或印刷合格。只输出一张静态映射板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

映射板不替代附着力、套准与色差测量、耐磨耐水、生产公差或印刷验收。
