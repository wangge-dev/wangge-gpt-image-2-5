# T355 · 中文对比表仅按人工差异单元格着色

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Charts & Infographics · 本库原创设计**

在多款商品对比表中只突出人工指定的差异单元格，保持相同值中性，避免模型自动评优、全列高亮或把缺失值当劣势。

## 准备材料与变量

图1至图3：SKU A-C身份图；图4：批准对比数据；图5：人工差异格清单；图6：空值规则；图7：配色与图例。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{列}}` | A基础款｜B进阶款｜C便携款 |
| `{{行数据}}` | R1重量：1.2 kg｜1.4 kg｜0.9 kg；R2接口：USB-C｜USB-C｜USB-C；R3随附线缆：1条｜2条｜—；R4颜色：黑｜黑｜白 |
| `{{差异格}}` | R1C1/R1C2/R1C3、R3C1/R3C2、R4C3用浅蓝框；R2全部中性；R3C3为未提供灰色，不标差 |
| `{{图例}}` | 浅蓝=人工标记差异；灰色=未提供；不表示优劣 |
| `{{标题}}` | 三款信息逐格对照 |

## 拿来就用的具体示例

差异格必须由人工或结构化工具给出；模型不能通过读表自行判定差异、优劣或缺失含义。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作三款3:4对比表。R1三格、R3的A/B、R4的C只按人工表加浅蓝框；R2三个USB-C全保持中性；R3C3写“—”并灰底，不解释为不支持。底部写“浅蓝=人工标记差异；灰色=未提供；不表示优劣”。不自动推荐或整列高亮。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作3:4中文对比表，标题只写“{{标题}}”。列按“{{列}}”，逐格录入“{{行数据}}”；只按“{{差异格}}”着色。相同值保持白底，未提供用灰底和“—”，不可标红、打叉或解释为不支持。底部逐字放“{{图例}}”。不得自动找差异、计算最轻、添加更优/推荐/冠军标签、整列染色、交换SKU、补空值或改单位。每格只保留批准短值，行列对齐，商品缩略图不遮表头。只输出一张表格图。
```

## 参数设置

建议画布：`1536x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

视觉高亮不构成性能评价、推荐或销售结论；原始数据和差异计算应保留在结构化表格中。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

```text

```
