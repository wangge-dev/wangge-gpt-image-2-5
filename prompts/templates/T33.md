# T33 · 跨渠道系列视觉适配

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Brand & Logos · 本库原创设计**

以已验收品牌母版适配单个渠道规格，保持活动识别但按渠道重新组织信息。

## 准备材料与变量

图1：已验收活动母版；图2：品牌规则卡；图3：无字主体素材；提供本次唯一渠道、比例、安全区、必留文字和渠道可删项。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{本次渠道}}` | 小红书封面 |
| `{{目标比例}}` | 3:4 |
| `{{安全区}}` | 四边各7% |
| `{{必留文字}}` | 主标题“秋日新章”；品牌名“LUMEN” |
| `{{可删项}}` | 母版底部网址和两枚小装饰 |

## 拿来就用的具体示例

准备活动母版、品牌规则、无字主体与一个渠道的真实规格；每次只处理一个渠道并单独验收。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以图1母版、图2品牌规则和图3主体制作小红书3:4封面。保持主体、活动主色、核心图形和LUMEN标志安全留白；主标题“秋日新章”和品牌名“LUMEN”逐字保留在四边7%安全区内。可删除母版底部网址和两枚小装饰，不拉伸母版，不加平台标志、账号或互动数字。只输出一张封面。
```


## 完整提示词

```text
以图1活动母版和图2品牌规则为依据，本次只制作{{本次渠道}}，比例{{目标比例}}。保持图3主体身份、活动主色、核心图形、品牌字体气质和标志安全留白；按渠道重新组织层级，而不是拉伸母版。{{必留文字}}逐字保留并位于{{安全区}}内；只可删除{{可删项}}。背景扩展、裁切和文字换行要服务当前渠道，主体不得被界面遮挡区切断。不要同时输出其他渠道、尺寸说明、设备样机或系列拼贴，不添加平台标志、账号、互动数字或新文案。只输出一张渠道成品。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

渠道比例和遮挡区应来自实际平台当前规范；本卡不自动推断或保证平台审核通过。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 横幅渠道

```text
以图1至图3为依据，只制作{{横幅渠道}}的{{横幅比例}}成品。保持品牌识别与主体，逐字保留{{必留文字}}于{{安全区}}，只删{{可删项}}，不同时输出竖版。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，重新附图1、图2。本轮只修正{{品牌或安全区偏差}}，恢复{{正确规则}}；本渠道其他内容不变。
```
