# T75 · 起绒面料顺逆毛四方向光泽对照

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在固定机位与固定光源下记录同一块起绒面料旋转四个方向的真实明暗与纹理，避免把方向性色差误当不同颜色或自动统一光泽。

## 准备材料与变量

图1至图4：同一块面料在0°、90°、180°、270°的固定机位实拍；图5：织边、毛向箭头与样品编号微距；图6：相机、光源和人工状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{面料}}` | 深绿色短绒布样V07 |
| `{{方向}}` | D0毛向朝上、D90朝右、D180朝下、D270朝左 |
| `{{锁定}}` | 同一样品、同一白平衡、同一曝光、左上方条形光源L1 |

## 拿来就用的具体示例

四张照片必须是同一样品并固定相机和光源设置，方向和问题由人工记录；生成对照不能作为测色、纤维或耐久测试。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“同一种绿色，换方向会换光泽”2×2板。使用同一深绿色短绒布样V07在D0朝上、D90朝右、D180朝下、D270朝左的实拍；同一白平衡、曝光和左上条形光L1。织边与毛向箭头随样品旋转，光泽和暗带按各图，不统一亮度或镜像。标“D0/D180明暗差已记录；D90右边缘压痕E6；D270未见新增问题”。不判断成分、耐磨、掉毛或色牢度。只输出一张图。
```


## 完整提示词

```text
依据图1至图6制作16:9“{{标题}}”2×2对照板，四格严格为{{方向}}。每格只使用{{面料}}对应方向的真实照片，保持{{锁定}}，样品在画面中等比例旋转，织边、裁口和图5毛向箭头随样品一起转动。绒毛高光、暗带、压痕、纹理密度和边缘阴影只按各方向实拍，不把四格调成同一亮度，不把D180镜像成D0，也不将色差夸张为四种面料。每格角落标D0/D90/D180/D270，底部逐字写“{{人工记录}}”；E6只在D90真实位置小框标注。不要生成色卡数值、纤维剖面、手触或刷毛动作，不推断绝对色差、成分、耐磨、掉毛、色牢度、批次一致或质量等级。只输出一张对照板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

视觉方向对照不替代仪器测色、纤维鉴定、摩擦色牢度、耐磨或批量检验。
