# T344 · 同主视觉跨尺寸审定断行方案单版适配

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Posters & Typography · 本库原创设计**

把同一标题适配到不同比例时，只采用人工批准的目标尺寸断行方案，避免模型擅自缩字、改字、增删标点或把一句标题拆坏。

## 准备材料与变量

图1：已验收母版；图2：无字主体层；图3：品牌字体参考；图4：各尺寸人工断行表；图5：本轮安全区与最小字号记录；图6：保护项遮罩。每次只指定一个尺寸。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{目标}}` | 小红书3:4封面 |
| `{{标题文字}}` | 轻装出发，自在抵达 |
| `{{审定断行}}` | 第一行‘轻装出发’；第二行‘自在抵达’；逗号移除已批准 |
| `{{副标题}}` | 城市通勤系列 |
| `{{字号规则}}` | 主标题两行等字号，不低于人工记录的72 px；副标题不低于30 px |
| `{{安全区}}` | 四边7%，顶部界面避让区12% |
| `{{保护项}}` | 完整双肩包、肩带、拉链、标志和人物右手 |

## 拿来就用的具体示例

断行、标点变更和最小字号必须由设计人员逐尺寸批准；模型不能自行决定哪些字词可删改。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
把母版适配为小红书3:4封面。完整保留双肩包、肩带、拉链、标志与人物右手，不拉伸。主标题只分两行：“轻装出发”/“自在抵达”，按批准方案移除逗号；副标题只写“城市通勤系列”。主标题等字号且不低于72 px，副标题不低于30 px，遵守四边7%与顶部12%避让区。数值不显示，不加平台UI、价格或新文案。只输出一张图。
```


## 完整提示词

```text
把图1母版适配为{{目标}}，本次只输出3:4一张成品。主体以图2为准，完整保护{{保护项}}，通过扩展背景和重排完成，不拉伸主体。主标题原文为“{{标题文字}}”，成片严格采用“{{审定断行}}”；副标题只写“{{副标题}}”。执行“{{字号规则}}”与“{{安全区}}”，这些数值不显示。不得自行恢复逗号、替换近义词、加第三行、压缩字宽、缩到阈值以下或用装饰遮字；若空间不足，优先缩小非保护装饰和扩大留白，不裁商品。不要增加平台标志、账号、互动数、价格和新文案。只输出一张成品图。
```

## 参数设置

建议画布：`1536x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

像素字号和安全区需在真实导出文件中测量；图片模型只能按给定版式约束生成，不能证明达到精确像素阈值。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
