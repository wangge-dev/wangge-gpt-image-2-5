# T352 · 绒面纺织商品跨场景顺逆毛明暗身份继承

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

同一绒面商品在平铺、折叠和使用场景中继承人工标记的绒毛方向、顺逆毛明暗与压痕位置，避免换场景后材质变成塑料、麂皮贴图或随机双色。

## 准备材料与变量

图1：同一商品平铺顺光；图2：逆光；图3：折叠状态；图4：绒毛微距；图5：人工毛向箭头与压痕图；图6：已验收场景P1；图7：本轮文案。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 墨绿色短绒抱枕 |
| `{{本轮}}` | P2沙发使用场景 |
| `{{毛向}}` | 正面F1自上向下；侧边F2向后；包边F3沿缝线环绕 |
| `{{明暗}}` | 顺毛区S1深墨绿且柔和；逆毛区R1稍亮但仍为同一颜色；压痕D1只在左下实拍位置 |
| `{{结构}}` | 方形比例、四周包边、右下隐形拉链、填充饱满度和缝线 |
| `{{标题}}` | 光走过，绒面有方向 |
| `{{说明}}` | 色泽变化来自同一绒面在不同方向下的可见状态 |

## 拿来就用的具体示例

顺光、逆光、折叠和微距必须来自同一商品，并提供人工毛向；不同批次或不同色号不能混作连续材质证据。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成墨绿色短绒抱枕P2沙发场景3:4图。F1向下、F2向后、F3沿包边，S1深墨绿、逆毛R1稍亮但仍同色；D1仅保留左下一个。方形、包边、右下拉链和缝线不变。只写“光走过，绒面有方向”及指定说明。不变塑料或皮革，不写成分和耐磨。只输出一张图。
```


## 完整提示词

```text
依据图1至图7只生成{{商品}}{{本轮}}一张3:4图。保持{{结构}}，按“{{毛向}}”让绒毛随枕面曲率和折角连续；严格表现“{{明暗}}”，S1/R1是同一墨绿色的方向性明暗，不得分成两种面料或大块染色。P1只提供米灰沙发、右侧窗光和构图节奏，本轮商品身份仍以图1至图5为准。标题只写“{{标题}}”，说明只写“{{说明}}”。不要把绒面变成光滑塑料、长毛、皮革或均匀噪点，不复制D1，不抹拉链和针脚，不写面料成分、克重、防污、耐磨、抗菌或色牢度。只输出一张成品图。
```

## 参数设置

建议画布：`1536x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

方向性明暗不等于标准颜色或质量结论；面料成分、色牢度、耐磨与批次一致性需另行检测。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
