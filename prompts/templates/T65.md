# T65 · 线下吊旗吊点与成品方向映射

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把已批准吊旗正反稿、真实成品角点和现场吊点逐一映射，预演悬挂方向与绳路，不让视觉图冒充承载或安装结论。

## 准备材料与变量

图1：已批准正面稿；图2：已批准背面稿；图3至图4：真实成品正反面；图5：现场吊点全景；图6：人工吊点、角点、绳路和方向表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{物料}}` | 双面矩形吊旗 |
| `{{映射}}` | 顶轨H1→吊绳L1→成品左上角C1；顶轨H2→吊绳L2→成品右上角C2 |

## 拿来就用的具体示例

吊旗稿、成品和现场照片需为同一项目，吊点与方向由现场人员提供；视觉连线不能证明结构承载、施工可行或安装安全。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“吊点、绳路与成品方向一一对应”。左栏放双面矩形吊旗批准正面稿F与背面稿B，中栏放真实正反成品并标C1/C2，右栏放现场顶轨H1/H2。按H1→L1→C1、H2→L2→C2分别连线；面向主通道显示F，背向主通道显示B。状态写“H1/C1已核对；H2/C2待现场复核D11”。不添孔位或挂钩，不判断承重、风载、许可或安装安全。只输出一张图。
```


## 完整提示词

```text
依据图1至图6制作16:9“{{标题}}”映射板。左栏上下放已批准的{{物料}}正面稿F与背面稿B，不重排文字；中栏放真实成品正反面并标C1、C2及正反方向；右栏原样展示现场顶轨与吊点H1、H2。严格按“{{映射}}”绘制两条独立细线，线序为吊点→吊绳→成品角点，不交叉、不穿过文字。方向只写“{{方向}}”，人工状态逐字写“{{人工状态}}”，D11用红框标在对应链路，不能凭透视补尺寸或判断左右互换。保持正反稿、成品图文朝向和现场机位，不生成额外孔位、挂钩、钢索或安装动作。不要给出承重、风载、层高、防火、施工许可、安装安全或可直接落地结论。只输出一张静态映射板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

映射板只服务视觉沟通，施工前仍须由合格人员复核结构、尺寸、材料、法规与安全方案。
