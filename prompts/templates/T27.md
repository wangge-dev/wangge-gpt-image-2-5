# T27 · 连续编辑的已验收状态锁定

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Other Use Cases · 本库原创设计**

在多轮局部编辑中明确当前底图、已验收项和本轮唯一改动，减少回退与连带漂移。

## 准备材料与变量

图1：上一轮已验收结果；图2起：本轮需要重新核对的原始参考。提供已验收锁定清单、本轮单一改动和验收文字。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{已验收锁定}}` | 人物身份、商品外形、蓝色背景、左上标题、底部日期 |
| `{{本轮唯一改动}}` | 把人物右手中的白色杯子替换为图2黑色保温杯 |
| `{{本轮验收}}` | 杯盖、杯身比例和标志位置与图2一致，握持自然 |

## 拿来就用的具体示例

准备上一轮已验收图、本轮物件原始参考、锁定清单和单一改动；每轮保存结果并重新作为下一轮图1。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1是当前唯一底图，不回到旧版本。锁定人物身份、商品外形、蓝色背景、左上标题和底部日期。本轮只把人物右手中的白色杯子替换为图2黑色保温杯；杯盖、杯身比例和标志位置按图2，握持自然。只重绘手掌与杯子接触所需最小区域，其他人物、文字和版式不动。只输出一张修改图。
```


## 完整提示词

```text
图1是当前唯一底图，不回到更早版本。锁定并保持{{已验收锁定}}；图2起只作为本轮局部证据。本轮唯一执行：{{本轮唯一改动}}。验收标准：{{本轮验收}}。只重绘完成该改动所必需的最小区域，边缘、遮挡、光向、透视和噪点与图1衔接；不得重排版式、改写文字、改变人物身份、重新设计商品或顺手优化其他区域。若参考不足，不猜测隐藏结构，保留图1状态。只输出一张本轮结果图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

连续编辑应保存每轮已验收结果和锁定清单；生成式编辑不能保证未选区域逐像素不变，关键文件仍需人工比对。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 文字轮次

```text
图1是当前唯一底图。锁定{{已验收锁定}}；本轮只把{{指定文字区域}}逐字改为“{{正确文字}}”，其他文字与像素区域不动。只输出一张本轮结果图。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
若本轮结果不合格，仍以图1为底图重新执行{{本轮唯一改动}}，只修正{{失败点}}；不要在失败结果上继续叠改。
```
