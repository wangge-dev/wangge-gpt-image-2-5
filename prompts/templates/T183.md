# T183 · 包装盲文点阵单元局部修正与压凸光影继承

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

按人工审定的六点位矩阵只修正指定盲文单元，并继承相邻真实凸点的高度外观、边缘与掠射光影，不让模型翻译或判断合规。

## 准备材料与变量

图1：当前合格包装盲文区域；图2：人工编号1至6的目标单元C1；图3：审定占位矩阵；图4：相邻保留单元C2微距；图5：平光参考；图6：掠射光参考；图7：唯一遮罩M-C1。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{对象}}` | 纸盒盲文区BR29 |
| `{{改点}}` | C1人工矩阵1/2/4点凸起，3/5/6点不凸起 |
| `{{工艺锚点}}` | C2的圆点直径外观、纸纤维边缘、左上短高光与右下短阴影 |
| `{{保护}}` | C2及其他单元、单元间距、纸纹、印刷文字、盒型、光源、阴影与背景 |
| `{{记录}}` | C1点位来自人工审定图；第4点边缘待复核D111 |
| `{{标题}}` | 只按人工点位图修一个盲文单元，其他点阵与纸面不动 |

## 拿来就用的具体示例

提供当前合格底图、编号明确的目标单元、人工审定六点矩阵、相邻真实凸点及同光源参考；模型不得自行翻译盲文。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
编辑BR29当前合格底图，只在M-C1按人工矩阵让1/2/4点凸起，3/5/6点保持不凸；不翻译、不镜像。凸点继承C2的纸纤维边缘、左上高光和右下短阴影，其他单元与纸面不变。底部写“C1点位来自人工审定图；第4点边缘待复核D111”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7编辑同一张{{对象}}底图，只执行“{{改点}}”。M-C1是唯一修改区，点位编号严格按图2视角，不旋转、不镜像；凸起点继承{{工艺锚点}}，未占位点保持原纸面。严格保护{{保护}}。不可由中文或语义自行推导点位、增加第7点、改变其他单元、把凸点画成印刷圆点或金属铆钉、统一复制高光、重排间距、重绘纸盒或宣称文字正确。画面底部小字逐字写“{{记录}}”，D111只框第4点。只输出一张修改后的核对图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

核对图不替代盲文翻译、点位审定、凸点尺寸测量、可触读性、印后加工、法规或无障碍合规审核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
