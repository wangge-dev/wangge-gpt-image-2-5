# T49 · 宠物穿戴用品尺码证据示意

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把真实宠物量体数据、商品实测尺寸和授权佩戴照分栏呈现，说明当前样本的穿戴位置而不自动推荐尺码。

## 准备材料与变量

图1：用品平铺与结构；图2：商品人工尺寸表；图3：获准使用的真实宠物侧面照；图4：同一宠物实际佩戴照；图5：该宠物人工量体表。提供测量口径、样本尺码和免责声明。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{用品}}` | Y字形犬用胸背 |
| `{{样本}}` | 成年比熊犬A |
| `{{商品尺寸}}` | M码：颈围34厘米、胸围46厘米、背片长18厘米 |
| `{{宠物量体}}` | 颈根围31厘米、胸围43厘米 |
| `{{观察点}}` | 前带位于胸骨前方、背片居中、腋下留出可见间距 |
| `{{标题}}` | 当前样本佩戴位置参考 |
| `{{声明}}` | 仅记录犬A与当前M码样品，不构成通用尺码推荐 |

## 拿来就用的具体示例

必须有同一宠物的授权照片、人工量体表和当前样品实测表；没有真实佩戴照时只能做平铺测量说明，不能合成后宣称适配。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9 Y字形犬用胸背尺码证据示意。左栏按实测表写“M码：颈围34厘米、胸围46厘米、背片长18厘米”；中栏在成年比熊犬A侧面照标量体位置，只写“颈根围31厘米、胸围43厘米”；右栏按真实佩戴照展示前带位于胸骨前方、背片居中、腋下留出可见间距。数字不从照片估算。顶部写“当前样本佩戴位置参考”，底部写“仅记录犬A与当前M码样品，不构成通用尺码推荐”。不写合身、安全、防挣脱或适用品种。只输出一张图。
```


## 完整提示词

```text
依据图1至图5制作16:9{{用品}}尺码证据示意。左栏展示图1用品平铺，三条尺寸线的起止点严格按图2测量口径，并逐字写“{{商品尺寸}}”；中栏展示{{样本}}图3侧面照，用短引线标出图5量体位置，只写“{{宠物量体}}”；右栏严格依据图4呈现同一宠物穿戴同一用品，带体路径、扣具数量、连接点、颜色和松紧外观不变，只标“{{观察点}}”。三个栏位不得用画面比例互相推算数字，商品尺寸和宠物量体不可混写。顶部只写“{{标题}}”，底部完整写“{{声明}}”。不要生成适合、合身、舒适、防挣脱、安全、承重、适用品种或建议购买尺码等结论。只输出一张三栏示意图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

单只宠物的视觉示意不能外推到品种、体重区间或安全适配；购买与使用需由真实尺码规则和人工确认决定。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
