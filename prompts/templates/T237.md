# T237 · 转舌锁前面钥匙方向与背面凸轮同轴继承

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把面板正面的钥匙/旋钮方向与背面的转舌凸轮通过同一轴逐状态对应，锁定前后观察面的旋转关系和中文开关标记。

## 准备材料与变量

图1：正面解锁态C0；图2：对应背面凸轮态C0-B；图3：正面半转态C1；图4：对应背面凸轮态C1-B；图5：正面锁定态C2；图6：对应背面凸轮进入承边K1；图7：轴A1、凸轮L1、正面中文“开/关”与人工状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{对象}}` | 柜门转舌锁CL25 |
| `{{状态}}` | C0正面“开”且背面凸轮离开K1；C1半转；C2正面“关”且L1按实拍位于K1后 |
| `{{结构锚点}}` | 正面旋钮F1、贯穿轴A1和背面凸轮L1为同一组件；门板与承边K1固定；前后状态必须成对 |
| `{{保护}}` | 门板、锁芯外圈、旋钮、轴端、凸轮、承边、中文开关标记、划痕、光源和背景 |
| `{{记录}}` | C0/C1前后角度已核对；C2 L1/K1遮挡待复核D165 |
| `{{标题}}` | 正面转多少，背面同轴凸轮按实拍同步到对应位置 |

## 拿来就用的具体示例

提供同一转舌锁各状态成对的正面和背面实拍、轴/凸轮/承边编号及审定文字；不得由正面角度推算未提供的背面。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成CL25的C0、C1、C2三组正背面对照。F1/A1/L1为同一组件，门板和K1固定；C0正面“开”且L1离开K1，C2正面“关”且L1按实拍位于K1后。底部写“C0/C1前后角度已核对；C2 L1/K1遮挡待复核D165”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7生成同一{{对象}}的C0-C2前后面对照，只执行“{{状态}}”。F1/A1/L1保持同一组件并继承{{结构锚点}}；每个状态正面与背面必须成对，中文“开/关”只属于固定面板标记，不随旋钮乱转，L1仅按对应背面实拍改变角度。严格保护{{保护}}。不可让前面转动而背面不动、镜像旋转方向、复制第二片凸轮、让K1随凸轮移动、穿透门板、透视显示锁芯内部或自动判断锁止。底部逐字写“{{记录}}”，D165只框C2的L1/K1。只输出一张三状态前后对照图。
```
