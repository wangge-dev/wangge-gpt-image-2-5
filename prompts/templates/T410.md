# T410 · 同一电商成片单变量返工与保留清单

[全部提示词](../README.md) · [首页](../../README.md)

**分类：编辑与一致性 · 本库原创设计**

在已通过人工检查的电商成片上一次只改一个变量，并把商品身份、版式、文字和光线列成保留清单，便于定位是哪一项返工造成漂移。

## 准备材料与变量

图1必需：上一轮人工批准成片，作为本轮唯一编辑底图。图2可选：同一商品原始参考，只校验底图已有可见特征，不替代底图、换角度或补隐藏面。图3可选：仅针对本轮变更的参考或允许修改区遮罩；没有它时可用明确文字定义材质、颜色和范围。人工文字记录必需：一个具体变更及保留清单，不需要转成图片。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{成片}}` | 已批准的帆布包详情首屏V3 |
| `{{唯一变更}}` | 仅将商品和文字后方的浅灰石材背景改成米白哑光纸张，不改变商品下方接触阴影 |
| `{{保留清单}}` | 商品轮廓、本色、标签、主体大小与位置、两行标题及位置、全部安全边距、接触阴影、光向和4:5裁切 |
| `{{验收}}` | 人工比较批准底图；除指定背景外出现商品、文字或布局漂移就退回 |

## 拿来就用的具体示例

只需一张已人工批准的帆布包详情首屏；背景材质、变更范围及保留项在正文中明确，不强制附第二张商品照或第三张背景图。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以图1已批准的帆布包详情首屏V3为唯一编辑底图。本轮只将商品和文字后方的浅灰石材背景改为米白哑光纸张，范围不包括商品、文字、商品下方的原接触阴影。没有其他参考图，纸张仅指米白哑光、轻微纤维感，不新增纸张折边、道具或图案。保留商品轮廓、帆布本色、标签、主体大小与位置、两行标题的逐字内容及位置、全部安全边距、接触阴影、光向和4:5裁切。背景不得穿入商品边缘或遮挡文字，不顺手改字、调色、转角度或重排。只输出与图1同尺寸一张图，不附说明或版本号。结果由人工和图1对比；保护项漂移则丢弃该稿并回到图1再改。若必须保证原区域像素完全相同，使用设计工具局部合成，不把提示词当像素锁定工具。
```


## 完整提示词

```text
以图1“{{成片}}”为唯一批准底图。本轮唯一变更为“{{唯一变更}}”；允许区域仅为这条记录明确指定的区域，完整保留{{保留清单}}。图2只有实际提供时才用于核对商品身份，不拿原照替换成片角度；图3只有实际提供时才控制变更外观或区域，其余职责为零。没有图3时依据明确文字执行，不虚构已上传参考；文字无法确定范围或外观时先请求明确该项，不自行扩大修改。

输出一张与图1相同尺寸和裁切的修改图，不重新排版、不顺手修字、调色或优化商品。不改变商品边缘、本色、比例、标签、数量、镜头和光向；换背景时不让新背景侵入实体边缘、毛边或覆盖原接触阴影。透明透射或反射区域若需同步改动，必须预先列入唯一变更的允许区，否则不擅改；与新背景存在冲突时先请求人工明确范围。新背景照明冲突时修改背景，不修改受保护商品表面；必须改变接触阴影或商品反射才成立的方案另开人工批准轮次，本轮不做。不要版本号、解释或新卖点。

输出后由人工按“{{验收}}”检查，图片模型不自称通过核验。发现保护项漂移时退回图1重新改，不叠加失败稿。保护清单表达编辑目标，不保证像素不变；需要区域像素完全一致时，另用设计工具把批准的局部修改合成回原图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

只需批准底图和明确的单变量记录；原商品照、变化参考、遮罩可选。每轮由人工检查，不把Keep清单说成像素冻结；像素完全一致由设计工具合成。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
回到图1已批准底图，不把失败稿作为新母稿。仍只执行{{唯一变更}}，本次纠正允许区内的{{单一具体问题}}；{{保留清单}}不变。不把商品边缘、接触阴影或其他漂移顺手重绘；保护区修复须另经人工确定范围。只输出同尺寸一张修改图。
```
