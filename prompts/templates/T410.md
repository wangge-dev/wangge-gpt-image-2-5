# T410 · 同一电商成片单变量返工与保留清单

[全部提示词](../README.md) · [首页](../../README.md)

**分类：编辑与一致性 · 本库原创设计**

在已通过人工检查的电商成片上一次只改一个变量，并把商品身份、版式、文字和光线列成保留清单，便于定位是哪一项返工造成漂移。

## 准备材料与变量

图1：上一轮已批准成片；图2：同一商品原始参考；图3可选：只针对本轮变量的参考图或遮罩；图4：人工保留清单与本轮唯一变更记录。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{成片}}` | EC系列详情首屏V3 |
| `{{唯一变更}}` | 把背景从浅灰石材改为米白纸张 |
| `{{保留清单}}` | 商品轮廓、标签文字、主体占比、标题位置、价格区、阴影方向和裁切比例 |
| `{{验收}}` | 只比较背景变化；商品与文字漂移则退回，不接受顺手优化 |

## 拿来就用的具体示例

上一轮成片必须已人工批准；变更记录只写一个变量，保留清单由人工填写，图3缺失时不能凭空改背景。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以EC系列详情首屏V3为底图，图2核对米白折叠水杯，图3只提供米白纸张背景。唯一变更是“把背景从浅灰石材改为米白纸张”；商品轮廓、折叠层数、标签、主体占比、标题位置、价格区、阴影方向和4:5裁切全部保持。只输出同尺寸一张图，不顺手改文案或重排版式；商品或文字漂移就退回。
```


## 完整提示词

```text
以图1为已批准底图、图2为商品身份依据、图3仅提供{{唯一变更}}的参考。严格执行“{{唯一变更}}”，并完整保留{{保留清单}}；本轮只输出一张同尺寸成片，不重排版式、不重写文字、不改变商品颜色、比例、标签、配件数量、镜头或光向。若{{唯一变更}}与原光线冲突，只调整背景，不修改商品表面来迎合。底部不加版本号、解释或新卖点。验收按“{{验收}}”执行，无法只改一个变量时停止，不提交混合修改。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

单变量返工用于定位漂移原因，不等于模型能像素级冻结；每轮仍需人工对比商品身份、文字、边缘与版式。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
只修正{{唯一变更}}造成的{{背景穿帮、边缘溢色或接触阴影}}；{{保留清单}}全部不变，其他区域不重绘。
```
