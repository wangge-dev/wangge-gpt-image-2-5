# T166 · 立体包装正侧顶三面中文局部改字锁定

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

对同一立体包装的正面、侧面和顶面分别绑定遮罩、旧新文字与阅读方向，只改指定字区而不重绘结构和其他面。

## 准备材料与变量

图1：当前合格包装三分之二视角底图；图2：正面遮罩M-F；图3：侧面遮罩M-S；图4：顶面遮罩M-T；图5：三面人工审定旧新文字表；图6：对应面位正视参考。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{对象}}` | 茶叶礼盒PK73 |
| `{{改字}}` | M-F“春日茶”→“春山茶”；M-S“净含量 80g”→“净含量 96g”；M-T“礼赠装”→“分享装” |
| `{{保护}}` | 盒型、透视、正面标志、非遮罩文字、纹样、封边、阴影与背景 |
| `{{记录}}` | 三处新文已审定；M-T换行待复核D94 |
| `{{标题}}` | 三个实体面各改一处，文字随原面透视但不串面 |

## 拿来就用的具体示例

提供当前合格底图、三个不重叠遮罩、人工审定旧新文字表和各面正视参考；文字不得由模型自行改写。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
编辑PK73当前合格底图：M-F把“春日茶”改为“春山茶”；M-S把“净含量 80g”改为“净含量 96g”；M-T把“礼赠装”改为“分享装”。三处各守原面透视，其他文字、标志、纹样、盒型、封边、阴影和背景不变。底部写“三处新文已审定；M-T换行待复核D94”。不输出对照拼图。只输出一张成品图。
```


## 完整提示词

```text
依据图1至图6编辑同一张{{对象}}底图，只执行“{{改字}}”。M-F、M-S、M-T为三个互不相交的唯一修改区；新文字逐字准确，字重、字号、行距、颜色和表面印刷质感匹配各自旧字，并分别服从正面、侧面、顶面的真实透视与遮挡。严格保护{{保护}}。不可把侧面文字搬到正面、把顶面文字水平铺平、自动翻译其他文字、扩大遮罩、重绘包装、增加卖点或输出前后拼图。画面底部小字逐字写“{{记录}}”，D94只框顶面换行。只输出一张修改后的成品图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

局部改字图不替代法务、净含量、标签规范、印前文件、色彩和实物打样审核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
