# T19 · 场景叙事

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Scenes & Storytelling · 通用来源改写 · 按 2.5 文档适配，未生图实测**

生成分镜、世界观、故事场景和情绪节奏。

## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{故事}}` | 旅人刚发现旧信中描述的小屋，停在门前 |
| `{{角色}}` | 背帆布包的成年旅人 |
| `{{光线}}` | 雨后傍晚，门缝暖光与室外冷光对比 |

## 完整提示词

```text
创作一张叙事场景图：{{故事}}。主角为{{角色}}，图1若提供则作为身份参考。前景放一个能提示原因的小物件，中景清楚表现关键动作，远景交代地点。光线{{光线}}，以视线与动作引导观看，不在单张画面里重复同一角色来表示时间流逝。不要对白或字幕。
```

## 参数设置

建议画布：`1536x1024`；模型选择及格式见[模型说明](../../guides/models.md)。这是本库的起步建议，不是效果保证。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 布局或风格变体

```text
创作一张叙事场景图：{{故事}}。主角为{{角色}}，图1若提供则作为身份参考。前景放一个能提示原因的小物件，中景清楚表现关键动作，远景交代地点。光线{{光线}}，以视线与动作引导观看，不在单张画面里重复同一角色来表示时间流逝。不要对白或字幕。

本次版本调整（以此段替换基础正文中的对应布景、布局或风格，未提及要求继续保留）：
改为四格静态分镜：发现信、沿路寻找、来到小屋、停在门前。各格保持同一角色，按左上到右下排列。
```

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
编辑上一张结果，只修正与本次输入原文或参考图不一致的文字、形态与对应关系。准确内容、主体身份、已确认的配色和构图保持不变。不要添加新的设计元素。
```

## 对照改写说明

- 保留情节与环境叙事，限定单张关键瞬间，避免冒充视频输出。

适配依据：[2.5 适配规则](../../guides/adaptation.md)。这些方法可能同样适用于其他模型，不宣称 2.5 独占。
