# T19 · 场景叙事

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Scenes & Storytelling · 通用来源改写**

生成分镜、世界观、故事场景和情绪节奏。

## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{故事}}` | 旅人刚发现旧信中描述的小屋，停在门前 |
| `{{角色}}` | 背帆布包的成年旅人 |
| `{{光线}}` | 雨后傍晚，门缝暖光与室外冷光对比 |
| `{{四格情节}}` | 用户故事中的四个连续动作，按1至4填写，不另编找信等固定故事 |

## 完整提示词

```text
创作一张叙事场景图：{{故事}}。主角为{{角色}}，图1若提供则作为身份参考。前景放一个能提示原因的小物件，中景清楚表现关键动作，远景交代地点。光线{{光线}}，以视线与动作引导观看，不在单张画面里重复同一角色来表示时间流逝。不要对白或字幕。
```

## 参数设置

建议画布：`1536x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 布局或风格变体

```text
制作2列2行静态故事分镜，故事为{{故事}}，四格依次呈现{{四格情节}}，不得更换故事。主角{{角色}}，图1如提供作为身份参考，每格同一角色、服装和配色。光线{{光线}}，每格一个明确动作，阅读顺序从左上到右下。不要对白、字幕或无关情节。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，重新附所需原始参考。本轮只修改故事图中的{{角色动作}}：改成{{本次情节要求}}，保持同一角色、地点和其他情节元素。只输出这一张修改后的图。
```
