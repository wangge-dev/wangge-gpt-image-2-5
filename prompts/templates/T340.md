# T340 · 详情页两模块之间专用背景过渡桥页

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

当相邻模块背景机制不同，单独生成一张只承担色彩、纹理和光线过渡的桥页，避免硬切，同时不混入新的商品事实或营销卖点。

## 准备材料与变量

图1：上游已验收模块A；图2：A底部边界条；图3：下游已验收模块C；图4：C顶部边界条；图5：人工过渡路径；图6：允许装饰清单。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{桥页}}` | B材质到场景过渡 |
| `{{上边状态}}` | 暖米白纯色、细砂颗粒、左上柔光 |
| `{{下边状态}}` | 浅鼠尾草绿、轻微纸纹、右后方窗影 |
| `{{过渡路径}}` | 上方35%保持A；中间30%缓慢混合；下方35%进入C |
| `{{允许装饰}}` | 一条由左向右变淡的细曲线 |
| `{{禁止内容}}` | 商品、包装、人物、标题、卖点、参数、按钮、标志和模块编号 |

## 拿来就用的具体示例

应提供上下游已验收边界条和人工过渡比例；桥页不负责修正两端成片，也不应借机加入缺失卖点。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成B材质到场景过渡3:4桥页：上35%延续暖米白、细砂颗粒和左上柔光；中30%缓慢混合；下35%进入浅鼠尾草绿、轻纸纹和右后窗影。只保留一条由左向右变淡的细曲线。不得出现商品、包装、人物、文字、标志、按钮、参数或模块编号，不做色带和拼贴。只输出一张无文字图。
```


## 完整提示词

```text
依据图1至图6，只生成详情页{{桥页}}一张3:4竖图。顶部严格为“{{上边状态}}”，底部严格为“{{下边状态}}”，按“{{过渡路径}}”连续变化；只可加入“{{允许装饰}}”。图1和图3仅提供边界状态，不得把其中商品、文字、道具或构图复制进桥页。整张图不得出现{{禁止内容}}。过渡必须自然且物理可信，不做明显渐变色带、左右拼接、撕纸分割、页面接缝、拼贴框或突兀光源跳变。不要生成新的场景物件来解释过渡。只输出一张无文字桥页。
```

## 参数设置

建议画布：`1536x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

桥页会增加页面长度，应只在两端视觉确实无法直接衔接时使用；最终无缝程度需在完整长图预览中检查。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
