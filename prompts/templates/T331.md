# T331 · 商品灰卡色卡同光位原图与人工白平衡状态记录

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把商品、灰卡和色卡在同一光位的原始照片并列，仅记录人工提供的拍摄与校色状态，不自动校色或输出绝对色值。

## 准备材料与变量

图1：商品与灰卡同框原图A0；图2：商品与色卡同框原图A1；图3：撤卡商品原图A2；图4：人工拍摄参数记录；图5：人工白平衡状态；图6：色卡格编号；图7：问题位。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 雾蓝布艺收纳盒CC72 |
| `{{照片}}` | A0灰卡同框、A1色卡同框、A2撤卡商品 |
| `{{固定条件}}` | 同一实物、机位、光源、曝光设置和背景；原图不得调色 |
| `{{人工状态}}` | 灰卡位置G1已核对；色卡方向C1已核对；白平衡采用人工记录WB-01；A2右侧局部偏色待复核D258 |
| `{{显示规则}}` | 只抄人工参数和状态，不从图片计算RGB/Lab/色温或自动校正 |
| `{{标题}}` | 先保留同光位灰卡与色卡证据，再记录人工校色状态 |

## 拿来就用的具体示例

提供同一拍摄条件下的灰卡同框、色卡同框和撤卡原图，以及人工参数与白平衡记录；不同光位的色卡不能用作本板依据。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作CC72的A0灰卡、A1色卡、A2撤卡原图记录板，三图不调色。写“灰卡位置G1已核对；色卡方向C1已核对；白平衡采用人工记录WB-01；A2右侧局部偏色待复核D258”“不从图片计算色值或自动校正”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”拍摄记录板。按{{照片}}原样排列并注明“{{固定条件}}”；A0标G1，A1按图6标C1方向，A2只框D258。右侧逐字写“{{人工状态}}”和“{{显示规则}}”。不可改变三图颜色、曝光或对比度，不得自动白平衡、吸取色值、生成缺失色卡格、把A0/A1调成标准色或声称A2颜色准确。不要输出RGB、Lab、色差、色温、材质色名、质量等级或平台色彩保证。只输出一张记录板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

记录板不替代色彩管理、校准显示器、测色仪、ICC流程、白平衡计算、色差测量、印刷打样或实物确认。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
