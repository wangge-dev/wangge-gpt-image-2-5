# T360 · 登山杖多节伸缩刻度与锁扣逐段状态核对

## 拿来就用的具体示例

收拢、两锁扣微距、中间和完成状态需来自同一根杖，并提供人工刻度记录；不得从商品页规格替代实拍状态。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作TP82 S0-S2三栏：S1只开K1把B拉至人工标记105；S2关K1，再开K2把C拉至110并按实拍关闭。K1只管A/B，K2只管B/C，三节共轴。不得相加刻度推算总长。写“B=105与C=110为人工刻度记录；S2 K2闭合边待复核D268”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9{{装备}}“{{标题}}”三状态板，依次展示“{{状态}}”。保持{{节段}}身份和“{{锁扣}}”，刻度数字只抄人工记录；不可从各节刻度相加、像素测量或推算整杖长度。伸缩节共轴，拉出部分只按实拍，S1的K2与C保持未操作状态。不得复制锁扣、交换K1/K2、让管节穿透、补内部弹簧或把S2画成受力弯曲。底部写“{{记录}}”，D268只框K2。不要出现人物、山路、撑地动作、承重、锁紧强度、适用身高或安全结论。只输出一张核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

状态板不替代实际长度、锁紧力、承重、疲劳、杖尖抓地、适用身高或户外安全测试。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
