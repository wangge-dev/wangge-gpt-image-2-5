# T348 · 同系列多色SKU瓶身盖色标签三元隔离

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

展示同系列多色SKU时，把每款瓶身色、盖色与标签文字绑定为不可拆的三元组，避免相邻颜色渗透、串盖和串字。

## 准备材料与变量

图1至图4：同系列SKU A-D独立中性光照片；图5：人工瓶身/盖色/标签表；图6：排列草图；图7：统一背景和光线参考。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{系列}}` | 四款护手霜 |
| `{{三元组}}` | A鼠尾草绿管身+白盖+‘森林’；B淡粉管身+白盖+‘花园’；C浅蓝管身+银盖+‘海风’；D米黄管身+棕盖+‘暖木’ |
| `{{排列}}` | A、B、C、D从左到右，各一支，标签朝前 |
| `{{共性}}` | 相同管型、肩部、封口和系列标志位置 |
| `{{光线}}` | 中性柔光，不用彩色环境光 |
| `{{标题}}` | 四种气息，各自清楚 |

## 拿来就用的具体示例

每款SKU需有中性光身份照及人工三元组表；标签文字无法确认时保留原图可见状态，不自行识别或补写。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作四款护手霜4:5图，A绿管白盖“森林”、B粉管白盖“花园”、C蓝管银盖“海风”、D黄管棕盖“暖木”，从左到右各一支，标签朝前。管型与系列标志位置一致，但颜色、盖子和文字绝不串组。中性柔光、浅灰白背景，只写“四种气息，各自清楚”。不加容量、成分或功效。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作{{系列}}4:5系列图。按“{{排列}}”展示，严格把“{{三元组}}”作为四个不可拆分身份组；保持{{共性}}，但不得用一款的颜色、盖子或标签覆盖另一款。商品之间留出可辨边界，使用{{光线}}，背景浅灰白，接触阴影独立。标题只写“{{标题}}”，标签文字分别只出现于对应管身一次。不要混色渐变、交换瓶盖、统一标签、复制某一SKU凑四支，也不增加容量、香型描述、成分、功效、价格和礼盒。只输出一张成品图。
```
