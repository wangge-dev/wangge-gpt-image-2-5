# T32 · 复杂中文层级海报

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Posters & Typography · 本库原创设计**

将标题、副标题、日期地点、三项要点和行动语分层排版，限制文字数量与重复。

## 准备材料与变量

图1：主视觉素材；提供主标题、副标题、日期、地点、三项短要点和行动语，另给不可拆分词与允许换行。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{主标题}}` | 把想法做出来 |
| `{{副标题}}` | AI视觉实战工作坊 |
| `{{日期地点}}` | 9月26日 14:00｜创意中心3楼 |
| `{{三项要点}}` | 构图拆解；中文排版；局部返工 |
| `{{行动语}}` | 限额30人 |
| `{{不可拆分词}}` | AI视觉、创意中心 |

## 拿来就用的具体示例

准备主视觉和人工审定的六类短文字；单条要点建议不超过8个汉字，并标出不可拆分词。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
使用图1主视觉制作4:5海报。一级标题“把想法做出来”最多两行；二级“AI视觉实战工作坊”；三级“9月26日 14:00｜创意中心3楼”；三个短标签依次为“构图拆解”“中文排版”“局部返工”；底部只写“限额30人”。“AI视觉”和“创意中心”不得断行。所有文字各一次，不加英文、二维码或主办方。只输出一张图。
```


## 完整提示词

```text
使用图1主视觉制作4:5中文活动海报。一级只放主标题“{{主标题}}”，最大且最多两行；二级放副标题“{{副标题}}”；三级放“{{日期地点}}”；四级把{{三项要点}}排成三个短标签；底部行动语只写“{{行动语}}”。{{不可拆分词}}不得断行。每段只出现一次，层级依靠字号、字重、留白和一枚强调色建立，不用重复文字做纹理。主视觉占画面约55%，文字不遮住脸、商品或关键动作。不要增加英文翻译、主办方、二维码、票价、地址细节、图标说明或装饰性乱码。只输出一张海报。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

长正文应拆到页面或文档，不应继续压入同一海报；正式活动信息需要人工逐字复核。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 横版标题层级

```text
使用图1制作{{横版比例}}海报，仍按一级主标题、二级副标题、三级日期地点、三项短标签、底部行动语排列；逐字使用{{全部文字}}，每段一次，不新增信息。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
