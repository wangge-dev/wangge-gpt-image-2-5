# T343 · 同SKU活动系列商品本色与主题环境色分离

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在同SKU活动编辑中分离商品固有色与主题环境色，或仅修正商品偏色而保持已验收活动构图。

## 准备材料与变量

图1：已验收16:9活动图，作为编辑底图并负责主体位置、占比、镜头和文字位置；图2：同SKU中性光原图，负责商品本色与结构。提供本色锚点、允许环境色区域、主题背景区域及定稿文字；分区可用人工文字或遮罩。旧活动系列图和主题板可选，不能替代图2。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 浅灰蓝耳机盒 |
| `{{本色锚点}}` | 外壳浅灰蓝、转轴深灰、标志白色、内衬黑色，以图2同部位为准 |
| `{{允许环境色}}` | 盒盖右上高光带与台面商品外侧倒影可轻微带主题色；外壳中间调、标签和内衬不染色 |
| `{{本轮主题}}` | 新年主题视觉 |
| `{{主题色与背景}}` | 只在商品外背景改为暖金散景和低饱和深红远景，无新增道具 |
| `{{标题}}` | 新声启程 |
| `{{说明}}` | 新年主题视觉 |
| `{{固定项}}` | 盒型、开合角度、两只耳机数量、标志位置、相机高度、商品位置与占比、文字承载位置 |
| `{{修色区}}` | 盒盖正面和下壳侧面，排除白色标志、内衬与环境高光带 |

## 拿来就用的具体示例

上传已验收活动底图和同SKU中性光照片；人工指出盒盖右上高光带、台面倒影及文字区域，批准上述标题和说明。图2本色不是模型从旧活动图猜出来的；未提供中性参考时，不声称恢复真实本色。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以图1已验收耳机盒活动图为底图，图2中性光照片核对商品本色，输出一张16:9“新年主题视觉”。盒型、开合角度、两只耳机、白色标志位置、相机高度、商品占比和文字承载位置不变。外壳恢复图2的浅灰蓝，转轴深灰、标志白色、内衬黑色；保留原纹理、暗部与高光层次，不整盒涂平。只把商品外背景改为暖金散景和低饱和深红远景，不加道具。只允许盒盖右上高光带与台面商品外侧倒影轻微带暖金；外壳中间调、标签和内衬不得染色。原文字位置只写“新声启程”“新年主题视觉”。不把主题说成限定SKU，不加价格、年份、生肖、礼盒、认证或功能，不生成拼贴。
```


## 完整提示词

```text
以图1为唯一编辑底图，图2只核对{{商品}}的本色和可见结构，本轮改成“{{本轮主题}}”活动视觉，只输出一张与图1同构图的16:9成品。先保持{{固定项}}，不移动主体或文字承载位置。商品固有色按{{本色锚点}}恢复，保留原材质纹理、光照层次与真实渐变，不把商品涂成平面色块。背景变化只按{{主题色与背景}}执行；主题色仅在{{允许环境色}}出现，不能把外壳中间调、标志、标签或内衬整片染色。标题只改为“{{标题}}”，说明只改为“{{说明}}”，不改字形层级、不溢出原承载区；文字过长在排版工具处理，不缩到不可读。可选系列图只帮助核对固定项，不复制其道具或文字。主题视觉不是商品限定版本事实，不新增价格、年份、生肖、礼盒、认证、功能参数或额外耳机。不改变开合状态，不生成系列拼贴。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

主题、背景色和文案都是变量，不把暖金写死为所有活动的通用要求。视觉色锚点不替代色彩管理、实物色样或印刷打样；原像素要求须在合成工具执行。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 只去商品偏色 · product-color-only

```text
以图1已验收活动图为底图，图2只提供{{商品}}的本色，不改活动主题。仅在{{修色区}}按{{本色锚点}}修正商品中间调的偏色，保持原纹理、亮暗渐变和材质反射，不做全图白平衡、不涂成平面色块。{{允许环境色}}里的已验收环境反射继续保留，不把合理主题高光当作偏色删除。保持{{固定项}}，背景、道具、接触阴影、镜头、商品占比及所有现有文字逐字不变；不要应用新标题或说明，也不替换主题色。未获准修色的标志、标签、内衬和边缘保持原样。若图2与图1不是同一SKU，不能据此重绘本色或结构。只输出一张与底图同尺寸的修色结果，不生成对比拼贴，不补功能、价格、认证或新配件。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
