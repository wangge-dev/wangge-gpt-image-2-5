# T343 · 同SKU活动系列商品本色与主题环境色分离

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在多套活动色明显变化时，把商品本色锚点与允许受环境光影响的区域分开，防止节日配色把包装、标签或材质永久染色。

## 准备材料与变量

图1：中性光商品原图O1；图2至图4：已验收活动图V1-V3；图5：人工商品本色色样；图6：允许环境色区域遮罩；图7：本轮主题板与准确文案。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 浅灰蓝耳机盒 |
| `{{本色锚点}}` | 外壳浅灰蓝C1、转轴深灰C2、标志白C3、内衬黑C4 |
| `{{允许环境色}}` | 外壳高光H1与台面反射R1可出现轻微暖金偏色；标签、阴影中性区和内衬不得染色 |
| `{{本轮主题}}` | 新年暖金V4 |
| `{{标题}}` | 新声启程 |
| `{{说明}}` | 新年限定视觉 |
| `{{固定项}}` | 盒型、开合角度、转轴、耳机数量、标志位置、相机高度和商品占比 |

## 拿来就用的具体示例

商品本色色样应来自中性光原图或人工批准色卡；环境光影响区须人工圈定，模型不能从多张活动图自动推断真实色。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作浅灰蓝耳机盒“新年暖金V4”16:9图。外壳C1、转轴C2、标志C3、内衬C4保持中性光本色；仅高光H1与台面反射R1允许轻微暖金，不能整盒染金。盒型、角度、两只耳机、标志位置和尺度不变。背景为克制暖金光斑与深红远景，只写“新声启程”“新年限定视觉”。不加价格、年份、生肖或功能。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作{{商品}}“{{本轮主题}}”16:9活动图。保持{{固定项}}，商品固有颜色严格参考“{{本色锚点}}”；主题暖金只允许出现在“{{允许环境色}}”，并保持真实光照渐变与材质反射，不可把整个外壳、标签或内衬统一改金色。背景可使用克制暖金光斑和深红远景，但不得复制V1-V3的活动道具。标题只写“{{标题}}”，说明只写“{{说明}}”。不要增加价格、年份、生肖、礼盒、认证、功能参数或额外耳机。只输出V4一张成品图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

视觉色锚点不替代色彩管理、实物标准样、显示器校准或印刷打样；本卡只控制生成画面中的固有色与环境色边界。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
