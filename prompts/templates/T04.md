## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{主题}}` | 独立书展 |
| `{{主视觉}}` | 一本展开的书变成小型街道 |
| `{{标题}}` | 把城市读开 |
| `{{副标题}}` | 在纸上遇见新的街角 |
| `{{配色}}` | 米白、墨蓝、少量橙色 |

## 完整提示词

```text
设计一张{{主题}}海报。主视觉为{{主视觉}}，放在画面中间约60%的区域。顶部标题“{{标题}}”，底部副标题“{{副标题}}”，各出现一次。采用{{配色}}，大幅留白，字体与主视觉相互配合但不能遮住关键字。只输出完成海报，不输出样机、设计过程或多个方案，不增加活动日期与地点。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。这是本库的起步建议，不是效果保证。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。
