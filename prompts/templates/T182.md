# T182 · 双层揭开标签上层开窗与下层字段对应核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

区分可揭上层、永久铰接边、上层开窗与下层信息格，让开窗只在闭合态露出对应字段，避免上下层文字串位。

## 准备材料与变量

图1：双层标签闭合正视；图2：上层揭起；图3：永久铰接边H1；图4：上层开窗W1/W2；图5：下层字段F1/F2；图6：复位状态；图7：人工对应表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{对象}}` | 双层揭开标签PL48 |
| `{{结构}}` | 上层L1、下层L2、永久边H1、开窗W1/W2、字段F1‘批次07’/F2‘客服说明’ |
| `{{状态}}` | S0闭合且W1只露F1；S1 L1绕H1揭起并显示F1/F2；S2 L1复位且W2不露文字 |
| `{{记录}}` | H1与W1/F1已核对；S2 W2边界待复核D110 |
| `{{标题}}` | 上层可揭但不脱离，闭合开窗只读取指定下层字段 |

## 拿来就用的具体示例

闭合、揭起、永久边、两个开窗、下层正视和复位照需来自同一标签；字段对应由人工确认。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“上层可揭但不脱离，闭合开窗只读取指定下层字段”。PL48中L1始终连H1；S0的W1只露F1“批次07”，W2为空，S1揭起显示真实F1/F2，S2复位。写“H1与W1/F1已核对；S2 W2边界待复核D110”。不判断粘性或标签合规。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”三状态核对板。固定同一{{对象}}与{{结构}}，按{{状态}}排列；L1在所有状态都连接H1，S0中W1只对准F1且W2按实拍为空，S1只让L1绕H1揭起并显示L2真实字段，S2按图6复位。不可完全移除L1、交换W1/W2、把F1印到上层、让F2穿窗、镜像下层文字、复制标签、扩大开窗或补造被遮挡字段。底部逐字写“{{记录}}”，D110只框W2。不要添加二维码或宣传语，不宣称粘性、复贴寿命、防伪、信息完整、标签合规或安全。只输出一张静态核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

核对板不替代粘性、复贴寿命、防伪、信息完整性、标签法规或安全验证。
