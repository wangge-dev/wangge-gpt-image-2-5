# T36 · 准确日期中文时间轴

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Charts & Infographics · 本库原创设计**

把已核对的日期、事件和状态按顺序做成短中文时间轴，不计算间隔或补造里程碑。

## 准备材料与变量

提供3至6条按时间升序的日期｜事件｜状态表；图1起可为各事件对应素材，并注明缺图项使用纯文字。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{标题}}` | 项目关键节点 |
| `{{节点表}}` | 2026-03-01｜需求确认｜已完成；2026-03-18｜原型评审｜已完成；2026-04-02｜小范围试用｜进行中；2026-04-20｜复盘会议｜计划中 |
| `{{日期格式}}` | YYYY-MM-DD原样保留 |

## 拿来就用的具体示例

准备已经核对并排序的节点表；日期、状态和事件名都作为文本输入，不从图片OCR推断。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“项目关键节点”时间轴，从左到右依次为“2026-03-01｜需求确认｜已完成”“2026-03-18｜原型评审｜已完成”“2026-04-02｜小范围试用｜进行中”“2026-04-20｜复盘会议｜计划中”。日期原样保留；已完成深蓝实心点，进行中橙色圆环，计划中灰色空心点。不要计算间隔、加负责人、百分比或第五个节点。只输出一张图。
```


## 完整提示词

```text
制作16:9中文时间轴，标题只写“{{标题}}”。严格按{{节点表}}从左到右排列四个节点，日期遵守{{日期格式}}，每个节点依次只放日期、事件、状态三行；素材如提供则逐节点对应，不交换，缺图节点使用简单几何标记。已完成用深蓝实心点，进行中用橙色圆环，计划中用灰色空心点；颜色只表达给定状态。不要重排日期、计算天数、添加当前日期、负责人、百分比、第五个节点或因果结论。只输出一张时间轴图。
```

## 参数设置

建议画布：`1536x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

时间轴是已有节点表的视觉呈现，不替代项目系统；时间敏感信息应在发布前重新核对。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 竖向时间轴

```text
制作4:5“{{标题}}”竖向时间轴，严格按{{节点表}}自上而下排列，日期按{{日期格式}}，状态色只服从输入，不新增节点和计算。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图。本轮只修正第{{节点号}}个节点的{{日期、事件或状态}}为“{{正确内容}}”；其余节点与连线不变。
```
