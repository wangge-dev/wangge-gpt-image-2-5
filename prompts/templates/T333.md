# T333 · 商品微距细节与整机实体位置一对一回连核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把多个微距照片逐一连回整机原图上的真实位置和方向，避免把局部纹理复制到错误部件、缩放成不存在的结构或混入不同样品。

## 准备材料与变量

图1：同一商品整机原图O1；图2至图5：微距M1-M4；图6：整机位置遮罩A1-A4；图7：样品身份与拍摄方向表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 双肩包BP74 |
| `{{回连表}}` | M1肩带车线→A1左肩带上段；M2拉链齿→A2主仓右上；M3底布纹理→A3底面前角；M4标牌边缘→A4正面下部 |
| `{{方向规则}}` | 每个微距保留人工上方向箭头U1-U4；只连同一样品位置；不可旋转纹理凑匹配 |
| `{{显示规则}}` | 整机与微距原图均不重绘，放大倍率不标数值，连线避开商品主体 |
| `{{记录}}` | M1-M3已回连；M4样品编号待复核D260 |
| `{{标题}}` | 每张微距都要回到整机上的唯一位置和方向 |

## 拿来就用的具体示例

提供同一商品整机、带身份记录的微距、位置遮罩和拍摄方向；样品身份不确定的微距必须标待复核，不能混用。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作BP74微距回连板：M1到左肩带A1，M2到主仓右上A2，M3到底面前角A3，M4到正面下部A4；保留U1-U4方向，原图不重绘，不标虚构倍率。写“M1-M3已回连；M4样品编号待复核D260”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”回连板。左侧原样放O1并标A1-A4，右侧原样排列M1-M4；严格按“{{回连表}}”使用不交叉细线连接，并执行“{{方向规则}}”与“{{显示规则}}”。不可复制微距纹理到整机、旋转或镜像局部、用不同样品补缺、从M1-M4重建被遮挡结构、把放大窗口画成透明透视或虚构倍率。底部逐字写“{{记录}}”，D260只标M4身份。不要判断车线强度、拉链耐久、面料成分、做工等级或真伪。只输出一张回连核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

回连板不替代样品追溯、材料鉴定、结构分析、尺寸测量、工艺质量、耐久、真伪或实物审核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
