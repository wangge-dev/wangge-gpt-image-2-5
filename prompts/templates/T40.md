# T40 · 已验收主视觉渠道裁切预演板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Documents & Publishing · 本库原创设计**

在真正重排前，用已验收主视觉预演多个渠道画框会裁掉什么，帮助确定保护项与后续单渠道任务。

## 准备材料与变量

图1：已验收主视觉；图2：人工标记的保护项与可裁区域；提供三个真实目标比例、各自安全区坐标、渠道名称和准确结论。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{主视觉}}` | 4:5新品保温杯海报V05 |
| `{{渠道规格}}` | 淘宝主图1:1；小红书封面3:4；横版广告16:9 |
| `{{保护项}}` | 完整杯体、左上标题、右下品牌标志 |
| `{{可裁区域}}` | 背景两侧落叶与下方空台面 |
| `{{标题}}` | 渠道裁切预演 |
| `{{结论}}` | 16:9需要另行重排；1:1与3:4可进入单渠道适配 |

## 拿来就用的具体示例

目标比例和安全区必须由当前渠道规范或设计人员提供；预演完成后，每个渠道仍应使用T26/T33等单独生成并验收。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“渠道裁切预演”板，母版为4:5新品保温杯海报V05。左侧完整保留图1并叠加图2保护项。右侧三栏为“淘宝主图1:1”“小红书封面3:4”“横版广告16:9”，同一图1只移动裁切框，不拉伸、补背景或重排。完整杯体、左上标题、右下品牌标志标绿；背景两侧落叶和下方空台面标浅灰；超出安全区的保护项标红。底部只写“16:9需要另行重排；1:1与3:4可进入单渠道适配”。不猜平台像素和规则。只输出一张图。
```


## 完整提示词

```text
依据图1、图2制作16:9“{{标题}}”板，用于预演{{主视觉}}，不是输出最终渠道成品。左侧保留一张完整图1作为母版，叠加图2的保护项轮廓但不改像素。右侧三栏分别标{{渠道规格}}中的渠道与比例，每栏把同一图1等比例放入对应画框，只允许移动裁切框，不拉伸、不补背景、不重排、不改文字；使用实线框标人工提供的安全区，半透明灰色覆盖将被裁掉的部分。{{保护项}}用绿色轮廓，{{可裁区域}}用浅灰轮廓；若保护项超出安全区，明确显示红色越界段，不自动缩小或修复。底部只写“{{结论}}”。不要猜平台像素、UI遮挡、推荐尺寸或审核规则，不生成最终适配图、评分和自动通过结论。只输出一张裁切预演板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

预演板不代表渠道适配已完成；平台规格有时效性，必须使用任务当时提供的真实比例与安全区。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
