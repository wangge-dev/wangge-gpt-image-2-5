# T353 · 珠光涂层跨角度系列色移轨迹而非固定渐变

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

同一珠光商品在多张不同观察角度系列图中，按实拍角度表继承高光与综合色移位置，避免每张都贴同一条彩虹渐变或误改商品底色。

## 准备材料与变量

图1至图4：同一商品角度A0/A1/A2/A3实拍；图5：中性光底色；图6：人工角度与综合色移区表；图7：已验收系列版式；图8：准确文案。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 珠光白无线鼠标 |
| `{{本轮角度}}` | A2右前45° |
| `{{底色}}` | 中性光主体为珠光白C0 |
| `{{色移轨迹}}` | A2中左肩H1淡粉、右侧曲面H2浅青、尾部H3保持白；只按图3区域 |
| `{{固定}}` | 左右键分缝、滚轮、侧键数量、底部轮廓、标志和观察角度 |
| `{{版式}}` | 商品居右占高度60%，左侧标题，浅灰背景与系列共同柔光 |
| `{{标题}}` | 角度变化，色泽跟着移动 |
| `{{说明}}` | 仅呈现所附样品在当前光位的可见效果 |

## 拿来就用的具体示例

必须提供同一实物各角度实拍和人工色移区表；只有一张照片时不得编造跨角度轨迹。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成珠光白无线鼠标A2右前45°的16:9系列图。底色C0保持珠光白；仅左肩H1淡粉、右侧H2浅青、尾部H3白，不能叠入其他角度色带。保持左右键缝、滚轮、侧键、轮廓与标志。珠光不是彩虹贴图、全息或发光。只写“角度变化，色泽跟着移动”和指定说明。不加参数。只输出一张图。
```


## 完整提示词

```text
依据图1至图8只生成{{商品}}{{本轮角度}}系列图一张16:9成品。保持{{固定}}与“{{版式}}”，底色为“{{底色}}”；综合色移严格按“{{色移轨迹}}”随真实曲率出现，不能把图1、图2或图4其他角度的色带叠到A2。珠光来自细微表面反射，不做固定横向彩虹渐变、全息箔、金属镜面或自发光。标题只写“{{标题}}”，说明只写“{{说明}}”。不要增加按键、灯效、连接方式、续航、传感器参数、认证或第二只鼠标。只输出A2一张图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

画面色移不替代涂层配方、光谱、色差、耐候或量产一致性测试；每个角度应单独验收。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
