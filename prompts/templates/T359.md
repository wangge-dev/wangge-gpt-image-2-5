# T359 · 腕表系列图表针日期窗固定读数与视角继承

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

同一腕表跨主图、侧视和佩戴场景时固定人工指定的时分秒针、日期窗与表冠状态，避免每张时间漂移、指针增减或日期乱码。

## 准备材料与变量

图1：腕表正面正对；图2：右侧表冠；图3：左侧表壳；图4：已验收主图P1；图5：人工表盘状态图；图6：本轮场景；图7：准确文案。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{腕表}}` | 银壳深蓝盘腕表WT81 |
| `{{固定读数}}` | 时针10点方向、分针2点方向、秒针指向30秒刻度；日期窗只写‘18’ |
| `{{表冠状态}}` | C0贴合表壳，不表现拉出或旋转 |
| `{{结构}}` | 十二枚时标、三根中心针、3点位日期窗、单表冠、两只表耳和棕色表带 |
| `{{本轮}}` | P2腕上侧视场景 |
| `{{标题}}` | 时间停在这一刻 |
| `{{说明}}` | 表盘状态以所附参考为准 |

## 拿来就用的具体示例

表盘正对照和人工读数必须清晰；日期或秒针不可辨时标未提供，不让模型从模糊图猜。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成WT81 P2腕上侧视16:9图。时针指10、分针指2、秒针指30秒，日期窗只写18；C0表冠贴合。保持12时标、3根中心针、3点日期窗、单表冠、表耳与棕色表带。只写“时间停在这一刻”“表盘状态以所附参考为准”。不补小表盘、机芯或防水。只输出一张图。
```


## 完整提示词

```text
依据图1至图7只生成{{腕表}}{{本轮}}一张16:9图。保持“{{结构}}”，表盘严格锁定“{{固定读数}}”，执行“{{表冠状态}}”；透视变化时各指针仍绕同一中心、长度与层级正确，日期窗不镜像、不换数字。图6只提供获准手腕姿态与背景，腕表身份以图1至图5为准。标题只写“{{标题}}”，说明只写“{{说明}}”。不可增加第四根针、额外小表盘、刻度、按钮或表冠，不把10:10误作其他时间，不生成走时轨迹、品牌故事、防水、机芯、材质纯度和价格。只输出一张成品图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

固定读数只服务系列视觉连续，不验证走时精度、机芯功能、日历逻辑、防水或佩戴安全。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
