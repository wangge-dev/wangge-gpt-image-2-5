# T58 · 多轮成品属性证据继承矩阵

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在新一轮生成前逐属性登记应回看原始素材、已验收父图还是本轮新增资料，避免把上一轮视觉误当全部商品事实。

## 准备材料与变量

图1起：原始商品素材、已验收父图与本轮新增资料；提供属性、唯一权威来源、允许继承、禁止继承、当前状态和目标版本六列表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{任务}}` | 保温杯详情页P4材质模块 |
| `{{继承表}}` | 杯体轮廓→原始图O1；杯身墨绿色→原始图O2；品牌版式→已验收P3；内胆纹理→本轮新增M1；容量文字→禁止继承，未提供 |
| `{{父版本}}` | P3 |
| `{{目标版本}}` | P4 |
| `{{标题}}` | P4属性证据继承矩阵 |

## 拿来就用的具体示例

先由人逐属性指定唯一权威来源；父图只可继承明确已验收的版式或视觉状态，不能替代原始商品证据。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“P4属性证据继承矩阵”，任务“保温杯详情页P4材质模块”，父版本P3，目标版本P4。逐行写：杯体轮廓→原始图O1；杯身墨绿色→原始图O2；品牌版式→已验收P3；内胆纹理→本轮新增M1；容量文字→未提供、停止补造。每个属性只连一个权威来源，原图蓝线、父图绿线、新资料橙线。不自动选源、不把P3全部细节当事实、不生成成品。只输出一张图。
```


## 完整提示词

```text
依据全部素材与{{继承表}}制作16:9“{{标题}}”。左上只写任务“{{任务}}”、父版本“{{父版本}}”和目标版本“{{目标版本}}”。主体表格每行一个属性，列严格为“属性｜唯一权威来源｜允许继承｜禁止继承｜当前状态”；来源只允许原始素材、已验收父图、本轮新增资料或未提供。用蓝线连接属性到对应原图缩略图，绿线连接到父图，橙线连接到新增资料；同一属性只能有一个权威来源。标为未提供的内容写“停止补造”，不从其他缩略图猜测。不要重绘素材、比较画质、自动选择来源、把父图中的商品细节全部视为真实，也不生成新成品。只输出一张继承矩阵。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

矩阵只可视化人工指定的证据继承关系，不自动证明素材真实性、版本合格或属性一致。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
只修正属性“{{属性}}”的{{权威来源、允许继承、禁止继承或状态}}为“{{准确内容}}”；其他行、缩略图和版本关系不变。
```
