# T96 · 物流面单母联子联与撕线归属映射

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把同一张多联物流面单的母联、可撕子联、撕线和留存状态逐一对应，并统一遮挡隐私，不推断签收或物流状态。

## 准备材料与变量

图1：未撕面单正面；图2：背面与撕线微距；图3：子联部分撕起实拍；图4：母联与已分离子联同框；图5：人工区域、字符遮挡和状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{面单}}` | 双联物流面单LB12 |
| `{{区域}}` | 母联M1、子联C1、撕线P1、母联留存边E1 |
| `{{状态}}` | L0未撕；L1沿P1部分撕起；L2 M1与C1分离 |
| `{{隐私}}` | 姓名、电话、地址、条码统一遮挡；公开编号仅保留末四位4826 |
| `{{标题}}` | 母联留存，子联沿真实撕线分离 |

## 拿来就用的具体示例

三状态必须来自同一面单或由人工确认同版样张；先完成隐私处理，画面不能作为物流系统记录。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“母联留存，子联沿真实撕线分离”。LB12依次显示L0未撕、L1沿P1部分撕起、L2 M1/C1分离，E1始终留在M1。姓名、电话、地址、条码统一遮挡，只保留公开编号末四位4826；不补背文、不画可扫条码、不判断签收或物流状态。只输出一张图。
```


## 完整提示词

```text
依据图1至图5制作16:9“{{标题}}”三状态映射板，依次展示同一{{面单}}的{{状态}}。每栏固定{{区域}}：L0只标P1边界；L1按图3呈现真实撕起长度、纸纤维和阴影，M1/C1仍相连；L2按图4分别放M1与C1，并让E1留在母联。用短线连接同一印刷定位点，禁止把子联内容复制到母联空缺区或补造背面文字。所有栏执行“{{隐私}}”，同一字段遮挡范围一致，条码不得重绘为可扫描图形。不要增加签收章、时间、路线或人员，不推断运输、签收、退货、责任或系统状态。只输出一张静态映射板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

映射板不替代承运系统记录、签收凭证、隐私合规审核或条码可读性测试。
