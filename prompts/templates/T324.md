# T324 · 立体包装正侧背多面审定文案逐区映射核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把正面、左侧、右侧和背面的审定字符串逐区绑定到实拍载体，区分不可见与未提供，不用OCR或镜像补齐包装文字。

## 准备材料与变量

图1至图4：同一包装正/左/右/背四面实拍；图5：批准文案表C01-C08；图6：面位与区域遮罩；图7：人工可见状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{包装}}` | 护肤纸盒PK65 |
| `{{面位}}` | F正面、L左侧、R右侧、B背面 |
| `{{文案映射}}` | C01→F-A品牌名；C02→F-B品名；C03→L-A使用提示；C04→R-A成分标题；C05→B-A规格；C06→B-B企业名；C07→B-C地址；C08→B-D批次留白标题 |
| `{{状态规则}}` | 实拍可读则逐字呈现；被转角遮挡写不可见；缺该面素材写未提供；不运行OCR猜字 |
| `{{记录}}` | C01-C06已人工核对；C07末行待复核D253；C08只保留标题不填批次 |
| `{{标题}}` | 每段审定文案只属于一个真实面位和区域 |

## 拿来就用的具体示例

必须提供同一实物多面照片、批准文案表、面位遮罩和人工可见状态；照片文字仅用于定位，不作为自动OCR权威源。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作PK65正/左/右/背四面文案映射板，C01-C08严格按批准表连接到F-A至B-D；被转角遮挡写不可见，缺图写未提供，不OCR补字，不以镜像补背面。底部写“C01-C06已人工核对；C07末行待复核D253；C08只保留标题不填批次”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”四面核对板。按{{面位}}原样展示同一{{包装}}，在对应区域外侧列出“{{文案映射}}”，短引线只连接同面真实遮罩。严格执行“{{状态规则}}”；文字内容只抄图5批准表，不根据包装照片OCR续写，不用正面镜像代替背面，不跨面移动段落。盒型、折线、透视和原图文字保持，不重绘成新包装。底部逐字写“{{记录}}”，D253只框C07末行。不要推断配方、功效、规格真实性、批次、法规或合规。只输出一张多面映射核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

映射板不替代印前文件、文字校对、配方规格核验、批次记录、法规、法务或实物包装审核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
