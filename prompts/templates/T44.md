# T44 · 系列成品人工锁定项核对板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把一组已生成成品与人工核对表并排，逐页显示哪些系列锁定项已确认、需返工或不适用，不让模型自行判定一致性。

## 准备材料与变量

图1起：系列成品；提供页码/资产编号、锁定项、人工状态、问题编号和备注五列表。状态只允许已确认、需返工、不适用。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{系列名}}` | 保温杯秋季活动三图 |
| `{{锁定项}}` | 商品轮廓、杯身墨绿色、标签文字、主光方向、标题左上位置 |
| `{{人工核对表}}` | P1全部已确认；P2标签文字需返工D4，其余已确认；P3标题位置不适用，其余已确认 |
| `{{标题}}` | 系列锁定项人工核对 |
| `{{结论}}` | P2处理D4后再进入发布清单 |

## 拿来就用的具体示例

先由人逐页填写核对矩阵；本板只负责展示结果，不能用缩略图或生成模型替代像素级、文字和商品身份检查。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“系列锁定项人工核对”板，副标题“保温杯秋季活动三图”。上方依次放P1、P2、P3原成品缩略图，不修图。下方矩阵列为商品轮廓、杯身墨绿色、标签文字、主光方向、标题左上位置。P1全部绿点；P2标签文字红点并写D4，其余绿点；P3标题位置灰横“不适用”，其余绿点。未提供状态就写“未核对”。底部只写“P2处理D4后再进入发布清单”。不自动找错或评分。只输出一张图。
```


## 完整提示词

```text
依据系列成品与{{人工核对表}}制作16:9“{{标题}}”板，副标题只写“{{系列名}}”。上半部按P1、P2、P3顺序等比例放置各成品缩略图，不重绘、不修正、不换裁切。下半部为核对矩阵：行是P1至P3，列严格为{{锁定项}}；每个格子的状态只从人工核对表读取，“已确认”用绿色圆点，“需返工”用红色圆点并写问题编号，“不适用”用灰色短横。若人工表没有某格状态，留白并写“未核对”，不由图像推断。底部只写“{{结论}}”。不要比较美观、计算相似度、自动发现差异、给总分、修改缩略图或把未核对写成通过。只输出一张人工核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

所有状态必须来自人工核对表；绿色圆点只代表该轮人工记录，不是模型自动验证或正式发布批准。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
只修正资产{{页码}}在锁定项“{{锁定项}}”下的状态为“{{准确状态}}”并更新问题编号；缩略图、其他格子和结论不变。
```
