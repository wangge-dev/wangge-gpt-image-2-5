# T105 · 瓶盖防拆环连接桥周向断开归属图

逐一映射瓶盖与防拆环之间的可见连接桥及开启后的断开位置，不把外观变化当作防伪或密封证明。

## 拿来就用的具体示例

未开启和开启后状态须来自同一瓶盖并由人工记录；缺少角度的连接桥保持待复核。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“连接桥逐个编号，断点不凭空补齐”。CP14的S0/S1各按0°、90°、180°、270°排列，B1–B6从0°顺时针对应微距；只保留真实连续、拉伸或断开。写“B1/B2/B4/B5断开已核对；B3/B6状态待复核D39”。不判断真伪或密封。只输出一张图。
```


## 完整提示词

```text
依据图1至图9制作16:9“{{标题}}”周向核对板。上下两行分别展示同一{{包装}}的{{状态}}，每行按{{方位}}排列并保持瓶盖文字、齿纹、螺纹轴线与防拆环位置。严格按“{{连接桥}}”连接对应微距；只呈现实拍可见的连续、拉伸或断开状态，不镜像编号、不补造隐藏桥、不把裂纹扩展到相邻桥。底部逐字写“{{人工记录}}”，D39只框B3/B6。不要生成开瓶手势或液体，不推断真伪、首次开启事实、密封、泄漏、防拆等级或食品安全。只输出一张静态核对板。
```
