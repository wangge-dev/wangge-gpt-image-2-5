# T34 · 技术标注引线防串位

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Charts & Infographics · 本库原创设计**

按编号锚点和标签区域生成少量技术标注，让每条引线只连接一个真实部位。

## 准备材料与变量

图1：主体正对照；图2：标有A至D锚点的位置图；提供锚点、准确名称、标签放置区三列表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{标注表}}` | A→旋钮→左上；B→状态灯→右上；C→进风口→左下；D→电源接口→右下 |
| `{{标题}}` | 结构标注 |
| `{{底部说明}}` | 部位名称以实物资料为准 |

## 拿来就用的具体示例

准备主体正对照、人工标注锚点图和名称/标签区映射；标注超过6条时拆成多张主题图。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
依据图1和图2制作4:5“结构标注”图。A旋钮标签放左上，B状态灯放右上，C进风口放左下，D电源接口放右下；每条引线只连对应锚点，不交叉、不分叉。名称各一次，主体结构不动。底部只写“部位名称以实物资料为准”。移除A至D标记，不加参数、功能或内部结构。只输出一张图。
```


## 完整提示词

```text
依据图1主体和图2锚点制作4:5“{{标题}}”图。严格按{{标注表}}生成四个标签：每条细引线从指定标签区出发，只终止于对应锚点，端点清楚，不交叉、不分叉、不穿过其他标签；名称逐字准确且各一次。保持图1主体的结构、比例、颜色、按钮和接口，不为了腾位置移动或复制部件。标签区保持足够留白，底部只写“{{底部说明}}”。成品移除A至D字母和锚点圆圈。不要增加第五条标注、参数、功能、内部结构、尺寸或认证。只输出一张图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

引线图只说明已标注的可见部位；内部结构、功能和参数仍需正式图纸或资料证明。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 局部细节窗

```text
依据图1、图2制作{{标题}}图，只保留{{三个锚点}}。每条引线连接一个锚点和一个局部放大窗，名称按{{标注表}}，不交叉、不补结构。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，重新附图2。本轮只修正{{标签名}}引线，使端点回到{{锚点}}且不与其他线交叉；主体和其余标注不变。
```
