# T253 · 横向百叶帘梯绳叶片同步翻转与分段文字归属

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

核对横向百叶帘调光时，多片叶片在梯绳约束下同步改变角度，分段中文始终留在指定叶片，不能拼成悬浮整字或独立画面。

## 准备材料与变量

图1：叶片水平态L0；图2：向上倾斜态L1；图3：近闭合态L2；图4：反向倾斜态L3；图5：叶片S1-S8、左右梯绳T-L/T-R与转棒W1；图6：分段中文M1-M4所在叶片；图7：人工角度和遮挡表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{对象}}` | 八片横向百叶帘VB32 |
| `{{状态}}` | L0水平、L1按实拍向上倾斜、L2近闭合、L3反向倾斜 |
| `{{结构锚点}}` | S1-S8上下次序固定并分别穿过T-L/T-R横档；W1只驱动同步倾角；M1-M4各属于指定叶片并随其转动遮挡 |
| `{{保护}}` | 八片叶片、双侧梯绳、转棒、上下次序、分段中文、边缘厚度、窗框、光源和背景 |
| `{{记录}}` | S1-S8与T-L/T-R映射已核对；L2 S6下缘遮挡待复核D181 |
| `{{标题}}` | 梯绳保持叶片次序，同步翻转也不能让分段文字脱片 |

## 拿来就用的具体示例

提供同一百叶帘四种倾角、左右梯绳、转棒和各叶片文字实拍；不得由单一正视图推断叶片背面。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成VB32的L0水平、L1上倾、L2近闭合、L3反向倾斜四栏图。S1-S8顺序固定并受T-L/T-R约束，M1-M4各守指定叶片，随角度产生真实遮挡。底部写“S1-S8与T-L/T-R映射已核对；L2 S6下缘遮挡待复核D181”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7生成同一{{对象}}的L0-L3状态核对图，只执行“{{状态}}”。S1-S8、T-L/T-R、W1与M1-M4保持身份并继承{{结构锚点}}；每栏只按对应实拍改变全部叶片倾角、可见面与相邻遮挡。严格保护{{保护}}。不可交换叶片次序、让单片逆向、复制或丢失梯绳、把分段中文拼成悬浮整字、让文字固定在窗上、把倾转画成帘布升降、透视补画顶轨内部或推断遮光率。底部逐字写“{{记录}}”，D181只框L2的S6下缘。只输出一张四状态核对图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

状态图不替代遮光率、调光性能、绳具安全、安装、耐久、消防、承载或实物测试。
