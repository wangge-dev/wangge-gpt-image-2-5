# T39 · 人工差异清单标注板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把已生成候选稿与原始商品参考并排，并只标注人工已经确认的差异，形成下一轮可定位的返工依据。

## 准备材料与变量

图1：原始商品主参考；图2起：负责具体属性的原图；最后一图：待验收候选稿。提供人工差异清单，含编号、候选稿坐标、问题、正确参考和期望状态。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{候选稿编号}}` | V03 |
| `{{差异清单}}` | D1 候选稿杯盖顶部：比例偏高→按图1；D2 候选稿正面标签第二行：字序错误→按图2；D3 候选稿右侧金属边：被删失→按图3 |
| `{{标题}}` | V03 人工差异标注 |
| `{{保护项}}` | 杯身墨绿色、商品位置、背景、阴影与标题区域 |
| `{{结论}}` | 返工：仅处理D1–D3 |

## 拿来就用的具体示例

差异必须先由人工核对并写明位置与正确参考；模型只负责排版标注，不负责自动视觉质检。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“V03 人工差异标注”板。左侧放图1至图3原始参考缩略图；右侧完整放V03候选稿，不修图。只标三项：D1杯盖顶部比例偏高，按图1；D2正面标签第二行字序错误，按图2；D3右侧金属边被删失，按图3。圆点落到指定部位并以细引线连接说明。保护项只写“杯身墨绿色、商品位置、背景、阴影与标题区域”；底部只写“返工：仅处理D1–D3”。不新增问题、评分或相似度。只输出一张图。
```


## 完整提示词

```text
依据原始参考与待验收候选稿制作16:9“{{标题}}”板。左侧30%展示图1商品主参考及图2起属性参考的缩略图，每张标原图号，不重绘。右侧70%完整展示候选稿{{候选稿编号}}，保持候选稿像素内容，不直接修正。只按人工提供的{{差异清单}}叠加D1、D2、D3圆点与细引线；圆点必须落在清单指定的候选稿部位，右侧说明区逐字写“编号｜问题｜正确参考｜期望状态”。另设“保护项”栏，只写“{{保护项}}”；底部结论只写“{{结论}}”。白底、红色问题编号、蓝色原图编号，文字清楚。不要自行寻找新差异、评价美观、计算相似度、给分、判断真伪或改动候选稿。只输出一张人工差异标注板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

没有进入人工清单的问题不应由模型新增；此板是返工沟通物，不是自动质检或真实性鉴定结果。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
只修正差异项{{编号}}的{{圆点位置、引线或说明文字}}为“{{准确内容}}”；候选稿、原始参考、其他差异与保护项不变。
```
