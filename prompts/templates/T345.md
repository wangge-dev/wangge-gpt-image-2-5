# T345 · 主视觉跨比例扩展区来源与防重复物体控制

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

横向或纵向扩展商品主视觉时明确原像素保护区和各扩展区的背景来源，避免扩图复制商品、道具、文字或形成镜像纹理。

## 准备材料与变量

图1：已验收母版V1；图2：原像素保护遮罩K0；图3：左、右、上、下扩展区L/R/U/D；图4：无物体背景参考；图5：人工允许延续纹理表；图6：必须保留文字。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{目标比例}}` | 16:9横幅 |
| `{{保护区}}` | K0内商品、标题、品牌标志与接触阴影像素不变 |
| `{{扩展规则}}` | L延续浅灰墙面与左上柔光；R延续空墙和台面；U/D不扩展 |
| `{{允许纹理}}` | 墙面细颗粒、台面水平纹理和柔和明暗渐变 |
| `{{禁止复制}}` | 商品、包装、圆形托盘、叶片、标题、标志、阴影轮廓和高光斑 |
| `{{保留文字}}` | 标题‘一杯随行’与品牌名‘MORI’各一次 |

## 拿来就用的具体示例

必须提供原像素保护遮罩、各方向扩展区和无物体背景依据；没有干净背景参考时，只允许延续简单颜色与纹理，不补复杂场景。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
把“一杯随行”保温杯母版扩展成16:9。K0中的商品、标题“MORI”、接触阴影像素不动，只向左右补浅灰墙面和台面：左侧延续左上柔光，右侧保持空墙；上下不扩。不得复制杯子、托盘、叶片、文字、阴影或光斑，不镜像和平铺边缘。只输出一张横幅。
```


## 完整提示词

```text
把图1扩展为{{目标比例}}。{{保护区}}；只在图3的L/R区生成新背景，按“{{扩展规则}}”和“{{允许纹理}}”延续，U/D保持不变。扩展区必须为空，不得出现“{{禁止复制}}”；不要镜像边缘像素、平铺重复纹理、拉伸墙面颗粒或制造竖直接缝。{{保留文字}}保持原字、原位置和次数，不因画布变宽另排一份。光线与透视连续，扩展只补背景，不移动、缩放或重绘K0。不要加价格、卖点、道具、平台标志或尺寸标注。只输出16:9成品图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

生成式扩图不保证K0真正逐像素不变，最终应使用差异工具检查保护区，并在设计软件中完成精确画布与导出。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

