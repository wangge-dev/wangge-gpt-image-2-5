# T222 · 双面翻片字牌正反中文与铰轴状态继承

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

修正可翻转双面字牌的正反文案：同一刚性翻片绕永久铰轴翻转，A面与B面各承载一条审定中文；翻转后只能看到朝外一面，另一面不得镜像透出。

## 准备材料与变量

图1：A面朝外状态；图2：B面朝外状态；图3：翻片轮廓P1；图4：A/B面审定文案；图5：永久铰轴H1与止挡S1；图6：正反面材质微距；图7：人工状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{对象}}` | 桌面双面状态牌FS24 |
| `{{状态}}` | A面“正在使用”；B面“暂时离开” |
| `{{结构锚点}}` | 同一翻片P1绕H1翻转，A/B文案分别固定在两面；止挡S1、边厚E1、轴端C1与支架B1连续 |
| `{{保护}}` | 底座、支架、H1、S1、P1轮廓、其他标记、光源、阴影和背景 |
| `{{记录}}` | A/B文案逐字已审定；B面“离”字基线待复核D150 |
| `{{标题}}` | 同一双面翻片绕固定铰轴翻转，每态只显示朝外一面 |

## 拿来就用的具体示例

提供同一字牌正反实拍、翻片轮廓、两面人工审定文案、铰轴、止挡和材质参考；不得从一面推断另一面内容。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成FS24的双状态：A面朝外写“正在使用”，绕H1翻转后B面朝外写“暂时离开”。P1、H1、S1、E1、C1和B1保持同一结构，每态只显示一面。底部写“A/B文案逐字已审定；B面‘离’字基线待复核D150”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7生成同一{{对象}}的A/B状态对照，只执行“{{状态}}”。同一翻片P1必须绕永久铰轴H1翻转，并继承{{结构锚点}}；A态只显示A面，B态只显示B面，背面文案不得透视、镜像或叠加。严格保护{{保护}}。不可复制翻片、把文案贴到支架、让铰轴脱离、越过止挡、同时展示两面、改变底座或用溶解转场替代机械翻转。底部逐字写“{{记录}}”，D150只框B面“离”字。只输出一张双状态核对图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

状态图不替代铰轴结构、止挡角度、耐久、稳定、文案准确性、安全、法规或实物审核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
