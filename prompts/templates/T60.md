# T60 · 纸盒刀模与成盒面位映射

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把已批准刀模上的面位编号映射到真实成盒六面，检查图文归属与朝向，不让生成图冒充生产刀模。

## 准备材料与变量

图1：已批准刀模预览；图2至图7：真实成盒前后左右顶底六面正对照；图8：面位编号和折叠关系表。提供面位、文字、折线/裁切线样式和声明。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{包装}}` | 长方体茶叶纸盒 |
| `{{面位}}` | F正面、B背面、L左侧、R右侧、T顶部、D底部 |
| `{{映射}}` | F→图2，B→图3，L→图4，R→图5，T→图6，D→图7 |
| `{{标题}}` | 刀模面位与真实成盒对应 |
| `{{声明}}` | 本图仅供视觉核对，生产以已批准刀模源文件为准 |

## 拿来就用的具体示例

刀模必须是当前批准版本，六面照片需来自同一实盒；缺少某一面时标“未提供”，不能用相邻面推断补齐。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“刀模面位与真实成盒对应”。左栏原样放长方体茶叶纸盒已批准刀模，标F正面、B背面、L左侧、R右侧、T顶部、D底部；右栏2×3放真实六面照片，并按F→图2、B→图3、L→图4、R→图5、T→图6、D→图7逐一连线。文字朝向和跨折边终止关系按实物，不交换、镜像或倒转面位。发现不一致只标人工问题号，不修刀模。底部写“本图仅供视觉核对，生产以已批准刀模源文件为准”。只输出一张图。
```


## 完整提示词

```text
依据图1至图8制作16:9“{{标题}}”。左栏原样放图1{{包装}}刀模预览，在各面中央标{{面位}}，裁切线用实线、折线用虚线，不能移动线、改尺寸或补出血；右栏以2×3网格放图2至图7真实六面正对照，严格按{{映射}}标号。用六条独立细线把刀模面位连接到对应成盒照片，保持文字朝向、标志位置和图案跨折边终止关系，不把相邻面内容交换、镜像或旋转180°。若刀模与实盒不一致，只按人工记录标红问题编号，不自动修刀模或重绘实盒。底部写“{{声明}}”。不要输出可印刷文件、尺寸、色值、条码校验、出血合规或已量产结论。只输出一张映射核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

生成板不是矢量刀模、印前文件或尺寸依据，不能用于生产下单与合规验收。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
