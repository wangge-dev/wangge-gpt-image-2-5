# T64 · 卷材展开曲率与边缘回卷对照

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

记录同一卷材从卷起、部分展开到静置平放时的真实曲率和边缘位置，避免把柔性材料生成成绝对平板或任意波浪。

## 准备材料与变量

图1：卷起状态；图2：部分展开状态；图3：指定时长后的平放状态；图4：边缘与接缝微距；图5：人工时点和基准点表。

| 变量 | 填写示例或说明 |

| `{{卷材}}` | 印花桌垫 |
| `{{状态}}` | 卷起R0、展开一半R1、平放30分钟R2 |
| `{{基准点}}` | 左前角A、右前角B、卷芯边C、拼接线D |
| `{{人工记录}}` | R2左前角轻微上翘，问题E4 |

## 拿来就用的具体示例

三个状态必须来自同一卷材且平放时长由人工记录；单次静态外观不能证明长期平整、尺寸稳定或材料性能。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“展开后，边缘停在哪里”。同一张印花桌垫依次为卷起R0、展开一半R1、平放30分钟R2。保持印花、裁边和A左前角、B右前角、C卷芯边、D拼接线一致；曲率、接触点、波纹和上翘只按实拍。R2写“左前角轻微上翘，问题E4”。不自动压平，不加重物或胶带，不宣称永久平整、无记忆或防滑。只输出一张图。
```


## 完整提示词

```text
依据图1至图5制作16:9“{{标题}}”三状态对照，依次展示同一张{{卷材}}的{{状态}}。三栏保持印花比例、裁切边、{{基准点}}和表面纹理身份一致；卷径、弧线、接触点、边缘上翘和局部波纹只按对应实拍，不把R0纹样压扁、把R1补成完全展开或把R2自动拉平成无曲率平面。用细线连接A、B、C、D在三栏中的对应位置，不跨越遮挡区。R2只写人工记录“{{人工记录}}”，30分钟来自外部计时，不从图像推算。柔和侧光保留真实投影和材质厚度。不要生成夹具、重物、胶带，不宣称永久平整、无记忆、耐久、防滑、尺寸稳定或合格。只输出一张对照图。
```

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。
