# T332 · 商品正侧顶原图与人工实测尺寸逐轴上屏核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把外部人工实测长宽高逐项绑定到正侧顶原图的对应轴线，不让图片模型从透视、像素或尺子照片自行计算尺寸。

## 准备材料与变量

图1：同一商品正视F；图2：侧视S；图3：顶视T；图4：人工测量记录；图5：测量端点与轴线遮罩；图6：单位和小数位规则；图7：问题位。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 桌面收纳箱DB73 |
| `{{人工尺寸}}` | 宽W=320 mm；深D=215 mm；高H=180 mm |
| `{{视图映射}}` | F显示W/H；S显示D/H；T显示W/D |
| `{{端点规则}}` | 尺寸线只连接图5人工端点E1-E6；不贴透视边、不从照片测量 |
| `{{文字规则}}` | 数值、单位和小数位逐字抄图4/图6，不换算厘米 |
| `{{记录}}` | W/H端点已核对；T视图D后端点待复核D259 |
| `{{标题}}` | 尺寸来自人工测量表，视图只负责承载对应轴线 |

## 拿来就用的具体示例

提供同一商品三视图、人工测量表、明确端点遮罩和单位小数规则；只有照片没有测量记录时不得生成尺寸值。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作DB73正/侧/顶原图尺寸板：F标W=320 mm/H=180 mm，S标D=215 mm/H=180 mm，T标W=320 mm/D=215 mm；尺寸线只连人工E1-E6，不从图片测量。写“W/H端点已核对；T视图D后端点待复核D259”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”三视图尺寸核对板。原样排列{{商品}}的F/S/T照片，按“{{视图映射}}”和“{{端点规则}}”绘制尺寸线，逐字写“{{人工尺寸}}”并执行“{{文字规则}}”。不可拉伸照片匹配数值、用像素比例计算、读取尺子照片、把斜边当尺寸轴、自动补公差、交换W/D/H或生成未提供底视图。底部逐字写“{{记录}}”，D259只框T视图D后端点。不要推断容量、壁厚、内尺寸、装载、承重、误差或合格性。只输出一张尺寸核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

尺寸板不替代量具校准、测量方法、公差、内尺寸、容量、装载、承重、工程图或实物检验。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

