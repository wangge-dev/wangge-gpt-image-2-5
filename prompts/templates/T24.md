# T24 · 原版式中文本地化替换

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Documents & Publishing · 本库原创设计**

把外语海报或页面替换为已审定中文，在不照搬字形的前提下保留信息层级与版式关系。

## 准备材料与变量

图1：原语言成品；图2：无文字底图或清晰原图；提供原文到审定中文的一一映射、专名禁译表和允许重排范围。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{替换映射}}` | SUMMER MARKET→夏日市集；JUL 18–20→7月18日至20日；FREE ENTRY→免费入场 |
| `{{专名规则}}` | 品牌名LUMEN保留英文 |
| `{{允许重排}}` | 标题可两行，日期和行动语保持单行 |

## 拿来就用的具体示例

准备原成品、无字底图或高质量原图、逐项翻译映射与专名禁译表；译文先由人工审定。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
参照图1海报层级和图2底图，把“SUMMER MARKET”替换为“夏日市集”，允许标题两行；把“JUL 18–20”替换为“7月18日至20日”，“FREE ENTRY”替换为“免费入场”，两者保持单行。品牌名“LUMEN”保留英文。主视觉、网格、版块顺序、色彩、图标和装饰不变；删除被替换外语，不加双语或新文案。只输出一张中文成品图。
```


## 完整提示词

```text
参照图1的信息层级和图2画面，把所有指定外语按{{替换映射}}替换为中文，遵守{{专名规则}}与{{允许重排}}。保留主视觉、网格、版块顺序、色彩、留白、图标和装饰关系；中文字体选择与原设计气质相称，不机械模仿外文字形。中文必须逐字准确、层级对应、边距充足，不溢出、不压住主体。删除已替换的外语，不保留双语；未在映射中的专名、数字和标志原样保留。不要翻译、补写或改写映射之外的内容。只输出一张本地化成品图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡执行已审定译文的视觉本地化，不承担翻译准确性判断；重要出版物应在排版软件中重建并校稿。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 保留双语版

```text
参照图1和图2按{{替换映射}}制作中英双语版。中文为主层级，原文缩小为次层级并紧邻对应中文；遵守{{专名规则}}，不得重复第三次。保留主视觉、网格、色彩和版块顺序，只输出一张成品图。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图。本轮只修正{{文字区域}}的中文为“{{审定文字}}”，按{{指定换行}}排版；其他译文、原版式和主视觉不变。
```
