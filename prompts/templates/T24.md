# T24 · 原版式中文本地化替换

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Documents & Publishing · 本库原创设计**

把外语海报或页面替换为已审定中文，在不照搬字形的前提下保留信息层级与版式关系。

## 准备材料与变量

基础版图1为清晰原语言成片，负责画幅、文字框、视觉层级与原字；图2为人工确认同一版本的无字底图，只允许补被替换旧字覆盖的局部，不替代整个背景。文字提供逐区旧字→审定中文、专名禁译表和边界／断行；不匹配底图不得使用。没有图2用“仅原成片本地化”，不是停止整项任务。双语版另需人工批准每个原文与译文的独立行区，缺空间不压小字。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{替换映射}}` | T1：SUMMER MARKET→夏日市集；T2：JUL 18–20→7月18日至20日；T3：FREE ENTRY→免费入场 |
| `{{专名规则}}` | 品牌名LUMEN保留英文；其余未在替换清单内的标志、包装原字、数字和专名原样保留 |
| `{{允许重排}}` | T1在原标题框内两行，T2和T3各在原框内单行；文本框、字号层级和四周留白不改，不能缩成小字 |
| `{{双语区域}}` | 每区中文按原字号层级置上，原英文置下；仅使用人工另批的下方空行区，原文不得缩成小字或侵入主体；没有足够空行区则停止双语版 |

## 拿来就用的具体示例

图1为4:5市集海报，实际可读T1 SUMMER MARKET、T2 JUL 18–20、T3 FREE ENTRY与LUMEN；图2需为同一批准版本无字底图。译文、断行与边界按下表审定，本例为排字演示；没有无字底图可选择单图完整分支。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
编辑图1原语言成片，只替换人工指定文字区：T1：SUMMER MARKET→夏日市集；T2：JUL 18–20→7月18日至20日；T3：FREE ENTRY→免费入场。专名规则：品牌名LUMEN保留英文；其余未在替换清单内的标志、包装原字、数字和专名原样保留。逐区先确认底图旧字和清单一致；原字不可读、区域不明或译文未审定时停止该区，不自动OCR猜字或重新翻译。图1是构图、画幅、文字框和商品的权威，图2必须是同一批准版本的无字底图，只在被替换旧字占据的局部补回已证实背景，不将图2整幅覆盖图1，也不借它替换人物或商品。

保留图1原画幅、主视觉、网格、区块顺序、色彩、图标、装饰、商品包装原字和照片内部内容。只在原文字框内执行“T1在原标题框内两行，T2和T3各在原框内单行；文本框、字号层级和四周留白不改，不能缩成小字”，中文逐字准确，字体气质与原作相称，不机械复刻外文字形。阅读层级与标题位置不变；边距按原框保留，不扩大框、不移动商品、不用小字号塞长字。长字、换行或纹理修复超出批准区时停止该区，转人工审定短文或外部排字，不截字、删词、压缩或越界。

本版单语：只删除清单中已替换的旧外语，不保留对应双语；清单外的标志、专名、数字和商品实拍原字不翻译、不补写、不按常识改内容。不要新增卖点、日期、价格、功效、认证、水印或第三种语言。图片模型只输出一张中文本地化成片，原图若必须逐像素不变，应在外部图层中仅替换文字。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡执行已审定译文，不承担翻译与发布合规判断。图2只补目标文字下方局部；双语须有另批空间，无底图仍有完整单图路径，复杂纹理或文字溢出改外部排版。

1536x1920仅对应4:5示例；其他画幅保留图1比例并设置相应合法画布，不为默认尺寸裁掉原信息。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 保留双语版

```text
编辑图1原语言成片，本版明确要求保留对应原文与中文。只处理人工指定文字区：{{替换映射}}。专名规则：{{专名规则}}。逐区先确认底图旧字和清单一致；原字不可读、区域不明或译文未审定时停止该区，不自动OCR猜字或重新翻译。图1是构图、画幅、文字框和商品的权威，图2必须是同一批准版本的无字底图，只在被替换旧字占据的局部补回已证实背景，不将图2整幅覆盖图1，也不借它替换人物或商品。

保留图1原画幅、主视觉、网格、区块顺序、色彩、图标、装饰、商品包装原字和照片内部内容。中文只在原文字框内执行“{{允许重排}}”，中文逐字准确，字体气质与原作相称，不机械复刻外文字形。阅读层级与标题位置不变；边距按原框保留，不扩大框、不移动商品、不用小字号塞长字。原英文只可进入另批的双语行区，不受中文框内规则扩展授权；长字、换行或纹理修复超出各自批准区时停止该区，转人工审定短文或外部排字，不截字、删词、压缩或越界。

本版双语：逐区保留原文并加入审定中文，每种各一次，不重复第三次。双语区域：{{双语区域}}。没有人工批准双语行区或行区容不下原字号时停止，不自行缩小原文、扩大文本框或移动主体；清单外的标志、专名、数字和商品实拍原字不翻译、不补写、不按常识改内容。不要新增卖点、日期、价格、功效、认证、水印或第三种语言。图片模型只输出一张中英双语本地化成片，原图若必须逐像素不变，应在外部图层中仅替换文字。
```

### 仅原成片本地化 · single-image-localization

```text
只编辑图1原语言成片，不需要无字底图或第二张图片。逐区替换清单：{{替换映射}}。专名与保留项：{{专名规则}}。原字不可读、区域不明或译文未经审定时停止对应区，不自动补字或翻译。

画幅、商品、人物、主视觉、网格、图标、色彩和留白以图1为准；只允许原文字框内替换，按“{{允许重排}}”排中文，原框边界、字号层级和阅读顺序不变。删除清单内旧字后，仅借紧邻、可确认的平坦底纹修复该字占区；背景涉及商品轮廓、复杂图案、遮挡或不能可靠还原时停止该区，转外部图层排字，不生成新的照片细节。

清单外的包装原字、标志、专名、数字不修改。本版只保留审定中文，删除已替换的对应外语，不生成双语、宣传语或额外语言。长字放不下停止，不缩成小字、截词、删字、扩框或侵入商品。无新卖点、价格、功效、认证、日期或水印。只输出一张本地化图；需要未编辑区像素原样时用外部合成，不能由提示词保证。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
