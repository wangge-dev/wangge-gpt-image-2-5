# T342 · 同SKU跨活动道具一进一出位置替换

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

从已验收活动图迁移到新主题时，用人工替换表逐个删除旧道具并在指定区域加入新道具，避免新旧节日元素混杂或数量失控。

## 准备材料与变量

图1：商品身份原图；图2：已验收旧活动图V1；图3：商品与文字保护遮罩；图4：旧道具删除区；图5：新道具参考；图6：人工一进一出表；图7：新活动文案。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 琥珀色洗护瓶 |
| `{{旧活动}}` | 冬日礼遇V1 |
| `{{新活动}}` | 春日焕新V2 |
| `{{替换表}}` | R1右后松枝1束→N1右后浅绿嫩枝1束；R2左下银色铃铛2枚→N2左下白色花瓣2片；R3顶部雪点→删除且不替换 |
| `{{固定项}}` | 瓶型、泵头、琥珀色、标签、商品位置、镜头、米白台面、左上主光和接触阴影 |
| `{{标题}}` | 春日焕新 |
| `{{说明}}` | 新季上架 |

## 拿来就用的具体示例

提供旧活动合格图、商品原图、旧道具删除区、新道具参考及逐项替换表；不能只写“换成春季”，否则边界不可验收。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
把冬日礼遇洗护瓶V1改成春日焕新V2：右后松枝1束换成同位置嫩枝1束，左下铃铛2枚换成花瓣2片，顶部雪点删除不替换。瓶型、泵头、琥珀色、标签、位置、镜头、台面、左上主光和阴影不变，绿色不能染瓶。只写“春日焕新”“新季上架”。不混留冬季元素，不加价格、功效或第二瓶。只输出一张图。
```


## 完整提示词

```text
以图2为底图、图1为{{商品}}身份依据，把{{旧活动}}改为{{新活动}}。严格执行“{{替换表}}”：先只在图4指定区删除R1-R3，再按图5把N1-N2放入对应位置与数量；未列旧道具不得保留，未列新道具不得增加。完整保护{{固定项}}和图3遮罩内像素，尤其不让嫩枝或花瓣的颜色染到商品。画外标题只写“{{标题}}”，说明只写“{{说明}}”，各一次；包装原字不改。不得叠加春冬两套元素，不新增蝴蝶、雨滴、礼盒、折扣、日期、价格、功效或第二件商品。只输出V2一张4:5成品图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡处理同一构图内的可数道具替换，不代表新主题文案、活动资格、折扣或上线日期已经审批。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

