# T31 · 多参考图冲突优先级表

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Other Use Cases · 本库原创设计**

当多张参考图在身份、结构、版式、光线或文字上互相冲突时，先声明逐项权威来源。

## 准备材料与变量

图1至图N：不同职责参考；提供属性、权威图号、允许借用项、禁止覆盖项四列表，冲突未裁决的属性留空并保持底图。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{优先级表}}` | 人物身份→图1；商品结构→图2；版式位置→图3；光线气氛→图4；准确文字→输入文本 |
| `{{允许借用}}` | 图4只借用暖侧光与背景明暗 |
| `{{禁止覆盖}}` | 图4不得改变人物、商品、文字和版式 |

## 拿来就用的具体示例

准备职责不同的参考图和逐属性优先级表；同一属性只能指定一个权威来源，无法裁决时不生成该细节。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1只定义人物身份，图2只定义商品结构，图3只定义版式位置，图4只借用暖侧光与背景明暗，准确文字只用输入文本。制作4:5成品：人物不得被图2至图4改脸，商品不得被图1、图3、图4改结构，图4不得覆盖文字和版式。未列属性若冲突就保持底图，不做平均融合。只输出一张图。
```


## 完整提示词

```text
先按{{优先级表}}解释图1至图4的职责，再生成一张4:5成品。每项属性只服从其指定权威来源：人物身份不从商品图借用，商品结构不从氛围图改写，版式不从人物姿态推断，准确文字只服从输入文本。{{允许借用}}；严格执行{{禁止覆盖}}。若两图对同一未列属性冲突，保持当前底图或省略该细节，不折中混合。主体、环境、光线、材质、配色、短文字和版式按上述映射组合，边缘与遮挡自然。不要平均融合人脸、商品、标志或文字，不新增第五个来源。只输出一张图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

优先级表由使用者裁决，不由模型自行判断哪张图更真实；身份、结构和准确文字应优先使用原始证据。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 编辑任务优先级

```text
以图1为底图，按{{优先级表}}只从图2起借用指定属性。{{允许借用}}；{{禁止覆盖}}。冲突项保持图1，不平均融合，只输出一张修改图。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图。本轮只修正{{冲突属性}}，改为服从图{{权威图号}}；其他属性继续按原优先级锁定。
```
