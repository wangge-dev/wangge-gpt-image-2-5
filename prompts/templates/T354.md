# T354 · 长中文规格表按审定行组拆页与表头复现

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Charts & Infographics · 本库原创设计**

规格行较多时按人工行组拆成单独页面，固定列结构并复现表头，避免把整表压成不可读小字、漏行或跨页串行。

## 准备材料与变量

图1：商品身份图；图2：批准规格表原文；图3：人工行号R1-R12；图4：拆页表；图5：列宽与对齐规则；图6：本轮页码。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 桌面投影仪 |
| `{{本轮}}` | 规格页2/3 |
| `{{列}}` | 项目｜批准值｜备注 |
| `{{本页行组}}` | R5接口：HDMI×1；R6电源输入：DC 19V；R7机身尺寸：180×145×62 mm；R8净重：1.25 kg |
| `{{表头规则}}` | 三列表头与第1页逐字相同；项目左对齐，批准值右对齐，备注左对齐；单位不换算 |
| `{{字号规则}}` | 正文不低于人工记录的34 px；行距不低于1.35倍；空间不足不得缩字 |
| `{{页脚}}` | 规格页 2/3｜仅录入批准资料 |

## 拿来就用的具体示例

必须提供批准规格原文、稳定行号、人工拆页与排版规则；分页不能由模型按语义重新组合。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
生成桌面投影仪规格页2/3，三列“项目｜批准值｜备注”。只写R5 HDMI×1、R6 DC 19V、R7 180×145×62 mm、R8 1.25 kg，单位不换算；项目左对齐、值右对齐，正文不低于34 px，空间不足不缩字。页脚写“规格页 2/3｜仅录入批准资料”。不带R1-R4或R9-R12。只输出一张图。
```


## 完整提示词

```text
依据图1至图6只生成{{商品}}{{本轮}}一张3:4规格页。固定三列“{{列}}”，严格录入“{{本页行组}}”，执行“{{表头规则}}”和“{{字号规则}}”；这些排版数值不在画面额外解释。每个R编号只出现一次，不把上一页R1-R4或下一页R9-R12带入。空间不足时保留留白并停止，不缩字、不挤行、不省略备注、不合并单元格。商品小图仅放右上角，不覆盖表格。页脚逐字写“{{页脚}}”。不要计算、换算、补空值、增加认证、推荐、图标、价格或二维码。只输出第2页。
```

## 参数设置

建议画布：`1536x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

图像表格不替代结构化数据、产品说明书、法规标签或无障碍文本；数值和最小字号需在导出文件中复核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
