# T71 · 透明保护膜撕除边界与基材保护对照

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

记录同一表面保护膜未撕、部分撕除和完全移除后的真实边界与基材状态，避免把膜层、反光或灰尘误画成基材缺陷。

## 准备材料与变量

图1：保护膜完整覆盖状态；图2：起撕角和膜边微距；图3：部分撕除状态；图4：完全移除后的同机位表面；图5：保护区、人工问题和状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{部件}}` | 黑色高光亚克力面板 |
| `{{区域}}` | 显示窗W1、触控标记K1、外框E1 |
| `{{状态}}` | F0膜完整；F1从右上角撕至边界L1；F2膜已完全移除 |
| `{{人工记录}}` | F1膜边L1已核对；F2灰尘点D3保留待人工清洁 |
| `{{标题}}` | 先分清膜面和基材 |

## 拿来就用的具体示例

三个状态必须来自同一表面和尽量一致机位，膜边与问题归属由人工确认；照片不能证明保护膜性能或基材无损。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9“先分清膜面和基材”。同一黑色高光亚克力面板依次展示F0膜完整、F1从右上角撕至L1、F2膜完全移除。保持显示窗W1、触控标记K1、外框E1和环境反射；F1膜边卷曲并有真实阴影，F2保留实拍灰尘点D3，不把膜面擦痕复制过去。状态写“F1膜边L1已核对；F2灰尘点D3保留待人工清洁”。不画手或工具，不宣称无划痕、防刮或合格。只输出一张图。
```


## 完整提示词

```text
依据图1至图5制作16:9“{{标题}}”三状态对照，严格依次展示同一{{部件}}的{{状态}}。保持{{区域}}、机位、裁切、面板轮廓和环境反射一致。F0按图1保留膜面轻微雾度、气泡或擦痕；F1按图2、图3展示真实起撕角、卷曲膜边与L1分界，膜片必须与未撕区域连续且有可信厚度和阴影；F2只按图4展示移除后的基材，不把F0膜面痕迹复制到基材，也不自动清除图4可见的灰尘点D3。用一条细黄线沿L1标界，不生成手、工具或撕膜动作。底部逐字写“{{人工记录}}”。不要自动判断划痕归属、修复基材、增强镜面，不宣称无划痕、防刮、洁净、合格或保护性能。只输出一张静态对照图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

对照图不替代表面检测、洁净检查、划伤判定、保护膜性能测试或质量放行。
