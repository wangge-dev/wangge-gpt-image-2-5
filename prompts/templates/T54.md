# T54 · 帐篷风绳与地钉拓扑图

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在同一顶真实搭建帐篷的俯视图上逐点绑定风绳、调节片和地钉，避免错接、交叉、漏点及凭空增加固定件。

## 准备材料与变量

图1：完整搭建状态四分之三视角；图2：正上方或高位俯视；图3：全部风绳、调节片、地钉同框清点；图4：帐篷连接点微距；图5：真实完成固定照。提供连接点编号、逐条路径表和组件数量。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{装备}}` | 双人穹顶帐篷 |
| `{{组件}}` | 风绳4根、调节片4个、地钉4枚 |
| `{{路径}}` | A1→绳1→调节片1→P1；A2→绳2→调节片2→P2；A3→绳3→调节片3→P3；A4→绳4→调节片4→P4 |
| `{{标题}}` | 四点风绳连接关系 |
| `{{声明}}` | 连接位置以当前样品说明书与实搭照片为准 |

## 拿来就用的具体示例

需提供同一帐篷的俯视、连接点微距、组件清点和真实固定完成照；缺少俯视证据时不推断背面连接关系。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9双人穹顶帐篷“四点风绳连接关系”。中央保持真实门厅方向和杆件，在四个连接点标A1–A4，外围地钉标P1–P4。四条路径严格为A1→绳1→调节片1→P1，依次到A4→绳4→调节片4→P4；每条独立连续，不交叉、不穿过帐篷。左侧各一次展示风绳4根、调节片4个、地钉4枚。底部写“连接位置以当前样品说明书与实搭照片为准”。不加第五根绳、锤子、人物、角度、拉力或抗风结论。只输出一张图。
```


## 完整提示词

```text
依据图1至图5制作16:9{{装备}}“{{标题}}”。中央使用图2俯视帐篷，保持门厅方向、布片、杆件交叉点和四个真实连接点；连接点按图4编号A1至A4，外围地钉按图5编号P1至P4。严格按{{路径}}绘制四条独立风绳，每条只有一根连续线、一个调节片和一枚地钉，不交叉、不合并、不穿过帐篷布面。左侧清点区按图3各一次展示{{组件}}，颜色与形状一致。右侧用四行短表逐字列出路径，不增加角度、距离或拉力数字。底部只写“{{声明}}”。不要新增第5根风绳、营绳灯、锤子、人物、岩石压绳或地下剖面，也不写抗风等级、牢固、安全、适用地面和恶劣天气结论。只输出一张拓扑图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

拓扑图只说明当前样品的可见连接关系，不替代说明书、现场地面判断、风况评估和安全搭建。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
