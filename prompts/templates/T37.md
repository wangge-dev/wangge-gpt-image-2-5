# T37 · 底图锚点式位置标注

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Charts & Infographics · 本库原创设计**

在用户提供的平面图、园区图或场地图上按编号锚点放置短中文标签，不重绘路线或猜地理关系。

## 准备材料与变量

图1：已确认底图；图2：标有A至E锚点的副本；提供锚点、地点名、图标类型三列表和标题。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{标题}}` | 活动区域示意 |
| `{{锚点表}}` | A→入口→门；B→签到处→桌；C→主会场→舞台；D→休息区→座椅；E→洗手间→通用指示 |
| `{{方向说明}}` | 本图不表示精确距离 |

## 拿来就用的具体示例

准备已确认底图、锚点副本和逐点名称；底图不准确时先回到正式场地资料修正。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以图1场地图为底图，图2定义A至E位置。A标“入口”，B标“签到处”，C标“主会场”，D标“休息区”，E标“洗手间”，各一个小图标和一次文字。标记不得漂移；文字重叠时用短线连回原锚点。保持原建筑、道路和边界，不加路线、距离、比例尺或新出入口。底部只写“本图不表示精确距离”。只输出一张图。
```


## 完整提示词

```text
以图1为底图，图2只定义锚点位置。制作4:5“{{标题}}”：严格按{{锚点表}}在A至E对应位置放置一个小图标和一条地点名，文字各出现一次；标记不得漂移到邻近房间、道路或区域。保持图1边界、建筑、道路、比例、颜色和原有标注，不新增路线、距离、比例尺、指南针或出入口。标签重叠时只移动文字框并用短线连回原锚点，不能移动锚点。底部只写“{{方向说明}}”。成品移除A至E字母和锚点圆圈。只输出一张标注图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡不生成导航、消防疏散或测绘结论；涉及安全路线时必须使用正式审核图纸。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 楼层导览

```text
以图1楼层图为底图，图2定义{{锚点范围}}。按{{锚点表}}放置短中文标签，锚点不移动，不新增房间、通道、疏散路线或距离。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，重新附图2。本轮只把“{{地点名}}”标签端点恢复到{{锚点}}；底图和其余标签不变。
```
