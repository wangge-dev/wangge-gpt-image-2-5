# T319 · 电商系列图单光源方向与接触阴影一致性核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把已验收系列成片作为不可重绘缩略图，逐张核对主光方向、投影方向、接触点和悬浮异常，只记录人工结论，不自动美化。

## 准备材料与变量

图1至图4：同系列已输出成片P1-P4；图5：人工光向箭头与接触区遮罩；图6：人工状态表；图7：允许返工编号。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{系列}}` | 桌面小家电四张主视觉 |
| `{{成片}}` | P1白底主图、P2台面场景、P3细节图、P4横版广告 |
| `{{核对项}}` | 主光L、投影S、接触点C、悬浮间隙F |
| `{{人工状态}}` | P1 L/S/C通过；P2 L通过、C待复核D247；P3 C不适用；P4 S方向待复核D248 |
| `{{固定规则}}` | 缩略图不得重绘，箭头和框只采用图5人工标注，不从像素自动判光 |
| `{{标题}}` | 系列图可以换场景，但光向、投影和落地关系要逐张有据 |

## 拿来就用的具体示例

提供原始成片文件、人工标注的光向/投影/接触区和状态表；没有人工记录时不得自动评价光线物理正确性。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作“系列图可以换场景，但光向、投影和落地关系要逐张有据”。P1-P4原图不重绘，分别列L/S/C/F；写“P1 L/S/C通过；P2 L通过、C待复核D247；P3 C不适用；P4 S方向待复核D248”。箭头与框只照人工标注。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”核对板。按{{成片}}原样放置四张缩略图，不重绘、补光或改商品；每张下方固定列出{{核对项}}，严格写入“{{人工状态}}”。光向箭头、投影描边和接触框只按“{{固定规则}}”落位，缺记录写“未核对”，不自行推断。不可把四图调成同一曝光、修掉真实阴影、生成新投影、把背景边缘当悬浮、自动判定通过或给质量评分。D247/D248只框对应人工问题位。不要增加营销文案、性能结论或发布批准。只输出一张静态核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

核对板记录人工视觉判断，不替代摄影测光、三维光照重建、平台审核、转化评估或发布批准。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
