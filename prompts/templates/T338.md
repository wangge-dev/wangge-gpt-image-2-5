# T338 · 详情页相邻模块上下边界锚点连续生成

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

生成长详情页的下一张独立模块时，用已验收上一模块的底部窄条和人工边界表锁定进入状态与离开状态，减少拼接处色带、纹理和装饰突然断裂。

## 准备材料与变量

图1：同一SKU商品原图；图2：已验收上一模块P2；图3：P2底部10%边界条B2；图4：本轮事实图；图5：人工边界锚点表；图6：品牌版式规范。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 墨绿色保温杯 |
| `{{本轮模块}}` | P3内胆材质 |
| `{{标题}}` | 内里，清楚看见 |
| `{{说明}}` | 内胆纹理以所附实拍为准 |
| `{{进入锚点}}` | 顶部背景色#E9E5DC；左侧细弧线在x=18%进入；柔光由左上延续 |
| `{{离开锚点}}` | 底部回到纯色#E9E5DC；不保留跨边文字和商品切片 |
| `{{版式}}` | 标题左上，商品右侧，占画面高度58%，四周安全边距8% |

## 拿来就用的具体示例

必须提供上一模块已验收版本、其底部边界条和人工锚点表；没有人工颜色或位置值时只写可见关系，不让模型测色或算坐标。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
只生成保温杯详情页P3“内胆材质”3:4竖图。顶部承接#E9E5DC背景、x=18%进入的细弧线和左上柔光；不复制P2旧标题与旧卖点。底部回到同一纯色，不留跨边文字或商品切片。标题只写“内里，清楚看见”，说明只写“内胆纹理以所附实拍为准”。商品杯型、杯盖、墨绿色和标志按原图，内胆只按本轮微距。不要页面框、接缝线、参数或认证。只输出一张图。
```


## 完整提示词

```text
依据图1至图6，只生成长详情页的{{本轮模块}}一张3:4竖图。顶部严格承接人工表中的“{{进入锚点}}”，但不要复制图2中的旧标题、旧商品或旧卖点；底部严格形成“{{离开锚点}}”，为下一模块留下干净接口。标题逐字写“{{标题}}”，说明逐字写“{{说明}}”，除此之外不加文字。{{商品}}身份、杯型、杯盖、比例、墨绿色和标志以图1为准，本轮材质事实只取图4；执行“{{版式}}”。背景色、光向、颗粒与装饰线在上下边缘连续，模块中央可按本轮内容重新构图。不得把B2当成要拼进成片的截图，不出现接缝线、页面框、模块编号或上一模块残片，不补容量、保温时长、钢材牌号、认证和价格。只输出P3一张独立成品图。
```

## 参数设置

建议画布：`1536x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

相邻模块仍需在真实页面中拼接预览；生成模型不保证像素级无缝，色值、坐标和接缝结果应由设计软件与人工复核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
