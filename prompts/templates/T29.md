# T29 · 实拍步骤图与短中文说明

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Charts & Infographics · 本库原创设计**

按真实步骤照片和审定短句生成顺序清晰的操作图，不补动作、工具或结果。

## 准备材料与变量

图1至图4：按时间顺序的四张真实步骤照；提供四条短标题、每步一句说明和明确结束状态。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{标题}}` | 滤芯更换步骤 |
| `{{步骤文字}}` | 1 断开电源｜拔下插头；2 打开仓盖｜按图示方向掀开；3 取出旧滤芯｜握住提手垂直取出；4 装入新滤芯｜对准卡槽压到位 |
| `{{结束状态}}` | 仓盖关闭，电源仍断开 |

## 拿来就用的具体示例

准备同一对象、同一环境的四张连续实拍和经说明书核对的短句；缺步骤时不让模型补演。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
依据图1至图4制作4:5“滤芯更换步骤”图。四格依次写“1 断开电源｜拔下插头”“2 打开仓盖｜按图示方向掀开”“3 取出旧滤芯｜握住提手垂直取出”“4 装入新滤芯｜对准卡槽压到位”，照片逐格对应，箭头只按1到4连接。最后保持仓盖关闭、电源仍断开。不要增加工具、通电测试或第五步。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作4:5中文步骤图，标题只写“{{标题}}”。按左上、右上、左下、右下排列四步，每格只使用对应编号照片，保持手、工具、部件、方向和状态；逐格准确排入{{步骤文字}}中的对应编号、短标题和一句说明。箭头只连接1→2→3→4，不跨格、不反向。第4格必须保持{{结束状态}}。不要合并步骤、交换照片、补造手势、工具、警告、耗材、按钮或通电结果，不增加第五步和未提供安全结论。只输出一张图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

涉及电气、医疗、车辆或安装安全时，步骤必须来自正式说明；本卡只做已有流程的视觉整理。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 三步横向版

```text
依据图1至图3制作{{标题}}三步横向图。三栏逐一绑定照片和{{三步文字}}，箭头只按1→2→3连接，保持{{结束状态}}，不补第四步。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

以上一轮结果为底图。本轮只修正第{{步骤号}}格的{{照片、方向或文字问题}}，按图{{参考图号}}与“{{正确文字}}”恢复；其他步骤与箭头不变。
