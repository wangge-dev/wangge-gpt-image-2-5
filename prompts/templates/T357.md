# T357 · 电商详情短卖点脚注编号与来源页绑定

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Documents & Publishing · 本库原创设计**

把详情页中的短卖点与底部脚注编号逐条绑定到批准来源页，控制脚注字号、顺序和未提供状态，避免脚注错号或凭空补出处。

## 准备材料与变量

图1：商品原图；图2：批准短卖点表；图3至图5：来源页E1-E3；图6：人工卖点—脚注映射；图7：文字区与字号规则。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 折叠露营灯 |
| `{{卖点}}` | ‘三档亮度’[1]；‘Type-C充电’[2]；‘折叠提手’[3]；‘防水’无来源不得出现 |
| `{{来源}}` | [1]说明书E1第4页；[2]规格表E2第2行；[3]结构图E3；顺序固定 |
| `{{字号}}` | 卖点不低于42 px；脚注不低于26 px；脚注每条单独一行 |
| `{{标题}}` | 照明方式，清楚列出 |
| `{{声明}}` | 脚注仅表示资料来源，不代表平台或法务批准 |

## 拿来就用的具体示例

卖点、来源页和编号映射必须人工批准；来源缺失的卖点直接移除，不能让模型搜索或猜测。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作折叠露营灯3:4详情模块。只列“三档亮度[1]”“Type-C充电[2]”“折叠提手[3]”；脚注依次为[1]说明书E1第4页、[2]规格表E2第2行、[3]结构图E3。卖点不低于42 px，脚注不低于26 px且每条一行。无来源的“防水”不出现。底部写“脚注仅表示资料来源，不代表平台或法务批准”。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作{{商品}}3:4详情模块。商品位于上半部，保持外形、灯罩、提手、接口盖、颜色和标志。中部标题只写“{{标题}}”，下方逐字排列“{{卖点}}”，上标编号与“{{来源}}”一一对应并按[1][2][3]排序；执行“{{字号}}”。底部写“{{声明}}”。没有来源的“防水”完全不出现，也不保留空编号。不可交换脚注、合并来源、从图片或常识补出处、把来源页改成认证徽章、添加网址二维码、价格、续航或亮度数值。只输出一张成品图。
```

## 参数设置

建议画布：`1536x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

脚注映射不替代事实核验、文档有效性、检测认证、广告合规、平台审核或法务批准。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
