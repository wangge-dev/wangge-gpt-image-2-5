# T11 · 品牌身份概念板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Brand & Logos · 通用来源改写**

将标志、配色与两个触点组织成单页提案。

## 准备材料与变量

按正文准备资料。图1、图2仅在正文需要时上传；文字和数据先核实再填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{品牌名}}` | 林间书屋 |
| `{{定位}}` | 面向社区读者的温暖独立书店 |
| `{{配色}}` | 墨绿 #234B3A、米白 #F5F1E8、暖棕 #93694B |
| `{{品牌短句}}` | 让阅读发生在身边 |

## 完整提示词

```text
为品牌“{{品牌名}}”绘制一张品牌身份概念板。定位：{{定位}}。左侧是一个简洁字标与图形标志方案，右上显示{{配色}}的色块及给定颜色值，右下展示名片和App图标应用。所有触点采用同一标志和字体气质。主标题只写品牌名，附文仅为“{{品牌短句}}”。不要输出多页策略文字，不声称生成矢量文件或已完成商标检索。
```

## 参数设置

建议画布：`1536x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 布局或风格变体

```text
为品牌“{{品牌名}}”绘制一个标志方案。定位：{{定位}}。只展示简洁字标与图形标志，使用{{配色}}，白底居中，无概念板、应用场景或品牌短句；有标志参考时保持其形状。不要输出多页策略文字，不声称生成矢量文件或已完成商标检索。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，重新附所需原始参考。本轮只修改品牌板{{应用区域}}的标志：改成与已确认主标志相同的轮廓，保留色块值和品牌短句。只输出这一张修改后的图。
```
