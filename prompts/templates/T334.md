# T334 · 局部编辑批准遮罩与人工差异区溢出核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

并列编辑前后原图、批准遮罩和外部人工差异区，区分遮罩内预期变化与遮罩外异常变化，不让图片模型自行计算像素差。

## 准备材料与变量

图1：批准底图V0；图2：编辑结果V1；图3：批准遮罩M1；图4：外部工具或人工提供差异区D1-D4；图5：允许变化清单；图6：保护区P1-P5；图7：人工状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{任务}}` | 包装标题局部返工ED75 |
| `{{允许变化}}` | M1内旧标题替换为审定新标题，局部底纹修补 |
| `{{保护区}}` | P1盒型、P2标志、P3其他文字、P4折线、P5阴影与背景 |
| `{{差异状态}}` | D1位于M1内允许；D2跨出M1右缘待复核；D3位于P2异常；D4为压缩噪声不判断 |
| `{{显示规则}}` | V0/V1原图不重绘；D1-D4只采用外部差异结果；不由模型计算像素差 |
| `{{记录}}` | D2待复核D261；D3需回退P2；D4交外部工具复核 |
| `{{标题}}` | 局部编辑是否越界，要把批准遮罩和外部差异区逐项对照 |

## 拿来就用的具体示例

提供编辑前后原图、批准遮罩、外部差异结果、允许变化与保护区表；没有差异工具或人工结果时不得让图片模型代算。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作ED75遮罩溢出核对板，V0/V1原图不改，M1按批准轮廓；D1标允许，D2标跨右缘待复核D261，D3标P2异常需回退，D4标压缩噪声交外部工具。不得自动找不同。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”核对板。左侧原样并列V0/V1，中间叠加M1轮廓，右侧按“{{差异状态}}”列D1-D4，并标“{{保护区}}”。严格执行“{{显示规则}}”；只记录外部提供的差异，不自动找不同、重绘结果、修复越界或把所有视觉差异判为错误。底部逐字写“{{记录}}”，D261只框D2。不可把核对板输出成新成品、合并V0/V1、扩大M1、删除D3或声称像素级一致。只输出一张核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

核对板不替代像素差工具、色差阈值、图像配准、质量标准、人工验收、法务或最终发布批准。
