# T335 · 透明底商品边缘白边黑边与半透明细节多底色核对

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把同一透明背景商品文件原样放在白、黑、灰棋盘三种检查底上，记录人工指出的边缘色边与半透明细节，不在核对板中修边。

## 准备材料与变量

图1：透明背景商品文件A1；图2：白底预览W；图3：黑底预览K；图4：灰棋盘预览C；图5：人工边缘区E1-E4；图6：半透明细节T1-T3；图7：状态表。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 透明玻璃瓶抠图PNG76 |
| `{{检查底}}` | W纯白、K纯黑、C灰棋盘 |
| `{{边缘状态}}` | E1瓶盖左缘白边；E2瓶底黑边；E3高光边正常；E4阴影尾部待复核D262 |
| `{{半透明状态}}` | T1瓶肩、T2瓶身、T3玻璃底均保留原文件透明表现，不重建 |

## 拿来就用的具体示例

提供同一透明文件及由外部工具导出的三种背景预览、人工边缘和半透明状态；只有合成JPG时不得声称拥有透明通道。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作PNG76白/黑/灰棋盘三底色核对板，同一A1像素不改。标E1白边、E2黑边、E3正常、E4阴影尾部待复核D262；T1-T3只保留源文件透明表现。不修边，不声称读取Alpha。只输出一张图。
```


## 完整提示词

```text
依据图1至图7制作16:9“{{标题}}”三底色核对板。将同一A1按{{检查底}}等大、同位置展示，商品像素、尺寸和透明表现不变；严格标注“{{边缘状态}}”与“{{半透明状态}}”，执行“{{显示规则}}”。不可在不同底色版重抠商品、擦白边黑边、补玻璃折射、伪造Alpha通道、把棋盘烘焙进A1、删除阴影或自动判断边缘合格。底部写“核对板不修改源PNG”，D262只框E4。只输出一张核对板。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

核对板不替代Alpha通道检查、专业抠图、边缘去色、色彩管理、导出测试、平台透明图支持或人工验收。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
