# G49 · 遇水显纹伞面干湿对照

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在同一把伞、同一视角下展示干燥与实拍湿润区域的图案变化，不把视觉变化解释成防水或耐久性能。

## 准备材料与变量

图1：完整展开雨伞干燥状态；图2：同一伞面湿润状态；图3：干湿分界微距；图4：伞骨、伞柄与边缘结构。提供实际显现图案、湿润范围和准确标题。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |

| `{{显现图案}}` | 浅蓝云朵与短雨线 |

## 拿来就用的具体示例

准备同一把伞的干燥、湿润、分界微距和结构照片；不同样品的图案位置不能拼成同一把伞的变化证据。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9深蓝八骨长柄伞干湿对照广告，只出现一把完整展开的伞。左侧四个扇区保持图1干燥深蓝，不显图案；右侧四个扇区按图2显示浅蓝云朵与短雨线，图案随扇区透视并在接缝处自然中断。弧形分界按图3保留水珠和湿润过渡，伞骨、伞柄与边缘按图4。顶部只写“雨落，图案出现”，底部写“仅展示所附样品在拍摄状态下的可见变化”。不写防水、速干、耐洗或寿命。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作16:9{{雨伞}}干湿对照广告。画面只出现一把完整展开的伞，正对略俯视，伞骨、八个扇区、中心帽、伞柄和边缘按图1、图4保持。以一条自然弧形水迹将伞面分成两区：左侧四个扇区保持图1干燥深蓝状态，不出现隐藏图案；{{湿润范围}}严格按图2呈现{{显现图案}}，图案随真实扇区透视和接缝中断，颜色、密度与图2一致。分界处按图3保留水珠、湿润深浅和局部过渡，不把整把伞浸湿，不让图案越过伞边或出现在背景。背景为中性浅灰棚拍，柔光保证结构可辨。顶部只写“{{标题}}”，底部写“{{说明}}”。不添加防水等级、拒水、速干、耐洗、耐晒、可重复次数或使用寿命结论。只输出一张图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

遇水显纹是所附样品的可见状态，不证明防水、耐久、可重复次数与其他环境下表现。
