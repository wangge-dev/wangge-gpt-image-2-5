## 准备材料与变量

按正文上传对应参考图；无需参考图的场景可以直接填词生成。下方图片只帮助理解旧案例的视觉方向。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{品牌}}` | 自有品牌名称 |
| `{{本页}}` | 企业介绍／产品／应用／客户案例／封面／封底，选一项 |
| `{{标题}}` | 填写本页审定标题 |
| `{{正文}}` | 填写本页审定正文 |

## 完整提示词

```text
为“{{品牌}}”制作画册的“{{本页}}”，只输出本页正面平面设计。图1是已确认的品牌版式，图2起为本页产品或场景素材。标题“{{标题}}”，正文“{{正文}}”，图文分区有清晰层级，保留品牌配色与统一字体气质。图片不得虚构客户合作或产品性能。后续其他页面沿用本页风格，当前不要自动生成全册或书本样机。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。这是本库的起步建议，不是效果保证。
