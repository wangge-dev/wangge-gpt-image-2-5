# G25 · 时尚目录三图拼贴

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 精选旧案例改写**

用同一成年模特与同一服装的获准照片制作目录拼贴，不凭空生成新穿着视角。

## 准备材料与变量

三图版：上传已获准使用、同一成年模特穿同一套实际服装的三张照片，人工逐格声明实际图号、姿态与可见区域；不是一张人物照加一张衣服图就补坐姿和背面。没有三张照片时选“单图目录海报”变体，只用图1完整外观与人工指定可读裁切。不得把第三方例图直接当本次模特或服装参考。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{目录对象}}` | 同一获准成年模特穿白色衬衫与深蓝长裤，以所附真实照片为准 |
| `{{照片职责}}` | 左主格＝图1全身站姿；右上＝图2同一套服装坐姿；右下＝图3同一套服装上身近照；三张均获准用于目录，不补缺失状态 |
| `{{背景配色}}` | 米白页面背景、暖灰细边框；照片内服装本色不变 |
| `{{单图裁切清单}}` | 左主格图1完整外观；右上取图1已可读的领口；右下取图1已可读的袖口，均不代表新视角 |

## 拿来就用的具体示例

图1全身站姿、图2坐姿、图3上身近照：同一成年模特穿同一白衬衫／深蓝长裤的三张获准照片。这是填写演示，未采集人物素材；只有图1时使用单图变体。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
目录对象：同一获准成年模特穿白色衬衫与深蓝长裤，以所附真实照片为准。人工照片职责：左主格＝图1全身站姿；右上＝图2同一套服装坐姿；右下＝图3同一套服装上身近照；三张均获准用于目录，不补缺失状态。仅采用清单对应照片已有的身份、姿态、服装版型、颜色、图案、配件和可见区域；不从人物照和单件衣服参考补造坐姿、背面或未拍到的搭配。

制作一张4:5时尚目录拼贴，四周6%留边；安全区左侧约62%为全身主格，右侧约38%为上下两格，间距计入两区，不挤出第四帧。主格保留完整身体与衣服轮廓，右侧只用指定照片，不把裤腿或领口截去后重绘。每张照片只等比例缩放和人工允许的裁切；可将小格边框轻微倾斜，但不改变照片内部透视，不裁掉关键商品特征。

页面配色：米白页面背景、暖灰细边框；照片内服装本色不变。照片内容保留自己的原光线与服装本色，背景配色不染衣服，不重新换装或修饰体型。没有对应照片就停止三图版并用单图版，不复制图1冒充不同姿态。不加价格、网页按钮、外部Logo、标题或水印；服装原有可见图案与商标不因“无Logo”被擦除。只输出一张目录图片，不是可交互购物页面。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

三图版用于已有获准目录照片的拼贴；单图版不生成新姿态。不把旧来源预览当成当前中文扩写的实测图。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 单图目录海报 · single-source-catalog

```text
只使用图1制作一张4:5目录海报。目录对象：{{目录对象}}。图1必须是获准使用的成年模特穿实际服装的完整照片，不需要其他人物或服装照片。

人工裁切清单：{{单图裁切清单}}。四周6%安全边距，左约62%为图1完整外观，右约38%仅为同照片指定可读局部，间距计入两区；局部不是新姿态、新服装或新视角。原图不够清楚或没有指定可读裁切时，取消所有局部格，完整图1居中展示，不填空框、不放大生成新织纹。

页面配色：{{背景配色}}。只等比例缩放、按批准区域裁切，不改变图1脸部、身形、姿态、穿着、本色、图案或内部光线；不扩出未拍到的脚、衣服背面和新配件。禁止新增价格、页面按钮、外部Logo、标题和水印；保留服装本身可见图案与商标。只输出一张完成目录图。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
