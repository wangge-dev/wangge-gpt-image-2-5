# G31 · 餐饮异形立牌与套餐展架

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 精选旧案例改写**

生成只含异形立牌本体的餐饮物料提案，展示真实菜品与活动。

## 准备材料与变量

图1为主推菜品照片；图2、图3为两款配餐照片；图4可选品牌标识。提供真实套餐和活动文字。没有配餐图时选择单品变体。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{品牌名}}` | 填写门店或自有品牌名称 |
| `{{主标题}}` | 新品尝鲜 |
| `{{副标题}}` | 今日好味 |
| `{{卖点一}}` | 填写真实菜品卖点 |
| `{{卖点二}}` | 填写另一条真实卖点 |
| `{{活动文字}}` | 填写真实套餐、价格、活动时间及必要条件，建议控制在三行 |
| `{{配色}}` | 暖红、奶油白、少量金黄 |

## 完整提示词

```text
生成一张餐饮异形立牌成品展示图，白色背景，只保留一个完整立牌及其完整底座，不出现门店、人物、桌椅或墙面。立牌外轮廓随标题和菜品形成连贯的不规则裁切边缘，浅色包边清楚，不做普通矩形海报。近正面视角，轻微厚度与柔和接触阴影，四周留出空间，不裁断底座。

图1负责主推菜品的食材、份量和外观，图2、图3分别负责两款配餐，图4如有只负责品牌标识。主菜放大位于中间，配餐稍小分布两侧，每款各出现一次。保持实际菜品成分，不自动添加虾仁、芝士、配菜、额外酱汁或赠品。真实商业美食摄影质感，食物不能变成立牌之外的实体盘子。

文字按下列层级排版，各出现一次：顶部品牌名“{{品牌名}}”，最大主标题“{{主标题}}”，其下副标题“{{副标题}}”；菜品两侧标签“{{卖点一}}”“{{卖点二}}”；底部活动区准确写“{{活动文字}}”。配色为{{配色}}，热闹的门店POP风，标题、菜品、标签与活动区分明，不加其他小字、二维码、虚构销量或认证。

只输出一张立牌视觉提案；不生成生产刀线、出血线、猜测尺寸或可制造保证。
```

## 参数设置

建议画布：`1152x1536`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

使用透明背景变体时另设 background=transparent，output_format=png或webp；基础版为白底。图像不是生产刀模文件。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。
