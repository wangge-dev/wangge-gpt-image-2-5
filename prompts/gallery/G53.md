# G53 · 可转换饰品两种成品状态

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

用组件清点和两张真实成品照展示同一套饰品的两种组合状态，避免变形、漏件和凭空增加连接件。

## 准备材料与变量

图1：全部组件平铺清点；图2：项链状态成品照；图3：双圈手链状态成品照；图4：扣头与连接环微距。提供组件数量表、两状态名称和准确标题。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{饰品}}` | 金色可转换链饰 |
| `{{组件清单}}` | 长链1条、圆形吊坠1枚、龙虾扣1个、连接环2个 |
| `{{状态一}}` | 长链项链 |
| `{{状态二}}` | 双圈手链 |
| `{{标题}}` | 同一组组件，两种佩戴方式 |

## 拿来就用的具体示例

准备全部组件平铺和两种真实完成状态；如果两种状态使用了不同配件，应分别列清，不能写成同一组组件守恒。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9金色可转换链饰结构对照。上方清点区各一次展示“长链1条、圆形吊坠1枚、龙虾扣1个、连接环2个”。下方左栏“长链项链”按图2，右栏“双圈手链”按图3；链节、吊坠、扣头和连接环一致，连接处按图4。不复制吊坠、不漏扣件、不加延长链或散件。顶部只写“同一组组件，两种佩戴方式”。不写纯度、重量、牢固、抗敏或尺寸适配。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作16:9{{饰品}}结构对照。上方中央用一行小型清点区展示{{组件清单}}，每件只出现一次并标准确短名。下方左右两栏：左栏“{{状态一}}”严格按图2展示完整成品；右栏“{{状态二}}”严格按图3展示完整成品。两栏均使用同一组组件的外观、链节形状、颜色、吊坠正面、扣头和连接环，连接位置以图4为准；两种状态分别完整呈现，不在同一栏同时放散件。不得改变链节数量观感、复制吊坠、隐藏必要扣件、生成额外延长链或让金属穿插。白色背景、柔和侧光，金属反射克制。顶部只写“{{标题}}”。不添加贵金属纯度、宝石、重量、尺寸、牢固度、过敏安全或所有人均可佩戴结论。只输出一张图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

只有两种真实完成照和组件表一致时才可称转换状态；图片不证明金属材质、牢固与佩戴安全。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
