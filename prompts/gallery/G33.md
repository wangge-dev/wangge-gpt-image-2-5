# G33 · 收藏玩具与配件发布板

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 旧创意对照适配**

把同一款收藏玩具、真实配件和包装组织成可清点的新品发布视觉。

## 准备材料与变量

图1：玩具正面完整照；图2：背面或侧面；图3：全部真实配件与包装同框照；图4：材质细节近照。没有实拍依据的替换脸、隐藏配件、稀有度和限量信息不要填写。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品身份}}` | 海洋研究员主题收藏公仔，蓝色外套、橙色潜水头盔 |
| `{{配件清单}}` | 透明展示底座1个、望远镜1个、记录板1个 |
| `{{包装信息}}` | 蓝白纸盒1个，正面只保留原有品名与标志 |
| `{{材质细节}}` | 哑光PVC公仔、透明亚克力底座、印刷纸盒 |
| `{{背景风格}}` | 深海蓝到浅青渐变摄影棚 |

## 拿来就用的具体示例

准备同一公仔的正面、侧背面、完整配件包装同框照和材质近照；示例数量必须与实物一致。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以图1至图4为同一款海洋研究员收藏公仔的唯一依据，制作4:5新品发布板。蓝色外套、橙色潜水头盔的主公仔位于中央偏上，占画面高度55%；保持脸、服装、头身比例、颜色与接缝。下方与两侧只陈列图3中真实存在的透明展示底座1个、望远镜1个、记录板1个和蓝白纸盒1个，每件一次。右下角小窗展示图4可见的哑光PVC表面与透明底座边缘。深海蓝到浅青渐变背景，干净商业柔光和可信阴影。包装只保留原有品名与标志，不新增价格、限量编号、稀有度、认证、替换脸或其他配件。只输出一张图。
```


## 完整提示词

```text
以图1至图4为同一SKU的唯一商品依据，制作一张4:5收藏玩具新品发布板。主公仔位于画面中央偏上，占高度55%，保持{{商品身份}}的头身比例、面部、服装、颜色、接缝和可见结构。下方与两侧分区陈列{{配件清单}}和{{包装信息}}，严格按图3的种类与数量，每件只出现一次；包装不遮挡主体，也不重写原有文字。右下角设置一个小型材质近照窗，只展示图4可见的{{材质细节}}。背景为{{背景风格}}，使用干净商业柔光、轻微轮廓光和可信接触阴影。版面只允许原包装已有文字，不新增价格、限量编号、稀有度、认证或虚构配件。不要拆解看不见的内部结构，不生成替换脸和第二个公仔。只输出一张完整发布板。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

适合已有实物的收藏玩具发布图。只有概念设定、没有成品实拍时，应明确标为概念设计，不能伪装成已生产套装。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
