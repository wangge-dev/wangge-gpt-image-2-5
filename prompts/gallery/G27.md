# G27 · 护肤商业静态分镜

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Scenes & Storytelling · 精选旧案例改写**

以批准的实际照片排六格护肤商业静态分镜；只有封闭商品图时可降为三格概念陈列，不编造开盖、膏体或人物使用过程。

## 准备材料与变量

六格版：图1–图6分别是人工批准的六张素材，可以是封闭商品、真实开盖、真实质地或获准成年人物持用照；只使用确已提供的状态。文字列明每格对应图号和允许裁切，不默认存在开盖或人物照片。只有一张封闭商品图时选三格商品概念分支。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 米白封闭护肤软管，原盖、原标志与原字，具体外观依上传照片 |
| `{{分镜映射}}` | 第1格用图1封闭商品环境全景；第2格用图2同款封闭正面；第3格用图3同款封闭侧面；第4格用图4原包装可读局部；第5格用图5同款封闭商品近景；第6格用图6同款封闭商品主视觉；全部只裁切已有画面，不出现人物、开盖或膏体 |
| `{{色调}}` | 暖象牙白与浅石色，仅用于画框间留白与背景，不改变商品本色 |
| `{{图1裁切}}` | 正面原标志附近已清楚可读的区域；没有可读细节时保留完整商品，不放大生成微观纹理 |

## 拿来就用的具体示例

图1–图6：同款米白封闭护肤软管的六张已批准照片，按示例映射依次提供；其中图4为真实可读包装局部，其他均保持封闭状态，无人物、开盖或膏体。只有图1时改选单图三格分支，示例不是本库实测素材。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作一张3列2行共六格的3:2横版静态广告分镜板，不生成视频或运动过程。商品信息：米白封闭护肤软管，原盖、原标志与原字，具体外观依上传照片。图1至图6各只负责自己的实拍可见内容；严格按第1格用图1封闭商品环境全景；第2格用图2同款封闭正面；第3格用图3同款封闭侧面；第4格用图4原包装可读局部；第5格用图5同款封闭商品近景；第6格用图6同款封闭商品主视觉；全部只裁切已有画面，不出现人物、开盖或膏体排格，同一商品的包装身份一致。若映射引用了未提供图号、未知状态或不同SKU，先换已批准照片并改映射，不由模型补开盖、手、脸、膏体、涂抹或前后效果。没有六张素材时使用三格单图分支，不留空格假装完整流程。

画布四边6%留白，六个格子等大，每格原图等比例适配，格间留白约画布宽2%；从左到右、从上到下阅读，每格一个主体，不跨格拼身体或包装。保留实拍遮挡和可见面，不重拍未知角度、不生成原照裁切外内容。首格交代环境，末格强化商品，层次来自原有景别和批准裁切，不靠新造事实。

全板使用暖象牙白与浅石色，仅用于画框间留白与背景，不改变商品本色，不同照片只允许温和统一明暗，不能漂移包装色或皮肤颜色。不要新增字幕、编号、音乐、音效、运动指令、功效、安全认证或品牌背书，不删除原包装字。不把分镜并置当真实连续使用、时间顺序或效果证据；人物素材仅在获准并真实提供时出现。只输出一张六格板。
```

## 参数设置

建议画布：`1536x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

格数由素材条件决定，六格版需六张已批准照片；只有一张封闭商品照也有完整三格正文。来源旧图只是原库参考，不是中文改写后的结果；不要求复刻原品牌、人物或肤质功效。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 单图三格商品概念 · product-only-three-panel

```text
只上传图1封闭商品照。商品信息：{{商品信息}}；图1是唯一外观依据，只保留其已拍到的角度、部件、原字与真实遮挡，不使用其他图号。制作一张3:2横版三格静态商业概念板，一行三格，四边6%安全留白、格间约画布宽2%，三格等宽。

第一格：完整商品原角度，在浅色背景里留较多空白；第二格：只对图1按“{{图1裁切}}”取真实局部，不超分辨率补纹理，不能裁断需要展示的文字；第三格：同一完整商品原角度，减少周围空白形成主视觉，不复制成多件在售商品。三格是同图的概念排版，不是假装三次拍摄或实际使用顺序。

色调为{{色调}}。没有开盖、膏体、手、人物或过程照片就全部不出现，不补内部、背面、功效、价格、道具或字幕，不删包装原字。可读细节不足时第二格仍用完整商品，宁可重复构图也不生成事实。只输出一张三格板，不生成六格、不留空占位格。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
