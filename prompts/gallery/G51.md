# G51 · 磁吸配件三阶段对位说明

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

把主件、磁吸配件和真实连接面拆成靠近前、对位中、吸附后三阶段，说明安装方向而不虚构磁力与兼容性。

## 准备材料与变量

图1：主件正面与连接区；图2：磁吸配件正反面；图3：真实吸附完成状态；图4：说明书中的方向与允许连接组合。提供连接区名称、对位标记和准确步骤短句。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{主件}}` | 黑色桌面台灯底座 |
| `{{配件}}` | 圆形磁吸遥控器 |
| `{{连接区}}` | 底座右前方圆形凹位 |
| `{{对位标记}}` | 遥控器白点朝向底座白线 |
| `{{标题}}` | 靠近，对准，放稳 |

## 拿来就用的具体示例

准备主件连接区、配件正反面、实际吸附完成照和说明书；没有完成照或说明书时只做位置概念，不能确认连接能力。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9圆形磁吸遥控器三栏对位说明。同一黑色桌面台灯底座和右前方圆形凹位保持。第一栏“1 靠近”：遥控器离开凹位约一个配件宽度；第二栏“2 对准”：遥控器在凹位正上方，白点朝向底座白线，只画一条向下直箭头；第三栏“3 放稳”：按图3真实贴合。每栏各一套，不画磁力线或内部磁铁。顶部只写“靠近，对准，放稳”。不写磁力、承重、充电、防脱或兼容型号。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作16:9三栏{{配件}}对位说明。三栏使用同一{{主件}}、同一机位、比例、桌面和柔光，主件结构与{{连接区}}不变。第一栏标“1 靠近”：配件完整离开连接区约一个配件宽度，正反面方向按图2；第二栏标“2 对准”：配件悬停在连接区正上方，严格显示{{对位标记}}，只用一条细直箭头表示移动方向，不画磁力线；第三栏标“3 放稳”：按图3显示配件与连接区真实贴合，边缘、凹位、遮挡和朝向一致。每栏主件与配件各一件，不复制、穿插或生成隐藏磁铁、线圈、触点和内部结构。顶部只写“{{标题}}”。不添加磁力强度、承重、充电、供电、防脱、兼容型号或安全结论，除非图4逐项明确提供且本次文案获准。只输出一张三栏说明图。
```

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

三阶段图说明可见位置关系，不证明磁力、承重、充电、防脱、安全与跨型号兼容。
