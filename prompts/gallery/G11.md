## 准备材料与变量

按正文上传对应参考图；无需参考图的场景可以直接填词生成。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{作品名}}` | 赤壁赋，或念奴娇·赤壁怀古，选择其一 |
| `{{意境}}` | 江月、扁舟与远山 |
| `{{全文}}` | 填写作品准确全文，供核对作品归属 |
| `{{本页段落}}` | 本次实际绘制的完整段落；短文可与全文相同，长文分卷时只填本页内容 |

## 完整提示词

```text
为作品《{{作品名}}》制作一张古典长卷。图像主题为{{意境}}，水墨淡彩、江水与远山形成横向动线。作品全文用于核对：“{{全文}}”。本页只排“{{本页段落}}”，按阅读顺序分栏放在留白区，题名与正文必须属于同一作品，不能混用《念奴娇·赤壁怀古》和《赤壁赋》。只使用给定文字。只绘制本页段落，保留后续分卷位置，不擅自删句或换文。
```
