[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

并排展示同一包装封签完整、首次揭起和已开启三种真实状态，用于客服与说明物料而不把画面当防伪鉴定。

## 准备材料与变量

图1：未开启包装正面；图2：完整封签微距；图3：首次揭起实拍；图4：开启后封签与包装表面；提供三状态名称、观察部位和准确说明。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 白色营养补充剂纸盒 |
| `{{封签位置}}` | 盒盖右侧跨缝透明封签 |
| `{{三个状态}}` | 封签完整、首次揭起、已开启 |
| `{{标题}}` | 收货先看封签 |
| `{{说明}}` | 状态仅供外观核对，如有疑问联系售后 |

## 拿来就用的具体示例

准备同一包装三个状态的连续实拍；若不是同一件样品，应明确样品编号并避免把个别痕迹说成固定规律。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9三栏“收货先看封签”对照图。同一白色营养补充剂纸盒、同一略俯机位、背景和柔光。左栏“封签完整”按图2；中栏“首次揭起”按图3；右栏“已开启”按图4。盒盖右侧跨缝透明封签的翘起、残留和表面变化只按实拍呈现，每栏一个包装。不补胶层、编码、暗记或内部，不判断真假、正品、未使用或退换责任。底部只写“状态仅供外观核对，如有疑问联系售后”。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作16:9三栏包装状态对照图，标题为“{{标题}}”。三栏使用同一{{商品}}、同一正面略俯机位、比例、背景和柔光，包装文字、盒盖结构与{{封签位置}}保持一致。左栏“封签完整”严格按图2；中栏“首次揭起”严格按图3，只显示已拍到的翘起位置、拉伸和局部痕迹；右栏“已开启”严格按图4，保留真实残留、断裂或表面变化。每栏各出现一个包装，不复制封签、不补造隐藏胶层、编码、暗记或包装内部。用细引线只标观察部位，不生成真假、正品、未使用、可退换或运输责任结论。底部只写“{{说明}}”。只输出一张三栏对照图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

画面只能说明所附样品的可见状态，不能单独证明真伪、是否使用、运输责任或售后资格。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

