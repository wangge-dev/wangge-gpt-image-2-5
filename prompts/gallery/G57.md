# G57 · 商品跨出广告牌内框的立体主视觉

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · GPT Image 2.5 社区案例改写**

让单件商品从广告牌平面跨向观众，通过边框遮挡和接触阴影形成可辨的立体出框广告概念图。

## 准备材料与变量

图1：商品正面与侧面实拍；图2：广告牌正面与边框照片或人工版式图；图3：人工指定出框边界及批准标题。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 深蓝色圆罐咖啡粉 |
| `{{广告牌}}` | 横版室内广告牌，深蓝色内框与白色外框 |
| `{{出框关系}}` | 罐体右上缘和右侧约四分之一越过内框，罐底仍落在画面内的台面 |
| `{{标题}}` | 把香气带回家 |
| `{{文字区}}` | 左侧35%只放标题 |

## 拿来就用的具体示例

商品正侧面与广告牌边框必须明确；出框区域由人工标注。输出只用于创意提案，实际结构由制作方评估。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9室内横版广告牌概念图：深蓝内框、白外框居中；唯一深蓝色圆罐咖啡粉在右侧，罐体右上缘与右侧约四分之一跨出内框，罐底仍在画内台面。越框处有正确遮挡与短接触阴影，罐盖和标签按商品实拍。左侧35%只写“把香气带回家”。不加第二罐、价格或不存在的支架。只输出一张图。
```


## 完整提示词

```text
依据图1至图3制作16:9广告牌正面概念图。{{广告牌}}占画面中部，先固定边框和{{文字区}}；图1中的唯一{{商品}}位于右侧，按{{出框关系}}跨越内框。商品越框处必须显示边框前后遮挡、短接触阴影和一致的视角，不能把整罐悬空、复制第二个罐或用随机碎片替代真实轮廓。商品外形、盖子、标签、主色和可见字序以图1为准；左侧只写“{{标题}}”一次。环境用克制室内柔光，商品与内框光向一致。不要添加价格、成分、功效、平台标志或未经提供的实体支架，也不要宣称这张概念图已可施工。只输出一张图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

出框图是静态广告概念；结构支撑、视角覆盖、载荷和现场安装仍需实体设计验证。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
