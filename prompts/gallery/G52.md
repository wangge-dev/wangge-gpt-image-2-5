# G52 · 双面夹克两面穿同人对照

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

让同一人物以同一姿态分别展示双面夹克的A面与B面，保持内外层、口袋和闭合结构不串面。

## 准备材料与变量

图1：夹克A面正面；图2：夹克B面正面；图3：领口、袖口、拉链与翻面结构；图4：获准成年人物全身照。提供两面名称、各自特征清单和准确标题。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{夹克}}` | 双面穿短款夹克 |
| `{{A面}}` | 深海军蓝面，左胸白色小标，两侧斜插袋 |
| `{{B面}}` | 浅灰面，无胸标，两侧竖向贴袋 |
| `{{标题}}` | 翻一面，换一种表达 |
| `{{人物造型}}` | 白色长裤与黑色低帮鞋 |

## 拿来就用的具体示例

准备同一件夹克A/B面、翻面结构和获准人物照；只有平铺照时不要凭空生成不可见的内外连接细节。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9双面穿短款夹克左右对照。同一成年人物、正面站姿、白色长裤和黑色低帮鞋。左栏“A面”：深海军蓝、左胸白色小标、两侧斜插袋；右栏“B面”：浅灰、无胸标、两侧竖向贴袋。衣长、肩袖、下摆、领口和拉链一致，翻面结构按图3，不串面、不加口袋或第二件外套。顶部只写“翻一面，换一种表达”。不写保暖、防水、面料或尺码结论。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作16:9左右对照服饰广告。左右两栏保持图4同一成年人物身份、脸部、发型、体型、正面自然站姿、裁切与{{人物造型}}。左栏标“A面”，穿着图1{{夹克}}的{{A面}}；右栏标“B面”，穿着图2的{{B面}}。两栏衣长、肩宽、袖长、下摆、领口和拉链位置一致，翻面关系按图3；A面的胸标与斜插袋只在左栏，B面的无胸标与竖向贴袋只在右栏，不把两面特征混在同一件衣服上。夹克自然贴合相同姿势，褶皱与遮挡可信，不出现双层领口、额外口袋、第二件外套或镜像文字。浅灰棚拍背景与同一柔光。顶部只写“{{标题}}”。不添加保暖、防水、透气、面料成分、尺码适配或穿着舒适结论。只输出一张对照图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

两面特征必须分别由真实照片支持，视觉对照不证明面料成分、功能、尺码与舒适度。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
