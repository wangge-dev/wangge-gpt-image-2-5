# G47 · 夜光表盘明暗状态序列

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

按照同一腕表的带时间记录实拍，展示常规光、关灯即刻和指定时点的表盘状态，不虚构夜光持续时间。

## 准备材料与变量

图1：腕表正面常规光；图2：同一表位关灯即刻实拍；图3：同一表位在记录时点的实拍；图4：表盘刻度和指针微距。提供真实时点标签、夜光区域清单和准确说明。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{腕表}}` | 黑色潜水风格腕表 |
| `{{三个状态}}` | 常规光、关灯即刻、10分钟实拍 |
| `{{夜光区域}}` | 时针、分针和十二枚时标 |
| `{{标题}}` | 同一表盘，三次记录 |

## 拿来就用的具体示例

准备同一腕表、固定相机参数和明确时间记录的三张照片；若曝光或充光条件不同，应先重拍，不能用生成图补齐性能序列。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9黑色潜水风格腕表三栏记录，依次标“常规光”“关灯即刻”“10分钟实拍”。三栏保持同一表、同一表针时刻、表冠方向、距离和设置；第一栏按图1，第二栏按图2只点亮时针、分针和十二枚时标，第三栏按图3保持10分钟记录的实际相对亮度，不增强成第二栏。顶部只写“同一表盘，三次记录”，底部写“亮度受充光、环境与拍摄设置影响”。不写材料、续航、潜水或认证。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作16:9三栏{{腕表}}表盘状态记录。三栏依次标“常规光”“关灯即刻”“10分钟实拍”，保持同一腕表、同一表针时刻、表冠方向、镜头距离、裁切和相机设置；表壳、表圈、文字、刻度数量与图4一致。第一栏按图1呈现；第二栏只按图2点亮{{夜光区域}}；第三栏只按图3呈现记录时点可见的相对亮度与范围，不人为增强到与第二栏相同。暗处发光服从指针和时标真实形状，不添加发光数字、刻度、外圈或背景光晕。顶部只写“{{标题}}”，底部写“{{说明}}”。不推断夜光材料、充光时长、可读距离、续航、潜水性能、认证或其他时点表现。只输出一张三栏记录图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

这是给定拍摄条件下的视觉记录，不是夜光持续时间、材料等级或使用性能测试。
