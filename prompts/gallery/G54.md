# G54 · 鞋带逐孔穿线路径说明

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在真实鞋面上按孔位编号展示鞋带从起点到终点的穿线路径，避免错孔、跳孔、镜像和凭空增加鞋带。

## 准备材料与变量

图1：鞋面俯视完整照；图2：无鞋带或松开状态；图3：正确系带完成照；图4：鞋带孔与鞋舌微距。提供左右孔位编号、起点、路径表和结尾方式。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{鞋款}}` | 灰白六组孔低帮鞋 |
| `{{路径}}` | L1→R1→L2→R2→L3→R3→L4→R4→L5→R5→L6→R6 |
| `{{起点}}` | 鞋头侧第一组孔 |
| `{{结尾}}` | 第六组孔上方对称蝴蝶结 |

## 拿来就用的具体示例

准备清晰俯视、松开态、完成态和孔位微距，并人工确认路径表；左右孔位或穿线方式不同的鞋款需重写路径。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作4:5灰白六组孔低帮鞋穿线说明。鞋面俯视，左孔标L1–L6、右孔标R1–R6。一根鞋带从鞋头侧第一组孔开始，按L1→R1→L2→R2→L3→R3→L4→R4→L5→R5→L6→R6穿过，每孔一次，上下遮挡按图3，最后在第六组孔上方形成对称蝴蝶结。不跳孔、不复制鞋带、不穿过鞋面。顶部只写“按孔位完成系带”。不写防滑、支撑、包裹或运动性能。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作4:5{{鞋款}}穿线说明图。主体是一只鞋面俯视图，鞋楦、鞋舌、六组孔、缝线、色块和鞋口按图1、图4保持。用小号圆点在左列依次标L1至L6、右列标R1至R6，标记紧邻对应孔但不遮孔。鞋带只有一根，起点为{{起点}}，严格按{{路径}}逐段穿过，每个孔只穿一次；上下遮挡与图3一致，不跳孔、不复制鞋带、不穿过鞋面实体。末端按{{结尾}}，左右长度观感一致。右侧用六条短句列步骤，每条只对应一组左右孔，不增加性能说明。顶部只写“{{标题}}”。浅灰背景、均匀柔光。不要添加快速系带器、防滑结、支撑、包裹、运动表现或安全结论。只输出一张说明图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

路径图只说明所附鞋款的外观系带顺序，不证明支撑、舒适、安全与运动性能。
