# G39 · 实体投影形成品牌符号

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Brand & Logos · 本库原创设计**

用真实商品与定向光形成指定品牌符号的投影概念广告，同时保持实体本身不变形。

## 准备材料与变量

图1：真实商品；图2：获准品牌符号黑白轮廓；图3：商品侧背面；提供光源方向、承托平面和短标题。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 黑色金属台灯 |
| `{{品牌符号}}` | 图2的圆环缺口符号 |
| `{{光源}}` | 右上方单一硬光 |
| `{{承托平面}}` | 暖灰墙面与深灰台面 |
| `{{标题}}` | LIGHT LEAVES A MARK |

## 拿来就用的具体示例

准备商品正侧背面和已获准使用的符号轮廓；物理投影可行性未验证时明确为概念广告。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
保持图1、图3黑色金属台灯的灯罩、关节、底座和比例，放在暖灰墙面前的深灰台面。右上方单一硬光让台灯与不出镜遮光片在墙上形成图2圆环缺口符号；符号只在投影里，台灯本体不弯曲或切割。投影方向与墙角折线可信，只出现一次。底部只写“LIGHT LEAVES A MARK”。不加品牌名、参数、烟雾或道具。只输出一张图。
```


## 完整提示词

```text
依据图1、图3保持{{商品}}的外形、关节、灯罩、底座、金属色和真实比例，放在{{承托平面}}。使用{{光源}}，让商品及一个不出镜的简单遮光片共同在墙面形成图2{{品牌符号}}的单一清晰投影；符号只存在于投影中，商品本体不得弯曲、切割或排列成标志。投影方向、边缘软硬、墙角折线和接触阴影符合单一光源，投影不漂浮、不出现第二套符号。画面克制、大片留白、黑灰与一枚暖光色。底部只写“{{标题}}”。不要增加品牌名、功能、价格、光效参数、烟雾或其他道具。只输出一张概念广告。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

这是投影概念视觉，不证明现场用单一商品即可形成该符号；标志使用须有授权。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
