# G50 · 击凸包装平光与掠射光对照

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

用平光和掠射光对照同一包装的真实击凸区域，既展示触感线索又不虚构浮雕高度与工艺参数。

## 拿来就用的具体示例

准备同一礼盒同机位的平光、掠射光、击凸微距和审定平面稿；仅有平面稿时不能凭效果图确定真实起伏。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9象牙白巧克力礼盒左右工艺对照。两栏保持同一礼盒正面和图4版面。左栏“均匀柔光”按图1；右栏“掠射光”从左侧约15度贴面扫过，只让图2、图3证实的中央可可果轮廓与品牌名外框出现高光边和短阴影，其他印刷区、盒边和背景不浮雕。顶部只写“光掠过，层次出现”，底部写“以实物照片可见起伏为准”。不写高度、克重、模具、压力或量产结论。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作16:9左右对照的{{包装}}工艺展示。左右两栏保持同一礼盒正面、尺寸、机位、裁切、象牙白底色、文字和图案位置，版面以图4为准。左栏标“均匀柔光”，按图1呈现克制的平面外观；右栏标“掠射光”，光线{{掠射光方向}}，只在图2、图3证实的{{击凸区域}}形成连续高光边与短阴影，起伏服从原轮廓，不扩大、不新增浮雕文字。普通印刷区、烫印区、盒边和背景不得出现同样浮雕。两栏礼盒都完整正对，不用夸张斜角。顶部只写“{{标题}}”，底部写“{{说明}}”。不生成击凸高度、纸张克重、模具、压力、工艺名称认证、触感优劣或量产偏差结论。只输出一张对照图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

画面用于展示实拍可见起伏，不是击凸高度、纸张、模具压力与量产质量的测量报告。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
