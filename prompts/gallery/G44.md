# G44 · 反光服饰闪光前后对照广告

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

在同一人物、动作和机位下对照常规光与闪光灯中的真实反光区域，用于材质传播而不宣称夜间安全性能。

## 拿来就用的具体示例

准备同一件服饰的常规光和闪光灯实拍、获准人物与同机位环境；没有图2时不得凭材质名称猜测反光位置和强度。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作16:9左右对照广告。两栏保持同一成年人物、站姿、傍晚城市自行车道、机位和深灰骑行外套。左栏“常规环境光”按图1呈现；右栏“相机闪光灯”只让图2证实的前胸两条细带、双袖外侧和下摆后侧变亮，其他布料与结构不发光。两栏逐项对齐。顶部只写“光来时，被看见”，底部写“仅描述闪光灯下可见亮度变化”。不写夜间安全、可视距离、等级或认证。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作16:9左右对照服饰广告。左右两栏保持图3同一成年人物身份、同一站姿、同一{{场景}}、同一机位、裁切和服装结构。左栏标“常规环境光”，按图1显示{{服饰}}的真实颜色与{{反光区域}}；右栏标“相机闪光灯”，只让图2已经证实的这些区域出现对应高亮，其他布料、拉链、口袋、缝线和标志不发光、不变色。两栏地面、背景物体与人物位置逐项对齐，只改变照明条件；反光高亮服从衣褶、遮挡与透视，不扩散成霓虹轮廓。顶部只写“{{标题}}”，底部小字写“{{允许描述}}”。不添加夜间安全、可视距离、反光等级、交通防护、认证或性能数字。只输出一张对照图。
```

## 参数设置

建议画布：`2048x1152`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

闪光灯下的视觉对照不能替代反光材料等级、可视距离和道路安全测试。
