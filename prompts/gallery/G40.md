# G40 · 眼镜镜片内外双场景广告

[全部提示词](../README.md) · [首页](../../README.md)

**分类：Products & E-commerce · 本库原创设计**

让同一真实场景在镜片内外形成受控视觉差异，用于镜片概念广告而不虚构光学性能。

## 准备材料与变量

图1：眼镜正面；图2：镜腿与铰链；图3：同一机位拍摄的无镜片场景；图4：经实拍确认的透过镜片效果。提供准确短标题和允许描述的镜片事实。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{眼镜身份}}` | 茶色透明框太阳镜 |
| `{{镜片内效果}}` | 按图4呈现较暖、略低亮度的同一海边场景 |
| `{{镜片外效果}}` | 按图3保持原始中性日光 |
| `{{标题}}` | 换一种目光 |
| `{{允许事实}}` | 仅描述画面可见色调差异 |

## 拿来就用的具体示例

准备眼镜正面、侧面、同一场景原图和真实透镜实拍；没有图4时只做视觉概念，不声称镜片真实效果。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
依据图1至图4制作4:5茶色透明框太阳镜广告。眼镜居中，保持两片镜片、鼻托、铰链和镜腿。镜片外按图3呈现中性日光海边；镜片内按图4呈现同一机位、同一海岸线的较暖低亮度效果，左右一致，不生成不同景物。顶部只写“换一种目光”。只描述可见色调差异，不写偏光、防紫外线、护眼或驾驶结论。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作4:5眼镜概念广告。{{眼镜身份}}正面略微倾斜悬于画面中央，占高度约55%，镜框、两片镜片、鼻托、铰链和镜腿结构保持。背景完整使用图3{{镜片外效果}}；仅在两片镜片真实边界内部显示图4{{镜片内效果}}，内外仍是同一机位、同一海岸线与物体位置，不生成第二个世界或错误折射。镜片边缘、反光、透明度与遮挡自然，左右镜片效果一致。顶部只写“{{标题}}”。{{允许事实}}，不添加防紫外线等级、偏光、变色、护眼、清晰度或适合驾驶结论。只输出一张图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

镜片内外效果必须由同机位实拍支持；视觉图不能替代透射率、偏光或防护检测。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
