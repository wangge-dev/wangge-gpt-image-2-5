# EC58 · 腕表右侧主视觉与左侧短文案广告

[全部提示词](../README.md) · [首页](../../README.md)

**分类：活动营销 · GPT Image 2.5 社区案例改写**

让同一只腕表占据画面右侧，用左侧短标题和事实文案形成清楚的阅读动线，适合投放海报与商品副图。

## 准备材料与变量

图1：腕表正面实拍；图2：表壳、表冠、表带与表盘细节；图3：人工批准的标题及一句事实文案；图4可选：品牌色板。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{腕表}}` | 银色钢带腕表 |
| `{{标题}}` | 每一刻，都有分寸 |
| `{{事实文案}}` | 银色表壳与深绿表盘 |
| `{{版式}}` | 腕表放右侧，占画面宽度约55%；左侧文字区占30%，中间保留间隔 |
| `{{背景}}` | 低饱和深翡翠绿棚拍背景 |

## 拿来就用的具体示例

腕表正面和细节须来自同一型号；文案由人工批准，模糊表盘文字先核对后使用。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
用同一只银色钢带、深绿表盘腕表正面与细节照制作3:4竖版广告。腕表在右侧占画宽约55%，左侧30%文字区只写“每一刻，都有分寸”，下一行只写“银色表壳与深绿表盘”。深翡翠绿棚拍背景，柔和侧光；表冠、表耳、日期窗、指针时刻、刻度与原图一致，不加钻石、价格、防水或精度信息。只输出一张图。
```


## 完整提示词

```text
依据图1至图3制作3:4竖版{{腕表}}广告。先锁{{版式}}：腕表完整置于右侧，表盘为第一视觉焦点，表冠、表耳与表带可见；左侧上半区只写“{{标题}}”，其下只写“{{事实文案}}”，每句出现一次，文字不压商品。图1与图2唯一负责腕表外观与印刷，保持表针时刻、刻度、日期窗、表冠位置、表链节数及真实反射边界。采用{{背景}}，大面积柔和侧光与少量轮廓光，保留表壳金属质感。不得新增品牌、钻石、复杂功能、价格、认证、走时精度或防水声明；不从模糊表盘补字。只输出一张完整广告。
```

## 参数设置

建议画布：`1536x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

右侧主视觉用于广告排版；生成图不证明材质等级、功能、走时或防水性能。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
