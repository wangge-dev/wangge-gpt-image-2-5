# EC58 · 腕表右侧主视觉与左侧短文案广告

[全部提示词](../README.md) · [首页](../../README.md)

**分类：活动营销 · GPT Image 2.5 社区案例改写**

让同一只腕表占据画面右侧，用左侧短标题和事实文案形成清楚的阅读动线，适合投放海报与商品副图。

## 准备材料与变量

图1为同一腕表完整可见角度照；图2如有，只核图1可见表盘与部件的同款细节，不提供另一面或新反射。标题、事实短文与背景用文字给出，不占图号。缺近照时选单图版本；模糊表盘不靠文字重造。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{腕表}}` | 银色钢带、深绿表盘腕表，具体角度与完整轮廓按原照 |
| `{{标题}}` | 每一刻，都有分寸 |
| `{{事实文案}}` | 银色表壳与深绿表盘 |
| `{{背景}}` | 低饱和深翡翠绿棚拍背景 |

## 拿来就用的具体示例

图1：银色钢带深绿表盘腕表完整原照；图2：同款且对应原可见面的清楚细节。人工批准标题与事实短文；缺图2时直接用单图分支。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1控制腕表身份与完整原视角；图2只核对同款、同一可见区域的细节，不把独立微距变成另一件表、不从近照转出新面。没有图2就选下面单图分支，不调用空图号。商品为银色钢带、深绿表盘腕表，具体角度与完整轮廓按原照，保持原可见角度、轮廓、比例、表冠方位、表带、原字和原有反射逻辑。表针、秒针与日期窗只沿原照已看清的状态；看不清则保留原视觉，不猜时间、日期或重绘刻度。未拍到的表耳、链节和背面不补全，原照片裁断关键结构时先换完整照片。

制作3:4竖版腕表广告。四边6%安全边距，安全区内左30%为两行层级短文、中15%干净间隔、右55%为完整腕表区域，三者总和100%，不是商品横向拉伸比例。腕表整体等比例缩放适配右区，超宽就缩小，不裁表冠和表带、不侵占文字区。标题在左上，事实短文紧随其后；先看表盘、再标题和事实短文。

背景为低饱和深翡翠绿棚拍背景，柔和侧光，不新增会被误认作表面设计的反光纹样。标题只写“每一刻，都有分寸”一次，事实短文只写“银色表壳与深绿表盘”一次；空项省略，短文必须有人工证据，放不下改批准短文或外部排字。画外字不印上表盘，不新增品牌、钻石、功能、价格、防水或精度结论，保留原字。只输出一张平面广告。
```

## 参数设置

建议画布：`1536x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

右侧主视觉用于广告排版；生成图不证明材质等级、功能、走时或防水性能。
