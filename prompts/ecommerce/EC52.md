# EC52 · 活动主视觉商品价格与行动区四层排版

[全部提示词](../README.md) · [首页](../../README.md)

**分类：活动营销 · 本库原创设计**

用固定四层信息结构生成活动主视觉，锁定商品、标题、价格和行动区，避免文案重复与视觉抢位。

## 准备材料与变量

图1必需：单件商品完整原照。图2可选：同一SKU标签近照，只核对图1可见标识。人工活动文案表必需：标题、价格原文、价格适用条件和行动文字；文字直接提供即可，不强制额外图片。品牌色板可选，仅定义背景与文字风格。没有已批准价格时选“无价格活动版”，不从商品推测售价。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{活动标题}}` | 秋日上新 |
| `{{价格}}` | 售价 ¥129 |
| `{{价格条件}}` | 无需附加优惠条件（示例文案，非真实销售承诺） |
| `{{行动文字}}` | 查看款式 |
| `{{商品位置}}` | 中央商品区内等比例居中，外接框高度不超过全画面44%并完整留边 |
| `{{配色}}` | 暖米色背景、深棕字、橙红点缀 |

## 拿来就用的具体示例

一张完整清晰的米白双提手帆布包照片；演示文案表为“秋日上新／售价 ¥129／无附加优惠条件／查看款式”。这是填写演示，发布时须由运营批准真实价格与条件。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作一张4:5米白帆布包活动图。图1是唯一商品依据，保留原角度、双提手、敞口、帆布本色和原标识，缺失细节不补造。四周6%安全边距；其内内容区按18%标题、50%商品、22%价格、10%行动划分，各区内部留间距但不画区框。顶部只写一次“秋日上新”；商品区等比例居中，含提手外接框高度不超过全图44%，轮廓完整且阴影不压字；下部只写一次“售价 ¥129”；底部只写一次“查看款式”。本演示价设定为无附加优惠条件，故不生成条件说明；实际销售有条件时必须另给批准条件并同区展示。暖米色背景、深棕字、少量橙红点缀，不改变商品颜色，不添加原价、到手价、折扣、销量、倒计时、优惠券、赠品或平台标志。只输出一张完成活动图。
```


## 完整提示词

```text
制作一张4:5活动主视觉，阅读顺序为活动标题→商品→价格及必要条件→行动文字。四周6%为安全边距；安全边距以内的内容区域从上到下分成18%标题区、50%商品区、22%价格及条件区、10%行动区，各区内部再留间距，不把商品边缘或投影压到文字上。标题区只写“{{活动标题}}”；图1商品按{{商品位置}}放商品区；价格区只写人工批准原文“{{价格}}”，适用条件为“{{价格条件}}”；行动区只写“{{行动文字}}”。百分比是版式目标，不把比例数字或区框画进成图。

价格条件若确实为无附加条件，不把这条内部说明印在图上；若涉及领取、满额、会员、限期或适用款，必须把批准条件完整写在同一价格区，不能只保留低价。不自行计算原价、折扣、优惠后金额；价格和必要条件过长时先要求人工短文或改用无价格版，不隐去条件、不堆难读小字。标题最多两行、价格一行、条件最多两行、行动文字一行，每条各出现一次。

商品身份以图1为准，图2仅在提供时核对可见标签；保留原角度、结构、颜色、标识和数量，不补背面和赠品。采用{{配色}}，活动色只用于背景与文字，商品本色不染色。不得新增销量、倒计时、优惠券、原价、折扣率、平台标志、按钮交互或未批准规则。只输出一张完成活动图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

示例金额不是商品报价。含优惠条件的价格必须与必要条件一起展示；没有批准价格时直接选无价格版。画面行动文字不是可点击按钮，活动规则与平台要求由人工确认。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 无价格活动版 · no-price-campaign

```text
依据图1制作一张4:5单商品活动图。图1负责原角度、比例、结构、本色、标识和数量，不补背面、隐藏结构、额外产品或赠品。四周6%安全边距，上部内容区约22%只写人工批准标题“{{活动标题}}”，中央约63%按{{商品位置}}等比例完整展示商品，下部约15%只写人工批准行动文字“{{行动文字}}”；标题最多两行、行动一行，各出现一次，商品和投影避开文字。采用{{配色}}，背景与文字可使用主题色，商品不染色。没有批准价格，所以不生成售价、到手价、原价、折扣、优惠条件、假金额、销量、倒计时、优惠券或占位符。不生成平台标志或可点击按钮。只输出一张完成的无价格活动图。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
上传本轮活动图和图1原商品照。只修改第{{层号}}层的{{具体文字或落位问题}}为{{人工批准的准确文字或位置}}；其余三层、商品身份、原角度、本色和安全边距不变。改价时同时核对并保留适用条件，不将有条件价格变成无条件承诺。只输出一张修改稿。
```
