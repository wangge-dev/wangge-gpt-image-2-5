# EC52 · 活动主视觉商品价格与行动区四层排版

[全部提示词](../README.md) · [首页](../../README.md)

**分类：活动营销 · 本库原创设计**

用固定四层信息结构生成活动主视觉，锁定商品、标题、价格和行动区，避免文案重复与视觉抢位。

## 准备材料与变量

图1：商品正面完整照；图2：标签近照；图3：人工审定活动文案表，包含标题、价格和行动文字；图4可选：品牌色板。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{活动标题}}` | 秋日上新 |
| `{{价格}}` | 到手价 ¥129 |
| `{{行动文字}}` | 立即选购 |
| `{{商品位置}}` | 画面中央偏下，占高度52% |
| `{{配色}}` | 暖米色、深棕、橙红点缀 |

## 拿来就用的具体示例

上传商品正面和标签近照，并提供已审定活动表；示例价格仅用于演示，发布前必须替换为真实价格。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
为米白色帆布包制作4:5活动图。顶部20%只写“秋日上新”；商品居中偏下，占高度52%；下部只写“到手价 ¥129”；底部只写“立即选购”。暖米色、深棕、橙红点缀，四层不重叠。保持双提手、敞口、帆布颜色和原标识，不加原价、销量、倒计时或赠品。只输出一张图。
```


## 完整提示词

```text
制作4:5活动主视觉，严格分为四层：顶部20%只放标题“{{活动标题}}”；中部52%按{{商品位置}}展示图1商品；下部18%只放价格“{{价格}}”；底部10%只放行动文字“{{行动文字}}”。采用{{配色}}，四层之间保留清楚间距，文字各出现一次。商品以图1、图2为准，保持结构、颜色、标签与数量，不让价格压住商品，不把活动色染到商品本色。不得新增原价、折扣率、销量、倒计时、优惠券、平台标志或赠品。只输出一张图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

活动价格与规则必须由人工审定；本卡不自动计算折扣或判断平台合规。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
