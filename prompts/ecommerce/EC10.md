# EC10 · 包装与开箱陈列

[全部提示词](../README.md) · [首页](../../README.md)

**分类：品牌表达 · 电商来源改写**

按真实组件数量、可见状态与指定参考制作包装陈列，开箱分格需独立状态实拍。

## 准备材料与变量

图1：单件商品清晰原照；图2：同款实际包装组件同框照。人工清单逐件指定来源、数量、开合状态和席位；图2里的旧商品只作核对，不重复添加。开箱版另提供各状态实拍并写实际上传图号；只有拆散陈列照不能补生成打开、揭纸和取出的过程。概念包装不走真实套装路径，需另有明确概念 brief，不能拿它当实际随售证据。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 一个封盖茶叶罐，以图1可见外观、颜色与原有印字为准 |
| `{{组件清单}}` | 商品茶叶罐1个取图1，前方中央；闭合外盒1个取图2，后方左侧；空内托1个取图2，后方右侧；图2同框茶罐仅核对，不重复新增；无卡片、丝带或赠品 |
| `{{陈列规则}}` | 商品为主；其余组件按各自实际参考角度和原比例缩放，不比较未知实物尺寸，不打开闭盒 |
| `{{状态清单}}` | 未提供逐步状态实拍，只做现有静态组件陈列 |

## 拿来就用的具体示例

图1为一个封盖茶叶罐；图2真实同框照含闭合外盒、已取出的空内托和同一茶罐。清单只展示一个商品、一个外盒和一个内托，不由这张拆散照片推开箱步骤。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1负责单件商品身份，图2只提供清单指定的真实包装组件。商品信息：一个封盖茶叶罐，以图1可见外观、颜色与原有印字为准。组件与席位清单：商品茶叶罐1个取图1，前方中央；闭合外盒1个取图2，后方左侧；空内托1个取图2，后方右侧；图2同框茶罐仅核对，不重复新增；无卡片、丝带或赠品。每项仅按清单数量出现；同框参考中的商品、盒子或其他组件不再作为额外一件复制。清单缺来源或数量的项先省略，不从包装照片补未知赠品。

制作一张3:2包装陈列成片，四周6%安全边距；商品居前为主，后方留独立组件席位，所有物体完整可辨，间隙不盖住印字。陈列规则：商品为主；其余组件按各自实际参考角度和原比例缩放，不比较未知实物尺寸，不打开闭盒。每件只等比例缩放并保留自己的实拍角度、颜色、材质与开合状态；不能为了展示内托打开只有闭合参考的盒子，不从槽位推导商品内部。缺包装图只做图1商品陈列，不留假盒框。

浅灰台面、柔和侧光，保持商品本色与包装实际纸张／表面工艺，不把哑光改成金属。只摆清单组件，不自动加入散落珍珠、丝带或卡片。

文字仅保留对应参考表面原有可辨内容，不把背面印字移到正面，不补二维码、证书或环保标志。看不清的关键印字先取得清晰参考或外部后期，不能猜写。背景与光线只负责陈列气质，不重做材料工艺、不宣称再生纸／大豆油墨或保护性能。只输出一张图片，不把本图作为实际赠品或开箱过程证明。
```

## 参数设置

建议画布：`1536x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

实际陈列与概念包装分开。本卡不凭原模板风格词补赠品、改材料或开盒；开箱版必须逐状态实拍，缺过程资料就用静态版。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 开箱体验 · unboxing

```text
图1负责单件商品身份，图2只提供清单指定的真实包装组件。商品信息：{{商品信息}}。组件与席位清单：{{组件清单}}。每项仅按清单数量出现；同框参考中的商品、盒子或其他组件不再作为额外一件复制。清单缺来源或数量的项先省略，不从包装照片补未知赠品。

批准状态与实际图号清单：{{状态清单}}。只有逐状态实拍齐全且人工明确顺序时，制作一张3:2横向状态拼贴；四周6%留边，按实际状态数分为1至3格，格间间隙计入可用区。每格使用指定状态照片，保留已拍到的盒盖、内托、纸张和商品归属；各格是同一套组件在不同状态，不代表多送一套。不从单张拆散照生成开盖、揭纸或拿取动作，不强凑三格。

缺任一所需状态时取消过程拼贴，按现有清单改做一张静态组件陈列，不补缺帧、不留空框；静态陈列四周6%留边，商品前置、组件后置，逐项沿用来源角度和原比例，不打开闭合包装。

文字仅保留对应参考表面原有可辨内容，不把背面印字移到正面，不补二维码、证书或环保标志。看不清的关键印字先取得清晰参考或外部后期，不能猜写。背景与光线只负责陈列气质，不重做材料工艺、不宣称再生纸／大豆油墨或保护性能。只输出一张图片，不把本图作为实际赠品或开箱过程证明。
```
