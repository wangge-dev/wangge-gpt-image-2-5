# EC60 · 整套Listing保版式逐图本地化

[全部提示词](../README.md) · [首页](../../README.md)

**分类：跨境本地化 · GPT Image 2.5 电商来源改写**

按人工审定的目标语言文案表逐张替换Listing套图中的画外文字，保持商品、版式、图标和视觉层级不变。

## 准备材料与变量

图1：本轮待本地化成片；图2：文字区域编号图；图3：源文—审定目标文逐区对照表；图4：目标市场标点、大小写和断行规范；图5：商品与图形保护区。整套图片需逐张执行。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{目标市场}}` | 日本站日语 |
| `{{当前图片}}` | 套图第4张卖点信息图 |
| `{{替换表}}` | T1‘FAST CHARGE’→‘急速充電’；T2‘UP TO 20 HOURS’→‘最大20時間’；T3‘USB-C’保持不变 |
| `{{文字版式}}` | T1两行居中、T2单行左对齐、T3原位；字号层级、颜色、行距和文本框宽度按原图 |
| `{{保护}}` | 耳机与充电盒、三个图标、箭头、背景渐变、商品阴影、区块边界和画布比例 |
| `{{停止规则}}` | 目标文放不下或含义未经批准时停止该区，不缩成小字、不擅自意译或删减 |

## 拿来就用的具体示例

翻译必须先由人工或专业翻译审定并按区域编号；商品包装上的法定字段、商标和接口名需单独决定是否翻译。整套逐张运行并逐字验收。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
把套图第4张耳机卖点信息图改成日本站日语版。按T1–T3替换：‘FAST CHARGE’改为两行居中的‘急速充電’，‘UP TO 20 HOURS’改为单行左对齐的‘最大20時間’，‘USB-C’保持原位不变。保留字号层级、颜色、文本框、耳机和充电盒、三个图标、箭头、背景渐变与阴影。文字放不下就停止，不缩小到不可读，不新增认证或卖点。只输出一张日语成品。
```


## 完整提示词

```text
编辑图1“{{当前图片}}”，目标为{{目标市场}}版本。严格按图2编号和图3“{{替换表}}”逐区换字，只使用已审定目标文；执行“{{文字版式}}”，允许在原文本框内微调字距和行距，但不得移动文本框、图标或商品。完整冻结“{{保护}}”，并遵守“{{停止规则}}”。源语言只可在替换表明确要求保留的品牌、型号和接口名中出现；不得自动翻译包装实拍上的未列文字，不新增卖点、认证、价格、单位或法律声明，不输出前后对照拼图。只输出本轮图片的一张目标语言成品；整套下一张另开一轮。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡执行已审定文本的视觉替换，不负责翻译、法规判断或市场合规；发布前需母语和法务复核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
