# EC57 · 三口味系列主次陈列与身份隔离

[全部提示词](../README.md) · [首页](../../README.md)

**分类：系列商品 · GPT Image 2.5 社区案例改写**

将三款同系列食品排成中心主款与两侧辅款，既让主款先被看见，又保持每款口味、包装和数量可辨。

## 准备材料与变量

图1至图3：三款实际销售包装或成品各自完整正面照；图4：人工确认的口味、名称、主推款和准确标题；图5可选：系列色板。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{主款}}` | 开心果口味冰淇淋杯 |
| `{{左款}}` | 香草口味冰淇淋杯 |
| `{{右款}}` | 可可口味冰淇淋杯 |
| `{{标题}}` | 三种口味，先选开心果 |
| `{{主次}}` | 中间主款视觉高度比两侧各高约15%；两侧内倾但不互相遮挡 |
| `{{安全区}}` | 顶部16%留标题，底部10%留渠道信息 |

## 拿来就用的具体示例

三款需分别提供同一系列的真实销售图与人工核对名称；视觉高度用于构图，不等于实物尺寸或容量差异。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
用三张实拍包装分别制作香草、开心果、可可冰淇淋杯4:5副图。左香草、中开心果、右可可各一杯；中心开心果视觉高度约比两侧高15%，靠前且略亮，两侧轻微向内倾，杯形、标签、口味色各按原图。顶部16%只写“三种口味，先选开心果”，底部10%留空。不要让开心果碎屑出现在香草或可可杯旁，不增加价格或容量。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作4:5系列商品电商副图。严格按左{{左款}}、中{{主款}}、右{{右款}}排列，每款只出现一次，三款名称、口味色、杯形、标签和配料图案分别以对应参考为准。按{{主次}}处理视觉层级，商品均保留真实相对比例，不通过虚构容量或放大包装尺寸冒充更大规格；中款靠前、光线略亮，两侧作引导，阅读动线由标题到中款再到两侧。保留{{安全区}}，标题只写“{{标题}}”。背景用统一浅奶油色，少量各口味真实食材只放在对应杯附近，不跨款串味。不得增加第四口味、配料、价格、容量、功效、销量或促销标签。只输出一张图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

成片用于系列口味选择，不证明配料含量、容量、营养或口味排名；三款身份与文案发布前逐项核对。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
