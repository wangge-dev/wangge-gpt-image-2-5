# EC05 · 中文促销海报

[全部提示词](../README.md) · [首页](../../README.md)

**分类：营销素材 · 电商来源改写**

制作一张短中文促销海报，先锁商品、文案、价格条件和行动区；没有批准价格时直接保留留白。

## 准备材料与变量

图1：商品完整正面或已批准可见视角照片，只负责商品身份和包装字。另用文字提供批准标题、副标题、价格及必要条件、行动文字和品牌配色；空项明确不写。示例价只用于练习，不能直接当真实报价。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 米白帆布手提包，封闭正面视角，两条手柄和原有标志；其余以图1可见外观为准 |
| `{{标题}}` | 轻装出门 |
| `{{副标题}}` | 日常随行 |
| `{{价格}}` | ¥99 |
| `{{价格条件}}` | 示例价，非真实报价 |
| `{{行动文字}}` | 查看详情 |
| `{{品牌配色}}` | 米白、深灰、少量橙色 |

## 拿来就用的具体示例

上传一张米白帆布手提包封闭正面照，完整拍到两条手柄和原标志。练习文案为“轻装出门”“日常随行”“¥99”“示例价，非真实报价”“查看详情”；真实发布前须替换为自己批准的价格与必要条件。无需价格参考图片。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1是唯一商品外观依据，商品信息：米白帆布手提包，封闭正面视角，两条手柄和原有标志；其余以图1可见外观为准。制作一张4:5竖版促销平面海报，只保留图1可见视角、轮廓、比例、材质颜色、部件数量、标志与包装原字；不转到未知侧背面、不重设计、不增加第二件商品。

先锁构图：成品四边向内6%为安全边距；可用区内部上段约22%放标题和副标题，中段约53%放完整商品，下段约25%放价格、必要条件及行动文字，段间留白计入各段，不再额外叠加高度。商品只整体等比例缩放，价格不能压过商品，文字不能盖住手柄或标志。阅读顺序为标题、商品、价格与条件、行动文字。

画外文字只允许：标题“轻装出门”、副标题“日常随行”、价格“¥99”、必要条件“示例价，非真实报价”、行动文字“查看详情”，非空项各出现一次。价格与必要条件必须同一块相邻可读，不把条件藏成微小脚注；若没有批准价格，省略价格和条件，保留原留白，不补数字或画空价签。没有批准副标题或行动文字时直接省略，不输出变量名、占位符或“暂无”。包装原字不是活动文字，保持原样，不移作额外宣传。短文采用清晰中文无衬线字体；长条件放不下先用人工批准短文或在排版工具处理，不截断、不自行概括。

背景为浅米色，按米白、深灰、少量橙色少量点缀；柔和侧光与短接触阴影，商品自然色不受背景统一染色。

只使用人工批准的文案与价格条件，不从商品图推导售价，不自动添加划线原价、折扣、限时、库存、销量、赠品、二维码、水印或认证。只输出一张成品，不生成拼贴、样机或交互页面；行动文字只是海报引导，不是可点击功能。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

变量默认与完整示例是同一组练习文案，示例价不是实际报价。真实活动先确认价格及必要条件；缺价格可在同一正文省略，不必新增重复无价格卡。生成图需人工核对文字，精确包装像素保留用合成工具。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

```text
以上一轮海报为底图，重新附商品图1。本轮只在{{文案区域}}把“{{旧文字}}”改为批准的“{{新文字}}”；只在该区内调整断行，包装原字、商品与其他区域不变。若本轮改的是价格，必要条件必须按同一份批准价格说明一起更新，不能保留不适用旧条件；其他返工不得改价格。
```
