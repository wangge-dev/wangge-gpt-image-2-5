# EC04 · 材质与工艺微距

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品展示 · 电商来源改写**

突出真实材质、膏体或接缝，不凭空制造产品细节。

## 准备材料与变量

先按正文的图1、图2等编号上传对应素材。涉及部件、内衬、背面、数据或人物时，补齐相应来源；没有素材不要让模型猜。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 填写商品名称、材质、颜色、规格与实际可见特征；不要填未经核实的功效 |
| `{{细节部位}}` | 皮包肩带车线，需上传对应近照 |

## 完整提示词

```text
图1是实际商品参考。商品信息：{{商品信息}}。保留图1中的外形比例、结构、颜色、材质、包装图案和可辨认的品牌文字；布景反光可以变化，但不要重新设计商品。只呈现参考图或资料中有依据的商品细节，不补造配件和性能。

图2是{{细节部位}}的清晰近照，以图2为细节依据，为该部位制作微距商品摄影。焦点落在真实纹理与接缝上，周边渐进虚化；用掠射柔光表现凹凸，保留比例和实际颜色，不夸大颗粒、厚度或光泽。让观看者能判断它属于图1商品。不要新增微观结构或文字。

只输出一张完成的图像。没有要求新增的文字、徽章和水印不要添加。
```

## 参数设置

建议画布：`1024x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

```text
重点展示近照中的表面纹理，光线从侧上方扫过，纹理尺度与原图一致。

```
