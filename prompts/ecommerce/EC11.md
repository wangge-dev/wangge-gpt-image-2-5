# EC11 · 卖点信息图与详情页模块

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · 电商来源改写**

将真实卖点转成手机上易读的图文模块。

## 准备材料与变量

图1：单件商品整体照片，控制身份和整体机位；图2（可选）：同SKU细节近照，仅核对对应局部，不作为第二件商品。另提供人工审定的1–3组“短标题：一句解释”和各组依据；不足三条不凑数，没有可用卖点时暂不制作本卡。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 填写商品名称、材质、颜色、规格与实际可见特征；不要填未经核实的功效 |
| `{{卖点文案}}` | 人工审定的1–3组，逐条编号并按“短标题：一句解释”填写；依据另附且不自动上屏，缺项不由模型补齐 |
| `{{配色}}` | 米白底、深灰字、酒红点缀 |

## 拿来就用的具体示例

图1：米白双提手帆布包整体照，开口可见；图2：同一只包内袋近照。三条说明已由人工核对，只描述照片中的结构，不宣称承重、容量或功效。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1控制当前商品身份、可见面和机位；保留原视角，不强行正面化，不镜像补侧背面。商品资料不覆盖照片中相反的外观；未拍到的结构不补造，看不清的标签字不猜写。

图2如提供，只确认同SKU对应细节，不重复画成另一件商品，不替换整体视角；无图2时仅使用图1可见细节，不生成放大窗补证据。卖点数量由已提供文案决定，只排1–3组，不补空区，不虚构第三条。依据只用于核对，不自动画成证书、报告或认证。文案与证据相反时先指出具体冲突并请人工核对，不改造商品或生成替代卖点。

图1是实际商品参考。商品信息：所附米白双提手帆布包的可见外形、颜色、结构、材质与标签，不添加未提供的规格和性能。保留图1中的外形比例、结构、颜色、材质、包装图案和可辨认的品牌文字；布景反光可以变化，但不要重新设计商品。只呈现参考图或资料中有依据的商品细节，不补造配件和性能。

制作商品详情页的一张独立模块图。商品在上方居中，下方按实际提供的1–3组文案安排卖点区；每块一个简洁图标、一条短标题、一句解释。卖点原文：1、双提手：两侧提手清楚可见。2、包口形态：展示图1可见的开口。3、内置小袋：位置以图2为准。品牌配色：米白背景、深灰文字、棕色点缀。严格按给定顺序和文字排版，不添加功效、销量、检测数字或认证徽章。留出清楚的块间距，不把所有信息挤进商品包装。

只输出一张完成的图像。没有要求新增的文字、徽章和水印不要添加。

上方约55%高度为商品，下方约35%为文案，中间约10%留空，四边至少6%安全区。阅读顺序是商品、短标题、解释。一组居中，两组并列，三组等宽排布；图标只作中性信息辅助，不暗示未核实功效或认证。解释最多两行；溢出时请人工缩短或拆成另一张模块，不删字或缩成难读小字。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

制作一张商品说明模块，不保证平台审核通过，不替代事实核查。缺少第三条卖点时只排一条或两条，不生成新承诺填空。
