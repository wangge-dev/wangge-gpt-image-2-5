# EC11 · 卖点信息图与详情页模块

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · 电商来源改写**

将真实卖点转成手机上易读的图文模块。

## 准备材料与变量

先按正文的图1、图2等编号上传对应素材。涉及部件、内衬、背面、数据或人物时，补齐相应来源；没有素材不要让模型猜。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 填写商品名称、材质、颜色、规格与实际可见特征；不要填未经核实的功效 |
| `{{卖点文案}}` | 1.轻便收纳：包内设独立收纳位；2.开合方便：拉链顺滑；3.日常通勤：适合随身携带（请替换为真实卖点） |
| `{{配色}}` | 米白底、深灰字、酒红点缀 |

## 完整提示词

```text
图1是实际商品参考。商品信息：{{商品信息}}。保留图1中的外形比例、结构、颜色、材质、包装图案和可辨认的品牌文字；布景反光可以变化，但不要重新设计商品。只呈现参考图或资料中有依据的商品细节，不补造配件和性能。

制作商品详情页的一张独立模块图。商品在上方居中，下方分三块展示卖点；每块一个简洁图标、一条短标题、一句解释。卖点原文：{{卖点文案}}。品牌配色：{{配色}}。严格按给定顺序和文字排版，不添加功效、销量、检测数字或认证徽章。留出清楚的块间距，不把所有信息挤进商品包装。

只输出一张完成的图像。没有要求新增的文字、徽章和水印不要添加。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。
