# EC11 · 卖点信息图与详情页模块

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · 电商来源改写**

将真实卖点转成手机上易读的图文模块。

## 准备材料与变量

图1：米白色双提手帆布包照片，开口与内袋可见；图2：内袋近照。三项文字仅适用于参考图确实具有这些结构的商品。 其他商品按相同图片分工准备素材，并填写下方变量。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 填写商品名称、材质、颜色、规格与实际可见特征；不要填未经核实的功效 |
| `{{卖点文案}}` | 恰好三组，每组按“短标题：一句解释”填写并编号1、2、3 |
| `{{配色}}` | 米白底、深灰字、酒红点缀 |

## 拿来就用的具体示例

图1：米白色双提手帆布包照片，开口与内袋可见；图2：内袋近照。三项文字仅适用于参考图确实具有这些结构的商品。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图2仅用于确认内袋细节，不作为另一件商品。
图1是实际商品参考。商品信息：以所附实际照片为准，保留原有外形、颜色、结构、材质和标签；未提供的规格与性能不添加。保留图1中的外形比例、结构、颜色、材质、包装图案和可辨认的品牌文字；布景反光可以变化，但不要重新设计商品。只呈现参考图或资料中有依据的商品细节，不补造配件和性能。

制作商品详情页的一张独立模块图。商品在上方居中，下方分三块展示卖点；每块一个简洁图标、一条短标题、一句解释。卖点原文：1、双提手：两侧提手清楚可见。2、宽开口：展示实际开口形态。3、内置小袋：内袋位置参照图2。。品牌配色：米白底、深灰文字、棕色点缀。严格按给定顺序和文字排版，不添加功效、销量、检测数字或认证徽章。留出清楚的块间距，不把所有信息挤进商品包装。

只输出一张完成的图像。没有要求新增的文字、徽章和水印不要添加。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

 先确认“具体示例”的素材条件再复制；商品、尺寸或文案不一致时选“变量模板”。示例文字只用于说明填写方法。
