# EC19 · 多角度与多配色网格

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品展示 · 电商来源改写**

按实际参考图逐格展示视角或SKU；缺多视角时可用单图外观与已指定裁切分支。

## 准备材料与变量

多角度路径：逐格提供同一商品真实角度；多配色路径：每个SKU独立实拍。缺格时删掉缺失项并改布局，不让模型代选裁切或沿用“背面”等旧标签。只有一张外观图时选“单图外观与可见裁切”；裁切区域与标签由人工填写，没有足够可读细节就只展示一张完整外观。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 同一白色马克杯，以所附真实照片可见特征为准 |
| `{{格位清单}}` | 左上＝图1，标签“正面”；右上＝图2，标签“侧面”；左下＝图3，标签“背面”；右下＝图4，标签“顶部” |
| `{{网格布局}}` | 2行2列，四格各对应一张实际上传图；缺格先删项并改为1行2列或单图，不留空格 |
| `{{细节清单}}` | 仅使用有实际参考的部位图和批准名称；未提供则取消细节小图 |

## 拿来就用的具体示例

图1正面、图2侧面、图3背面、图4顶部，均为同一白色马克杯真实照片。只有图1时不要复制这个四图示例，选择“单图外观与可见裁切”，填写人工裁切区域与标签。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
商品信息：同一白色马克杯，以所附真实照片可见特征为准。人工格位清单：左上＝图1，标签“正面”；右上＝图2，标签“侧面”；左下＝图3，标签“背面”；右下＝图4，标签“顶部”。每项明确实际参考图号、视角或SKU和批准短标签；只使用对应原图的身份、颜色、结构、材质和可辨文字。图号只是上传编号，不代表用同一商品补出新面或新配色；商品不得串款、镜像、复制附件或补背面。

按2行2列，四格各对应一张实际上传图；缺格先删项并改为1行2列或单图，不留空格制作一张1:1商品展示网格。四周6%安全边距，格间留4%画布宽的间隔，间距在可用区域内计算。每格完整展示指定视角，商品只等比例缩放，展示尺度以人工批准关系为准，不把不同实物大小强行伪装相同。各格下方只写清单中的批准标签一次，背景纯白、柔光和文字层级一致。

格位资料不足时，先删除该项及其旧标签，再按剩余真实素材重新批准布局；不擅自从其他格裁切冒充缺少的角度。只有图1则改用单图变体，不能继续调用缺失图号。没有对应图片就不展示该视角或SKU；不从文字描述生成未售颜色。只输出一张完成展示图，不加价格、性能、排行或未经批准的比较事实。
```

按{{网格布局}}制作一张1:1商品展示网格。四周6%安全边距，格间留4%画布宽的间隔，间距在可用区域内计算。每格完整展示指定视角，商品只等比例缩放，展示尺度以人工批准关系为准，不把不同实物大小强行伪装相同。各格下方只写清单中的批准标签一次，背景纯白、柔光和文字层级一致。

格位资料不足时，先删除该项及其旧标签，再按剩余真实素材重新批准布局；不擅自从其他格裁切冒充缺少的角度。只有图1则改用单图变体，不能继续调用缺失图号。没有对应图片就不展示该视角或SKU；不从文字描述生成未售颜色。只输出一张完成展示图，不加价格、性能、排行或未经批准的比较事实。

## 参数设置

建议画布：`1024x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

只有图1：使用单图变体，仅替换商品信息和单图裁切清单；没有可读局部时填写“只用图1完整外观，标签正面外观，无局部裁切”。两／三图可用基础模板，但先重填格位清单与实际布局，不保留旧四格及缺图号。裁切只是原照片区域，不用于补真实微距。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 多配色展示 · colorway

```text
商品信息：{{商品信息}}。人工格位清单：{{格位清单}}。每项明确实际参考图号、视角或SKU和批准短标签；只使用对应原图的身份、颜色、结构、材质和可辨文字。图号只是上传编号，不代表用同一商品补出新面或新配色；商品不得串款、镜像、复制附件或补背面。

制作一张1:1真实SKU配色展示，采用{{网格布局}}；四周6%边距，格间4%留白。每个SKU都必须有自己的实际参考，人工清单明确名称与颜色，各格保留独立本色、盖色和标签，不把全组改成图1。只有机位证据一致时才按同一机位展示，不旋转补隐藏面。

各格等比例排放、背景及柔光统一，短标签仅出现一次；缺某SKU时连同原标签和席位一起删去，再批准剩余布局，不改色生成替代款，也不以重复商品填满六格或九格。只保留真实数量，不新增销量、赠品、参数、价格、功能或性能文字。只输出一张完整配色图。
```

### 带功能标注网格 · feature-grid

```text
商品信息：{{商品信息}}。人工格位清单：{{格位清单}}。每项明确实际参考图号、视角或SKU和批准短标签；只使用对应原图的身份、颜色、结构、材质和可辨文字。图号只是上传编号，不代表用同一商品补出新面或新配色；商品不得串款、镜像、复制附件或补背面。

制作一张1:1商品与已知细节图，四周6%边距；左侧安全区约60%放完整原商品，右侧约40%按{{细节清单}}排列已提供的真实细节，间距计入区内。名称只是批准部位名，不升级成功能或功效。小图只来自清单指定实拍，不生成第二个SKU，不从整体照片补微观结构。

每个小图与原商品位置有明确人工对应，缺参考就删除小图和旧名称；没有任何细节图时改成单图外观，不留下四个空框或猜图。图号与名称一次一对应，统一背景与短字，保持商品轮廓、原比例及原角度。只输出一张完整图，不新增性能、认证、尺寸、价格和优劣结论。
```

### 对比网格 · comparison

```text
商品信息：{{商品信息}}。人工格位清单：{{格位清单}}。每项明确实际参考图号、视角或SKU和批准短标签；只使用对应原图的身份、颜色、结构、材质和可辨文字。图号只是上传编号，不代表用同一商品补出新面或新配色；商品不得串款、镜像、复制附件或补背面。

制作一张1:1左右双SKU比较图。只有两款各自有实拍时使用；四周6%边距，两列宽度一致，中间4%画布宽留白，各列完整展示自己的原视角与名称，不把左右款强行改成相同外观。人工比较原文：{{比较事实}}。每条只在对应SKU列出现一次，不计算或推断差异。

资料只有款名时只排款名和照片，不加“升级”“更好”等结论；任一款缺图则停止双款比较，切换已有商品的单图外观分支，不伪造竞品。不同款真实尺寸关系未提供时只说明并排陈列，不暗示比例实测。统一背景与文字层级，不新增性能、销量、价格、徽章或未经批准优势。只输出一张完成比较图。
```

### 单图外观与可见裁切 · single-photo-crops

```text
只使用图1制作一张1:1商品外观说明图，不需要其他角度或SKU图片。商品信息：{{商品信息}}。人工裁切及标签清单：{{单图裁切清单}}。图1只提供原照片真实可见角度与可辨外观，不旋转补面、不镜像、不生成背面或新配色。四周6%安全边距，左侧约60%放一张完整原外观，右侧约40%只放清单指定区域的裁切，间距包含在区内。裁切是同一张照片的局部，不代表额外商品或新的视角；各标签必须说明外观或局部，不用“背面”“内部”“微观”等无依据词。原图不够清晰或没有批准裁切区域时，取消全部局部图和标签，完整外观居中占安全区，不能放大重绘细节或留空框。商品只等比例缩放，保留本色、轮廓和原可辨文字；不增加配件、尺寸、功能、价格或认证。只输出一张完整图片。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮结果为底图，重新附实际参考图。本轮只修改{{格位或裁切区}}，使用{{实际图号与可见区域}}，短标签只写“{{准确标签}}”。移除该区原来的错误视角标签；缺参考则删除该区，不补新角度或新SKU，其他格身份、本色与文字不变。只输出一张修改图。
```
