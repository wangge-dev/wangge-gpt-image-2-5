# EC14 · 套装与产品线陈列

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品展示 · 电商来源改写**

将真实多SKU按清单、数量和实测比例制作套装主图；礼盒、使用顺序与产品线分别使用独立变体。

## 准备材料与变量

图1起：每个SKU的完整同类视角照片，图号与清单逐一对应；文字清单写明数量及同一维度实测尺寸。提供主商品与席位。礼盒变体另写实际礼盒图号及是否为空盒；使用程序变体另给批准顺序，不能由上传顺序推断使用方法。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{套装清单}}` | 图1=主包，1件，高25cm；图2=小包，1件，高12cm；图3=卡包，1件，高8cm；高度来自人工实测示例 |
| `{{主商品}}` | 图1主包 |
| `{{席位}}` | 左侧图2小包、中间图1主包、右侧图3卡包 |
| `{{礼盒依据}}` | 未提供；本轮不画礼盒 |
| `{{使用顺序}}` | 未提供；不加使用序号，按基础席位陈列 |

## 拿来就用的具体示例

图1主包、图2小包、图3卡包各一张完整正面照；人工示例实测高度分别25、12、8cm，并批准上述席位。这些数值只示范填写方式，换商品须提供自己的实测。没有图4礼盒，不画礼盒；没有使用顺序，不加序号。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
根据图1=主包，1件，高25cm；图2=小包，1件，高12cm；图3=卡包，1件，高8cm；高度来自人工实测示例制作一张3:2横版商品陈列图。每个图号只负责对应SKU的外观，各件按清单数量出现，不因一张参考含包装或其他SKU就重复加入。保留每件的原可见视角、外形比例、颜色、材质、部件、标志与包装字，不换色串款、不转到未知背面、不补造内部。

主商品是图1主包，按左侧图2小包、中间图1主包、右侧图3卡包排列；每件各一。三件同一深度、同一支撑面，图2与图3的实物高度相对图1为12:25和8:25；不单独放大主包，只用中间位置和留白突出。保持各自原正面视角、米白／原色、手柄、拉链、标志与包装原字，不增加肩带或礼盒。

成品四边向内6%留安全边距，所有实体完整可见，成员之间有间隙、标志不被遮挡。让套装整体宽度不超过可用区90%，空间不足时所有商品按同一个比例缩小，不单独拉伸或放大主品。相对尺寸只依据清单中的同一维度实测：在同一深度和共同支撑面排列，保留参考视角；不要从像素尺寸推算实物尺寸，也不把图中标注写到包装上。尺寸资料不全时，不声称严格真实比例，先补测量或保留真实同框照片的相对尺度，不猜。

浅米色背景、统一柔光和商品外短接触阴影，商品自然色不变。无批准布景就不加道具、礼品、价格、功效、认证、未批准的画外文字或水印。只有明确出售为同一套装时才把陈列当套装主图；产品线陈列不自动等于随单全送。只输出一张平面商品图，不生成拼贴或样机。
```

## 参数设置

建议画布：`1536x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

商品、包装与布景分别计数。同维度实测只约束展示比例，不能从生成图反推尺寸；尺寸缺失时不猜比例。礼盒参考只取批准组件，使用顺序要独立给出。原像素／包装准确性有硬要求时用原素材合成。
