# EC61 · 商品环绕动图的十六帧连续源图

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品动效 · GPT Image 2.5 电商来源改写**

先生成4×4十六帧连续源图，再离线切分合成GIF或WebP，用于商品详情页、小程序和社媒的轻量环绕展示。

## 准备材料与变量

图1至图5：同一商品正面、左右30度、左右60度实拍；图6：标签近照；图7：人工帧位表。缺少某一角度时缩小环绕范围，不让模型猜背面。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 深灰色降噪耳机充电盒 |
| `{{环绕范围}}` | 从左30度到右30度，16帧等步进，视线高度固定 |
| `{{固定项}}` | 盒体居中、开盖角度38度、两只耳机在槽内、深灰本色、标志位置、标签字序、米白背景和左上柔光 |
| `{{网格}}` | 4×4等大方格，按从左到右、从上到下读取；格间距一致，无边框、无编号 |
| `{{运动规则}}` | 商品落点和尺度不变，仅观察角度逐帧变化；相邻帧角度变化均匀，不跳帧、不倒转 |
| `{{输出用途}}` | 离线切分为16张后合成往返循环WebP |

## 拿来就用的具体示例

至少提供覆盖全部环绕范围的多角度同一实物照片；单张正面照只能做小幅视差，不能声称完整转台。动图切分、时长、循环和压缩在图像生成后完成。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
用同一深灰色降噪耳机充电盒的正面、左右30度和左右60度实拍制作4×4十六帧源图。从左30度到右30度等步进，盒体始终居中，开盖38度，两只耳机留在槽内，标志、深灰本色、米白背景和左上柔光不变；相邻帧角度连续。无边框、编号、速度线或背面补造。只输出一张源图，之后离线切成16帧合成往返循环WebP。
```


## 完整提示词

```text
依据图1至图7制作同一{{商品}}的十六帧连续源图。执行“{{环绕范围}}”和“{{运动规则}}”，每帧严格保持“{{固定项}}”；按“{{网格}}”排版。各帧只显示参考资料支持的外观角度，镜面、高光、遮挡与接触阴影随观察角度连续变化，不能让商品自身旋转同时又移动相机。不得改变开盖角、耳机数量、颜色、标签、商品尺度或光源，不生成背面未知结构，不增加速度线、手、支架、文字、帧号或第二件商品。只输出一张4×4源图；本轮不直接生成GIF，后续按“{{输出用途}}”离线处理。
```

## 参数设置

建议画布：`2048x2048`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

十六帧源图不是已完成动图，也不证明真实360度结构；需离线切分、去边距、合成和检查平台文件大小。当前未运行生成或合成。
