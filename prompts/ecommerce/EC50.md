# EC50 · 详情页首屏标题商品与利益点三层动线

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · 本库原创设计**

把详情页首屏固定为标题、商品和单一利益点三层，先建立阅读动线，再补充风格与光影。

## 准备材料与变量

图1：商品正面完整照；图2：包装文字近照；图3：人工确认的标题、副标题和唯一利益点；图4可选：批准的品牌配色或既有首屏。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{标题}}` | 轻装随行 |
| `{{副标题}}` | 折叠水杯系列 |
| `{{利益点}}` | 收起后更省桌面空间 |
| `{{商品位置}}` | 右下，外接框占画面45% |
| `{{配色}}` | 米白、深灰、橙色点缀 |

## 拿来就用的具体示例

上传商品正面和包装近照，并逐字提供三行批准文案；利益点必须有商品资料依据。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
为橙色折叠水杯制作4:5首屏。左上标题“轻装随行”，下一行“折叠水杯系列”；水杯位于右下，外接框占画面45%，底部只写“收起后更省桌面空间”。米白、深灰、橙色点缀，四周8%安全边距。保持折叠层数、杯盖、颜色和标签，不添加容量、耐温、食品级、价格或按钮。只输出一张图。
```


## 完整提示词

```text
依据图1和图2制作4:5详情页首屏。阅读动线固定为：顶部左侧标题“{{标题}}”，其下一行副标题“{{副标题}}”，视觉中心为商品，底部只放一个利益点“{{利益点}}”。商品按{{商品位置}}落位，四周保留8%安全边距；采用{{配色}}，图4仅用于继承配色、字体气质和留白。所有文字逐字出现一次，不加第二卖点、参数、价格、认证或按钮。保持图1商品结构、比例、颜色、标签和配件数量，背景装饰不得穿过标题或遮挡商品。只输出一张首屏图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡只做首屏，不替代完整长详情页；每张图只保留一个主要利益点。
