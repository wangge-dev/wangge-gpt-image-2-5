# EC50 · 详情页首屏标题商品与利益点三层动线

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · 本库原创设计**

把详情页首屏固定为标题、商品和单一利益点三层，先建立阅读动线，再补充风格与光影。

## 准备材料与变量

图1必需：单件商品完整原照。图2可选：同一SKU包装文字近照，只核对图1可见包装；不把背面文字搬到正面。文字表必需：人工批准的标题、副标题和单一利益点及其证据；不需要把文字表转成图片。品牌色板可选，仅负责背景、字体气质与留白，不覆盖商品本色。只有图1、没有利益点证据时选“无利益点首屏”变体。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{标题}}` | 轻装随行 |
| `{{副标题}}` | 帆布包系列 |
| `{{利益点}}` | 双提手设计 |
| `{{商品位置}}` | 右下区域，含提手外接框高度约52%，宽度按原比例联动，避开全部文字区 |
| `{{配色}}` | 米白背景、深灰字、橙色小面积点缀 |

## 拿来就用的具体示例

上传一张完整清晰的米白双提手帆布包照片，人工批准文案“轻装随行／帆布包系列／双提手设计”；双提手须在图1中清楚可见。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作一张4:5帆布包详情首屏。图1是米白双提手帆布包唯一商品依据，保留原角度、轮廓、帆布本色、缝线、原标识和两只提手，不补背面、肩带或内部。左上标题只写一次“轻装随行”，下一行只写一次“帆布包系列”；商品右下落位，外接框高度约52%，宽度按原比例联动并完整留边，位于画面高度28%–78%区域。底部只写一次“双提手设计”，这条描述仅依据图1可见的两只提手，不延伸为承重或舒适结论。四周8%安全边距，米白背景、深灰文字、少量橙色点缀，三层不互相遮挡。标题最多两行，另外两行各一行；不要价格、尺寸、承重、认证、按钮或第二卖点。只输出一张完成首屏。
```


## 完整提示词

```text
依据图1制作一张4:5详情页首屏，继承原拍摄角度、结构、比例、本色、标识和实际数量；图2仅在实际提供时核对可见包装文字。文字表中的利益点必须有同一商品资料或可见外观依据，不从商品名称、用途或常识补性能。阅读顺序为标题→商品→单一利益点：左上标题“{{标题}}”，其下副标题“{{副标题}}”；商品按{{商品位置}}等比例落位；底部只写“{{利益点}}”。外圈8%为安全边距，标题和副标题在上部约22%内，商品安排在高度28%–78%区域，利益点在底部约10%内，不相互遮挡。

采用{{配色}}，品牌参考只传递背景配色、字体气质和留白，不把主题色染到商品。标题、副标题、利益点各出现一次，不改写、重复、加单位或第二卖点。标题最多两行、副标题和利益点各一行；长文挤不下时要求人工批准短文，不生成难读小字。保留原包装标识，不把画面文案印到商品上。禁止价格、认证、参数、按钮、新配件和无依据的折叠或功能状态。只输出一张完成首屏。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

只做单张首屏，不一次生成整条详情。利益点没有依据时使用下方无利益点版，不让模型自行推荐卖点；文字溢出由人工缩短，精确排版可在设计工具完成。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 无利益点首屏 · approved-title-only

```text
制作一张4:5详情首屏。图1是唯一商品原照，沿用原角度、比例、结构、本色、标识和数量；只呈现原照已经可见的细节，不补隐藏面。左上只写人工批准标题“{{标题}}”，其下只写人工批准副标题“{{副标题}}”，各出现一次，标题最多两行、副标题一行。外圈保留8%安全边距，文字放上部约22%，商品按{{商品位置}}等比例完整落位，避开文字。采用{{配色}}，主题色仅作用于背景和文字，不改商品本色。底部原利益点区域留为安静背景，不写利益点、性能、参数、价格、认证、按钮或假占位文字；不要把标题印在商品上。长文字挤不下时请求人工短文，不缩成难读小字。只输出一张完成首屏。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
