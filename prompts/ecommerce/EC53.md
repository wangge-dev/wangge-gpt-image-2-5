# EC53 · 商品、模特与氛围三参考图职责绑定

[全部提示词](../README.md) · [首页](../../README.md)

**分类：模特展示 · 本库原创设计**

把商品外观、成年模特身份和场景氛围分给三张参考图，生成可用于详情页或社媒的上身商品图，避免把氛围图中的人物和商品带入成片。

## 准备材料与变量

图1：商品正面与关键标签照；图2：获准使用的成年模特身份与体型照；图3：只用于色调、光线和背景气氛的参考图。另提供动作、商品佩戴位置和准确文案（如无则不加字）。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 黑色通勤双肩包 |
| `{{动作}}` | 成年模特站在浅灰城市入口，右手握住右肩带，包体完整可见 |
| `{{商品位置}}` | 背部中央，包体底边位于画面下方22%处 |
| `{{氛围}}` | 图3的冷灰晨光和低饱和蓝灰背景 |
| `{{文字}}` | 不添加文字 |

## 拿来就用的具体示例

三张图按图1商品、图2成年模特、图3氛围顺序上传；模特需有使用授权，商品尺寸与佩戴位置由人工提供。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
用图1黑色通勤双肩包、图2获准成年女模特半身照、图3冷灰晨光城市入口参考，制作4:5电商上身图。模特站在浅灰城市入口，右手握住右肩带，包体背在背部中央，底边约在画面下方22%，双肩带、前袋、拉链和标识完整可见。只借用图3的冷灰晨光和低饱和蓝灰背景，不带入图3人物、包或文字。不加价格、容量、防水、承重或平台标志。只输出一张图。
```


## 完整提示词

```text
依据三张参考图制作4:5电商上身图。图1只控制{{商品}}的外形、颜色、结构、标签、肩带和材质；图2只控制获准成年模特的脸部、发型、肤色、体型与姿态；图3只借用{{氛围}}，不得复制图3中的人物、商品、文字或道具。按{{动作}}和{{商品位置}}安排商品，接触、背带受力方向、褶皱、遮挡与投影自然；商品标签和关键结构保持清楚。只执行这一种人物与商品关系，不添加未提供的配件、品牌、价格、销量或功能宣称。{{文字}}。只输出一张完整图片。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

氛围参考只负责色调、光线和背景，不负责人物或商品；输出仍需人工核对商品结构、人物授权与实际佩戴关系。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

