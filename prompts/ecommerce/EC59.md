# EC59 · 整套参考图保版式逐张换入新商品

[全部提示词](../README.md) · [首页](../../README.md)

**分类：批量编辑 · GPT Image 2.5 电商来源改写**

把同一款新商品逐张换进一套已批准的参考图，保留每张图的版式、场景、光线、道具与文字位置，适合快速制作结构一致的Listing套图。

## 准备材料与变量

图1至图3：新商品正面、侧面和标签近照；图4：本轮目标参考成片；图5：人工商品保护清单；图6：本轮替换区与接触面标注。多张目标图需逐张执行并记录目标编号。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{新商品}}` | 米白色按压泵洗手液瓶 |
| `{{目标图}}` | 套图第3张浴室台面场景 |
| `{{替换区}}` | 只替换原瓶轮廓及其接触阴影，保留右侧毛巾与左后方镜面 |
| `{{商品保护}}` | 瓶型、泵头方向、米白瓶色、黑色标签、品牌字序和液位不可改变 |
| `{{版式保护}}` | 4:5画布、商品中心位于画面宽度46%、背景、机位、焦段、左上柔光、道具、标题位置和上下留白 |
| `{{文字规则}}` | 包装原字来自新商品参考；画外标题继续使用目标图已批准文字，不新增文字 |

## 拿来就用的具体示例

新商品需有同一SKU正侧面和标签近照；目标成片须有使用权并已批准。批量任务逐张执行，防止一轮多图造成商品身份和版式串位。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以套图第3张浴室台面场景为底图，只替换原瓶轮廓和接触阴影，换入图1至图3的米白色按压泵洗手液瓶。保持瓶型、泵头方向、米白瓶色、黑色标签、品牌字序和液位；商品中心仍在画宽46%，4:5画布、右侧毛巾、左后镜面、左上柔光、标题位置与留白不变。不得继承原瓶标签，不挪道具，不加功效或第二瓶。只输出第3张替换成品。
```


## 完整提示词

```text
以图4“{{目标图}}”为底图，只在图6“{{替换区}}”把原商品换成图1至图3的唯一{{新商品}}。新商品必须严格继承“{{商品保护}}”，并按图4原商品的透视、落点、占比与接触面自然适配；接触阴影可随新轮廓重建，但光源方向不变。完整冻结“{{版式保护}}”，执行“{{文字规则}}”。不可把图4原商品的颜色、标签或结构带到新商品，不得挪动道具、重排文字、改变背景色、复制第二件商品、补造规格功效或一次输出多张拼图。只输出本轮目标图的一张替换成品；下一张目标图另开一轮并重新附新商品参考。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

换品图只继承有权使用的版式与场景；不得把竞品商标、专有包装或未经授权素材作为可发布成品。生成结果需逐张核对商品身份和文字。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
