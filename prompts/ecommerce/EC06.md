# EC06 · 社媒种草与视频封面

[全部提示词](../README.md) · [首页](../../README.md)

**分类：营销素材 · 电商来源改写**

把一张商品照做成短标题社媒封面；普通竖图、方图与短视频竖封面分别锁版式，不补包内物品或平台互动数字。

## 准备材料与变量

图1：商品完整清晰的实际可见角度照，保持原封闭／开合状态。标题与背景用文字提供，标题不应暗示未拍到的包内物品、使用结果或评价。没有动作照不生成人手或开箱过程。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 米白帆布手提包，封闭正面、两条提手、原有印花；其余以图1为准 |
| `{{标题}}` | 今天，轻装出门 |
| `{{背景}}` | 浅灰墙与米白桌面，无额外道具 |

## 拿来就用的具体示例

图1为米白帆布包封闭正面照；人工批准标题“今天，轻装出门”，背景浅灰墙与米白桌面，无其他道具。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

## 参数设置

建议画布：`1152x1536`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

默认标题不再暗示未提供的包内内容。三个原来源键保留，各用独立完整构图；9:16留边是本卡设计建议，发布前核当次平台预览。

默认3:4用1152x1536；Instagram方图用1024x1024；TikTok/Reels的9:16分支用1152x2048。选择分支时同步切换实际画布，不能仅改正文比例却沿用默认尺寸。
