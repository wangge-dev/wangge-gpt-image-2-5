# EC09 · 真实素材前后对比排版

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · 电商来源改写**

把已有对比照片和数据排成图，不生成虚假的效果证据。

## 准备材料与变量

基础版：图1为商品独立原照，图2为真实前图、图3为同一对象真实后图；人工确认同一记录对象、顺序、可比较范围和需披露的机位／光照差异。文字提供标题及审定说明，数据必须另有数值、条件、单位与来源。缺独立商品图但有真实前后照时选“双图仅对照”；缺任一时点照就停止对比版，不生成缺失状态。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 一只收纳盒，外观、结构、颜色和原字仅以图1可见部分为准 |
| `{{前标题}}` | 整理前 |
| `{{后标题}}` | 整理后 |
| `{{数据说明}}` | 同一桌面整理记录；物品与位置以照片为准 |
| `{{对照范围}}` | 两张桌面照片均完整保留桌面四周边缘；保持原顺序、原色和原曝光，不裁掉边缘物品 |

## 拿来就用的具体示例

自备图1收纳盒原照、图2同一桌面整理前实拍和图3整理后实拍；人工确认顺序与比较范围。本示例不含测量数据，不声称已验证整理效果；不要用生成照片代替真实时点记录。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
只用已提供的真实照片制作一张3:2左右对比详情图。图1负责商品身份：一只收纳盒，外观、结构、颜色和原字仅以图1可见部分为准；图2是前图，图3是后图，人物、物件、位置和已拍状态分别以各自原照为准。人工审定的对照范围：两张桌面照片均完整保留桌面四周边缘；保持原顺序、原色和原曝光，不裁掉边缘物品。没有真实前后照或未确认是同一对象时停止本版，不造缺图，不把摆拍或不同对象拼成同一次变化。

四周5%安全区；可用高度上12%为两列标题、中间68%为照片区、下20%为商品缩略图与说明。照片区可用宽度按左47%、中隔6%、右47%划分，两张照片各自等比例完整适配等大的窗，不拉伸，不为相同裁切而删除真实差异；不同宽高比用留白补齐，不镜像、不扩图。图1只在底部出现一次，不能覆盖前后照片或伪装成两时点新增物件。阅读从左标题到右标题，再看照片和底部说明。

左标题只写“整理前”，右标题只写“整理后”，底部说明只用“同一桌面整理记录；物品与位置以照片为准”；每项一次，说明为空就不排该项，不补“效果因人而异”等无依据套话。白底与深灰字，照片内不加箭头、数字或滤镜。不重绘效果区域、不美化后图、不恶化前图；两张照片各自保留原有亮度与色温，不能为了统一而调成相同曝光。机位、光照或拍摄条件不同须在审定说明中披露，不由模型修成同条件。数据只排有来源的原值、单位和条件，无数据就不画进度条、百分比、评级、临床或认证标记。文字超出原分配区时停止该区，转人工删改审定文案或外部排字，不缩成小字。需要证据照片像素原样保留时在外部排版软件合成，本图不能替代原始记录。只输出一张详情图。
```

## 参数设置

建议画布：`1536x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

“同窗大小”不等于把照片曝光、色温或真实物件调成一样。只做已有证据的可读排版，不作因果、功效或质量结论；原照像素严格保持应使用外部图层合成。双图版图号已重新从1编号。

### 双图仅对照 · comparison-only

```text
图1为真实前图，图2为同一对象真实后图，只使用这两张照片和人工审定的短文案，不需要独立商品照。缺任何时点或同一对象未确认时停止，不生成缺失状态。对照范围：{{对照范围}}。

制作一张3:2左右对照详情图，四周5%安全区，可用高度上12%标题、中间72%照片、底16%说明；中部左47%、中隔6%、右47%。图1和图2各自等比例完整放进照片窗，不镜像、补边、重绘或裁掉真实差异；宽高比不同则留白。左只写“{{前标题}}”，右只写“{{后标题}}”，底部只排“{{数据说明}}”，每项一次，空项省略，不放第三张商品小图。

保持两张原照各自原有曝光、色温和可见状态，不统一亮度或增强前后效果；已知条件差异必须由人工写入说明，不能校色伪装同条件。不加百分比、进度条、评级、临床、认证、价格或功效。长字放不下停止该区并转外部排字；证据照片需像素原样时用外部原照排版。只输出一张对照图，不输出新的效果证据。
```
