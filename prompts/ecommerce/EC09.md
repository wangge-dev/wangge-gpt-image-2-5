# EC09 · 真实素材前后对比排版

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · 电商来源改写**

把已有对比照片和数据排成图，不生成虚假的效果证据。

## 准备材料与变量

先按正文的图1、图2等编号上传对应素材。涉及部件、内衬、背面、数据或人物时，补齐相应来源；没有素材不要让模型猜。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 填写商品名称、材质、颜色、规格与实际可见特征；不要填未经核实的功效 |
| `{{前标题}}` | 使用前（按真实素材填写） |
| `{{后标题}}` | 使用后（按真实素材填写） |
| `{{数据说明}}` | 填入经核实的数据、条件和来源；没有数据则填“效果因实际条件而异” |

## 完整提示词

```text
图1是实际商品参考。商品信息：{{商品信息}}。保留图1中的外形比例、结构、颜色、材质、包装图案和可辨认的品牌文字；布景反光可以变化，但不要重新设计商品。只呈现参考图或资料中有依据的商品细节，不补造配件和性能。

图2为真实前图，图3为真实后图。制作左右对比版式：左放图2，右放图3，两侧同尺寸同裁切原则，中心细线分隔，底部放图1商品小图。不得修饰对比区域、加深前图问题或增强后图效果。左标题“{{前标题}}”，右标题“{{后标题}}”，底部仅排“{{数据说明}}”。资料没有提供的数值和效果不要补充；不以画面色温差制造改善。

只输出一张完成的图像。没有要求新增的文字、徽章和水印不要添加。
```

## 参数设置

建议画布：`1536x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

需要照片或截图像素不变时，请在排版软件中合成原素材；生成式编辑适合视觉提案，不能保证原图像素、文字或数据完全不变。
