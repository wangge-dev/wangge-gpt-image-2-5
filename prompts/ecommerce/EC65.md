# EC65 · 随售内容与拍摄道具排除说明

[全部提示词](../README.md) · [首页](../../README.md)

**分类：高频电商成片 · 本库原创设计 · 面向 GPT Image 2.5**

把明确随售的商品和明确不包含的布景分成两个照片区，帮助买家理解交付范围；不把场景道具当赠品，也不把未提供信息判成不包含。

## 准备材料与变量

图1为随售商品原照；图2为需要明确排除的道具原照，二者有各自人工身份与包含／不包含声明。随售清单是商家确认的文字事实，不能由图片推导。本例为自拟教学清单，不代表真实商家销售配置。缺道具原照用“仅主品照片与文字排除”完整分支，不生成道具；没有明确清单时先补资料。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{标题}}` | 本例包含什么 |
| `{{随售商品}}` | 图1所示System76 Launch 2键盘，仅保留顶面、键位、键帽颜色和双空格可见外观 |
| `{{排除道具}}` | 图2所示白色方桌，仅作本教学排版的布景例，不表示与键盘真实同场拍摄 |
| `{{包含清单}}` | 键盘1把 |
| `{{不包含清单}}` | 白色方桌1张（布景例） |
| `{{待确认说明}}` | 其他配件与包装信息本例未提供，需另确认 |

## 拿来就用的具体示例

图1上传 assets/samples/system76-launch-2/top.webp（System76／CC BY-SA 4.0）；图2上传 assets/samples/ikea-lack-white-table/source.jpg（Juhan Sonin／CC BY 2.0）。本例人工声明仅为练习：键盘在包含区、方桌在不包含区；不声称System76原包装配置、两品牌合作或当前可购买。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作一张4:5面向买家的交付范围详情图，不是套装陈列或内部清点板。图1只对应随售商品：图1所示System76 Launch 2键盘，仅保留顶面、键位、键帽颜色和双空格可见外观；图2只对应明确排除的道具：图2所示白色方桌，仅作本教学排版的布景例，不表示与键盘真实同场拍摄。人工批准的包含清单“键盘1把”，不包含清单“白色方桌1张（布景例）”；这些清单是文字输入，不由照片、品牌常识、已有包装或看起来配套推导。未提供的物件既不画进包含区，也不自动写成不包含。

四周5%安全区；可用高度上10%标题、4%留白、中间54%两照片区、4%留白、下22%清单、底6%说明。中间可用宽左62%为随售商品、间隔6%、右32%为道具；每张原照各自等比例完整适配，保留原视角、可见文字、颜色与真实遮挡，宽高比不同用留白，不裁断键盘或桌腿。两区严格隔开，不同框拼成键盘摆桌上的使用现场，不表达两件实物比例或品牌联名。左下对齐包含清单，右下对齐排除清单，不使用跨区引线或“整套”括号。阅读先标题，再左侧主品与清单，最后右侧道具与排除项。

标题只写“本例包含什么”；左区只写“包含”及“键盘1把”，右区只写“不包含”及“白色方桌1张（布景例）”，每项一次；底部只写“其他配件与包装信息本例未提供，需另确认”。米白背景、深灰文字，右区用细灰边框与“不包含”字样区分，不把真实道具涂红、打叉或变灰来修改原照。没有道具原照时不生成右侧物件，须人工批准改成纯文字排除区后再执行。

不补线缆、说明书、礼盒、赠品、运费、价格、保修、功效或兼容承诺；不把原照中的地板、墙面与其他背景纳入随售或排除清单。文字过长停对应区，转人工短文或外部排版，不删限定词、不缩成小字。照片须像素完全保留时外部原照合成。只输出一张详情图，不能把本教学清单当真实店铺的销售配置。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

与EC14套装成员陈列、T325三层内部清点及EC63双选购入口不同，本卡只有一个随售主品，另一照片区明确排除，不设独立购买按钮。实际发布必须先取得对应SKU的商家清单；本例不是供货证明。两张照片各自按原许可署名，BY-SA改编遵守适用共享条件，不归本库MIT。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 仅主品照片与文字排除 · text-exclusions

```text
只用图1真实主品照片制作一张4:5交付范围详情图，不需要道具照片，不生成道具或新的场景。图1负责随售商品：{{随售商品}}。包含清单只采用人工确认的“{{包含清单}}”，排除清单只采用“{{不包含清单}}”；未提供项目不自动归入任一区。

四周5%安全区，可用高度上10%标题、4%留白、中部46%主品原照、4%留白、下28%两列文字清单、底8%说明。主品原照等比例完整放入中部，原视角、结构、键位、颜色、包装字和可见边缘不改；照片背景可留在独立窗内，不新增相对比例或同场使用关系。清单区可用宽度左47%、间隔6%、右47%；左列只写“包含”及批准包含清单，右列只写“不包含”及批准排除清单，右列纯文字、不画缺失道具轮廓。先看标题和主品，再左后右读清单。

标题只写“{{标题}}”，底部只写“{{待确认说明}}”，每项一次；米白底、深灰字、细分隔线。不凭照片和常识补线缆、包装、礼盒、赠品、保修、价格、运费或兼容信息；原图背景不自动成为随售或排除物。放不下的清单先停对应区，交人工短文或外部排版，不删除限定词、不缩成小字。照片需像素精确保留时外部合成。只输出一张详情图，本例清单仅为教学，不证明真实店铺销售配置。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
