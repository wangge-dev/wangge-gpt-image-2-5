# EC51 · 单商品换背景与边缘反射冻结

[全部提示词](../README.md) · [首页](../../README.md)

**分类：局部编辑 · 本库原创设计**

只替换商品周围背景，同时冻结商品轮廓、透明边缘、镜面反射和接触关系，减少换景后的商品漂移。

## 准备材料与变量

图1：待换背景的商品成图；图2：同一商品原始参考；图3：目标背景参考；另提供商品保护区遮罩或人工边界说明。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{目标背景}}` | 浅灰石材台面与暖白墙面 |
| `{{保护区}}` | 商品外轮廓向外扩3%的区域 |
| `{{允许变化}}` | 保护区外的背景、背景虚化和环境光色 |
| `{{冻结内容}}` | 商品像素、标签文字、透明边缘、镜面高光、底部接触点 |

## 拿来就用的具体示例

上传底图、同SKU原始商品照和目标背景；透明或镜面商品必须给出清楚保护边界。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以图1透明香水瓶成图为底图，图2核对瓶型和标签，图3提供浅灰石材台面与暖白墙。只替换商品轮廓外3%的背景；冻结瓶身、木质瓶盖、液位、标签、玻璃边缘、高光和底部接触点。新阴影只在瓶外延伸，不加花草、文字或第二瓶。只输出一张4:5图片。
```


## 完整提示词

```text
以图1为底图，图2核对商品身份，图3只提供{{目标背景}}。本轮仅改变{{允许变化}}；完整冻结{{冻结内容}}以及{{保护区}}，不得重绘商品、改变瓶型、颜色、液位、标签、反光形状或配件数量。新背景的透视和光向与原商品兼容；若无法兼容，只调整保护区外的环境明暗，不修改商品表面来迎合背景。底部接触阴影只允许在商品外侧延伸，不能让商品悬浮或陷入台面。不添加文字、道具或第二件商品。只输出一张4:5换背景结果。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

生成式编辑不能保证像素级冻结；高风险包装文字仍需放大人工核对。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
