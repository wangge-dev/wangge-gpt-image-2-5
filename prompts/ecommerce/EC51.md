# EC51 · 单商品换背景与边缘反射分区保护

[全部提示词](../README.md) · [首页](../../README.md)

**分类：局部编辑 · 本库原创设计**

为单商品成图换背景，保护商品身份、轮廓和标签；不透明商品与透明／镜面商品采用不同的边缘及光学编辑范围。

## 准备材料与变量

图1：已验收4:5商品成图，唯一编辑底图；用文字指定目标背景和分区即可。图2同SKU原始照片可选，只核对身份、轮廓和标签；图3背景参考可选，只负责布景，不带入其商品。透明／镜面变体须人工指出可改的透射或反射区，可用文字或遮罩，不由模型猜分区。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{目标背景}}` | 浅灰石材台面与暖白墙面，无新增道具 |
| `{{保护区}}` | 不透明商品实体、外轮廓形状、标签、缝线与手柄 |
| `{{允许变化}}` | 商品外背景、轮廓外紧邻旧背景残边和商品外侧接触阴影 |
| `{{保留项}}` | 商品身份、原比例、视角、位置、占比、材质颜色、标志文字和配件数量 |
| `{{光学编辑区}}` | 透明瓶身标签外左右两块透射区、玻璃轮廓外侧旧背景残边、瓶盖右侧人工圈定反射带 |
| `{{光学保留项}}` | 瓶型、玻璃厚度轮廓、液位、标签逐字内容、木质瓶盖材质、瓶底接触位置 |

## 拿来就用的具体示例

基础示例只需一张不透明帆布包成图及上述背景说明；原商品照和背景图均可选。若换成透明香水瓶或镜面物件，先人工圈定透射／反射编辑区，再使用光学适配变体；未批准区域不推测隐藏结构。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
以图1已验收米白帆布手提包成图为唯一底图，输出一张4:5图片；没有图2或图3，不虚构额外参考。只把包外背景改成浅灰石材台面与暖白墙面，无新增道具。手提包身份、外轮廓、比例、视角、位置、占比、帆布颜色、缝线、两条手柄和正面原标志文字不变。清理包轮廓外紧邻的旧背景残边，但不侵蚀帆布边缘，也不保留固定3%的旧背景光圈。新背景透视与原落地角度兼容；只在包外调整接触阴影，不悬浮、不把包整体染成暖白。不新增文案、配件或第二个包，只输出一张。
```


## 完整提示词

```text
以图1为唯一编辑底图，本轮只把背景替换为{{目标背景}}，输出一张4:5成品。本基础版用于不透明商品：先保持{{保留项}}，保护{{保护区}}，不改变商品朝向、结构或表面纹理。编辑范围只限{{允许变化}}；清理轮廓外的旧背景残边，不向外留固定宽度的旧背景保护圈，不侵蚀商品实体。图2若提供，只核对同SKU身份；图3若提供，只取背景透视、材质与布景，不复制它的物件。新背景光向和透视应兼容原商品，主体不随背景统一调色。接触阴影只在商品外侧调整，保持原落地位置，不悬浮、不陷入台面。不新增文字、道具、配件或第二件商品。若图1存在需要随背景变化的透射或镜面反射，本基础版不同时要求其保留旧背景内容；改用光学适配变体并明确人工编辑区。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

保护商品外观不等于像素级冻结。透明透射或镜面反射若必须跟随新背景改变，应明确局部编辑范围；若必须完全保留商品原像素，请用抠图合成而非同时要求生成式换景。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 透明与镜面商品局部光学适配 · optical-region-edit

```text
以图1已验收透明或镜面商品成图为唯一底图，将商品外背景改为{{目标背景}}，只输出一张4:5成品。保持商品原位置、视角与占比，并保留{{光学保留项}}。商品内部只允许在人工指定的{{光学编辑区}}调整透射背景色和反射内容，使其与新背景光向及透视协调；保留原高光层次，不把透明材质涂成不透明色块、不凭空加亮斑。标签、未批准编辑的实体表面与未圈定反射区不重绘；不从新背景推测商品遮挡后的结构或增加内部物件。清理轮廓外旧背景残边，不侵蚀商品外轮廓或保留固定宽度旧背景圈；接触阴影只在商品外侧调整，原接触位置不变。图2若提供，只核对同SKU结构与标签；图3若提供，只提供目标背景，不带入商品。人工文字分区不清楚时先明确边界，不能自动扩大到整个商品。不要同时要求可编辑透射区保留旧背景像素，不新增文字、道具、配件或第二件商品，不生成对比拼贴。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

```text
以上一轮结果为底图，重新附原图1。本轮只修正{{人工指定区域}}的{{旧背景残边、透射背景色、反射穿帮或接触阴影}}，不得扩大编辑区；商品身份、轮廓、标签和其余已验收区域不变。
```
