# EC17 · 产品结构爆炸示意

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · 电商来源改写**

依据部件资料展示结构，缺少资料时只做明确概念图。

## 准备材料与变量

图1：可拆卸收纳盒完整照；图2：盒盖；图3：可取出的隔板；图4：盒体。必须确有这三个可分离部件。 其他商品按相同图片分工准备素材，并填写下方变量。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 填写商品名称、材质、颜色、规格与实际可见特征；不要填未经核实的功效 |
| `{{部件清单}}` | 由上到下填写真实部件名称、对应参考图和顺序；概念设计需写明概念 |
| `{{装配轴}}` | 按真实结构填写水平、垂直或其他有资料支持的装配方向 |

## 拿来就用的具体示例

图1：可拆卸收纳盒完整照；图2：盒盖；图3：可取出的隔板；图4：盒体。必须确有这三个可分离部件。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图2起是部件或结构资料。按由上到下：盒盖对应图2、隔板对应图3、盒体对应图4，各一件制作产品爆炸示意，部件沿垂直方向，盒盖在最上、隔板在中间、盒体在下分离，顺序与资料一致，间距足以看清。每个部件只出现一次，用细引线标注所给名称。浅灰背景、轻柔阴影，外壳若已在部件清单中，仅在其装配顺序位置出现一次；不要另放完整商品或复制外壳。没有内部资料时不得从外观推断真实结构，只能按用户提供的概念清单绘制并在底部写“概念结构示意”。
```


## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

 先确认“具体示例”的素材条件再复制；商品、尺寸或文案不一致时选“变量模板”。示例文字只用于说明填写方法。
