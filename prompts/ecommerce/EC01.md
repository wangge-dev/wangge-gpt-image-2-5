# EC01 · 白底与纯色商品主图

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品展示 · 电商来源改写**

让商品轮廓和真实材质在搜索列表中清楚可见。

## 准备材料与变量

先按正文的图1、图2等编号上传对应素材。涉及部件、内衬、背面、数据或人物时，补齐相应来源；没有素材不要让模型猜。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 填写商品名称、材质、颜色、规格与实际可见特征；不要填未经核实的功效 |

## 拿来就用的具体示例

上传一张真实保温杯的完整正面照；示例保持照片本身的材质、颜色与结构，不要求另填商品参数。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
使用上传的保温杯正面照片，制作一张方形白底商品主图。保持杯型、杯盖、杯身颜色、表面材质与原有文字，单件杯子正面居中，完整展示，约占画面高度75%。背景纯白，底部保留轻柔接触阴影，不加道具、广告字或未提供的配件。输出一张图片。
```


## 完整提示词

```text
图1是实际商品参考。商品信息：{{商品信息}}。保留图1中的外形比例、结构、颜色、材质、包装图案和可辨认的品牌文字；布景反光可以变化，但不要重新设计商品。只呈现参考图或资料中有依据的商品细节，不补造配件和性能。

制作一张电商商品主图。单件商品正面居中，约占画面高度75%，四周完整留边，底部保留轻柔接触阴影。背景纯白且没有地平线，采用大面积柔光，亮面有层次不过曝，包装文字清楚。不要道具，不要额外广告字。

只输出一张完成的图像。没有要求新增的文字、徽章和水印不要添加。
```

## 参数设置

建议画布：`1024x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。
