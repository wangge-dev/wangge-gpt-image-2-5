# EC12 · 超现实商品创意广告

[全部提示词](../README.md) · [首页](../../README.md)

**分类：营销素材 · 电商来源改写**

用一个明确的空间机制制作商品商业创意，先锁商品占比、背景层和文案留白；纸艺、悬停或不可能几何只作用于布景。

## 准备材料与变量

图1必需：单件商品完整原照，身份、原角度和可见材质唯一依据。细节近照可选，只核对原照已可见标签。创意文字必需：只写布景的空间机制；品牌色板或布景参考可选，只负责背景，不传递其中产品、文案或配件。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 香水瓶，以实际原照中的瓶盖、瓶身、颜色和标签为准 |
| `{{创意}}` | 商品站在米白弧形纸艺谷底，浅绿纸张从两侧向后卷起；纸张不连接瓶体，不遮标签 |
| `{{主体占比}}` | 商品外接框高度约48%，宽度按原比例联动，正面标签完整可见 |
| `{{留白}}` | 顶部24%为干净文案留白，本轮不生成任何新增文字；四周至少6%安全边距 |
| `{{布景配色}}` | 米白和浅绿，仅作用于布景，不改变商品本色 |

## 拿来就用的具体示例

仅上传一张完整清晰的香水瓶原照；不需要纸艺实拍。正文把纸艺明确作为原创布景设计，不作为配方或产品事实。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作一张4:5香水商业创意广告。图1为唯一商品参考，沿用原角度、瓶盖、瓶身比例、本色、材质和清楚可见的标签；不可辨认的字不猜写，背面不补造。商品站在画面中央偏下，完整外接框高度约48%，宽度按原比例联动，标签完整朝向原照方向；顶部24%保留干净文案空间但本轮不生成文字，四周至少6%安全边距。米白弧形纸艺谷底承托商品，浅绿纸张只从左右向后卷起，位置在瓶体两侧和后方，不连接瓶体，不越过瓶盖或遮挡标签。商品底部有接触阴影，纸张各自有一致的后方投影；左上柔光，右侧弱补光，背景米白和浅绿不染商品本色。画面只使用这一种纸艺空间机制，不加水花、烟雾、花果或第二只香水。纸张是原创广告布景，不表示真实配方或香调；不新增功效、文字、认证和水印。只输出一张完成广告。
```


## 完整提示词

```text
制作一张4:5单商品商业创意广告。图1是{{商品信息}}的身份唯一依据，沿用原拍摄角度、比例、瓶盖/结构、颜色、可见材质和原标签，不改成另一款商品，不补隐藏面、内部组件或猜写不清晰的标识。商品位于画面中央偏下，{{主体占比}}，完整轮廓不裁切；{{留白}}。主次顺序为商品→单一布景机制→安静背景，不能让特效成为更大的视觉主体。

创意机制为{{创意}}，配色为{{布景配色}}。幻想仅作用于布景，布景位于商品两侧和后方，不覆盖瓶盖、标签或底部轮廓，不与商品长成一体；接触、前后遮挡与阴影关系必须明确，不用多个无关特效堆叠。采用左上柔光和右侧弱补光，保留商品材质的可见依据；背景反光可以配合环境，但不能把布景颜色当成商品固有色。

纸艺、液体、几何和悬停只表达广告隐喻，不代表配方、香调、原料、承重、防水或其他性能。没有原料证据不加入花果粉体，也不把产品放入液体暗示使用。不给商品加文字、证书、功效、第二件商品、新配件或水印。只输出一张完成创意广告，不输出分镜、对比拼版或设计过程。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

无文案的单张创意成片；预留区域可由设计工具后排文字。配方、成分和性能不可从布景反推；商业创意不替代真实商品拍摄或检测。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 飞溅动态效果 · splash-dynamic

```text
制作一张4:5单商品商业创意广告。图1为{{商品信息}}的唯一身份依据，沿用原拍摄角度、比例、结构、本色、材质和可见标识，不补背面或内部，不猜不清晰的字。商品中央偏下，{{主体占比}}；{{留白}}；采用{{布景配色}}，主题色仅用于背景。商品→单一布景机制→安静背景的主次明确，不新增文字、功效、认证、新配件、第二件商品或水印。

唯一机制是透明水花在商品左右两侧悬停。水花弧线从外侧下方向两侧上方绕行，始终处于瓶体侧后方，不盖瓶盖、正面标签或顶部文案留白，不穿过实物；瓶体置于干燥简洁底面而非泡在水里。液体单独反射左上柔光，商品保留原材质与干燥状态。不要粉体爆炸、烟雾或花果。水花仅为广告布景，不宣称防水、耐浸、清洁或配方。只输出一张完成广告。
```

### 超现实概念 · surreal

```text
制作一张4:5单商品商业创意广告。图1为{{商品信息}}的唯一身份依据，沿用原拍摄角度、比例、结构、本色、材质和可见标识，不补背面或内部，不猜不清晰的字。商品中央偏下，{{主体占比}}；{{留白}}；采用{{布景配色}}，主题色仅用于背景。商品→单一布景机制→安静背景的主次明确，不新增文字、功效、认证、新配件、第二件商品或水印。

唯一机制是商品悬停于两段倒置阶梯之间，阶梯位于瓶体左右侧后方，瓶身与阶梯之间留明显空气间隔，商品自身保持刚性真实形态，不折弯、复制或无限递归。顶部留白不放阶梯；标签和底部轮廓完整可见，左上柔光、背景方向阴影一致，不制造商品接触阶梯的假接点。超现实重力只属于原创广告空间，不表示产品能悬浮或改变现实。不要水花、烟雾、花果或其他特效。只输出一张完成广告。
```

### 极简艺术风格 · minimal-art

```text
制作一张4:5单商品商业创意广告。图1为{{商品信息}}的唯一身份依据，沿用原拍摄角度、比例、结构、本色、材质和可见标识，不补背面或内部，不猜不清晰的字。商品中央偏下，{{主体占比}}；{{留白}}；采用{{布景配色}}，主题色仅用于背景。商品→单一布景机制→安静背景的主次明确，不新增文字、功效、认证、新配件、第二件商品或水印。

唯一机制是左后方一个哑光圆环雕塑与右前方商品的前后对照，雕塑视觉高度不超过商品高度三分之二，不套住瓶颈、不穿过瓶身或遮标签，二者分别接触同一简洁底面并有独立阴影。圆环与背景只用所填布景配色中的两个颜色，左上柔光、短而柔和接触阴影。顶部文案留白保持安静，不添飞溅、烟雾、漂浮颗粒或多雕塑。雕塑不是配件或赠品，不外推任何功能。只输出一张完成广告。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以本轮创意成片为底图，重附图1商品原照。本轮只修改商品周围的{{单一布景元素}}到{{准确位置及前后关系}}，避开标签、瓶盖、主体轮廓和文案留白；商品角度、比例、本色、材质、包装内容及其他布景不变。若商品已漂移，先回到批准底图另开商品身份返工，不在布景轮次顺手重画。只输出一张修改稿。
```
