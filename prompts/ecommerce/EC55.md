# EC55 · 食品包装三证据区：白底、配料语境与成品场景

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · GPT Image 2.5 社区案例改写**

把同一食品包装依次放入白底识别、真实配料语境和成品食用场景，用一张详情图讲清包装、原料与食用结果的关系。

## 准备材料与变量

图1：商品包装正面和侧面；图2：人工确认的真实配料；图3：按真实食用方式制作的成品；图4：批准标题与短标签。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品}}` | 燕麦坚果冲饮袋 |
| `{{三证据区}}` | 上区白底包装；中区包装与燕麦、杏仁原料；下区包装与一碗按图3制作的冲饮成品 |
| `{{标题}}` | 从包装到这一碗 |
| `{{短标签}}` | 包装正面、真实配料、冲调示意 |

## 拿来就用的具体示例

包装、配料和成品必须来自同一SKU及真实制作资料；配料未经确认时删除中区具体原料，不依据包装插画推断。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
为燕麦坚果冲饮袋制作4:5三段详情图：上区白底完整包装；中区包装两侧只放图2确认的燕麦和杏仁；下区同一包装旁放图3对应的一碗冲饮。标题“从包装到这一碗”，短标签“包装正面 / 真实配料 / 冲调示意”。包装标签、封边和配色保持一致，不加水果、蛋白质数字、低脂或饱腹宣称。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作4:5电商详情图，按上中下三段展示同一{{商品}}。上区30%为白底包装识别，包装正面完整、标签逐字以图1为准；中区32%展示包装与图2确认的配料，配料只放两侧，不遮挡商品；下区38%展示同一包装与图3成品，餐具、稠度和份量只按参考。三段的包装尺寸可随版式调整，但袋型、颜色、封边、标签和商品身份一致。标题只写“{{标题}}”，三段短标签依次写“{{短标签}}”。不得增加未提供的水果、坚果、营养数字、产地、功效、口味或冲调步骤，不把场景示意写成实物证明。只输出一张图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

三证据区是详情页叙事结构，不证明配方含量、营养、功效或冲调结果；标签与配料仍需人工核对。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
