# EC54 · 数码主机、屏幕截图与配件清单一页对应

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · 本库原创设计**

把数码商品本体、已校对屏幕内容、真实配件和人工清单放在同一张详情图里，避免把概念样机当成销售套装或凭外观补写参数。

## 拿来就用的具体示例

主机、屏幕截图、全部配件同框照和人工清单必须来自同一销售套装；截图需先人工校对文字与图标。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
制作4:5便携投影仪详情图。上部60%展示银灰色主机，保留镜头、散热孔、HDMI口、USB-C口和标志；面板只按图2显示首页画面和三枚已确认图标。下部40%只展示主机1台、电源适配器1个、遥控器1个、HDMI线1条、说明书1本，各一次并分别标注。标题只写“主机、屏幕与盒内配件”。不加电池、支架、收纳包、分辨率、亮度或投影效果。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作4:5电商详情说明图。上部60%展示图1主机三分之四正面，保持机身比例、镜头、散热孔、接口和标志；屏幕或面板区域只按图2呈现{{屏幕状态}}，不凭空增加菜单、分辨率或数值。下部40%严格按图3和{{配件清单}}逐件展示，每件只出现一次并用人工短标签对应；图4只负责文字和数量。标题只写“{{标题}}”，各标签只出现一次。不得添加未提供的遥控器、电池、支架、收纳包、投影画面或性能参数，不把示意界面当成真实设备功能。只输出一张图。
```

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。
