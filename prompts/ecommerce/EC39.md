# EC39 · 中文包装正背面校对图

[全部提示词](../README.md) · [首页](../../README.md)

**分类：包装 · 本库原创设计**

把包装正背面实拍与已确认文字整理成校对图，不让模型重写整套包装。

## 准备材料与变量

图1：包装正面正对照；图2：包装背面正对照；图3、图4：正背面文字设计稿或高清近照；另给出最多四处需核对的位置和准确文字。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品名称}}` | 燕麦坚果棒 |
| `{{校对项}}` | 正面品名、净含量；背面配料标题、储存方式 |
| `{{准确文字}}` | 品名：每日燕麦坚果棒；净含量：210克；配料；储存方式：置于阴凉干燥处 |
| `{{标题}}` | 包装文字校对 |

## 拿来就用的具体示例

准备包装正背面正对照和对应文字设计稿；示例四项必须经人工校对后使用。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
依据图1至图4制作4:5“包装文字校对”图，商品为燕麦坚果棒。左侧图1正面，右侧图2背面，保持包装袋型、封边、颜色、图案、条码位置和原排版。只框选四处：正面品名、净含量，背面“配料”标题、储存方式。下方逐字列出“品名：每日燕麦坚果棒”“净含量：210克”“配料”“储存方式：置于阴凉干燥处”。不补写配料内容、营养数值、保质期、认证、厂家、地址或条码数字。只输出一张图。
```


## 完整提示词

```text
依据图1至图4制作一张4:5“{{标题}}”校对图，商品为{{商品名称}}。左侧展示图1正面，右侧展示图2背面，包装轮廓、封边、颜色、图案、条码位置和原有文字排版保持，不生成新的包装设计。只对{{校对项}}设置四个以内编号框，并在下方校对栏逐字列出：{{准确文字}}。图3、图4只负责核对字符、字重和对应区域，不覆盖整面包装。校对栏与包装图分离，深灰字、浅色底、细引线，不遮挡原图。不要补写配料内容、营养数值、保质期、认证、厂家、地址或条码数字；未提供的文字保持原图可见状态，不猜测。只输出一张校对图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡用于视觉校对和沟通，不代替法规审核、印前文件或OCR逐字校验。需要真正改包装时，应按EC30逐处局部修改并复核。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

