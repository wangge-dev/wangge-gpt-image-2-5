# EC16 · 参考图试穿与场景融入

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品展示 · 电商来源改写**

将服装穿到人物身上，或把家居商品放进既有空间。

## 准备材料与变量

图1：与模特尺码匹配的白色短袖T恤正面照；图2：获准使用的成年模特正面照，肩部与上身无遮挡。 其他商品按相同图片分工准备素材，并填写下方变量。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 填写商品名称、材质、颜色、规格与实际可见特征；不要填未经核实的功效 |
| `{{模式}}` | 试穿，或空间融入，二选一 |
| `{{尺寸与位置}}` | 试穿填衣物尺码与覆盖部位；家居填实际长宽高和摆放位置 |

## 拿来就用的具体示例

图1：与模特尺码匹配的白色短袖T恤正面照；图2：获准使用的成年模特正面照，肩部与上身无遮挡。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1是实际商品参考。商品信息：以所附实际照片为准，保留原有外形、颜色、结构、材质和标签；未提供的规格与性能不添加。保留图1中的外形比例、结构、颜色、材质、包装图案和可辨认的品牌文字；布景反光可以变化，但不要重新设计商品。只呈现参考图或资料中有依据的商品细节，不补造配件和性能。

图2为目标人物或空间照片。任务模式为试穿。若为试穿：保持图2人物身份、姿态、体型和环境，只将相应衣物换成图1商品，按真实衣物结构形成自然褶皱。若为空间融入：保持图2机位、墙面和家具布局，将图1商品放在指定位置，按上衣尺码须与模特匹配；只替换上身衣物，领口、袖长和下摆依图1处理尺度与遮挡。只执行所选模式，不同时生成人物与空间两套结果。

只输出一张完成的图像。没有要求新增的文字、徽章和水印不要添加。
```

## 参数设置

建议画布：`1024x1536`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

 先确认“具体示例”的素材条件再复制；商品、尺寸或文案不一致时选“变量模板”。示例文字只用于说明填写方法。
