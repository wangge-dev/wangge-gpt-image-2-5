# EC16 · 参考图试穿与场景融入

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品展示 · 电商来源改写 · 按 2.5 文档适配，未生图实测**

将服装穿到人物身上，或把家居商品放进既有空间。

## 准备材料与变量

先按正文的图1、图2等编号上传对应素材。涉及部件、内衬、背面、数据或人物时，补齐相应来源；没有素材不要让模型猜。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 填写商品名称、材质、颜色、规格与实际可见特征；不要填未经核实的功效 |
| `{{模式}}` | 试穿，或空间融入，二选一 |
| `{{尺寸与位置}}` | 试穿填衣物尺码与覆盖部位；家居填实际长宽高和摆放位置 |

## 完整提示词

```text
图1是实际商品参考。商品信息：{{商品信息}}。保留图1中的外形比例、结构、颜色、材质、包装图案和可辨认的品牌文字；布景反光可以变化，但不要重新设计商品。只呈现参考图或资料中有依据的商品细节，不补造配件和性能。

图2为目标人物或空间照片。任务模式为{{模式}}。若为试穿：保持图2人物身份、姿态、体型和环境，只将相应衣物换成图1商品，按真实衣物结构形成自然褶皱。若为空间融入：保持图2机位、墙面和家具布局，将图1商品放在指定位置，按{{尺寸与位置}}处理尺度与遮挡。只执行所选模式，不同时生成人物与空间两套结果。

只输出一张完成的图像。没有要求新增的文字、徽章和水印不要添加。
```

## 参数设置

建议画布：`1024x1536`；模型选择及格式见[模型说明](../../guides/models.md)。这是本库的起步建议，不是效果保证。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以刚生成的图为编辑底图。只修正与原始参考不一致的商品外观、标签或图文对应错误，依据重新上传的原始素材恢复。保持已确认的构图、背景、光线和其他准确文字。不要借修正重新设计整张图。
```
