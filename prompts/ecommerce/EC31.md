# EC31 · 中文长详情页单模块系列

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · 本库原创设计**

将长详情页拆成一轮一个成品模块；首张可用商品图与文字规则启动，后续始终继承同一批准母版。

## 准备材料与变量

图1：商品完整可见视角照，必需。标签近照和固定已验收系列母版均可选；按实际上传顺序编号，在标签参考状态／视觉母版状态中写清实际图号，未提供项不占空编号。母版只管视觉规则，不自动换成最近一张。文字提供本页标题／说明、品牌配色、版式与事实。细节变体必须另附同SKU真实近照并填写实际图号及部位；只有图1加近照时，近照就是图2，不虚构图3／图4。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

## 拿来就用的具体示例

首张示例只上传一张橙色折叠水杯完整正面照并批准上述短文和文字规则；近照及母版都不是首张必需。后续附同一张固定批准母版，不用最新结果自动覆盖。示例文字、状态与商品可见事实不符时改变量，细节模块必须补对应近照。 如首张只附商品图和细节近照，近照填写为图2，标签近照与母版状态都写未提供。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
只上传图1橙色折叠水杯完整正面照，当前状态为首张，无图2标签近照、无图3母版，不虚构额外参考。只生成“首屏主视觉”一张4:5平面成品。保留图1实际折叠纹路、杯盖、原比例、颜色和可辨原字，不展现未提供的展开或背面。四边向内8%留安全边距，标题左上逐字写“轻装随行”，其下说明只写“折叠结构以商品实拍为准”，各一次；商品右下，高度最多占可用区60%，只等比例缩放。米白背景、深灰文字、少量橙色点缀，不给杯身改色。柔和侧光和短接触阴影。说明只是练习短文，不新增吸管、挂绳、容量、耐温、食品级认证、价格或赠品。只输出本模块，不拼长图；人工验收后可把本张批准为系列母版。
```


## 完整提示词

```text
图1只定义当前SKU的可见外形、视角、结构、比例、颜色与材质。标签参考状态为{{标签参考状态}}：只有实际指定的同SKU标签近照才辅助核对原字，不生成第二件商品；未提供就只保留图1可辨字，不猜模糊字，不调用其他图片代替标签。视觉母版状态为{{视觉母版状态}}：首张没有母版时只用下面的文字规则；提供母版时只沿用该实际图号对应的人工批准固定母版的字体层级、留白与配色，不沿用其旧商品、旧卖点或旧文字。按实际上传序号分工，不虚构缺失图片；上一轮结果不自动升级为母版。

本轮只生成“{{本轮模块}}”模块。先锁{{版式锚点}}，阅读顺序为标题、说明、商品；长文字不要挤压商品或缩成不可读小字，先用人工批准短文或在排版工具补齐。品牌配色为{{品牌配色}}，只用于背景和画外文字，不给商品改色。标题只写“{{模块标题}}”，说明只写“{{模块说明}}”，非空项各一次。主体完整可见、只整体等比例缩放，背景简洁，柔和侧光和短接触阴影。

本轮事实只按{{本页证据}}，不从包装、上一模块或常识补容量、尺寸、内部结构、耐温、功效、认证、售价或赠品。没有证据的模块不能生成想象细节，应回到可见外观首屏或补素材；没有批准说明时直接省略，不上屏“暂无”或变量名。保持原包装字与商品身份，不能把画外短文印到包装上。只输出当前模块的一张4:5平面成品，不生成整条长图、其他模块、书本样机或拼贴；生成后人工验收，再在排版工具组装。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

首张只需图1及文字规则；后续共同母版与本页事实分开，母版不提供商品事实。细节模块需要真实近照，微距放大不能证明材质或性能。单模块验收后再人工排成长图，不保证跨图像素级一致。

## 可复制变体

选择一个版本，替换变量后整段复制；每段已包含基础要求。

### 细节证据模块 · evidence-detail

```text
图1只定义当前SKU的可见外形、视角、结构、比例、颜色与材质。标签参考状态为{{标签参考状态}}：只有实际指定的同SKU标签近照才辅助核对原字，不生成第二件商品；未提供就只保留图1可辨字，不猜模糊字，不调用其他图片代替标签。视觉母版状态为{{视觉母版状态}}：首张没有母版时只用下面的文字规则；提供母版时只沿用该实际图号对应的人工批准固定母版的字体层级、留白与配色，不沿用其旧商品、旧卖点或旧文字。按实际上传序号分工，不虚构缺失图片；上一轮结果不自动升级为母版。

本轮只输出一张同系列4:5细节成品，真实细节来自{{细节参考图号}}，只对应图1商品的{{细节位置}}；近照只负责纹理、接缝和颜色，不提供另一款商品、背景或新卖点。没有这张近照就不生成微观结构，回到基础首屏或先补素材。布局严格为{{细节布局}}，品牌配色为{{品牌配色}}；先读左上标题“{{细节标题}}”和说明“{{细节说明}}”，再看真实细节主区，最后看商品定位小图。两处画外短文各一次。定位小图保留图1完整原视角，只整体等比例缩小；细节图仅作同一SKU部位放大，不把它算成第二件商品、第二个配件或新的展开状态。保持近照的真实纹理尺度及光泽，不自动增粗缝线、加厚壁体或补背面；定位关系只依据人工指定部位，不让模型推断隐藏位置。

本轮事实只限图1的可见外观及上述真实细节近照，不从包装、上一模块或常识补容量、尺寸、内部结构、耐温、功效、认证、售价或赠品。没有证据的模块不能生成想象细节，应回到可见外观首屏或补素材；没有批准说明时直接省略，不上屏“暂无”或变量名。保持原包装字与商品身份，不能把画外短文印到包装上。只输出当前模块的一张4:5平面成品，不生成整条长图、其他模块、书本样机或拼贴；生成后人工验收，再在排版工具组装。
```

修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。

## 接着修改

上传上一轮结果；涉及商品或人物时，同时保留原始参考图。

```text
以上一轮当前模块为底图，重新附商品图1及实际需要的原始证据。本轮只修正{{指定区域}}的{{指定问题}}，恢复为批准的{{准确内容}}；保持固定母版的字体／配色／留白和其他本页文字，不继承旧模块卖点。修细节时只依据对应近照，不顺手优化纹理或生成未知结构。
```
