# EC31 · 中文长详情页单模块系列

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品解释 · 本库原创设计**

把长详情页拆成逐张生成的独立模块，并在多张图之间保持同一商品与品牌系统。

## 准备材料与变量

图1：商品正面完整照；图2：标签或包装文字近照；图3：本系列已通过验收的上一张模块图（首张不需要）；另提供本轮模块所需的真实细节、尺寸、结构或场景照片。一次只做一个模块。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{本轮模块}}` | 首屏主视觉 |
| `{{模块标题}}` | 轻装随行 |
| `{{模块说明}}` | 一行不超过18个汉字的已确认说明 |
| `{{品牌配色}}` | 米白、深灰、橙色点缀 |
| `{{版式锚点}}` | 标题左上，商品右下，四周保留8%安全边距 |

## 拿来就用的具体示例

准备同一折叠水杯正面照、包装文字近照；如不是首张，再附上一张已通过模块。示例文字和结构必须与商品一致。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1和图2定义同一款橙色折叠水杯的外形、折叠层数、杯盖、硅胶颜色和包装文字；图3用于继承上一张已通过模块的米白、深灰、橙色配色与左上标题节奏。本轮只生成“首屏主视觉”一张4:5图片，不拼成长图。标题只写“轻装随行”，说明只写“折叠结构以商品实拍为准”。商品位于右下，四周保留8%安全边距，柔和侧光和浅色背景。不得增加吸管、挂绳、容量、耐温、食品级认证、价格或赠品。只输出一张图。
```


## 完整提示词

```text
图1和图2定义同一SKU的外形、结构、颜色、材质、标签与包装文字；图3只用于继承已经通过验收的品牌配色、字体气质、留白和版式节奏。本轮只生成长详情页中的“{{本轮模块}}”一张4:5图片，不拼接整条长图。标题逐字为“{{模块标题}}”，说明逐字为“{{模块说明}}”，除此之外不新增画外文字。采用{{品牌配色}}，固定{{版式锚点}}。商品保持与图1相同的比例、部件、标志和可见文字；本轮模块需要的事实只使用额外提供的对应照片或资料。不要从上一张模块复制旧卖点，不补造尺寸、结构、功效、认证、价格或赠品。只输出当前模块一张图。
```

## 参数设置

建议画布：`1536x1920`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

首屏、卖点、材质、尺寸、结构、场景、包装和收尾应分别生成；每张单独验收后再排成长详情页。生成式模型不保证多张图片像素级一致。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
