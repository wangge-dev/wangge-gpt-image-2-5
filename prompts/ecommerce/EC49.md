# EC49 · 搜索列表主图主体占比与缩略图可读性

[全部提示词](../README.md) · [首页](../../README.md)

**分类：商品主图 · 本库原创设计**

在方形搜索缩略图里锁定单件商品的占比、完整轮廓和视觉中心，避免主体过小或被角标安全区遮挡。

## 准备材料与变量

图1：单件商品正面完整照；图2：同一SKU标签或关键识别细节近照；另提供平台真实角标占位截图或人工标出的安全区。

将下表中的值按实际任务填写，然后复制正文。示例值用于说明填写方式，不是已核实的商品事实。

| 变量 | 填写示例或说明 |
| --- | --- |
| `{{商品信息}}` | 米白色双提手帆布包，顶部敞口 |
| `{{主体占比}}` | 商品外接框占画布宽度72%、高度78% |
| `{{安全区}}` | 右上12%与左下10%保持纯背景 |
| `{{背景}}` | 纯白无地平线 |

## 拿来就用的具体示例

上传同一帆布包正面照和提手近照，并提供平台角标位置；不知道平台安全区时先用变量模板，不凭经验猜。

按示例准备对应素材后，直接复制下段；其他商品使用后面的变量模板。

```text
图1为米白色双提手帆布包，图2为提手缝线近照。制作1:1搜索主图，包体外接框占画布宽72%、高78%，正面居中，完整保留双提手、敞口、侧边和包底；右上12%与左下10%纯白留空。不要角标、文字、道具、额外肩带或第二只包。只输出一张图。
```


## 完整提示词

```text
图1定义{{商品信息}}的轮廓、结构、颜色和材质，图2只核对关键识别细节。制作1:1搜索列表主图，{{主体占比}}，商品正面居中并完整留边，底部只有轻柔接触阴影。背景为{{背景}}，严格保持{{安全区}}，安全区内不放商品、投影、文字或道具。不得裁掉提手、底边和侧缘，不复制商品，不增加角标、价格、销量、赠品或平台标志。缩小到120像素预览时仍能一眼看清商品轮廓。只输出一张图。
```

## 参数设置

建议画布：`1024x1024`；模型选择及格式见[模型说明](../../guides/models.md)。网页版可按相同比例描述画布。

本卡只预留平台覆盖区域，不生成平台角标；平台规格应以发布时真实后台要求为准。


修改前，将修改指令中的双花括号内容按实际问题填写；每次只处理一个位置。
