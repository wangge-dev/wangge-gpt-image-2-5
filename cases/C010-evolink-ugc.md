# C010 · 护肤品人物持用推广图

[一品三用专题](../ecommerce/evolink-product-story.md) · [来源提示词](README.md)

## 准备材料

上传清晰的白底护肤品图。模板中的市场、语言和文案由你提供；具体示例不加营销文案，人物为虚构成年创作者。

## 拿来就用的具体示例

```text
以上传的白底护肤品照片为商品依据，生成一张面向中文社交内容的自然持用展示图。一位虚构成年创作者在明亮的居家梳妆台旁拿着同一件商品，手机随拍构图，自然窗光，动作放松。保持包装颜色、比例、标志和标签一致；手指不挡住正面标签，握持与商品大小可信。不要添加画外文字、评价、星级、认证或功效说明，不表现使用前后效果。输出一张竖版图片。
```

## 完整中文提示词

```text
以图1白底商品照为唯一商品依据，为{{目标市场}}制作一张护肤品人物持用推广图。虚构成年创作者自然拿着商品，环境为{{日常场景}}；手机随拍构图与自然光，商品可辨认。保持实际包装、颜色、比例、标志与标签，手部握持自然且不遮挡关键标签。画外文案只使用{{语言}}的“{{已确认文案}}”；填“无”时不添加画外文字。不得编造用户评价、认证、功效或成分，不把虚构人物表现成真实客户的体验见证。输出一张独立图片。
```

目标市场：中文社交平台；日常场景：居家梳妆台；语言：简体中文；已确认文案：无，或自行提供可用短句。

## 接着修改

上传上一轮结果，并保留原商品参考；每次只改一个问题。

