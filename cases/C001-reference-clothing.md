# C001 · 参考衣物换装

[来源明确的提示词](README.md) · [首页](../README.md)

## 准备材料

图1：人物全身照；图2：外套；图3：内搭；图4：鞋子。服装与鞋子的款式需清楚可见。

本卡首轮正文无需填写变量；按上述要求上传图片即可直接复制。后续修改时再填写具体问题。

## 完整中文提示词

```text
为图1人物换装：外套用图2、内搭用图3、鞋子用图4。款式、图案和颜色各依对应参考，自然贴合身体。人物脸、发型、体型、姿态、未指定衣物和背景保持；不加配饰或文字。输出一张完整换装照片。
```

## 接着修改

上传上一轮结果，涉及参考图的任务同时保留原图；每次只发一条修改指令。

```text
只修正{{衣物或鞋子}}的{{具体部位}}，按图{{参考编号}}恢复{{款式细节}}，保留其他穿搭、人物与背景。
```

## 使用提示

重点看外套领口与袖口、内搭图案、鞋型是否分别对应参考图。

画布沿用输入图比例；模型与可用设置见[模型说明](../guides/models.md)。
