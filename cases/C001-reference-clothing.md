# C001 · 参考衣物换装

[来源明确的提示词](README.md) · [首页](../README.md)

## 准备材料

图1：人物全身或半身照；图2：要替换的上衣，正面款式清楚。

将双花括号内容换成自己的信息，然后整段复制。

## 完整中文提示词

```text
把图1人物的上衣换成图2款式。衣领、袖口、图案依图2，服装自然贴合身体。人物脸、发型、体型、姿态、其他衣物和背景依图1保持。只输出一张换装照片，不加配饰或文字。
```

## 接着修改

上传上一轮结果，涉及参考图的任务同时保留原图；每次只发一条修改指令。

```text
只修正上衣的{{具体部位}}，按图2恢复{{款式细节}}，保留本轮人物与背景。
```

## 使用提示

重点看领口、袖口、图案是否与衣物参考对应。

画布沿用输入图比例；模型与可用设置见[模型说明](../guides/models.md)。
