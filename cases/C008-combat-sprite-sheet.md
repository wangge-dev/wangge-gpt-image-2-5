# C008 · 同一角色的16帧战斗精灵图

[来源提示词](README.md) · [首页](../README.md)

## 准备材料

上传一张完整角色图，头发、衣服、鞋子与四肢清楚可见，角色不要被裁切。示例使用同一角色和固定侧视方向，制作一张静态动作表。

## 拿来就用的具体示例

```text
将上传角色转成简洁像素画风格的战斗动作精灵图，4列4行，共16格，按从左到右、从上到下排列。
动作依次是：待机、防御、左拳蓄力、左拳伸出、左拳收回、右拳蓄力、右拳伸出、右拳收回、踢腿蓄力、踢腿伸出、踢腿收回、下蹲、前冲蓄力、向前突进、恢复站立、回到待机。
每格只有同一角色，统一朝右的侧视角、相同角色尺度与地面基线。保留参考角色的发型、服装配色、鞋子和配饰，不在不同格换装。四肢完整留在各格内，拳脚伸展时也不能跨格。采用适合小尺寸显示的清晰像素轮廓，不加文字、编号、格线或场景道具。背景透明，输出一张PNG精灵图，不输出GIF。
```

## 完整中文提示词

```text
以图1作为唯一角色外观参考，生成简洁像素画风格的战斗动作精灵图，4列4行，共16格。动作按从左到右、从上到下严格使用以下16项：{{16帧动作清单}}。
所有格子保持同一角色的发型、衣服、鞋子、配饰与配色，使用{{固定视角与朝向}}，统一角色尺度和地面基线。每格一个完整角色，动作连贯，四肢与配件不得伸入相邻格；不为填满画格而改变角色大小。不添加文字、编号、边框或背景物品。采用清晰的小尺寸像素画视觉，透明背景，输出一张PNG静态精灵图。
```

变量：`{{16帧动作清单}}`填写恰好16个按顺序排列的动作或过渡姿势；`{{固定视角与朝向}}`例如“朝右的侧视角”。不要用8个动作名称让模型自行决定如何分配16格。

## 接着修改

重新附角色原图与上一轮精灵图，只发一条：

```text
只修正第{{行}}行第{{列}}列角色的{{具体问题}}，正确要求为{{修正要求}}。保持其他格子、画格大小、角色尺度与地面基线不变，不增加新的动作或格子。
```

## 使用提示

- 这是静态动作表；GIF播放或游戏导入需要后续切图和设置帧时长。
- 原作者的“128px”用来描述小尺寸像素图需求。本模板不把它当API画布设置；需要每帧严格128×128时，生成后检查画格、切分和像素尺寸，不把视觉像素风当成准确分辨率。
- 透明背景要检查下载PNG的实际透明通道，棋盘格图案不等于透明。型号与格式配置见[模型说明](../guides/models.md)。
