# C005 · 在图表留白处添加角色

[来源明确的提示词](README.md) · [首页](../README.md)

## 准备材料

上传一张已有图表，确保留白足够；填写角色位置。

将双花括号内容换成自己的信息，然后整段复制。

## 拿来就用的具体示例

上传右下角有足够空白的图表；该区域不能包含坐标轴、图例、数字或曲线。

```text
在这张图表右下角的空白区域加入一只戴眼镜、穿白大褂的卡通浣熊，它正在认真观察图表。角色完整落在空白区内，不得覆盖坐标轴、折线、图例、数字和标题。保留原始图表内容，不添加新数据或品牌标志。
```

## 完整中文提示词

```text
在这张图表的{{留白位置}}加入一只戴眼镜、穿白大褂的卡通浣熊，它正在认真观察图表。角色不得覆盖坐标轴、折线、图例、数字和标题。保留所有原始图表内容，不添加新的数据或品牌标志。
```

## 接着修改

上传上一轮结果，涉及参考图的任务同时保留原图；每次只发一条修改指令。

```text
仅把浣熊移到{{新位置}}并缩小到{{大小}}，保留图表及其他内容。
```

## 使用提示

需要数据和线条像素完全不变时，单独生成角色后在排版软件叠加到原图；生成式编辑不能保证图表无损。

画布沿用输入图比例；模型与可用设置见[模型说明](../guides/models.md)。
