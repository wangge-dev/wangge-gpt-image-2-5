# C004 · 草图转写实场景

[来源明确的提示词](README.md) · [首页](../README.md)

## 准备材料

上传一张空间或景观线稿，明确已有物体和透视；填写材料与光线。

将双花括号内容换成自己的信息，然后整段复制。

## 拿来就用的具体示例

上传一张包含河流、山体和植被的景观线稿。其他空间或材质使用下面的模板。

```text
把这张河谷景观线稿转成写实场景图。保留河道、山体和植被的位置、比例与透视；河流呈自然水面，山体呈岩石与土壤质感，植物保留线稿中已有分布。使用阴天柔和自然光。草图的注释不作为成品文字，不新增建筑、人物或其他物体。
```

## 完整中文提示词

```text
把这张草图转成写实场景图。保留物体数量、位置、比例和透视，材质使用{{材质}}，光线为{{光线}}。草图的注释不作为成品文字，不添加新的物体。
```

## 接着修改

上传上一轮结果，涉及参考图的任务同时保留原图；每次只发一条修改指令。

```text
只将{{物体}}移回草图中的位置，保留其余布局、材质与光线。
```

## 使用提示

上传草图即可使用；这是图像输入用法，不要求调用Sketch产品入口。

画布沿用输入图比例；模型与可用设置见[模型说明](../guides/models.md)。
