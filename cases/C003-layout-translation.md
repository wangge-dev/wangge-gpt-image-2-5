# C003 · 信息图翻译并保留版式

[来源明确的提示词](README.md) · [首页](../README.md)

## 准备材料

上传一张文字清楚的信息图，填写目标语言。已有专有名词译法时可在发送提示词后附术语表。

将双花括号内容换成自己的信息，然后整段复制。

## 完整中文提示词

```text
把这张信息图中的文字全部翻译成{{目标语言}}。保持原图的图形、数字、颜色、版式和文字层级；译文在原区域内排版，不增删信息，不改变图示关系。只输出翻译后的信息图。
```

## 接着修改

上传上一轮结果，涉及参考图的任务同时保留原图；每次只发一条修改指令。

```text
只把{{文字位置}}的译文修正为“{{准确译文}}”，必要时在原区域调整换行，其他译文、图形和数据不变。
```

## 使用提示

检查是否漏译、误译或文字溢出；专有名词和数据逐项核对。已有准确译文时用下方修改指令修正对应区域。需要另改横竖版时使用跨境适配卡。

画布沿用输入图比例；模型与可用设置见[模型说明](../guides/models.md)。
