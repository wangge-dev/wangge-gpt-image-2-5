# C003 · 保留版式替换语言文案

[来源明确的提示词](README.md) · [首页](../README.md)

## 准备材料

上传一张信息图；准备准确的旧文字和校对后的目标语言文字。每次替换一处，其他处按同样步骤继续。

将双花括号内容换成自己的信息，然后整段复制。

## 完整中文提示词

```text
编辑这张信息图：仅把“{{旧文字}}”替换为“{{目标语言文字}}”，保留所在区域、字体风格和其他图文。较长文字在原区域换行，不移动图形、不改数字，不自行翻译其他文字。
```

## 接着修改

上传上一轮结果，涉及参考图的任务同时保留原图；每次只发一条修改指令。

```text
仅调整刚替换文案的{{溢出位置}}，保持“{{目标语言文字}}”完整，其他图文不变。
```

## 使用提示

本卡使用已校对译文，保留原比例；需要另改横竖版时使用跨境适配卡。

画布沿用输入图比例；模型与可用设置见[模型说明](../guides/models.md)。
