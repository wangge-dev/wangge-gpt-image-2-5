# 美妆个护：一张商品图连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

示例商品统一为“30 mL 琥珀色玻璃精华瓶、黑色滴管盖、白色矩形标签”。先准备：图1商品正面完整照、图2标签高清近照、图3滴管与膏体/液体细节照、图4获准使用的成年模特照。商品名称、容量、成分和功效只采用实物或已确认资料。

## 1. 搜索主图

来源卡：[EC01 白底商品主图](../../prompts/ecommerce/EC01.md)；输入图1、图2。

```text
图1是实际商品，图2只用于核对标签。制作一张1:1电商白底主图：单瓶正面居中，占画面高度75%，瓶身与滴管盖完整留边，底部有轻柔接触阴影。保持图1的琥珀色玻璃、瓶肩、滴管盖、液位与比例；标签文字、标志、位置以图2为准，不重新设计包装。用大面积柔光表现透明玻璃边缘，正面标签区域不得出现遮字高光。不要道具、卖点字、徽章或额外商品。只输出一张图。
```

验收：轮廓完整；SKU、容量和标签一致；反光不遮字；没有多瓶。局部返工：`只修正正面标签被反光遮挡的区域，按图2恢复原文字；其余商品结构、背景和阴影保持不变。`

## 2. 透明瓶质感特写

来源卡：[EC26 玻璃瓶反光与标签可读性](../../prompts/ecommerce/EC26.md)；输入图1、图2。

```text
编辑图1中的精华瓶，制作4:5近景商品照。浅暖灰背景，瓶身略偏左，保留完整瓶盖和瓶底。将横穿正面标签的刺眼反光收窄到瓶身两侧，保留玻璃边缘亮线、真实透射、底部厚度、液体颜色和液位。标签仍贴合原曲面，文字和图案严格按图2，不重新排版。右侧留出干净空间，但不添加文字、花草、滴管液滴或第二件商品。只输出一张图。
```

验收：仍像同一瓶；玻璃没有变成塑料或磨砂；标签可读。局部返工：`只减弱标签中央的过曝亮斑，恢复图2可见文字；保留瓶身两侧的自然反射。`

## 3. 梳妆台使用场景

来源卡：[EC02 生活场景商品图](../../prompts/ecommerce/EC02.md)；输入图1、图2。

```text
把图1精华瓶放在晨间梳妆台上，作为前景视觉中心，占画面高度约一半。镜头与瓶身标签平齐，背景可见柔焦镜面和一条折叠毛巾；道具只作为环境元素，不表现为赠品。侧窗自然光从左侧进入，瓶底与台面接触自然，透视、光向和投影一致。保持商品外形、琥珀色玻璃、液位、黑色滴管盖和图2标签，不添加功效或活动文案。只输出一张4:5图片。
```

验收：场景可识别；商品仍是主体；道具不遮瓶；阴影方向一致。局部返工：`只修正瓶底悬浮和阴影方向，使瓶底贴合台面；商品、标签与背景布局不变。`

## 4. 模特持用图

来源卡：[EC08 模特持用](../../prompts/ecommerce/EC08.md)；输入图1、图2、图4。

```text
图4是获准使用的成年模特身份参考，图1和图2负责商品。保持图4的面部特征、肤色、发型、体型和服装。模特在窗边自然手持图1精华瓶，瓶身正面朝向镜头，手指不遮标签，商品尺寸与手掌比例合理。半身商业摄影，柔和自然光，背景简洁，保留真实皮肤纹理。商品保持琥珀色玻璃、黑色滴管盖、液位与准确标签；不要改变人物身份，不增加涂抹效果、文字或其他产品。只输出一张4:5图片。
```

验收：人物身份稳定；五指合理；瓶子尺寸和标签正确。局部返工：`只修正持瓶手指与瓶身的接触，让五指自然且不遮标签；人物面部、姿态和商品外观保持不变。`

## 5. 三卖点详情模块

来源卡：[EC11 卖点信息图](../../prompts/ecommerce/EC11.md)；输入图1、图2及三条已确认卖点。

```text
制作一张4:5商品详情模块。上方55%居中展示图1精华瓶，下方45%分成三个等宽信息块。只排已确认的三条文案：标题“轻盈肤感”，说明“质地清爽，易于涂抹”；标题“滴管取用”，说明“按需控制单次用量”；标题“30 mL规格”，说明“容量以商品标签为准”。每块一个简洁线性图标，使用暖琥珀、米白和深灰配色。商品与标签按图1、图2；不添加未提供的成分、功效、认证、百分比或销量。只输出一张图。
```

验收：三组文字各出现一次；手机尺寸可读；没有医疗或功效扩写。局部返工：`只修改第2个信息块，使标题为“滴管取用”、说明为“按需控制单次用量”；其他文字和商品不变。`

## 6. 包装文字精准修正

来源卡：[EC30 包装文字局部修正](../../prompts/ecommerce/EC30.md)；输入待修结果和图2。

```text
以待修图片为底图，只检查并修正标签容量这一行，使其与图2完全一致。图2用于确认字符、字重、对齐和印刷风格，不把整张标签重新覆盖。正确容量文字必须逐字采用图2内容；保持原行字高、曲面透视、印刷质感与留白。其他商标、品名、瓶型、颜色、液位、光线和背景全部不变。不新增卖点、成分或认证图标。只输出一张修正图。
```

验收：只改目标行；其他像素区域视觉上保持；不存在重复容量字。若你的商品不同，请直接用各来源卡的变量模板替换示例事实。
