# 美妆个护：一张商品图连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

先在同一会话提交一次下面的《商品事实单》，再执行六步。六步中的“商品”“准确文字”和图号都共同引用这份事实单；换会话时须重新提交，不要让模型沿用旧商品。

## 一次填写：商品事实单

| 字段 | 填写内容 |
| --- | --- |
| 商品身份 | 品类、商品名、SKU；示例：30 mL 琥珀色玻璃精华瓶 |
| 外观不可变项 | 瓶型、颜色、材质、滴管盖、液位、标签位置与比例 |
| 已提供图片及职责 | 图1正面完整照；图2标签高清近照；图3滴管与液体细节照；图4获准使用的成年模特照 |
| 真实规格 | 容量及其他已确认规格；示例：30 mL |
| 准确文字 | 商标、品名、容量、三条已确认卖点；逐字填写 |
| 允许出现的配件/组件 | 只列实物确有的滴管、外盒等；没有就写“无” |
| 禁止推测项 | 未提供的成分、功效、认证、肤感结论、包装背面和配件 |

上表中的示例 SKU 只是填写示范。每段提示词内出现的示例描述仅用于展示成稿密度；与事实单冲突时一律以事实单为准，未填写的事实不得补造。

## 选择执行路径

- 单图最小路径：只有图1时先复制下方“只有图1时直接复制”，不要直接复制第1步的多图正文；第2、3步可在不露出未知背面、不改标签文字的前提下降级执行。跳过第4步（缺人物）、第5步（缺准确卖点）、第6步（缺标签近照或待修结果）。
- 资料齐全路径：图1至图4、准确文字与规格齐全后执行全部六步。缺任一项时只跳过依赖该项的步骤，不让模型猜测。

将填写后的表格连同下面这句一次发送到当前会话：

> 后续六步中的商品身份、外观、图片职责、规格、准确文字、组件和禁止项，只以这份《商品事实单》为准；步骤正文里的示例 SKU 只示范构图与任务，不得覆盖事实单或补造空缺。

复制任一步前，确保这份事实单仍在当前会话中。

### 只有图1时直接复制

```text
只使用图1和当前会话中的《商品事实单》制作一张1:1电商白底主图。完整保留图1正面可见的瓶型、盖体、颜色、材质观感、液位、标签位置、可见文字和比例；看不到的背面、侧面、内部结构、配件、成分、功效和认证保持未知，不补画、不推测。商品正面居中，占画面高度约75%，四周完整留边，纯白无地平线背景，使用柔光与轻微接触阴影；透明或反光区域不得遮住图1中可见的标签。不要新增道具、卖点字、徽章或第二件商品。只输出一张图。
```

## 1. 搜索主图

来源卡：[EC01 白底商品主图](../../prompts/ecommerce/EC01.md)；输入图1、图2。

```text
图1是《商品事实单》中的实际商品，图2只用于核对标签。制作一张1:1电商白底主图：单件商品正面居中，占画面高度75%，商品与事实单列出的固定组件完整留边，底部有轻柔接触阴影。外形、颜色、材质观感、液位和比例只按图1；标签文字、标志和位置只按图2，不重新设计包装。用大面积柔光表现真实材质边缘，正面标签区域不得出现遮字高光。不要添加事实单未列出的道具、组件、卖点字、徽章或额外商品。只输出一张图。
```

验收：轮廓完整；SKU、容量和标签一致；反光不遮字；没有多瓶。局部返工：`只修正正面标签被反光遮挡的区域，按图2恢复原文字；其余商品结构、背景和阴影保持不变。`

## 2. 透明瓶质感特写

来源卡：[EC26 玻璃瓶反光与标签可读性](../../prompts/ecommerce/EC26.md)；输入图1、图2。

```text
编辑图1中的《商品事实单》商品，制作4:5近景商品照。浅暖灰背景，商品略偏左，保持主体和事实单列出的固定组件完整。仅调整遮挡标签的刺眼反光，保留图1已有的材质反射、透射或表面纹理；标签仍贴合原曲面，文字和图案严格按图2，不重新排版。右侧留出干净空间，但不添加文字、花草、液滴、未列组件或第二件商品。只输出一张图。
```

验收：仍像同一瓶；玻璃没有变成塑料或磨砂；标签可读。局部返工：`只减弱标签中央的过曝亮斑，恢复图2可见文字；保留瓶身两侧的自然反射。`

## 3. 梳妆台使用场景

来源卡：[EC02 生活场景商品图](../../prompts/ecommerce/EC02.md)；输入图1、图2。

```text
把图1中的《商品事实单》商品放在晨间梳妆台上，作为前景视觉中心，占画面高度约一半。镜头与正面标签平齐，背景可见柔焦镜面和一条折叠毛巾；道具只作为环境元素，不表现为赠品。侧窗自然光从左侧进入，商品底部与台面接触自然，透视、光向和投影一致。外形、颜色、材质、液位、组件和图2标签只按参考与事实单，不添加功效或活动文案。只输出一张4:5图片。
```

验收：场景可识别；商品仍是主体；道具不遮瓶；阴影方向一致。局部返工：`只修正瓶底悬浮和阴影方向，使瓶底贴合台面；商品、标签与背景布局不变。`

## 4. 模特持用图

来源卡：[EC08 模特持用](../../prompts/ecommerce/EC08.md)；输入图1、图2、图4。

```text
图4是获准使用的成年模特身份参考，图1和图2负责《商品事实单》商品。保持图4的面部特征、肤色、发型、体型和服装。模特在窗边自然手持图1商品，正面标签朝向镜头，手指不遮标签，商品尺寸与手掌比例按事实单或同框证据。半身商业摄影，柔和自然光，背景简洁，保留真实皮肤纹理。商品外形、颜色、材质、液位、组件与标签只按图1、图2和事实单；不要改变人物身份，不增加涂抹效果、文字或其他产品。只输出一张4:5图片。
```

验收：人物身份稳定；五指合理；瓶子尺寸和标签正确。局部返工：`只修正持瓶手指与瓶身的接触，让五指自然且不遮标签；人物面部、姿态和商品外观保持不变。`

## 5. 三卖点详情模块

来源卡：[EC11 卖点信息图](../../prompts/ecommerce/EC11.md)；输入图1、图2及三条已确认卖点。

```text
制作一张4:5商品详情模块。上方55%居中展示图1商品，下方45%分成三个等宽信息块。三个标题和三条说明逐字使用《商品事实单》“准确文字”中已确认的三组卖点；若不足三组则停止并要求补充，不自行生成。每块使用一个不扩展含义的简洁线性图标，配色从图1商品与包装中提取。商品与标签按图1、图2；不添加未提供的成分、功效、认证、百分比、规格或销量。只输出一张图。
```

验收：事实单中的三组文字各出现一次；手机尺寸可读；没有功效扩写。局部返工：`只把指定信息块恢复为《商品事实单》“准确文字”中的对应标题和说明；其他文字、商品和版式不变。`

## 6. 包装文字精准修正

来源卡：[EC30 包装文字局部修正](../../prompts/ecommerce/EC30.md)；输入待修结果和图2。

```text
以待修图片为底图，只检查并修正《商品事实单》指定的一个标签文字区域，使其与图2完全一致。图2用于确认字符、字重、对齐和印刷风格，不把整张标签重新覆盖。正确文字必须逐字采用事实单“准确文字”与图2内容；保持原区域字高、曲面透视、印刷质感与留白。其他文字、商品外形、颜色、材质、液位、光线和背景全部不变。不新增卖点、成分或认证图标。只输出一张修正图。
```

验收：只改目标行；其他像素区域视觉上保持；不存在重复容量字。返工：`只恢复事实单“准确文字”中的容量行，其他商标、品名、瓶型、光线和背景不变。`
