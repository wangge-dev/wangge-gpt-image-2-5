# 母婴：一款用品连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

示例商品为“带双侧握把的儿童训练杯，杯身、杯盖和防尘盖三件”。准备图1完整组装照、图2各组件同框照、图3杯口与握把近照、图4包装正反面、图5获准使用且有监护人在场的真实使用参考、实测尺寸与说明书。年龄、材质、容量和安全结论只用合规资料。

## 1. 白底商品主图
来源卡：[EC01](../../prompts/ecommerce/EC01.md)；输入图1至图3。
```text
制作1:1白底主图。组装完整的儿童训练杯正面居中，占画面高度75%，双侧握把、杯身、杯盖和防尘盖完整可见，底部自然接触阴影。图1至图3限定结构、颜色、材质、接口和比例；不增加吸管、奶嘴、刻度、配重球、刷子或第二只杯。纯白无地平线背景，柔光保留半透明材质层次。只输出一张图，不加年龄、认证或功效文字。
```
验收：组件和结构一致；无额外配件；无安全宣称。返工：`只删除参考图不存在的吸管和配重球，恢复杯盖真实结构。`

## 2. 三件组件陈列
来源卡：[EC14 套装陈列](../../prompts/ecommerce/EC14.md)；输入图2。
```text
依据图2制作4:5白底组件陈列。杯身放中央，杯盖放左侧，防尘盖放右侧，严格三件，每件只出现一次，尺度和接口方向按真实照片。双侧握把属于杯身，不拆成额外赠品。使用柔和顶侧光和轻微阴影，不添加吸管、清洁刷、收纳盒、文字或装饰。只输出一张图。
```
验收：恰好三件；归属明确；没有套装扩充。返工：`只删除重复的防尘盖，使杯身、杯盖、防尘盖各一件。`

## 3. 握把与杯口细节
来源卡：[EC04](../../prompts/ecommerce/EC04.md)；输入图3。
```text
以图3为唯一细节依据制作1:1微距，焦点覆盖杯口连接结构、杯盖边缘和一侧握把连接处，周围渐进虚化。柔和掠射光表现真实塑料或硅胶质感，保留拼接、厚度和实际颜色。不增加防漏阀、刻度、纹理、防滑颗粒或安全认证，不用视觉效果暗示材质等级。只输出一张图。
```
验收：结构来自图3；没有虚构防漏设计。返工：`只删除新增的防漏阀，按图3恢复杯口结构；其余不变。`

## 4. 监护使用场景
来源卡：[EC08](../../prompts/ecommerce/EC08.md)；输入图1、图5。
```text
图5是获准使用的真实使用参考。保持儿童与监护人的身份、姿态、环境和监护关系，仅让儿童双手自然握住图1训练杯的两个握把，杯身保持正向且不遮挡面部。商品尺寸按真实比例，杯盖、防尘盖状态以参考场景为准。自然家庭光线，不改变儿童年龄和面部，不增加独自使用、奔跑饮用、热饮、文字或其他商品。只输出一张4:5图片。
```
验收：有监护场景；握持自然；没有危险动作或功效暗示。返工：`只修正双手与握把的接触，使手指自然包住握把；人物和杯体不变。`

## 5. 尺寸与适用信息
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入实测尺寸与合规包装资料。
```text
制作4:5规格说明图。上半部展示训练杯并标出实测总高、杯身宽和含握把总宽，尺寸线连接准确边界；下半部只列包装或说明书已确认的容量、适用年龄和材质名称，逐字使用合规资料。白底、深灰字、柔和蓝绿色点缀。不得自行添加食品级、无毒、防呛、防漏或医疗安全结论。只输出一张图。
```
验收：年龄和材质可追溯；尺寸单位准确；无扩展安全承诺。返工：`只删除资料未明确支持的“绝对防漏”文字，其他参数和商品不变。`

## 6. 清洁与组装步骤
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入说明书和真实步骤照。
```text
制作4:5三步说明图：步骤1按照片拆下防尘盖和杯盖；步骤2按说明书清洁允许清洗的部件；步骤3按照片方向重新组装。每步一幅真实依据小图和一条已确认说明，组件数量保持杯身、杯盖、防尘盖三件。不要补造高温消毒、洗碗机、微波炉或化学清洁剂用法。白底、深灰字、蓝绿色编号。只输出一张图。
```
验收：拆装方向和清洁方式来自说明书；三件无遗漏。返工：`只修正第2步清洁方式，使其逐字符合说明书，其他步骤不变。`
