# 母婴：一款用品连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

先在同一会话提交一次下面的《商品事实单》，再执行六步。六步共同引用该事实单；换会话时须重新提交。

## 一次填写：商品事实单

| 字段 | 填写内容 |
| --- | --- |
| 商品身份 | 品类、商品名、SKU；示例：带双侧握把的儿童训练杯 |
| 外观不可变项 | 杯身、杯盖、防尘盖、握把、接口、颜色、材质外观和比例 |
| 已提供图片及职责 | 图1完整组装；图2组件同框；图3杯口与握把；图4包装正反面；图5获准使用且有监护人在场的参考；另列步骤照 |
| 真实规格 | 实测尺寸、容量、适用年龄、材质及清洁方式的合规资料 |
| 准确文字 | 包装、说明书、规格与步骤文字；逐字填写 |
| 允许出现的配件/组件 | 只列实物存在的杯身、杯盖、防尘盖等 |
| 禁止推测项 | 未提供的吸管、阀门、认证、食品级/无毒、防呛、防漏和消毒方式 |

示例 SKU 只演示填写方式。正文示例与事实单冲突时，以事实单为唯一商品事实来源；安全信息只能来自合规资料。

## 选择执行路径

- 单图最小路径：只有图1时先复制下方“只有图1时直接复制”，不要直接复制第1步的多图正文；其他步骤全部跳过，除非补齐组件、细节、合规资料、监护使用参考与步骤照。不得依据单图生成安全、年龄或材质结论。
- 资料齐全路径：图1至图5、合规包装资料、说明书、实测尺寸和步骤照齐全后执行全部六步。

将填写后的表格连同下面这句一次发送到当前会话：

> 后续六步中的商品身份、外观、图片职责、规格、准确文字、组件和禁止项，只以这份《商品事实单》为准；步骤正文里的示例 SKU 只示范构图与任务，不得覆盖事实单或补造空缺。

复制任一步前，确保这份事实单仍在当前会话中。

### 只有图1时直接复制

```text
只使用图1和当前会话中的《商品事实单》制作一张1:1电商白底主图。按图1正面可见状态完整展示商品，占画面高度约75%，四周留边，纯白无地平线背景，使用柔光和自然接触阴影。完整保留图1可见的主体、盖体、握持或连接结构、颜色、材质观感、标识和比例；图1看不到的背面、侧面、内部结构、配件、材质成分、适用年龄、认证和安全功能保持未知，不补画、不推测。不要新增吸管、阀门、刻度、刷子、文字或第二件商品。只输出一张图。
```

## 1. 白底商品主图
来源卡：[EC01](../../prompts/ecommerce/EC01.md)；输入图1至图3。
```text
制作1:1白底主图。《商品事实单》的商品按图1至图3共同证实的正面状态居中，占画面高度75%，主体和事实单列出的固定组件完整可见，底部自然接触阴影。结构、颜色、材质观感、接口和比例只按对应参考；不增加事实单未列出的吸管、阀门、刻度、刷子或第二件商品。纯白无地平线背景，柔光保留真实材质层次。只输出一张图，不加年龄、认证或功效文字。
```
验收：组件和结构一致；无额外配件；无安全宣称。返工：`只删除参考图不存在的吸管和配重球，恢复杯盖真实结构。`

## 2. 三件组件陈列
来源卡：[EC14 套装陈列](../../prompts/ecommerce/EC14.md)；输入图2。
```text
依据图2制作4:5白底组件陈列。严格展示《商品事实单》“允许出现的配件/组件”中且图2可见的全部组件，每件只出现一次，位置、尺度、接口方向和归属按真实照片。与主体永久连接的结构不得拆成额外赠品。使用柔和顶侧光和轻微阴影，不添加事实单未列出的组件、文字或装饰。只输出一张图。
```
验收：恰好三件；归属明确；没有套装扩充。返工：`只删除重复的防尘盖，使杯身、杯盖、防尘盖各一件。`

## 3. 握把与杯口细节
来源卡：[EC04](../../prompts/ecommerce/EC04.md)；输入图3。
```text
以图3为唯一细节依据制作1:1微距，焦点只覆盖《商品事实单》指定的真实连接结构、边缘和接口，周围渐进虚化。柔和掠射光表现图3可见的材质质感，保留拼接、厚度和实际颜色。不增加阀门、刻度、纹理、防滑颗粒或安全认证，不用视觉效果暗示材质等级。只输出一张图。
```
验收：结构来自图3；没有虚构防漏设计。返工：`只删除新增的防漏阀，按图3恢复杯口结构；其余不变。`

## 4. 监护使用场景
来源卡：[EC08](../../prompts/ecommerce/EC08.md)；输入图1、图5。
```text
图5是获准使用的真实使用参考。保持儿童与监护人的身份、姿态、环境和监护关系，仅按图5与《商品事实单》让儿童自然接触或持用图1商品，不改变真实接触点，不遮挡面部。商品尺寸按实测比例，所有组件状态以参考场景为准。自然家庭光线，不改变儿童年龄和面部，不增加独自使用、危险动作、热饮、文字或其他商品。只输出一张4:5图片。
```
验收：有监护场景；握持自然；没有危险动作或功效暗示。返工：`只修正双手与握把的接触，使手指自然包住握把；人物和杯体不变。`

## 5. 尺寸与适用信息
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入实测尺寸与合规包装资料。
```text
制作4:5规格说明图。上半部展示《商品事实单》商品并标出实测资料中已确认的三个尺寸；尺寸线连接对应真实边界。下半部只列包装或说明书已确认的规格、适用范围和材质名称，逐字使用合规资料；不足三项则减少信息块。白底、深灰字，点缀色从商品提取。不得自行添加食品级、无毒、防呛、防漏或医疗安全结论。只输出一张图。
```
验收：年龄和材质可追溯；尺寸单位准确；无扩展安全承诺。返工：`只删除资料未明确支持的“绝对防漏”文字，其他参数和商品不变。`

## 6. 清洁与组装步骤
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入说明书和真实步骤照。
```text
制作4:5三步说明图。步骤1至3严格按《商品事实单》列出的真实步骤照和说明书顺序；每步一幅有依据的小图和一条已确认说明，组件数量与部件清单一致。不要补造高温消毒、洗碗机、微波炉、化学清洁剂或其他未确认用法。白底、深灰字、蓝绿色编号。只输出一张图。
```
验收：拆装方向和清洁方式来自说明书；三件无遗漏。返工：`只修正第2步清洁方式，使其逐字符合说明书，其他步骤不变。`
