# 小家电：一款产品连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

先在同一会话提交一次下面的《商品事实单》，再执行六步。六步共同引用该事实单；换会话时须重新提交。

## 一次填写：商品事实单

| 字段 | 填写内容 |
| --- | --- |
| 商品身份 | 品类、商品名、SKU；示例：白色桌面加湿器 |
| 外观不可变项 | 机身、水箱、出雾口、按钮、接口、液位线、颜色和比例 |
| 已提供图片及职责 | 图1正面；图2侧背面；图3水箱与按钮；图4拆分部件；图5真实使用场景；另列步骤照 |
| 真实规格 | 容量、功率、操作方式和部件清单 |
| 准确文字 | 机身标识、参数、部件名与步骤说明 |
| 允许出现的配件/组件 | 只列实物中存在的水箱、盖、底座等 |
| 禁止推测项 | 未提供的滤芯、电路、杀菌、净化、香薰、覆盖面积和静音等级 |

示例 SKU 只演示填写方式。正文示例与事实单冲突时，以事实单为唯一商品事实来源。

## 选择执行路径

- 单图最小路径：只有图1时先复制下方“只有图1时直接复制”，不要直接复制第1步的多图正文；可有限执行第2步，但不显示未知背面，不添加雾气或功能暗示。跳过第3至第6步，因为结构、细节、参数和操作均需额外证据。
- 资料齐全路径：图1至图5、步骤照、参数表、部件清单和说明书齐全后执行全部六步。

将填写后的表格连同下面这句一次发送到当前会话：

> 后续六步中的商品身份、外观、图片职责、规格、准确文字、组件和禁止项，只以这份《商品事实单》为准；步骤正文里的示例 SKU 只示范构图与任务，不得覆盖事实单或补造空缺。

复制任一步前，确保这份事实单仍在当前会话中。

### 只有图1时直接复制

```text
只使用图1和当前会话中的《商品事实单》制作一张1:1电商白底主图。按图1正面可见角度完整展示商品，占画面高度约75%，四周留边，纯白无地平线背景，使用柔光和轻微接触阴影。完整保留图1可见的机身轮廓、控制件、开口、接口、颜色、材质观感、标识和比例；图1看不到的侧背面、内部结构、功能组件、配件和工作状态保持未知，不补画、不推测。不要新增灯效、遥控器、雾气、功能图标或第二件商品。只输出一张图。
```

## 1. 白底主图
来源卡：[EC01](../../prompts/ecommerce/EC01.md)；输入图1至图3。
```text
制作1:1白底商品主图。《商品事实单》的商品按图1至图3共同证实的角度居中，占画面高度75%，机身和事实单列出的固定组件完整可见。轮廓、控制件、开口、接口、液位标记、颜色、材质和比例只按对应参考；不增加事实单未列出的开口、灯带、遥控器或其他组件。纯白无地平线背景，柔光控制真实反射，底部有自然接触阴影。只输出一张图，不加文字或工作效果。
```
验收：控制件与可见结构正确；无新增附件。返工：`只删除参考中不存在的新增结构，恢复图1对应区域；其他部分不变。`

## 2. 桌面使用场景
来源卡：[EC02](../../prompts/ecommerce/EC02.md)；输入图1、图5。
```text
将图1中的《商品事实单》商品放入图5场景的指定位置，保持现场机位、桌面、墙面和光向。商品为前景主体，尺度按实物尺寸与现场参照处理，底部真实落在承载面。只在事实单与参考明确提供工作状态证据时表现对应效果，否则保持未运行状态；效果不得遮挡商品轮廓。机身与组件只按参考，不增加事实单未列出的植物、配件、功效字或第二台机器。只输出一张4:5图片。
```
验收：雾从正确位置出现；尺度合理；商品不悬浮。返工：`只把水雾起点移回顶部真实出雾口并减弱浓度，场景和商品不变。`

## 3. 部件结构示意
来源卡：[EC17](../../prompts/ecommerce/EC17.md)；输入图4和部件清单。
```text
依据图4制作白底纵向结构示意。只按《商品事实单》的真实拆卸顺序分离部件清单中的组件，各部件只出现一次，位置对齐并保留合理间距。细引线只标注清单中已有名称；图4看不到的内部泵、电路、滤芯、加热或其他功能模块不要绘制。保持外壳颜色、透明度、卡扣和接口结构。只输出一张4:5示意图。
```
验收：每部件一次；结构有照片依据；没有伪造内部件。返工：`只删除资料未提供的内部滤芯，保留三件真实部件和对齐关系。`

## 4. 水箱与按钮微距
来源卡：[EC04](../../prompts/ecommerce/EC04.md)；输入图3。
```text
以图3为依据制作1:1微距图，焦点只覆盖《商品事实单》指定的真实边缘、标记和控制件，周围渐进虚化。用柔和侧光表现图3可见的材质厚度、纹理和光泽，保留真实标识、拼接和按键形状。不得增加刻度、触控屏、彩灯或功能图标，不夸大材料等级。只输出一张图。
```
验收：控制件和标识一致；材质真实。返工：`只恢复图3指定控制件的形状与现有标识，删除新增图标；其余不变。`

## 5. 三项真实参数
来源卡：[EC11](../../prompts/ecommerce/EC11.md)；输入确认过的参数表。
```text
制作4:5详情模块。上方展示《商品事实单》商品，下方三块逐字采用事实单“准确文字”及参数表中的三组标题、数值和说明；不足三组则减少信息块，不自行补齐。配色从商品与包装提取，图标简洁且不扩展含义，信息在手机上清楚。不得添加资料未提供的功能、性能等级、覆盖范围或续航结论。只输出一张图。
```
验收：单位准确；参数均有来源；无功能扩写。返工：`只把额定功率改回参数表准确数值和单位，其他模块不变。`

## 6. 三步使用说明
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入真实步骤照和说明书。
```text
制作4:5三步使用图。步骤1至3严格按《商品事实单》列出的三张真实步骤照和说明书顺序，每步使用对应照片，说明文字逐字采用已确认资料。保持手部动作、作用位置、标记和部件方向，不补加耗材、液体、工具或未经说明书允许的操作。白底、深灰字、浅蓝编号。只输出一张图。
```
验收：步骤顺序和注水位置正确；没有危险或无依据操作。返工：`只修正第2步注水位置和水位线，使其符合说明书；其他步骤不变。`
