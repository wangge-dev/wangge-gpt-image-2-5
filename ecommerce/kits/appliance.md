# 小家电：一款产品连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

先在同一会话提交一次下面的《商品事实单》，再执行六步。六步共同引用该事实单；换会话时须重新提交。

## 一次填写：商品事实单

| 字段 | 填写内容 |
| --- | --- |
| 商品身份 | 品类、商品名、SKU；示例：白色桌面加湿器 |
| 外观不可变项 | 机身、水箱、出雾口、按钮、接口、液位线、颜色和比例 |
| 已提供图片及职责 | 图1正面；图2侧背面；图3水箱与按钮；图4拆分部件；图5真实使用场景；另列步骤照 |
| 真实规格 | 容量、功率、操作方式和部件清单 |
| 准确文字 | 机身标识、参数、部件名与步骤说明 |
| 允许出现的配件/组件 | 只列实物中存在的水箱、盖、底座等 |
| 禁止推测项 | 未提供的滤芯、电路、杀菌、净化、香薰、覆盖面积和静音等级 |

示例 SKU 只演示填写方式。正文示例与事实单冲突时，以事实单为唯一商品事实来源。

## 选择执行路径

- 单图最小路径：只有图1时执行第1步和有限的第2步；不显示未知背面，不添加雾气或功能暗示。跳过第3至第6步，因为结构、细节、参数和操作均需额外证据。
- 资料齐全路径：图1至图5、步骤照、参数表、部件清单和说明书齐全后执行全部六步。

将填写后的表格连同下面这句一次发送到当前会话：

> 后续六步中的商品身份、外观、图片职责、规格、准确文字、组件和禁止项，只以这份《商品事实单》为准；步骤正文里的示例 SKU 只示范构图与任务，不得覆盖事实单或补造空缺。

复制任一步前，确保这份事实单仍在当前会话中。

## 1. 白底主图
来源卡：[EC01](../../prompts/ecommerce/EC01.md)；输入图1至图3。
```text
制作1:1白底商品主图。白色桌面加湿器正面略带侧面居中，占画面高度75%，机身、透明水箱、顶部单出雾口和底座完整可见。按图1至图3保持圆柱比例、按钮、接口、液位线和材质；不增加第二出雾口、灯带、遥控器或香薰盒。纯白无地平线背景，柔光控制透明水箱反射，底部自然接触阴影。只输出一张图，不加文字和雾气。
```
验收：单出雾口；按钮与水箱正确；无附件。返工：`只删除新增的第二出雾口，恢复图1顶部结构；其他部分不变。`

## 2. 桌面使用场景
来源卡：[EC02](../../prompts/ecommerce/EC02.md)；输入图1、图5。
```text
将图1加湿器放入图5书桌指定位置，保持现场机位、桌面、墙面和光向。商品为前景主体，尺度按实物尺寸与桌面参照处理，底座落在桌面。只表现一股从真实出雾口向上扩散的轻柔水雾；不遮挡商品轮廓，不制造房间充满浓雾的效果。保持机身、水箱、按钮和接口，不增加植物、遥控器、功效字或第二台机器。只输出一张4:5图片。
```
验收：雾从正确位置出现；尺度合理；商品不悬浮。返工：`只把水雾起点移回顶部真实出雾口并减弱浓度，场景和商品不变。`

## 3. 部件结构示意
来源卡：[EC17](../../prompts/ecommerce/EC17.md)；输入图4和部件清单。
```text
依据图4制作白底纵向结构示意。按真实拆卸顺序由上至下分离顶部盖、水箱和底座，各部件只出现一次，位置对齐并保留合理间距。细引线只标注部件清单中已有名称；看不到的内部泵、电路、滤芯或杀菌模块不要绘制。保持外壳颜色、透明度、卡扣和接口结构。只输出一张4:5示意图。
```
验收：每部件一次；结构有照片依据；没有伪造内部件。返工：`只删除资料未提供的内部滤芯，保留三件真实部件和对齐关系。`

## 4. 水箱与按钮微距
来源卡：[EC04](../../prompts/ecommerce/EC04.md)；输入图3。
```text
以图3为依据制作1:1微距图，焦点覆盖透明水箱边缘、液位标记和操作按钮，周围渐进虚化。用柔和侧光表现透明塑料厚度与白色机身哑光，保留真实标识、拼接和按键形状。不得增加刻度、触控屏、彩灯或功能图标，不夸大材料等级。只输出一张图。
```
验收：按钮和标识一致；水箱材质真实。返工：`只恢复图3按钮的形状与现有标识，删除新增图标；其余不变。`

## 5. 三项真实参数
来源卡：[EC11](../../prompts/ecommerce/EC11.md)；输入确认过的参数表。
```text
制作4:5详情模块。上方展示加湿器，下方三块分别写“水箱容量”“额定功率”“操作方式”，每块数值和说明逐字采用提供的参数表。白色、浅蓝和深灰配色，图标简洁，信息在手机上清楚。不得添加净化、除菌、静音等级、覆盖面积或续航结论。只输出一张图。
```
验收：单位准确；参数均有来源；无功能扩写。返工：`只把额定功率改回参数表准确数值和单位，其他模块不变。`

## 6. 三步使用说明
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入真实步骤照和说明书。
```text
制作4:5三步使用图：步骤1按照片取下水箱；步骤2按说明书要求加水；步骤3装回并按真实按钮启动。每步使用对应照片，编号1至3，说明文字逐字采用已确认资料。保持手部动作、注水位置、最大水位线和部件方向，不补加精油、清洁剂或未经说明书允许的操作。白底、深灰字、浅蓝编号。只输出一张图。
```
验收：步骤顺序和注水位置正确；没有危险或无依据操作。返工：`只修正第2步注水位置和水位线，使其符合说明书；其他步骤不变。`
