# 服饰：一件衣服连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

先在同一会话提交一次下面的《商品事实单》，再执行六步。六步共同引用该事实单；换会话时须重新提交。

## 一次填写：商品事实单

| 字段 | 填写内容 |
| --- | --- |
| 商品身份 | 品类、商品名、SKU；示例：白色纯棉圆领短袖 T 恤 |
| 外观不可变项 | 版型、颜色、领型、袖长、缝线、印花位置与比例 |
| 已提供图片及职责 | 图1正面；图2背面；图3领口与面料；图4印花；图5获准使用的成年模特 |
| 真实规格 | 尺码、衣长、胸围、材质等已确认资料 |
| 准确文字 | 印花、洗标或展示标签中必须逐字保留的内容 |
| 允许出现的配件/组件 | 只列实物或造型允许出现的搭配；没有就写“无” |
| 禁止推测项 | 未提供的背面、面料成分、尺码效果、内衬、洗标和装饰 |

示例 SKU 只演示填写方式。正文中的示例描述与事实单冲突时，以事实单为唯一商品事实来源。

## 选择执行路径

- 单图最小路径：只有图1时执行第1步；可有限执行第2步，但只呈现正面可证结构。跳过第3步（缺模特/尺码）、第4步（缺试穿结果和印花近照）、第5步（缺面料近照）、第6步（缺背面与细节图）。
- 资料齐全路径：图1至图5、真实尺码和准确文字齐全后执行全部六步。

将填写后的表格连同下面这句一次发送到当前会话：

> 后续六步中的商品身份、外观、图片职责、规格、准确文字、组件和禁止项，只以这份《商品事实单》为准；步骤正文里的示例 SKU 只示范构图与任务，不得覆盖事实单或补造空缺。

复制任一步前，确保这份事实单仍在当前会话中。

## 1. 平铺白底主图

来源卡：[EC01 白底商品主图](../../prompts/ecommerce/EC01.md)；输入图1、图4。

```text
以图1为商品结构参考、图4为印花细节参考，制作1:1白底服装主图。白色圆领短袖T恤正面平铺居中，衣身完整，占画面高度80%，肩线、袖口和下摆自然对称但保留真实布料状态。保持实际版型、白色面料、缝线及海军蓝圆形印花的位置、大小、文字与线条。纯白无地平线背景，柔光和轻微接触阴影。不要衣架、模特、尺码字、徽章或额外服装。只输出一张图。
```

验收：全衣完整；印花未重绘；白衣与白底仍有边界。返工：`只恢复图4中的印花字序和线条，保持衣服版型、褶皱与白底不变。`

## 2. 隐形模特立体图

来源卡：[EC18 服装隐形模特](../../prompts/ecommerce/EC18.md)；输入图1、图3、图4。

```text
根据图1制作白色T恤隐形模特商品摄影。衣物自然立体撑起，肩线、胸围轮廓、袖口和下摆符合真实圆领短袖结构；画面中没有人体、衣架或支架。图3负责领口、缝线和面料，图4负责胸前海军蓝圆形印花。不得收腰、加长衣身、改变袖长或增加内衬。浅灰背景，三点柔光，完整展示衣服。只输出一张4:5图片，不加文字。
```

验收：无人形残留；领口结构有依据；版型和印花一致。返工：`只修正领口内侧和肩线，按图3恢复真实缝线；其余版型、印花和背景不变。`

## 3. 同一模特试穿

来源卡：[EC16 参考图试穿](../../prompts/ecommerce/EC16.md)；输入图1、图3、图4、图5及真实尺码。

```text
图5是获准使用的成年模特，保持其面部、发型、体型、姿态、裤装和环境。只把图5上身衣物替换为图1白色圆领短袖T恤，按提供的真实尺码表现合身程度。图3负责领口、袖口和面料质感，图4负责胸前海军蓝圆形印花。布料沿身体和姿势形成自然褶皱，不自动收腰、增肌或改变人物比例。印花位置和大小相对衣片稳定。只输出一张4:5试穿图，不加文字。
```

验收：身份和姿态未变；只替换上衣；尺码观感合理。返工：`只修正上衣腰侧过度收紧的问题，恢复真实直身版型；人物和印花保持不变。`

## 4. 褶皱上的印花修复

来源卡：[EC27 印花跨褶皱保留](../../prompts/ecommerce/EC27.md)；输入图1、图4和步骤3结果。

```text
以步骤3的试穿图为底图，在胸前恢复图1这件T恤的原始印花。图1决定印花相对位置和大小，图4决定文字、线条和海军蓝颜色，底图决定人物、衣服轮廓、姿态与褶皱。图案必须随布面褶皱产生自然透视、弯曲和遮挡，不能像平面贴纸。保持原有字序和图形数量，不改变领口、袖长、面料颜色、人物脸部或背景。只输出一张修正图。
```

验收：褶皱仍存在；图案连续；人物未漂移。返工：`只修正右胸褶皱处的印花连续性，按图4恢复可见线条，保持褶皱和其余画面。`

## 5. 面料与走线微距

来源卡：[EC04 材质工艺微距](../../prompts/ecommerce/EC04.md)；输入图1、图3。

```text
图3是这件T恤领口罗纹与肩部走线的清晰近照。制作1:1微距商品摄影，焦点落在真实棉质纹理、针脚和接缝，周边渐进虚化；使用掠射柔光表现凹凸，但不夸大纤维粗细、厚度或光泽。颜色保持真实白色，让观看者能判断该细节属于图1商品。不要增加不存在的双线、洗标、成分字或装饰。只输出一张图。
```

验收：纹理来自近照；针脚数量不被美化；没有虚构标签。返工：`只恢复图3中肩部走线的真实针距和方向，保留当前微距裁切与光线。`

## 6. 正背面与细节网格

来源卡：[EC19 多角度网格](../../prompts/ecommerce/EC19.md)；输入图1至图4。

```text
制作2行2列白底商品网格。左上使用图1正面，标签“正面”；右上使用图2背面，标签“背面”；左下使用图3领口近照，标签“领口细节”；右下使用图4印花近照，标签“印花细节”。每格只采用指定参考，不从正面猜背面。统一柔光、白底和细白分隔线；整衣格展示尺度一致，细节格保持真实颜色与纹理。每格只出现指定中文标签，不添加卖点、尺码或价格。只输出一张1:1图片。
```

验收：四格来源对应；正背不混；标签各一次。返工：`只把右上格恢复为图2真实背面并保留“背面”标签，其他三格不变。`
