# 食品：一款包装食品连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

示例商品统一为“一袋6枚冷冻水饺”。准备：图1未开封包装正面、图2包装背面与配料/规格近照、图3实际一份6枚水饺、图4指定餐具、图5真实熟制成品、图6实际外盒与内袋同框照。数量、净含量、配料和烹饪步骤必须来自实物或已确认资料。

## 1. 包装搜索主图

来源卡：[EC01 白底商品主图](../../prompts/ecommerce/EC01.md)；输入图1、图2。

```text
制作1:1电商白底主图。图1的未开封水饺包装正面居中，包装完整，占画面高度75%，四周留边，底部有轻柔接触阴影。保持袋型、封边、颜色、图案、品牌和正面可见文字，不重新设计包装；图2只用于核对规格信息。背景纯白无地平线，柔光使塑料袋褶皱和印刷都清楚。不要加入水饺、餐具、蒸汽、活动字、徽章或第二袋商品。只输出一张图。
```

验收：包装边缘完整；净含量和SKU不变；无附送错觉。返工：`只恢复包装右下角规格文字，使其与图2一致；袋型、其他印刷和白底不变。`

## 2. 一份6枚装盘图

来源卡：[EC29 食品份量与装盘数量](../../prompts/ecommerce/EC29.md)；输入图3、图4。

```text
图3是实际一份水饺，一份共6枚。将这6枚水饺放入图4餐盘，排成两行，每行3枚，彼此轻微留缝且全部完整可数。保持单个水饺相对餐盘的实际尺寸、饱满程度、颜色和表面纹理；不得复制、堆高、放大或补加第7枚。自然柔光、干净浅色桌面，不切开展示未经提供的馅料，不增加蘸料、香草、价格或功效文字。只输出一张4:5装盘图。
```

验收：恰好6枚；每枚完整可数；尺寸合理。返工：`只纠正水饺数量为6枚并排成两行，每行3枚；餐盘、单个尺寸和光线不变。`

## 3. 家庭餐桌场景

来源卡：[EC02 生活场景商品图](../../prompts/ecommerce/EC02.md)；输入图4、图5。

```text
把图5真实熟制水饺放入图4餐盘，置于明亮家庭餐桌前景，餐盘占画面宽度约60%。背景只保留柔焦木桌、餐垫和一双筷子，不能让道具被误认为随商品附送。侧窗自然光，餐盘接触和投影真实，水饺数量、大小、颜色、熟制程度与图5一致。不增加夸张蒸汽、馅料剖面、蔬菜点缀、人物、包装或广告文字。只输出一张4:5图片。
```

验收：成品来自实拍依据；环境不过度抢眼；无虚构配料。返工：`只去掉未经参考提供的馅料剖面和配菜，恢复图5的完整水饺外观；场景与餐盘不变。`

## 4. 面皮纹理微距

来源卡：[EC04 材质工艺微距](../../prompts/ecommerce/EC04.md)；输入图5的高清细节。

```text
以图5中一枚熟水饺的表面与封口褶为依据，制作1:1微距食品摄影。焦点落在真实面皮纹理、封口压痕和熟制后的轻微光泽，周边渐进虚化；用柔和掠射光表现凹凸。不得夸大晶莹程度、油脂、厚度或个头，不切开水饺，不补造馅料和汁水。保持图5真实颜色，让观看者能认出属于同一商品。不要文字或装饰。只输出一张图。
```

验收：只展示有依据的外部结构；没有爆汁等虚构效果。返工：`只减弱表面过度油亮，恢复图5真实面皮颜色和哑光程度；裁切与封口结构不变。`

## 5. 包装与内袋陈列

来源卡：[EC10 包装开箱陈列](../../prompts/ecommerce/EC10.md)；输入图1、图2、图6。

```text
图6负责实际组件和数量，图1、图2负责包装印刷核对。将外盒放在后侧、未开封内袋放在前侧，严格只展示图6中存在的组件。浅灰石材台面，柔和侧光表现纸盒和塑料袋材质；包装颜色、图案、规格和可见文字按参考图，不改成烫金，不增加托盘、赠品、蘸料包或散装水饺。组件完整可辨，内袋不遮外盒主要信息。只输出一张4:5商品图。
```

验收：组件数量与图6相同；包装印刷未重构；没有赠品。返工：`只删除参考图中不存在的额外蘸料包，外盒、内袋位置及其他内容不变。`

## 6. 烹饪步骤说明图

来源卡：[EC13 规格与步骤](../../prompts/ecommerce/EC13.md)；输入图2及三张真实步骤照。

```text
制作一张4:5烹饪步骤说明图。上方展示图1包装，下方按1至3排列三幅小图，严格采用已提供的真实步骤照与包装背面说明。每步标题和说明逐字使用包装上的已确认文字，不自行缩短时间、改变火力或补加调料。白底、深灰字、细分隔线，编号醒目，包装和步骤互不遮挡。只显示已确认的三步文字，不添加营养功效、认证、销量、价格或口号。资料中没有的动作留空，不猜测。只输出一张图。
```

验收：步骤文字与包装一致；顺序正确；没有编造时间。返工：`只把第2步的时间和火力改回图2包装说明中的准确文字，其他步骤和版式不变。`
