# 食品：一款包装食品连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

先在同一会话提交一次下面的《商品事实单》，再执行六步。六步共同引用该事实单；换会话时须重新提交。

## 一次填写：商品事实单

| 字段 | 填写内容 |
| --- | --- |
| 商品身份 | 品类、商品名、SKU；示例：一袋冷冻水饺 |
| 外观不可变项 | 包装袋型、封边、颜色、图案、食品外形和熟制状态 |
| 已提供图片及职责 | 图1包装正面；图2背面说明；图3实际份量；图4餐具；图5熟制成品；图6包装组件同框照；另列三张步骤照 |
| 真实规格 | 净含量、每份数量、烹饪时间与火力等已确认资料；示例份量为6枚 |
| 准确文字 | 品牌、品名、规格、配料与步骤说明；逐字填写 |
| 允许出现的配件/组件 | 只列包装内真实存在的外盒、内袋或餐具职责 |
| 禁止推测项 | 未提供的馅料剖面、配料、营养功效、认证、赠品和烹饪动作 |

示例 SKU 只演示填写方式。正文中的“6枚水饺”等示例事实与事实单冲突时，以事实单为准。

## 选择执行路径

- 单图最小路径：只有图1时先复制下方“只有图1时直接复制”，不要直接复制第1步的多图正文；可做不改变包装的有限背景清理。跳过第2至第6步，因为份量、餐具、熟制状态、内部组件和烹饪步骤均缺证据。
- 资料齐全路径：图1至图6、三张真实步骤照、规格及包装文字齐全后执行全部六步。

将填写后的表格连同下面这句一次发送到当前会话：

> 后续六步中的商品身份、外观、图片职责、规格、准确文字、组件和禁止项，只以这份《商品事实单》为准；步骤正文里的示例 SKU 只示范构图与任务，不得覆盖事实单或补造空缺。

复制任一步前，确保这份事实单仍在当前会话中。

### 只有图1时直接复制

```text
只使用图1和当前会话中的《商品事实单》制作一张1:1电商白底主图。图1中的未开封包装正面居中，包装完整，占画面高度约75%，四周留边，底部有轻柔接触阴影；纯白无地平线背景，使用柔光保留包装真实褶皱、封边与印刷。完整保留图1正面可见的袋型或盒型、颜色、图案、品牌和文字；图1看不到的背面、侧面、内部食品、份量、配料、组件和规格保持未知，不补画、不推测。不要加入食品成品、餐具、蒸汽、活动字、徽章或第二件商品。只输出一张图。
```

## 1. 包装搜索主图

来源卡：[EC01 白底商品主图](../../prompts/ecommerce/EC01.md)；输入图1、图2。

```text
制作1:1电商白底主图。图1中的《商品事实单》未开封包装正面居中，包装完整，占画面高度75%，四周留边，底部有轻柔接触阴影。保持包装形态、封边、颜色、图案、品牌和正面可见文字，不重新设计包装；图2只用于核对事实单指定的背面或规格文字。背景纯白无地平线，柔光使包装褶皱、材质与印刷清楚。不要加入食品成品、餐具、蒸汽、活动字、徽章或第二件商品。只输出一张图。
```

验收：包装边缘完整；净含量和SKU不变；无附送错觉。返工：`只恢复包装右下角规格文字，使其与图2一致；袋型、其他印刷和白底不变。`

## 2. 一份定量装盘图

来源卡：[EC29 食品份量与装盘数量](../../prompts/ecommerce/EC29.md)；输入图3、图4。

```text
图3是《商品事实单》中实际一份食品，数量只采用事实单“真实规格”的确认值。将全部食品放入图4餐具，按事实单批准的排列方式摆放，彼此轻微留缝且完整可数。保持单件食品相对餐具的实际尺寸、形态、颜色和表面纹理；不得复制、遗漏、堆高或放大。自然柔光、干净浅色桌面，不切开展示未经提供的内部，不增加配料、装饰、价格或功效文字。只输出一张4:5装盘图。
```

验收：数量与事实单一致；每件完整可数；尺寸合理。返工：`只把食品数量和排列恢复为《商品事实单》“真实规格”的确认值；餐具、单件尺寸和光线不变。`

## 3. 家庭餐桌场景

来源卡：[EC02 生活场景商品图](../../prompts/ecommerce/EC02.md)；输入图4、图5。

```text
把图5中的《商品事实单》真实成品放入图4餐具，置于明亮家庭餐桌前景，餐具占画面宽度约60%。背景只保留柔焦桌面、餐垫和事实单允许的餐具，道具不能被误认为随商品附送。侧窗自然光，餐具接触和投影真实，食品数量、大小、颜色与状态只按图5。不增加夸张蒸汽、内部剖面、配料点缀、人物、包装或广告文字。只输出一张4:5图片。
```

验收：成品来自实拍依据；环境不过度抢眼；无虚构配料。返工：`只去掉未经参考提供的内部剖面和配菜，恢复图5的完整食品外观；场景与餐具不变。`

## 4. 面皮纹理微距

来源卡：[EC04 材质工艺微距](../../prompts/ecommerce/EC04.md)；输入图5的高清细节。

```text
以图5中一件《商品事实单》食品的可见表面与边缘结构为依据，制作1:1微距食品摄影。焦点只落在图5真实可见的纹理、压痕与表面光泽，周边渐进虚化；用柔和掠射光表现凹凸。不得夸大晶莹程度、油脂、厚度或个头，不切开展示未经提供的内部，不补造馅料和汁水。保持图5真实颜色，让观看者能认出属于同一商品。不要文字或装饰。只输出一张图。
```

验收：只展示有依据的外部结构；没有爆汁等虚构效果。返工：`只减弱表面过度油亮，恢复图5真实面皮颜色和哑光程度；裁切与封口结构不变。`

## 5. 包装与内袋陈列

来源卡：[EC10 包装开箱陈列](../../prompts/ecommerce/EC10.md)；输入图1、图2、图6。

```text
图6负责《商品事实单》中的实际组件、数量和相对关系，图1、图2负责包装印刷核对。按图6摆放所有真实组件，每件只出现一次，不固定外盒、内袋或其他不存在的结构。浅灰台面，柔和侧光表现各自真实材质；包装颜色、图案、规格和可见文字按参考图，不升级工艺，不增加托盘、赠品、配料包或散装食品。组件完整可辨，彼此不遮挡主要信息。只输出一张4:5商品图。
```

验收：组件数量与图6相同；包装印刷未重构；没有赠品。返工：`只删除参考图中不存在的额外蘸料包，外盒、内袋位置及其他内容不变。`

## 6. 烹饪步骤说明图

来源卡：[EC13 规格与步骤](../../prompts/ecommerce/EC13.md)；输入图1、图2及三张真实步骤照。

```text
制作一张4:5烹饪步骤说明图。上方展示图1中的《商品事实单》包装，下方按1至3排列三幅小图，严格采用已提供的真实步骤照与包装背面说明。每步标题和说明逐字使用事实单“准确文字”与包装上的已确认文字，不自行缩短时间、改变火力或补加调料。白底、深灰字、细分隔线，编号醒目，包装和步骤互不遮挡。只显示已确认的三步文字，不添加营养功效、认证、销量、价格或口号。资料中没有的动作留空，不猜测。只输出一张图。
```

验收：步骤文字与包装一致；顺序正确；没有编造时间。返工：`只把第2步的时间和火力改回图2包装说明中的准确文字，其他步骤和版式不变。`
