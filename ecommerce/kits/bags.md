# 箱包：一只包连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

示例商品为“米白色帆布托特包，双提手、顶部敞口、一个内袋”。准备图1正面、图2背面、图3侧面、图4内袋与缝线近照、图5获准使用的成年模特照、实测尺寸和实际可装物品清单。

## 1. 白底主图
来源卡：[EC01](../../prompts/ecommerce/EC01.md)；输入图1至图3。
```text
制作1:1白底主图。米白色帆布托特包正面略带侧面居中，占画面高度75%，双提手、顶部敞口、包底和侧边完整可见，底部有自然接触阴影。按图1至图3保持包型、帆布颜色、提手长度、缝线、内袋位置和原有标识；不增加拉链、肩带、挂饰或第二只包。纯白背景，柔光保留帆布纹理。只输出一张图。
```
验收：提手数量、开口和包型一致；无附件。返工：`只删除新增拉链并恢复图1顶部敞口结构，其他不变。`

## 2. 模特手提比例图
来源卡：[EC08](../../prompts/ecommerce/EC08.md)；输入图1和图5。
```text
图5为获准使用的成年模特。保持人物身份、体型、发型、服装和姿态，让其自然单手提图1托特包，手指与双提手接触合理，包身自然下垂。按实测尺寸表现包与人体比例，不扩大容量，不自动增加肩带。保持米白帆布、敞口、缝线和标识，半身街拍商业摄影，背景简洁。只输出一张4:5图片，不加文字。
```
验收：人物稳定；手部合理；包的尺度和结构准确。返工：`只修正手指穿过提手的问题，保持人物、包型和姿态不变。`

## 3. 帆布缝线微距
来源卡：[EC04](../../prompts/ecommerce/EC04.md)；输入图4。
```text
以图4为唯一细节依据，制作1:1微距。焦点落在提手连接处的帆布纹理、加固走线和内袋边缘，周围渐进虚化。掠射柔光表现真实织纹与针脚，不夸大厚度、密度或耐磨性，不增加铆钉、皮革包边和不存在的线迹。颜色保持米白。只输出一张图，不加文字。
```
验收：走线和材质来自图4；无工艺升级。返工：`只恢复图4的真实针脚行数与方向，裁切和光线不变。`

## 4. 正背侧内四格
来源卡：[EC19](../../prompts/ecommerce/EC19.md)；输入图1至图4。
```text
制作2行2列网格：左上图1“正面”，右上图2“背面”，左下图3“侧面”，右下图4“内袋”。每格只用指定参考，不从正面猜背面或内部。统一白底、柔光、展示尺度和细白边，四个标签各出现一次。保持双提手、敞口、包底宽度和一个内袋，不添加尺寸、卖点或物品。只输出一张1:1图片。
```
验收：四格来源正确；内部只有一个已知内袋。返工：`只把右下格恢复为图4的一个真实内袋，其他三格不变。`

## 5. 容量陈列图
来源卡：[EC03 俯拍平铺](../../prompts/ecommerce/EC03.md)；输入商品及实际可装物品同框照。
```text
制作4:5俯拍容量陈列。托特包打开平放在中央，周围只摆放实际同框参考中已验证可装入的物品，每件出现一次，排列整齐且不互相遮挡。保持物品真实尺寸关系，不缩小游戏本、放大包体或复制物品。包保持米白帆布、双提手、敞口和一个内袋。浅灰背景，不添加容量数字、赠品暗示或参考中没有的物品。只输出一张图。
```
验收：每件物品有实拍依据；比例可信；没有赠品误导。返工：`只删除参考中不存在的额外物品，保留包和其余陈列位置。`

## 6. 尺寸与结构详情
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入实测尺寸和结构照。
```text
制作4:5规格图。上半部展示托特包正面，用引线标出实测宽、高和底宽，数值与单位逐字采用测量记录；下半部展示“顶部敞口”“双提手”“一个内袋”三项真实结构。白底、深灰字、米白与深蓝点缀。尺寸线连接实际边界，不从照片估数，不添加承重、容量升数或防水结论。只输出一张图。
```
验收：尺寸线位置正确；结构数量一致。返工：`只修正底宽数值及引线，连接包底前后边界；其余不变。`
