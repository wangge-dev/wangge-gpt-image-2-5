# 箱包：一只包连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

先在同一会话提交一次下面的《商品事实单》，再执行六步。六步共同引用该事实单；换会话时须重新提交。

## 一次填写：商品事实单

| 字段 | 填写内容 |
| --- | --- |
| 商品身份 | 品类、商品名、SKU；示例：米白色帆布托特包 |
| 外观不可变项 | 包型、颜色、材质、提手、开口、缝线、内袋、标识与比例 |
| 已提供图片及职责 | 图1正面；图2背面；图3侧面；图4内袋和缝线；图5获准使用的成年模特；另列容量同框照 |
| 真实规格 | 实测宽、高、底宽及已验证可装物品 |
| 准确文字 | 商品标识、尺寸和结构名称 |
| 允许出现的配件/组件 | 只列实物存在的肩带、挂饰或包装；没有就写“无” |
| 禁止推测项 | 未提供的背面、内部隔层、拉链、承重、容量升数、防水和赠品 |

示例 SKU 只演示填写方式。正文示例与事实单冲突时，以事实单为唯一商品事实来源。

## 选择执行路径

- 单图最小路径：只有图1时先复制下方“只有图1时直接复制”，不要直接复制第1步的多图正文；可有限执行第2步，但必须另有获准模特与实测尺寸。跳过第3至第6步，除非补齐细节、多角度、同框容量照和尺寸记录。
- 资料齐全路径：图1至图5、容量同框照、实测尺寸和准确文字齐全后执行全部六步。

将填写后的表格连同下面这句一次发送到当前会话：

> 后续六步中的商品身份、外观、图片职责、规格、准确文字、组件和禁止项，只以这份《商品事实单》为准；步骤正文里的示例 SKU 只示范构图与任务，不得覆盖事实单或补造空缺。

复制任一步前，确保这份事实单仍在当前会话中。

### 只有图1时直接复制

```text
只使用图1和当前会话中的《商品事实单》制作一张1:1电商白底主图。按图1正面可见角度完整展示商品，占画面高度约75%，四周留边，纯白无地平线背景，使用柔光和自然接触阴影。完整保留图1可见的包型、颜色、材质纹理、提手或肩带、开口、缝线、标识和比例；图1看不到的背面、侧面、内袋、隔层、拉链、配件、容量和承重保持未知，不补画、不推测。不要新增挂饰、肩带、文字、道具或第二件商品。只输出一张图。
```

## 1. 白底主图
来源卡：[EC01](../../prompts/ecommerce/EC01.md)；输入图1至图3。
```text
制作1:1白底主图。《商品事实单》的商品按图1至图3共同证实的角度居中，占画面高度75%，主体和事实单列出的固定组件完整可见，底部有自然接触阴影。包型、颜色、材质纹理、提手或肩带、开口、缝线、内袋位置和标识只按对应参考；不增加事实单未列出的拉链、肩带、挂饰或第二件商品。纯白背景，柔光保留真实材质纹理。只输出一张图。
```
验收：提手数量、开口和包型一致；无附件。返工：`只删除新增拉链并恢复图1顶部敞口结构，其他不变。`

## 2. 模特手提比例图
来源卡：[EC08](../../prompts/ecommerce/EC08.md)；输入图1和图5。
```text
图5为获准使用的成年模特。保持人物身份、体型、发型、服装和姿态，让其按《商品事实单》指定方式自然持用图1商品，手指、肩部或身体与真实提手、肩带和包身接触合理。按实测尺寸表现商品与人体比例，不扩大容量，不自动增加配件。商品外形、颜色、材质、开口、缝线和标识只按参考；半身商业摄影，背景简洁。只输出一张4:5图片，不加文字。
```
验收：人物稳定；手部合理；包的尺度和结构准确。返工：`只修正手指穿过提手的问题，保持人物、包型和姿态不变。`

## 3. 帆布缝线微距
来源卡：[EC04](../../prompts/ecommerce/EC04.md)；输入图4。
```text
以图4为唯一细节依据，制作1:1微距。焦点落在《商品事实单》指定的真实材质纹理、连接处、走线和边缘，周围渐进虚化。掠射柔光表现真实织纹与针脚，不夸大厚度、密度或耐磨性，不增加铆钉、包边和不存在的线迹。颜色只按图4。只输出一张图，不加文字。
```
验收：走线和材质来自图4；无工艺升级。返工：`只恢复图4的真实针脚行数与方向，裁切和光线不变。`

## 4. 正背侧内四格
来源卡：[EC19](../../prompts/ecommerce/EC19.md)；输入图1至图4。
```text
制作2行2列网格：左上图1“正面”，右上图2“背面”，左下图3“侧面”，右下图4使用《商品事实单》指定的细节标签。每格只用指定参考，不从正面猜背面或内部。统一白底、柔光、展示尺度和细白边，四个标签各出现一次。提手或肩带、开口、包底和内部结构只按对应参考，不添加尺寸、卖点或物品。只输出一张1:1图片。
```
验收：四格来源正确；内部只有一个已知内袋。返工：`只把右下格恢复为图4的一个真实内袋，其他三格不变。`

## 5. 容量陈列图
来源卡：[EC03 俯拍平铺](../../prompts/ecommerce/EC03.md)；输入商品及实际可装物品同框照。
```text
制作4:5俯拍容量陈列。《商品事实单》商品按同框参考中的真实状态放在中央，周围只摆放已验证可装入的物品，每件出现一次，排列整齐且不互相遮挡。保持物品真实尺寸关系，不缩小物品、放大商品或复制物品。商品外形、颜色、材质、组件和内部结构只按参考。浅灰背景，不添加容量数字、赠品暗示或参考中没有的物品。只输出一张图。
```
验收：每件物品有实拍依据；比例可信；没有赠品误导。返工：`只删除参考中不存在的额外物品，保留包和其余陈列位置。`

## 6. 尺寸与结构详情
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入实测尺寸和结构照。
```text
制作4:5规格图。上半部展示《商品事实单》商品正面，用引线标出测量记录中已确认的宽、高和深度或底宽；数值与单位逐字采用记录。下半部只展示事实单“准确文字”中的三项真实结构；不足三项则减少信息块。白底、深灰字，点缀色从商品提取。尺寸线连接实际边界，不从照片估数，不添加承重、容量升数或防水结论。只输出一张图。
```
验收：尺寸线位置正确；结构数量一致。返工：`只修正底宽数值及引线，连接包底前后边界；其余不变。`
