# 数码：一款设备连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

先在同一会话提交一次下面的《商品事实单》，再执行六步。六步共同引用该事实单；换会话时须重新提交。

## 一次填写：商品事实单

| 字段 | 填写内容 |
| --- | --- |
| 商品身份 | 品类、商品名、SKU；示例：深灰色紧凑布局无线键盘 |
| 外观不可变项 | 键位、字符、旋钮、外壳、脚撑、接口及比例 |
| 已提供图片及职责 | 图1正面；图2侧面；图3背面；图4接口和键帽；图5已确认界面截图；另列桌面参考 |
| 真实规格 | 尺寸、键数、连接方式和兼容资料 |
| 准确文字 | 键帽字符、接口标识、三项已确认功能文字 |
| 允许出现的配件/组件 | 只列实物存在的线缆、接收器或场景道具 |
| 禁止推测项 | 未提供的接口、灯效、轴体、续航、低延迟与系统兼容性 |

示例 SKU 只演示填写方式。正文示例与事实单冲突时，以事实单为唯一商品事实来源。

## 选择执行路径

- 单图最小路径：只有图1时先复制下方“只有图1时直接复制”，不要直接复制第1步的多图正文；可有限执行第3步，场景只改变环境，不露出未知背面、接口或配件。跳过第2、4步（缺对应视角）、第5步（缺参数）、第6步（缺界面截图）。
- 资料齐全路径：图1至图5、桌面参考、尺寸与兼容资料齐全后执行全部六步。

将填写后的表格连同下面这句一次发送到当前会话：

> 后续六步中的商品身份、外观、图片职责、规格、准确文字、组件和禁止项，只以这份《商品事实单》为准；步骤正文里的示例 SKU 只示范构图与任务，不得覆盖事实单或补造空缺。

复制任一步前，确保这份事实单仍在当前会话中。

### 只有图1时直接复制

```text
只使用图1和当前会话中的《商品事实单》制作一张1:1电商白底主图。主体按图1正面可见角度居中，占画面宽度约80%，四周完整留边，纯白无地平线背景，使用柔光和轻微接触阴影。完整保留图1可见的外壳、按键或控制件、字符、颜色、材质观感和比例；图1看不到的背面、侧面、接口、脚撑、灯效、线缆、配件和功能保持未知，不补画、不推测。不要新增品牌、文字、道具或第二件商品。只输出一张图。
```

## 1. 白底主图
来源卡：[EC01](../../prompts/ecommerce/EC01.md)；输入图1至图3。
```text
制作1:1白底数码商品主图。《商品事实单》的商品以图1至图3共同证实的角度居中，占画面宽度80%，四周完整留边，底部有轻柔接触阴影。外壳、按键或控制件、字符、颜色、材质、接口和比例只按指定参考；不得把一张图中看不到的结构从其他相似商品补入。纯白背景，柔光显示真实层次。不要新增事实单未列出的灯效、接口、配件、品牌或第二件商品。只输出一张图。
```
验收：可见按键、控制件和字符与参考一致；没有幻造接口。返工：`只恢复图1中指定控制件及相邻区域的数量、形状和位置；其余画面不变。`

## 2. 四视角网格
来源卡：[EC19](../../prompts/ecommerce/EC19.md)；输入图1至图4。
```text
制作2行2列白底网格：左上图1“正面”，右上图2“侧面”，左下图3“背面”，右下图4“接口细节”。每格只使用指定参考，不从正面推测背面或接口。统一柔光、展示尺度和细白分隔线；四个中文标签各出现一次。按《商品事实单》保持各视角可见的按键、控制件、脚撑和接口数量，不加参数或卖点。只输出一张1:1图片。
```
验收：四格来源明确；接口和背面有实拍依据。返工：`只把右下格恢复成图4真实接口细节，并保留“接口细节”标签。`

## 3. 桌面使用场景
来源卡：[EC02](../../prompts/ecommerce/EC02.md)；输入图1和真实桌面参考。
```text
将图1中的《商品事实单》商品放到真实桌面参考的指定位置，镜头和环境按桌面参考，商品占画面宽度约60%。背景道具只作为环境元素，不表现为套装。侧窗柔光，商品与桌面接触、透视和投影一致。只保留图1可见的外壳、按键或控制件、字符、颜色和比例；不露出未知背面，不增加事实单未列出的灯效、线缆、配件、文字或额外商品。只输出一张16:9图片。
```
验收：主体突出；道具不造成套装误解；商品外观不漂移。返工：`只删除《商品事实单》未列出的新增配件，商品、桌面及光线不变。`

## 4. 接口结构特写
来源卡：[EC04](../../prompts/ecommerce/EC04.md)；输入图4。
```text
以图4为《商品事实单》商品的唯一接口结构依据，制作1:1接口与外壳微距。焦点落在图4实际可见的接口、开关及外壳拼接处，保留接口数量、形状、方向和旁边可见标识；使用掠射柔光表现真实材质。不得增加图4不存在的接口、卡槽、图标或隐藏功能，不改变原有表面光泽。只输出一张图，不加说明字。
```
验收：接口逐一对应图4；没有功能暗示。返工：`只删除参考图不存在的额外接口，恢复图4的开关和拼接线。`

## 5. 功能信息图
来源卡：[EC11](../../prompts/ecommerce/EC11.md)；输入已确认参数表。
```text
制作4:5详情模块。上方展示《商品事实单》商品，下方三块只排事实单“准确文字”与已确认参数表中的三组标题和说明；若不足三组则停止并要求补充，不自行生成。数字、单位、连接或兼容文字逐字采用资料，图标不得扩展含义；配色从商品与包装提取。不得补写资料未提供的性能、续航、兼容或内部结构。只输出一张图。
```
验收：每项可回查参数表；没有空泛性能承诺。返工：`只删除资料中没有的续航时长，其他文字和商品不变。`

## 6. 屏幕配套场景
来源卡：[EC23](../../prompts/ecommerce/EC23.md)；输入图1和图5。
```text
制作16:9桌面工作场景。显示器屏幕只放入图5已确认界面截图，保持截图比例、文字和布局，不重绘界面；图1中的《商品事实单》商品放在显示器前方，保持图1可见外观。屏幕透视与显示器一致，亮度不过曝，商品与桌面投影自然。不要暗示截图中的软件由商品附送，不增加浮空窗口、霓虹灯或广告文案。只输出一张图。
```
验收：界面未改字；设备身份稳定；无捆绑误导。返工：`只恢复屏幕中的图5原始界面和文字，商品及场景不变。`
