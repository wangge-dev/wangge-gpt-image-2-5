# 家居：一件商品连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

先在同一会话提交一次下面的《商品事实单》，再执行六步。六步共同引用该事实单；换会话时须重新提交。

## 一次填写：商品事实单

| 字段 | 填写内容 |
| --- | --- |
| 商品身份 | 品类、商品名、SKU；示例：浅橡木色双层床头柜 |
| 外观不可变项 | 层数、抽屉、开放层、拉手、柜脚、颜色、木纹和比例 |
| 已提供图片及职责 | 图1正面；图2侧面；图3背面；图4五金木纹；图5目标空间；另列安装步骤照 |
| 真实规格 | 实测长宽高、部件名称和数量 |
| 准确文字 | 尺寸、结构名与已确认卖点；逐字填写 |
| 允许出现的配件/组件 | 只列真实五金、安装工具或场景保留物 |
| 禁止推测项 | 未提供的背面、内部结构、材质等级、承重、环保认证和安装步骤 |

示例 SKU 只演示填写方式。正文示例与事实单冲突时，以事实单为唯一商品事实来源。

## 选择执行路径

- 单图最小路径：只有图1时执行第1步；可有限执行第5步，但卖点只能来自正面可见结构。跳过第2步（缺空间与尺寸）、第3步（缺近照）、第4步（缺实测值）、第6步（缺步骤照和部件清单）。
- 资料齐全路径：图1至图5、实测尺寸、部件清单和步骤照齐全后执行全部六步。

将填写后的表格连同下面这句一次发送到当前会话：

> 后续六步中的商品身份、外观、图片职责、规格、准确文字、组件和禁止项，只以这份《商品事实单》为准；步骤正文里的示例 SKU 只示范构图与任务，不得覆盖事实单或补造空缺。

复制任一步前，确保这份事实单仍在当前会话中。

## 1. 白底搜索主图
来源卡：[EC01](../../prompts/ecommerce/EC01.md)；输入图1至图3。
```text
制作1:1白底商品主图。浅橡木色床头柜以正面略带右侧面的三分之四角度居中，占画面高度75%，柜脚、台面和侧板完整留边，底部保留自然接触阴影。图1至图3共同限定单抽屉、开放层、黑色圆形拉手、背板和真实比例，不增加第二个抽屉、隔板、灯带或摆件。纯白无地平线背景，大面积柔光保留木纹和边缘层次。只输出一张图，不加文字。
```
验收：层数、拉手、柜脚和比例一致；无摆件。返工：`只恢复开放层和单抽屉的真实结构，其他外观、机位与白底不变。`

## 2. 卧室空间融入
来源卡：[EC16](../../prompts/ecommerce/EC16.md)；输入图1、图2、图5和实测尺寸。
```text
保持图5卧室的机位、床、墙面、地板和光向，只把图1床头柜放到床的右侧空位。按实测长宽高及床沿高度处理尺度，柜脚落地，遮挡和投影符合现场。商品保持浅橡木色、单抽屉、开放层和黑色圆形拉手；不要移动原家具，不增加台灯、书、植物或第二个柜子。画面为4:5真实室内摄影，只输出一张图。
```
验收：尺度有数据依据；不穿墙、不悬浮；房间布局未变。返工：`只修正床头柜相对床沿的高度和落地阴影，卧室与商品结构保持不变。`

## 3. 木纹五金微距
来源卡：[EC04](../../prompts/ecommerce/EC04.md)；输入图4。
```text
以图4为唯一细节依据，制作1:1微距商品摄影。焦点落在浅橡木纹、抽屉边缘接缝和黑色圆形拉手的连接处，周边渐进虚化。用柔和掠射光表现真实纹理、涂层和金属哑光，不夸大木纹深度，不改成实木、金色五金或无缝结构。不要出现尺寸字、认证或装饰。只输出一张图。
```
验收：材质没有升级；接缝和拉手安装方式一致。返工：`只把拉手表面恢复为图4的黑色哑光，保留木纹、接缝和裁切。`

## 4. 尺寸规格图
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入图1、图2及实测值。
```text
制作4:5规格说明图。上方放床头柜三分之四视图，用细引线分别连接实际宽、深、高的对应边界；数值和单位逐字使用提供的实测资料，不从照片估算。下方只列“单抽屉”“开放层”“黑色圆形拉手”三项已确认结构。白底、深灰字、浅橡木色点缀，尺寸数字清楚，不遮商品。不要增加承重、材质等级或环保认证。只输出一张图。
```
验收：三条尺寸线连接正确边界；单位一致。返工：`只修正深度引线及其数值，使其连接前后边界；其他尺寸和版式不变。`

## 5. 三卖点详情模块
来源卡：[EC11](../../prompts/ecommerce/EC11.md)；输入商品图和已确认卖点。
```text
制作4:5详情页模块。上方55%展示床头柜，下方三块依次排版：标题“床边收纳”，说明“抽屉与开放层分区放置”；标题“圆角台面”，说明“以实物边缘结构为准”；标题“离地柜脚”，说明“底部空间按实拍展示”。使用米白、浅木色和深灰，图标简洁。只使用以上文字，不添加承重、静音、环保或耐磨结论。只输出一张图。
```
验收：三卖点均可由参考确认；手机端可读。返工：`只删除未经资料证明的承重数字，商品与其余两块文字不变。`

## 6. 安装步骤图
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入真实部件清单和三张步骤照。
```text
制作4:5安装步骤图。按真实步骤照从左到右、从上到下排列三步，每步一幅小图和一条已确认说明；部件名称、数量和工具均以清单为准。保持螺丝孔位、板件方向和床头柜结构，不补造步骤，不把同一部件重复出现为赠品。白底、深灰字、蓝色编号。只输出一张图。
```
验收：步骤、方向、部件数量对应资料。返工：`只修正第2步板件方向，按步骤照恢复孔位朝向；其余步骤不变。`
