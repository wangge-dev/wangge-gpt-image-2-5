# 家居：一件商品连续制作六类素材

[电商专区](../README.md) · [通用组合任务单](../product-kit.md)

先在同一会话提交一次下面的《商品事实单》，再执行六步。六步共同引用该事实单；换会话时须重新提交。

## 一次填写：商品事实单

| 字段 | 填写内容 |
| --- | --- |
| 商品身份 | 品类、商品名、SKU；示例：浅橡木色双层床头柜 |
| 外观不可变项 | 层数、抽屉、开放层、拉手、柜脚、颜色、木纹和比例 |
| 已提供图片及职责 | 图1正面；图2侧面；图3背面；图4五金木纹；图5目标空间；另列安装步骤照 |
| 真实规格 | 实测长宽高、部件名称和数量 |
| 准确文字 | 尺寸、结构名与已确认卖点；逐字填写 |
| 允许出现的配件/组件 | 只列真实五金、安装工具或场景保留物 |
| 禁止推测项 | 未提供的背面、内部结构、材质等级、承重、环保认证和安装步骤 |

示例 SKU 只演示填写方式。正文示例与事实单冲突时，以事实单为唯一商品事实来源。

## 选择执行路径

- 单图最小路径：只有图1时先复制下方“只有图1时直接复制”，不要直接复制第1步的多图正文；可有限执行第5步，但卖点只能来自正面可见结构。跳过第2步（缺空间与尺寸）、第3步（缺近照）、第4步（缺实测值）、第6步（缺步骤照和部件清单）。
- 资料齐全路径：图1至图5、实测尺寸、部件清单和步骤照齐全后执行全部六步。

将填写后的表格连同下面这句一次发送到当前会话：

> 后续六步中的商品身份、外观、图片职责、规格、准确文字、组件和禁止项，只以这份《商品事实单》为准；步骤正文里的示例 SKU 只示范构图与任务，不得覆盖事实单或补造空缺。

复制任一步前，确保这份事实单仍在当前会话中。

### 只有图1时直接复制

```text
只使用图1和当前会话中的《商品事实单》制作一张1:1电商白底主图。按图1正面可见角度展示完整商品，占画面高度约75%，四周完整留边，底部保留自然接触阴影；纯白无地平线背景，使用大面积柔光。完整保留图1可见的层级、开口、门板或抽屉、拉手、支脚、颜色、纹理和比例；图1看不到的侧面、背面、内部结构、五金、材质等级、承重和配件保持未知，不补画、不推测。不要新增摆件、灯带、文字或第二件商品。只输出一张图。
```

## 1. 白底搜索主图
来源卡：[EC01](../../prompts/ecommerce/EC01.md)；输入图1至图3。
```text
制作1:1白底商品主图。《商品事实单》的商品按图1至图3共同证实的角度居中，占画面高度75%，主体和事实单列出的固定组件完整留边，底部保留自然接触阴影。层级、开口、门板或抽屉、拉手、支脚、颜色、纹理、背面和比例只按对应参考，不新增隔板、灯带、摆件或第二件商品。纯白无地平线背景，大面积柔光保留真实纹理和边缘层次。只输出一张图，不加文字。
```
验收：层数、拉手、柜脚和比例一致；无摆件。返工：`只恢复开放层和单抽屉的真实结构，其他外观、机位与白底不变。`

## 2. 卧室空间融入
来源卡：[EC16](../../prompts/ecommerce/EC16.md)；输入图1、图2、图5和实测尺寸。
```text
保持图5空间的机位、家具、墙面、地板和光向，只把图1中的《商品事实单》商品放到事实单指定空位。按实测长宽高及现场参照处理尺度，商品真实落地，遮挡和投影符合现场。商品外观和组件只按图1、图2及事实单；不要移动原家具，不增加事实单未列出的摆件、灯具、植物或第二件商品。画面为4:5真实室内摄影，只输出一张图。
```
验收：尺度有数据依据；不穿墙、不悬浮；空间布局未变。返工：`只修正商品相对现场参照的高度和落地阴影，空间与商品结构保持不变。`

## 3. 木纹五金微距
来源卡：[EC04](../../prompts/ecommerce/EC04.md)；输入图4。
```text
以图4为唯一细节依据，制作1:1微距商品摄影。焦点只落在《商品事实单》指定的真实纹理、接缝与五金连接处，周边渐进虚化。用柔和掠射光表现图4可见的表面纹理、涂层和五金光泽，不夸大纹理深度，不升级材质，不改颜色或抹掉真实接缝。不要出现尺寸字、认证或装饰。只输出一张图。
```
验收：材质没有升级；接缝和拉手安装方式一致。返工：`只把拉手表面恢复为图4的黑色哑光，保留木纹、接缝和裁切。`

## 4. 尺寸规格图
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入图1、图2及实测值。
```text
制作4:5规格说明图。上方放《商品事实单》商品的已证实三分之四视图，用细引线分别连接实际宽、深、高的对应边界；数值和单位逐字使用实测资料，不从照片估算。下方只列事实单“准确文字”中三项已确认结构；不足三项则减少信息块，不自行补齐。白底、深灰字，点缀色从商品提取，尺寸数字清楚且不遮商品。不要增加承重、材质等级或环保认证。只输出一张图。
```
验收：三条尺寸线连接正确边界；单位一致。返工：`只修正深度引线及其数值，使其连接前后边界；其他尺寸和版式不变。`

## 5. 三卖点详情模块
来源卡：[EC11](../../prompts/ecommerce/EC11.md)；输入商品图和已确认卖点。
```text
制作4:5详情页模块。上方55%展示《商品事实单》商品，下方按事实单“准确文字”排版最多三组已确认标题和说明；不足三组则减少信息块，不自行补齐。每组图标只能指向参考中可见且已确认的结构，配色从商品与目标页面提取。不得添加承重、静音、环保、耐磨或其他未确认结论。只输出一张图。
```
验收：三卖点均可由参考确认；手机端可读。返工：`只删除未经资料证明的承重数字，商品与其余两块文字不变。`

## 6. 安装步骤图
来源卡：[EC13](../../prompts/ecommerce/EC13.md)；输入真实部件清单和三张步骤照。
```text
制作4:5安装步骤图。按真实步骤照从左到右、从上到下排列三步，每步一幅小图和一条已确认说明；部件名称、数量和工具均以《商品事实单》及清单为准。保持照片中的孔位、板件方向和商品结构，不补造步骤，不把同一部件重复出现为赠品。白底、深灰字、蓝色编号。只输出一张图。
```
验收：步骤、方向、部件数量对应资料。返工：`只修正第2步板件方向，按步骤照恢复孔位朝向；其余步骤不变。`
