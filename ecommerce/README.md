## 一条电商实测应该留下什么

商品原图和可确认的事实 → 任务目标 → 首次指令 → 原始输出 → 返工指令与结果 → 可用性判断。

记录商品外形、颜色、材质、Logo、包装文字及不应改变的可见结构。无法从现有图片确认的背面或内部，不通过生图补成“真实细节”。

系列图不要用同一背景的小变化冒充不同用途：主图看清商品、场景图解释使用环境、细节图展示有依据的局部。每张图分别输出、分别评估。

## 结果怎样评价

| 维度 | 记录内容 |
| --- | --- |
| 商品保真 | 哪些可见特征保留，哪些偏差 |
| 表达完成度 | 卖点和视觉层级是否完成任务 |
| 编辑影响 | 请求的改动和额外变化 |
| 文字准确性 | 逐字校对，不只看整体清晰 |
| 使用成本 | 真实尝试次数、耗时、可获得的费用 |
| 上架与经营效果 | 平台审核/实投才记录；没有就写未验证 |

我们先研究素材是否可用；点击率、转化率和平台规则需要各自的证据。
