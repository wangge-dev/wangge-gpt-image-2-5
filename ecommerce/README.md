# 电商提示词专区

[首页](../README.md) · [全部提示词](../prompts/README.md)

58 套场景模板，包含完整变体与后续修改指令。先上传真实商品图，填写商品事实，再复制对应模板。

## 按任务找提示词

### 商品展示

- [EC01 白底与纯色商品主图](../prompts/ecommerce/EC01.md)：让商品轮廓和真实材质在搜索列表中清楚可见。
- [EC02 生活场景商品图](../prompts/ecommerce/EC02.md)：把同一商品放进适合使用的真实生活环境。
- [EC03 俯拍平铺静物](../prompts/ecommerce/EC03.md)：适合套装预热、生活方式配图和品牌社媒。
- [EC04 材质与工艺微距](../prompts/ecommerce/EC04.md)：突出真实材质、膏体或接缝，不凭空制造产品细节。
- [EC08 模特持用与穿戴展示](../prompts/ecommerce/EC08.md)：让模特与商品自然互动，并明确两张参考图的职责。
- [EC14 套装与产品线陈列](../prompts/ecommerce/EC14.md)：明确每个SKU，避免漏件、复制或错误放大。
- [EC16 参考图试穿与场景融入](../prompts/ecommerce/EC16.md)：将服装穿到人物身上，或把家居商品放进既有空间。
- [EC18 服装隐形模特](../prompts/ecommerce/EC18.md)：呈现衣服立体形态，同时保留真实剪裁。
- [EC19 多角度与多配色网格](../prompts/ecommerce/EC19.md)：一张图呈现多个有来源的视角或SKU。
- [EC38 多SKU规格对照陈列](../prompts/ecommerce/EC38.md)：将多个真实SKU分别绑定参考图和规格，避免串色、串结构、漏件或重复。

### 营销素材

- [EC05 中文促销海报](../prompts/ecommerce/EC05.md)：商品、活动文案和价格分区，适合活动主视觉。
- [EC06 社媒种草与视频封面](../prompts/ecommerce/EC06.md)：生成社媒内容图片，文案可控。
- [EC07 生活随拍广告风格](../prompts/ecommerce/EC07.md)：模拟随拍审美，用于广告创意和开箱封面。
- [EC12 超现实商品创意广告](../prompts/ecommerce/EC12.md)：保留商品身份，围绕它构建视觉创意。
- [EC15 直播封面与布景概念](../prompts/ecommerce/EC15.md)：设计直播视觉素材，不伪造真实直播截图。
- [EC21 四季与节日系列图](../prompts/ecommerce/EC21.md)：同一商品、统一机位，替换系列布景。
- [EC25 运动商品广告与三联画](../prompts/ecommerce/EC25.md)：用动作、构图和字体表现运动感。
- [EC32 同SKU跨活动视觉系列](../prompts/ecommerce/EC32.md)：同一商品逐张制作不同活动视觉，只改变主题布景与已确认画外文案。

### 商品解释

- [EC09 真实素材前后对比排版](../prompts/ecommerce/EC09.md)：把已有对比照片和数据排成图，不生成虚假的效果证据。
- [EC11 卖点信息图与详情页模块](../prompts/ecommerce/EC11.md)：将真实卖点转成手机上易读的图文模块。
- [EC13 尺寸规格与使用步骤](../prompts/ecommerce/EC13.md)：按真实尺寸和步骤制作说明图。
- [EC17 产品结构爆炸示意](../prompts/ecommerce/EC17.md)：依据部件资料展示结构，缺少资料时只做明确概念图。
- [EC31 中文长详情页单模块系列](../prompts/ecommerce/EC31.md)：把长详情页拆成逐张生成的独立模块，并在多张图之间保持同一商品与品牌系统。
- [EC50 详情页首屏标题商品与利益点三层动线](../prompts/ecommerce/EC50.md)：把详情页首屏固定为标题、商品和单一利益点三层，先建立阅读动线，再补充风格与光影。
- [EC54 数码主机、屏幕截图与配件清单一页对应](../prompts/ecommerce/EC54.md)：把数码商品本体、已校对屏幕内容、真实配件和人工清单放在同一张详情图里，避免把概念样机当成销售套装或凭外观补写参数。
- [EC55 食品包装三证据区：白底、配料语境与成品场景](../prompts/ecommerce/EC55.md)：把同一食品包装依次放入白底识别、真实配料语境和成品食用场景，用一张详情图讲清包装、原料与食用结果的关系。

### 品牌表达

- [EC10 包装与开箱陈列](../prompts/ecommerce/EC10.md)：展示已有包装，或明确制作概念包装方案。
- [EC20 品牌杂志封面与内页](../prompts/ecommerce/EC20.md)：将商品和人物组织成自有品牌编辑视觉。
- [EC22 奢华氛围商品大片](../prompts/ecommerce/EC22.md)：用光、烟雾或花瓣构建氛围，保持标签可见。
- [EC23 设备屏幕展示样机](../prompts/ecommerce/EC23.md)：把已有界面置入设备展示场景。
- [EC24 品牌门店与空间概念](../prompts/ecommerce/EC24.md)：设计门面或陈列空间，区分实际改造与概念。

### 美妆与玻璃包装

- [EC26 玻璃瓶反光与标签可读性](../prompts/ecommerce/EC26.md)：玻璃瓶反光与标签可读性：围绕实际商品素材处理一个明确问题。

### 服装

- [EC27 服装印花跨褶皱保留](../prompts/ecommerce/EC27.md)：服装印花跨褶皱保留：围绕实际商品素材处理一个明确问题。

### 饰品

- [EC28 饰品镶嵌与链节细节](../prompts/ecommerce/EC28.md)：饰品镶嵌与链节细节：围绕实际商品素材处理一个明确问题。
- [EC41 饰品佩戴比例与实测尺寸](../prompts/ecommerce/EC41.md)：将饰品实物、获准人物参考和实测尺寸结合，展示可信佩戴比例。

### 食品

- [EC29 食品份量与装盘数量](../prompts/ecommerce/EC29.md)：食品份量与装盘数量：围绕实际商品素材处理一个明确问题。

### 包装

- [EC30 包装文字局部修正](../prompts/ecommerce/EC30.md)：包装文字局部修正：围绕实际商品素材处理一个明确问题。
- [EC39 中文包装正背面校对图](../prompts/ecommerce/EC39.md)：把包装正背面实拍与已确认文字整理成校对图，不让模型重写整套包装。

### 鞋靴

- [EC33 鞋靴鞋面与鞋底结构卡](../prompts/ecommerce/EC33.md)：把同一双鞋的整体、鞋面、鞋底纹路和准确规格组织成可核对结构卡。

### 宠物用品

- [EC34 宠物用品佩戴与尺寸说明](../prompts/ecommerce/EC34.md)：依据真实宠物与商品尺寸展示佩戴位置，不生成安全性或适配性承诺。

### 汽车用品

- [EC35 汽车用品安装位置说明](../prompts/ecommerce/EC35.md)：把真实汽车内饰、配件结构和安装步骤组合成位置清楚的安装说明图。

### 透明与反光

- [EC36 透明容器与内容物计数主图](../prompts/ecommerce/EC36.md)：保留透明容器的边缘、透射和真实内容物数量，避免透明材质被改成磨砂或空壳。
- [EC37 镜面金属商品换场景](../prompts/ecommerce/EC37.md)：为镜面金属商品替换环境，同时控制反射内容、边缘和真实表面瑕疵。

### 家装五金

- [EC40 家装五金配件清点与安装](../prompts/ecommerce/EC40.md)：同时展示五金套装数量、安装位置和真实步骤，不补造螺丝、孔位或承重。

### 户外装备

- [EC42 户外装备展开与收纳清点](../prompts/ecommerce/EC42.md)：同时展示户外装备展开形态、收纳体积和真实组件数量。

### 数码配件

- [EC43 数码线材接口与长度说明](../prompts/ecommerce/EC43.md)：清楚展示线材两端接口、线身材质和实测长度，不推测协议与性能。

### 纺织品

- [EC44 纺织品多色与纹理对照](../prompts/ecommerce/EC44.md)：在统一光线下对照多个真实颜色SKU，同时保留织纹、包边和尺寸差异。

### 美妆个护

- [EC45 彩妆多色试色与膏体对照](../prompts/ecommerce/EC45.md)：把真实色号、膏体和获准皮肤试色一一绑定，避免色号串位或虚构妆效。

### 家具家居

- [EC46 家具开合路径与空间尺寸](../prompts/ecommerce/EC46.md)：展示家具关闭、打开与放置状态所需空间，避免门板、抽屉或尺寸关系失真。

### 厨具餐具

- [EC47 厨具套装嵌套与配件归属](../prompts/ecommerce/EC47.md)：同时说明厨具套装的展开数量、嵌套顺序和盖具归属，避免错配与凭空兼容。

### 小家电

- [EC48 小家电面板状态与配件对应](../prompts/ecommerce/EC48.md)：将真实控制面板、指定工作状态和配件清单绑定，避免虚构按钮、程序或功能。

### 商品主图

- [EC49 搜索列表主图主体占比与缩略图可读性](../prompts/ecommerce/EC49.md)：在方形搜索缩略图里锁定单件商品的占比、完整轮廓和视觉中心，避免主体过小或被角标安全区遮挡。

### 局部编辑

- [EC51 单商品换背景与边缘反射冻结](../prompts/ecommerce/EC51.md)：只替换商品周围背景，同时冻结商品轮廓、透明边缘、镜面反射和接触关系，减少换景后的商品漂移。

### 活动营销

- [EC52 活动主视觉商品价格与行动区四层排版](../prompts/ecommerce/EC52.md)：用固定四层信息结构生成活动主视觉，锁定商品、标题、价格和行动区，避免文案重复与视觉抢位。
- [EC58 腕表右侧主视觉与左侧短文案广告](../prompts/ecommerce/EC58.md)：让同一只腕表占据画面右侧，用左侧短标题和事实文案形成清楚的阅读动线，适合投放海报与商品副图。

### 模特展示

- [EC53 商品、模特与氛围三参考图职责绑定](../prompts/ecommerce/EC53.md)：把商品外观、成年模特身份和场景氛围分给三张参考图，生成可用于详情页或社媒的上身商品图，避免把氛围图中的人物和商品带入成片。

### 场景图

- [EC56 配料丰盛构图与包装垂直阅读通道](../prompts/ecommerce/EC56.md)：在食品包装周围铺陈真实配料，同时用中央垂直通道保护商品轮廓和标签阅读，适合主图、副图或社媒封面。

### 系列商品

- [EC57 三口味系列主次陈列与身份隔离](../prompts/ecommerce/EC57.md)：将三款同系列食品排成中心主款与两侧辅款，既让主款先被看见，又保持每款口味、包装和数量可辨。
